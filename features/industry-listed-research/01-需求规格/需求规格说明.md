# 行业研究·上市公司深化（industry-listed-research）需求规格说明

> 创建：2026-09-17 | 里程碑：MS-09（二期） | 模块：M10 行业研究中心（F03/F04/F05）
> 页面：`/industry`（扩展）+ `/industry/[industryCode]`（新增） | 前置：MS-05 ✅；F04 的快照历史依赖以 5 年自算回填解决（见澄清 #1）

## 一、背景与目标

MS-05 已交付行业估值对比（F01）与热力图（F02），但行业研究止步于**估值横截面**——不知道行业内有哪些公司与龙头、当前估值处于历史什么位置、行业基本面在改善还是恶化。MS-08 收尾后再平衡与筛选闭环完成，二期主线转入行业研究深化。本特性补齐三块：

1. **上市公司排名**（M10-F03）：行业下钻页，成员按市值/营收/ROE 排名，回答「这个行业有哪些玩家、谁是龙头」；
2. **历史分位对比**（M10-F04）：行业 PE/PB 的近 5 年分位，回答「这个行业比历史上贵还是便宜」；
3. **景气度提示**（M10-F05）：基于 ROE 趋势 + 营收增速的行业/个股两级景气标注，回答「行业基本面在变好还是变坏」。

**交付物**：

1. collector：`stock_financial` 加营收列（V15）+ `income` 采集并入；`stock_valuation_daily` 一次性回填 5 年；新增行业估值历史重算回填任务；
2. 后端：新建 `domain/industry`（+ application/web/infrastructure 读侧），聚合 board 端点 + 行业成员端点，`PackageConventionsTest` 白名单登记；
3. 前端：`/industry` board 加分位/景气列并切换聚合端点；新路由 `/industry/[industryCode]` 下钻页。

MS-10（行业研究·未上市与竞争格局）的天眼查部分将直接落在同一域与同一宿主页。

## 三、功能需求

### A. 历史分位对比（M10-F04）

- board 31 行业每行输出 **PE 5y 分位 / PB 5y 分位**（0~100%，高 = 贵）；基准 = `industry_valuation` 该行业近 5 年滚动窗口 pe/pb 序列的经验分布（口径同估值域 `Percentile`，加窗口参数）。
- 窗口参数化（5y/10y），上线仅展示 5y；10y 待回填加深后开放。
- 序列不足 250 个交易日（约 1 年）→ 分位 null → 前端「—」。
- 分位列 tooltip 显式标注回溯口径：「历史按当前申万 2021 分类成分回溯重算」（成分变迁不可考，近似口径显式化）。

### B. 上市公司排名（M10-F03）

- 路由 `/industry/[industryCode]`（申万一级行业代码）；board 行点击进入；页头含行业名 / 成员数 / 行业景气标注。
- 成员表列：**排名 / 代码 / 名称 / 总市值 / 营收（最新报告期累计，亿元格式化 + 报告期标注）/ ROE / PE / PB / 股息率 / 景气**；排序切换（市值/营收/ROE），默认市值降序。
- 取数与筛选域 `BASE_SQL` 同构：`stock_valuation_daily` 最新交易日 ⋈ `stock_financial` 最新报告期（`DISTINCT ON`）⋈ 申万映射，加 `revenue` 列；报告期混合（次新股/延迟披露）按每股最新可得，列表标注。
- 全量成员返回（最大行业 500+ 只），`limit` 上限 1000 兜底；前端表格分页。
- 端点 `GET /api/industry/{industryCode}/stocks`，公开只读 + 5min 条件缓存（同筛选域模式）。

### C. 景气度提示（M10-F05）

- **个股输入**：ROEΔ = 近 4 季 ROE 均值 − 前 4 季均值（pp）；营收增速 = 最新报告期 `revenue_yoy`（%）。
- **规则**（显式阈值常量集中定义，改口径走发版——同 MS-08 5pp 先例）：
  - ↑ 上行：ROEΔ ≥ +1pp **且** 营收增速 ≥ +10%
  - ↓ 下行：ROEΔ ≤ −1pp **或** 营收增速 ≤ −10%（下行判定更敏感，「且/或」不对称为有意设计）
  - → 平稳：其余
- **行业级**：成员 ROEΔ、营收增速各取**中位数**后套同一规则（中位数抗大市值偏置）。
- ROE 不足 8 季 → 不标注（「—」）。
- **展示**：board 加「景气」列（↑/→/↓ + 配色）；下钻页个股行同款标注。
- **架构**：读侧即时计算（SQL 聚合 `stock_financial` 约 6.5 万行，毫秒级）+ 5min 缓存；不落库、不调度。

### D. 数据底座（collector）

- **营收采集**：V15 给 `stock_financial` 加 `revenue NUMERIC(20,4)`（元，报告期累计）；`StockFinancialSource` 逐股循环追加调用 `income` 取 `revenue`，与既有指标**同行一次 upsert**；窗口同近 12 季。
- **一次性回填**：`make collect-backfill TASK=stock_valuation_daily --start=<5 年前> --end=今天`（既有能力，~1200 交易日 × 全市场 ≈ 6-7M 行；按日拉全市场的单次调用已生产验证，预计 15-20 分钟）。
- **行业估值历史重算回填任务**（新增）：遍历库内 `stock_valuation_daily` 历史，`IndustryValuationCalc` 同公式重算每日行业 pe/pb，幂等 upsert `industry_valuation`（`UNIQUE(trading_day, industry_code)`）；纯本地重算，无外部调用。
- 既有每日快照任务（`industry_valuation.yaml`）增量续写不变。

## 四、非功能需求（NFR）

| 类别 | 要求 |
|------|------|
| 计算正确性 | 分位/景气为纯函数、已知答案单测（阈值边界：±1pp/±10%/250 日/8 季、且/或不对称）；行业成员排名抽验 |
| 一致性 | 下钻页与筛选器同底座口径（同构 BASE_SQL）；board 估值四指标与 `/api/valuation/industries` 同源同值 |
| 性能 | board 单请求含四指标 + 分位 + 景气（SQL 聚合毫秒级 + 缓存）；下钻全量 ≤1000 行 |
| 安全 | `/api/industry/*` 公开只读，无用户态（`PublicEndpointPaths` 前缀登记） |
| 覆盖率 | 后端 JaCoCo / 前端 V8 / collector pytest ≥80%，`make test` 通过 |
| e2e | board 分位/景气列渲染、下钻排序切换、数据不足「—」空态、board 行点击进入下钻 |
| 回填可验证 | 重算任务幂等可重跑；回填后分位数与独立计算对照抽验一致 |

## 五、验收标准（沿用产品落地计划 MS-09 + F04 补充）

1. **行业内市值/营收/ROE 排名正确**（抽验，含报告期混合口径）；
2. **景气标注规则（ROE 趋势 + 营收增速）可解释**（阈值显式 + 边界单测）；
3. **5 年回填落地**：`industry_valuation` 历史序列 ≥5 年，行业分位数与独立计算对照抽验一致；
4. `make test`（≥80%）+ Playwright e2e 全绿；`make smoke` 无新增段（回填用既有 daily_basic 源，口径同 MS-07/08）。

## 六、明确不做（YAGNI）

- **10y 分位窗口的前端展示**（数据未回填，仅参数化预留；回填加深后开放）；
- **下钻页个股跳转行情台**（M10-F10 企业详情卡片属 MS-10）；
- **MS-10 全部内容**（行业全景/未上市画像/融资动态/竞争格局/天眼查接入——二期独立里程碑，付费源需先拍板）；
- **景气历史序列/趋势图**（仅标注当前档位，不画时间序列）；
- **行业成员 CSV 导出**（M09 筛选导出已覆盖跨行业需求，不重复建）；
- **AI 行业分析工具**（M05-F12 属 MS-12；MS-09 交付后其 M10 数据依赖即就绪）；
- **热力图加分位维度**（F02 保持现状）；
- **全 A 市场分位回填**（MS-02 风险项的另一侧，`valuation_snapshot` 自然积累，不在本特性范围）。

## 七、依赖与风险

| 事项 | 影响 | 对策 |
|------|------|------|
| tushare `income` 接口积分档位 | 逐股拉取需与 `fina_indicator` 同级配额 | 交付前确认配额；不满足时 F03 营收列降级「—」并同步修正模块文档口径 |
| 回填耗时与配额 | ~1200 次按日调用（既有 daily_basic 源） | 单日全市场调用已生产验证 3 周，仅量变；交付时实跑并记录耗时与行数 |
| 申万成分回溯近似 | 历史行业 pe/pb 与「当时成分」有偏差 | 页面 tooltip 显式标注回溯口径（澄清 #6 关联） |
| 次新股/延迟披露多期不足 | 景气不标注、营收期混合 | 景气「—」；营收列标注报告期 |
| 大行业成员 500+ 只 | 传输与渲染压力 | limit 1000 兜底 + 前端分页 |
| `stock_financial` 任务时长翻倍（~30→60 分钟/轮） | 与 15:45 `industry_valuation` 任务的读侧并发窗口变长 | roe 语义为「最新可得报告期」，部分更新期间行业快照可能混用新旧报告期（既有现象，量级不变，次日自愈）；必要时错峰调度 |
| `industry_valuation` 现存仅 ~3 周历史 | 回填前 F04 无可用分位 | 交付顺序：先回填后上线（实施计划 P 阶段排序约束） |

## 附：术语

- **5y 分位**：当前值在近 5 年滚动窗口序列经验分布中严格小于它的占比 ×100（口径同估值域 `Percentile`，加窗口）；
- **ROEΔ**：近 4 季 ROE 均值 − 前 4 季均值（个百分点），景气度的趋势输入；
- **报告期累计营收**：`income.revenue`，报告期年初至今累计值（元），非 TTM、非单季；
- **回溯成分口径**：历史行业估值按**当前**申万 2021 分类成分重算，成分变迁不可考的显式近似；
- **景气三档**：上行（↑）/平稳（→）/下行（↓），规则见 §三.C；
- **board**：`/industry` 行业榜单页（F01 表格 + F02 热力图），本特性加分位与景气列。
