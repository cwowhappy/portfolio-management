# AI 投研工具二期（ai-research-tools-phase2）需求规格说明

> 创建：2026-09-22 | 里程碑：MS-12（二期） | 模块：M05 AI 投研能力（F08/F09/F10/F11/F12）
> 页面：无新页面（对话内核扩展） | 前置：MS-03/04/05/09 对应数据就绪（已全部 ✅）

## 一、背景与目标

一期 7 个内置工具（行情/K线/财务/新闻/大盘/估值）只覆盖**市场公开数据**，AI 无法参与投资闭环的私有数据侧。二期补 5 个工具，让对话可消费筛选（M09）、持仓（M08）、风险测评与配置（M07）、财报底座、行业研究（M10）五块数据：

1. **F08 筛选器调用工具**：自然语言执行 M09 多条件筛选（「ROE 连续 5 年大于 15%、PE 小于 20 的股票」口径内的单期多条件组合）；
2. **F09 持仓分析工具**：读取 M08 用户持仓，分析结构、集中度、行业分布；
3. **F10 资产配置建议工具**：基于 M07 风险测评结果推荐配置模板，结合当前持仓给出偏离提示；
4. **F11 财报解读工具**：杜邦三因子拆解 + 多季趋势分析 + 结构化解读；
5. **F12 行业分析工具**：行业估值排名 + 头部企业。

**交付物**：

1. 后端：`InvestTools` 追加 3 个无用户态工具（F08/F11/F12）+ 新建 `UserInvestTools` 承载 2 个用户态工具（F09/F10，per-会话构造注入 userId）+ `stock_financial` 库表读侧端口与杜邦纯函数；
2. 提示词：`InvestSystemPrompt` 工具使用规范补 5 工具映射与私有数据口径；
3. 前端：`ToolCallCard` 工具标签 +5、图表卡复用既有 ChartSpecs 双通道；
4. 冒烟：`make smoke` AI 对话段覆盖 5 工具链路。

**验收标准**（产品落地计划 MS-12）：5 个工具纳入提示词与工具进度卡片；遵守回答规范（数据真实、禁止虚构）；`make smoke` 覆盖新工具链路。

## 三、功能需求

### A. 筛选器调用工具（M05-F08）

- 自然语言 → 多条件组合筛选，参数面即 `ScreeningCriteria` 既有 15 维可空条件（PE/PB/股息率/ROE/ROA/毛利率/资产负债率/流动比率/营收同比/净利同比/市值/换手率 + 行业码 + 指数成分白名单 000300/000905）+ 排序字段/方向 + limit；
- 至少一个条件才执行（无条件返回错误提示 JSON，不调服务）；
- 输出：命中结果表格图表卡（emit）+ LLM 摘要（命中数与头部标的）；空结果如实返回。

### B. 持仓分析工具（M05-F09）

- 无参数（userId 由装配注入，仅本人会话可访问）；
- 一次取齐 M08 五个读侧数据：总览（市值/成本/盈亏）、资产配置、行业分布、集中度、持仓列表；
- 输出：资产配置饼图卡 + LLM 摘要（结构/集中度/盈亏要点，含风险提示）；空持仓返回「暂无持仓」摘要（不 emit 空图）。

### C. 资产配置建议工具（M05-F10）

- 无参数；消费 M07 `latestAssessment`（测评结果，含 `RiskProfile` 推荐权重）+ M08 `allocation`（当前资产分布，与推荐权重同属 AssetClass 键空间可直接对照）+ `deviation`（当前偏离，有活跃方案时）；
- 无测评记录 → 返回引导提示（先完成风险测评），不虚构建议；
- 建议口径：**测评推荐权重 + 当前分布对照为事实底座，建议文字由 LLM 基于结构化数据生成**（数据真实原则——推荐权重来自 M07 问卷评分模型，非 LLM 编造）；
- 输出：推荐配置 vs 当前资产分布对照表格卡 + LLM 摘要。

### D. 财报解读工具（M05-F11）

- 参数：股票代码（6 位，与 `get_financials` 同入口先例——名称先经 `search_stock` 换码）；
- 数据：`stock_financial` 库表 12 季序列（roe/roa/毛利率/资产负债率/流动比率/营收/双同比）+ 东财 live 财务（净利润/营收→净利率）；
- 杜邦三因子按 §二#3 口径推导，各自标注报告期（两源各取最新可得期）；
- 输出：12 季趋势表格卡 + LLM 摘要（杜邦拆解数字、趋势结论、结构化解读要点）；库表无该股数据 → 降级提示（新股/未采集）。

### E. 行业分析工具（M05-F12）

- 参数：行业码可空——**双形态**：无参返回全行业估值排名板面（表格卡 + 摘要）；带申万一级码返回该行业估值位 + 头部企业表（按市值/估值排序取头部，复用 `IndustryApplicationService.stocks` 排序能力）；
- LLM 问「XX 行业怎么样」时先无参取板面对齐行业码，再带参下钻（工具描述写明该用法）。

## 四、非功能需求（NFR）

| 类别 | 要求 |
|------|------|
| 数据隔离 | F09/F10 仅消费 `userId` 归属数据（服务层既有 `findByIdAndUserId` 三重保障）；userId 不进 LLM 上下文 |
| 回答规范 | 沿用 M05 模块 §四横切规范：结论先行、数据真实（工具错误如实说明）、事实与观点分离 |
| 错误兜底 | 沿用 `run()/runBlock()` 模式：`MarketDataException` → 数据源不可用提示；其余异常 → 通用错误 JSON；失败不 emit |
| 图表契约 | 全部走 ChartSpecs 双通道（SSE emit 全量 + LLM 摘要），空数据 emit 前守卫 |
| 覆盖率 | 后端 JaCoCo / 前端 V8 ≥80%，`make test` 三端全绿（无 collector 变更） |
| e2e | chat 工具链路 1~2 条（真实 LLM key 门控范式，同 chat.spec 既有做法） |

## 五、验收标准（沿用产品落地计划 MS-12）

1. **5 个工具纳入提示词与工具进度卡片**——`InvestSystemPrompt` 规范条目 + `ToolCallCard` 标签 + 工具卡渲染；
2. **遵守回答规范**（数据真实、禁止虚构）——工具错误路径与空数据路径有测试钉住；
3. **`make smoke` 覆盖新工具链路**——AI 对话段扩 5 工具提问（DEEPSEEK_API_KEY 门控内）；
4. `make test` 三端全绿 + Playwright e2e 全绿。

## 六、明确不做（YAGNI）

- **F12 融资动态**（无数据源，§二#5 留痕；待数据源引入再补）；
- **collector 扩展**（资产负债表绝对值采集、融资数据采集——杜邦用推导口径已可满足）；
- **新数据库表 / 新 DDD 域**（工具层 + 既有域读侧扩展，无持久化新实体）；
- **BDD 新增旅程**（`FixedReplyModel` 无工具调用能力，工具行为由单测/集成/e2e 覆盖——留痕）；
- **F10 自动调仓执行 / 交易动作**（建议仅到文字与结构化数据，不触发 M08 写路径）；
- **筛选条件跨期表达式**（「连续 5 年 ROE>15%」的时序筛选属 M09 后续进化，本期单期多条件）。

## 七、依赖与风险

| 事项 | 影响 | 对策 |
|------|------|------|
| F11 两源期不一致（东财 live vs 库表报告期） | 杜邦因子混合期口径需明确 | 各取最新可得期并在输出标注报告期；库表无数据时降级提示 |
| 库表数据冷启动（个股未采集/未回填） | F11/F12 部分标的空结果 | 空数据如实返回 + 降级文案（「数据积累中」先例）；smoke 断言容忍空但链路通 |
| 真实 LLM 的 e2e/smoke 依赖 DEEPSEEK_API_KEY | CI 缺 key 时链路不可验 | 沿用既有门控（缺 key skip/smoke 跳过段），单测+集成不依赖 key 钉住工具契约 |
| 用户持仓数据进 LLM 上下文 | 隐私口径 | 对话本身为登录态私有会话（conversation 域既有边界）；提示词明示私有数据不外传 MCP 工具 |
| smoke 每工具一段增加 LLM 调用成本 | 冒烟时长与 token | 5 问合并为 1~2 段会话（同 threadId 连续问），断言工具调用事件而非逐段独立 |
