## 一、背景与目标

一期投研信息获取闭环、估值数据底座（MS-01）、市场估值仪表盘（MS-02）、持仓组合管理（MS-03）均已交付。MVP 阶段目标「判断市场、配置资产」，**资产配置基础**回答「我的钱应该怎么分配」，并与已交付的持仓组合管理（MS-03）联动，实现「目标配置 vs 当前持仓实际」的偏离度对比，形成「设定目标 → 对照现状 → 调整持仓」的配置闭环入口。

**交付物**：

1. 新增后端 `domain/allocation` 域 + `/api/allocation/**` 接口（需登录）；
2. 新增前端 `/allocation` 页面：方案列表、模板套用、自定义权重编辑、偏离度对比图；
3. 与 M08 持仓联动：目标配置与当前持仓实际配置的偏离度计算与展示；
4. （F03，2026-09-15 补充）风险测评问卷：8 题答卷 → 五档风险偏好 → 推荐配置权重 → 一键创建 `source=ASSESSMENT` 方案，最新结果落库供后续 MS-12（M05-F10 AI 配置建议工具）消费。

## 三、功能需求

### A. 配置模板库（M07-F01）

**FR-A1 模板一览（F01）**

- 内置 4 个经典模板，各含名称 + 资产类别目标权重（单位：%）：

| 模板 | 股票 | 债券 | 黄金 | 现金 | REITs |
|---|---:|---:|---:|---:|---:|
| 60/40 股债平衡 | 60 | 40 | 0 | 0 | 0 |
| 永久组合 | 25 | 25 | 25 | 25 | 0 |
| 全天候 | 30 | 55 | 15 | 0 | 0 |
| 巴菲特 90/10 | 90 | 0 | 0 | 10 | 0 |

**FR-A2 模板套用（F01）**

- 用户选择一个模板 → 一键创建方案（`source=TEMPLATE`，权重预填模板值，默认名称为模板名）。
- 套用后权重可再编辑保存（模板仅作起点；编辑不改变 `source` 来源标记）。

### B. 自定义配置方案（M07-F02）

**FR-B1 方案创建与编辑（F02）**

- 用户自定义资产类别 + 目标权重（类别来自固定 5 大类枚举），支持创建 / 改名 / 改权重 / 删除方案。
- 权重约束：非负、总和 = 100%（校验不过拒绝保存并提示）。

**FR-B2 生效方案（多方案 + 生效标记）**

- 一个用户可保存多个方案，其中至多一个「生效」。
- 激活某方案自动取消其他方案的生效标记；偏离度计算以生效方案为准。

### C. 偏离度对比（与 M08 持仓联动）

**FR-C1 偏离度计算**

- 读取生效方案的目标权重，与当前持仓实际配置聚合对比，逐资产类别计算偏离（实际占比 − 目标占比）。
- 持仓侧映射：A股 + ETF → 股票；账户现金 → 现金；债券 / 黄金 / REITs 持仓侧恒为 0。
- 无生效方案时，偏离度接口返回空（前端提示「无生效方案」）。

**FR-C2 展示**

- `/allocation` 页面展示：生效方案目标权重、当前持仓实际权重、各类别偏离度（目标 vs 实际对比图）。

### D. 风险测评问卷（M07-F03，2026-09-15 补充）

**FR-D1 题库与评分口径**

- 内置 8 题单选问卷，覆盖三类维度：风险承受能力（客观，Q1–Q4）、风险容忍意愿（主观，Q5–Q7）、投资经验（Q8）。每题选项按风险取向计 1–5 分，总分 8–40：

| # | 维度 | 题目 | 选项（分值，由高到低） |
|---|------|------|----------------------|
| Q1 | 承受能力·客观 | 您的年龄段是？ | 30 岁及以下(5) / 31–40 岁(4) / 41–50 岁(3) / 51–60 岁(2) / 60 岁以上(1) |
| Q2 | 承受能力·客观 | 这笔投资计划放置多久？ | 5 年以上(5) / 3–5 年(4) / 1–3 年(3) / 6 个月–1 年(2) / 6 个月以内(1) |
| Q3 | 承受能力·客观 | 投入资金占您可投资金融资产的比例？ | 小部分，大部分另有安排(5) / 约三成(4) / 约一半(3) / 约七成(2) / 几乎全部(1) |
| Q4 | 承受能力·客观 | 您的收入状况更接近？ | 收入稳定且持续增长(5) / 收入稳定(4) / 略有波动(3) / 波动较大(2) / 无固定收入(1) |
| Q5 | 容忍意愿·主观 | 组合单月下跌多少您会明显不安？ | 超过 30% 也可接受(5) / 20%–30%(4) / 10%–20%(3) / 5%–10%(2) / 5% 以内(1) |
| Q6 | 容忍意愿·主观 | 组合亏损 10% 时，您会？ | 逢低加仓摊低成本(5) / 继续持有等待回升(4) / 卖出部分降低仓位(3) / 卖出大部分(2) / 全部清仓并远离市场(1) |
| Q7 | 容忍意愿·主观 | 收益与波动，您更看重？ | 追求长期高收益，可接受大波动(5) / 偏向较高收益，容忍一定波动(4) / 收益与波动兼顾(3) / 偏向稳健，波动小一些(2) / 保本优先(1) |
| Q8 | 经验 | 您参与股票/基金等权益投资的年限？ | 10 年以上(5) / 5–10 年(4) / 3–5 年(3) / 1–3 年(2) / 1 年以内(1) |

- **分档切点**（覆盖 8–40 无空洞无重叠）：8–15 保守 / 16–22 稳健 / 23–29 平衡 / 30–35 成长 / 36–40 进取。

**FR-D2 五档推荐权重**

- 五档风险偏好（`RiskProfile`）各绑定一套推荐配置（%，各列和 = 100）：

| 档位 | 枚举 | 股票 | 债券 | 黄金 | 现金 | REITs |
|---|---|---:|---:|---:|---:|---:|
| 保守 | CONSERVATIVE | 20 | 60 | 10 | 10 | 0 |
| 稳健 | STABLE | 35 | 45 | 10 | 10 | 0 |
| 平衡 | BALANCED | 50 | 30 | 10 | 10 | 0 |
| 成长 | GROWTH | 65 | 20 | 5 | 5 | 5 |
| 进取 | AGGRESSIVE | 80 | 5 | 5 | 5 | 5 |

- 债券 / 黄金 / REITs 仅作目标配置类别（同决策 5 口径，持仓侧恒为 0），不新增持仓录入。

**FR-D3 测评提交与结果落库**

- `POST /api/allocation/assessment` 提交答卷（题号 + 选项标识），后端校验齐全性 / 选项合法性后评分，**upsert 最新结果**（`user_id` 唯一，重测覆盖）；`GET /api/allocation/assessment` 返回最新结果（无则空）。
- 落库内容：总分、档位、答卷明细（JSONB）、测评时间。题库与评分口径仅存于后端代码（单一事实源），前端从 `GET /api/allocation/assessment/questionnaire` 拉取渲染。

**FR-D4 按推荐创建方案**

- 测评结果页展示档位徽章 + 总分 + 推荐权重表，提供「按推荐创建方案」入口：预填推荐权重、`source=ASSESSMENT`，复用现有创建/编辑/激活链路；创建后权重可再编辑，source 保留溯源（同 FR-A2 模板套用语义）。
- `PlanSource` 枚举扩 `ASSESSMENT`（V6 `source VARCHAR(16)` 无 CHECK 约束，存量数据兼容）。

**FR-D5 测评卡展示**

- `/allocation` 页顶部新增测评卡：无结果时显示「开始测评」；有结果时显示当前档位、总分、测评时间与「重新测评」入口。问卷为页内展开区块（单页 8 题全列，未答完禁提交）。

## 四、非功能需求（NFR）

| 类别 | 要求 |
|---|---|
| 数据一致性 | 权重之和 = 100% 且非负；偏离度与 M08 持仓聚合对账一致 |
| 安全 | `/allocation` 需登录；后端按登录用户隔离，非本人方案返回 404 不泄露存在性 |
| 可解释性 | 资产类别映射口径（权益→股票、现金→现金、其余未持有记 0）在页面可查看 |
| 性能 | 偏离度复用 M08 持仓聚合（一次批量现价查询），不逐持仓串行调用行情 |
| 评分口径一致性（F03） | 题库 / 分值 / 切点 / 推荐权重以后端代码为单一事实源，前端不内置副本；评分函数为纯函数，已知答案可测 |
| 用户隔离（F03） | 测评结果按登录用户隔离（`user_id` 唯一），接口行为与现有 `/allocation` 一致 |

## 五、验收标准

- 模板一键套用生成方案，权重与模板一致；
- 自定义方案创建 / 编辑 / 删除、生效标记唯一性正确；
- 偏离度与 M08 持仓对账正确（股票 / 现金映射、未持有类别记 0）；
- `/allocation` 未登录跳转登录；非本人方案不可见；
- （F03）评分已知答案校验通过：全 1 选项 → 8 分保守；全 5 选项 → 40 分进取；切点边界（15/16、22/23、29/30、35/36）落档正确；
- （F03）答卷不合法（缺题 / 选项越界 / 重复题）被拒绝并返回明确错误；
- （F03）重测覆盖旧结果（user_id 唯一 upsert）；「按推荐创建方案」生成 `source=ASSESSMENT` 方案且权重与推荐一致，可激活参与偏离度计算；
- （F03）e2e 全链路：答题 → 提交出档位 → 按推荐创建方案 → 方案列表出现并可激活；
- `make test`（覆盖率 ≥80%）+ `make smoke` + Playwright e2e 通过。

## 六、明确不做（YAGNI）

- F03 测评历史记录留存与档位变化轨迹（仅存最新一条）；
- F03 题库运营化管理（DB 题库 / 管理界面 / 不发版调题）；
- F03 定期重测提醒；
- F04 再平衡提醒 / F05 再平衡金额计算（二期）；
- F06 配置回测（三期）；
- 资产类别地域拆分（A股 / 港股 / 美股）——现价数据源未就绪；
- 债券 / 黄金 / REITs 的持仓录入——数据源未就绪，仅作为目标配置类别；
- AI 资产配置建议工具（M05-F10，属 MS-12）——本期仅落库最新测评结果供其将来消费；
- 多组合（家庭 / 个人等多组合模型）。

## 七、依赖与风险

**依赖**

- M08 持仓组合管理：`PortfolioApplicationService.allocation` 提供当前持仓「权益 / 现金」聚合，是偏离度计算的持仓侧数据源；
- 认证体系（M01）支撑 `/allocation` 私有与用户隔离。

**风险**

| 风险 | 影响 | 应对 |
|---|---|---|
| 持仓侧仅两类的映射契约 | 权益→股票、现金→现金依赖 portfolio 聚合的固定类别标签 | 以契约文档化；偏离度实现内做显式映射，集成测试覆盖 |
| 无持仓 / 无生效方案的空态 | 偏离度无可比数据 | 明确空态（未持有类别记 0、无生效方案返回空并前端提示） |
| 权重精度 | 百分比小数舍入 | 统一 BigDecimal + 精度规范，校验和 = 100%（含容差） |
| 题库 / 切点 / 推荐权重静态硬编码 | 调整需代码发版 | 接受（决策 10，与模板库同口径）；评分与权重单测固化，改动须过已知答案用例 |

## 附：术语

| 术语 | 含义 |
|---|---|
| 资产类别（AssetClass） | 固定 5 大类枚举：股票 / 债券 / 黄金 / 现金 / REITs |
| 方案（AllocationPlan） | 一个用户的一套目标配置（name + 各类权重），多方案并存、至多一个生效 |
| 生效方案 | `active=true` 的方案，偏离度计算的基准 |
| 模板（AllocationTemplate） | 内置经典配置（60/40、永久组合、全天候、90/10） |
| 偏离度（Deviation） | 实际配置占比 − 目标配置占比，逐资产类别计算 |
| 风险测评（RiskAssessment） | 8 题问卷答卷及其评分结果（总分 + 档位），每用户仅存最新一条 |
| 风险档位（RiskProfile） | 五档风险偏好枚举：保守 / 稳健 / 平衡 / 成长 / 进取，各绑定一套推荐配置权重 |
