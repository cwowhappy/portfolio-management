# 风险指标与归因回测（risk-attribution-backtest）需求规格说明

> 创建：2026-09-24 | 里程碑：MS-13（三期首个） | 模块：M12 收益与风险分析（F07~F09）+ M07 资产组合配置（F06）
> 页面：`/analytics`（风险指标 + 归因）、`/allocation`（配置回测）
> 上游：MS-07 净值序列（流水重放 × 收盘融合，零落库）、M07 配置方案、collector 指数/国债数据底座

## 一、背景与目标

核心问题：**我承担了多大风险？收益从哪来——配置的还是选股的？这套配置历史上表现如何？**

三个视角叠加在既有能力之上：风险指标（F07/F08）消费 MS-07 的净值序列；归因（F09）把组合超额收益拆解为行业配置贡献与个股选择贡献；配置回测（M07-F06）对 allocation 方案权重做历史模拟，回答「这套股债金比例过去几年会怎样」。

## 二、需求澄清汇总（2026-09-24 brainstorming 定稿）

| # | 决策点 | 结论 |
|---|--------|------|
| 1 | F09 归因口径 | **行业级 Brinson**：基准=沪深300，以申万一级行业为单元拆配置/选择贡献，交互项并入选择贡献（Brinson-Fachler 变体，数学口径见设计规格 §二）。需新增 31 只申万一级行业指数收盘采集；探测不可得时降级**个股级简化**（仅个股贡献分解，无严格二分，降级须拍板并同步文档） |
| 2 | M07-F06 回测资产面 | **四类全上**：股票=沪深300（已有）、债券=中证全债指数（新增采集）、黄金=黄金 ETF（新增采集）、现金=1Y 国债收益率日复利（已有 `treasury_yield_curve`）；REITs 不支持（模板未用，权重非 0 时明确提示，不静默按 0 处理） |

| 4 | 无风险利率 | **1Y 期国债收益率**（贴近现金机会成本），日频 = 年化 / 365，取自既有 `treasury_yield_curve`（2006 年起），零新采集 |

## 三、功能需求

### A. 最大回撤（M12-F07）

- 全窗口最大回撤幅度（MDD）、峰/谷日期、峰→谷持续交易日数、恢复日（谷后重回峰值首日，未恢复标注「进行中」）。
- 当前回撤（最新值 vs 当前历史峰值）与 MDD 并列展示。
- 计算基础：TWR 净值指数（澄清 #5）。

### B. 夏普比率 / Calmar（M12-F08）

- 夏普（年化）：日超额收益 `r_t − rf_t` 的均值 ÷ 样本标准差（n−1）× √252；`rf_t` = 1Y 国债收益率百分数 ÷100 ÷ 365（如 1.85% → 0.0185/365；缺失日 forward-fill，全缺失退化为 rf=0 并标注口径）。
- Calmar = TWR 年化收益 ÷ \|MDD\|（MDD=0 或序列不足时置空，前端显示「—」）。
- 序列 < 2 个收益点或 std=0 → 置空。

### C. 收益归因分析（M12-F09）

- 对沪深300 的全窗口超额收益拆解：每申万一级行业 ×（配置贡献、选择贡献）+ 现金特殊单元（贡献全记配置项，现金拖累显式可见）。
- 基准行业权重取最近一次 `index_constituent` 成分快照聚合（历史漂移不重建，近似口径文档化）；组合行业权重按前一日收盘持仓市值分组（个股→行业用既有 `shenwan_mapping` 周更映射）。
- 加总校验：Σ(配置+选择) ≈ 组合 TWR − 基准 TWR，超容差在响应带 `residual` 字段显式留痕（日频权重近似的数学损耗，不隐藏）。
- 个股无行业映射（新股/映射缺失）归「未分类」桶并标注，不阻断。

### D. 配置回测（M07-F06，简易）

- 输入：`AllocationPlan` 权重（或内置模板 / 风险测评推荐）+ 回测区间（近 3 年 / 5 年 / 最长可用）+ 再平衡频率（永不 / 季度 / 年度，默认永不）。
- 日频重放四类资产收益序列（见澄清 #2），再平衡日重置目标权重。
- 输出：模拟净值曲线 + 年化收益 / MDD / 夏普（夏普 rf 同 1Y 口径，与 F08 一致）。
- 区间超出资产数据深度 → 截到最长可用并标注；REITs 权重非 0 → 422 明确提示不可回测。
- 「简易」边界（文档化）：不含费用/税/滑点；现金按日复利；不做蒙特卡洛与参数扫描。

## 四、非功能需求（NFR）

1. **计算正确性**：风险指标用已知答案的样本净值序列校验（里程碑验收标准原文）；Brinson 用两行业手工样例对拍（加总=超额）；回测引擎用「永不 vs 年度再平衡」权重漂移对比校验——全部纯函数 JUnit 已知答案单测。
2. **覆盖率**：后端 JaCoCo / 前端 V8 ≥80%，`make test` 通过（全程质量门槛）。
3. **性能**：个人量级（数年日线 × 31 行业指数）请求时计算可接受，零落库零缓存（YAGNI，慢了再评估）。
4. **DDD**：新增代码落 `domain/analytics`、`domain/allocation` 既有子包，ArchUnit 按层守卫天然覆盖（`PackageConventionsTest` 无需改）。
5. **口径文档化**（验收标准原文）：归因拆解数学口径在设计规格 §二完整推导留痕。

## 五、验收标准（沿用产品落地计划 MS-13 + 展开）

1. 风险指标用已知答案的样本净值序列校验通过（domain 单测）；
2. 归因拆解数学口径文档化（设计规格 §二）+ Brinson 手工样例对拍；
3. 三源（申万行业指数/中证全债/黄金 ETF）真实 token 探测有结论，采集任务 + 回填落库；
4. `/analytics` 风险指标卡 + 归因区、`/allocation` 回测卡有真实数据渲染；
5. `make test`（≥80%）+ Playwright e2e 全绿；`make smoke` 无新增段（无新实时外源——行业/债券/黄金为 collector 离线数据）。

## 六、明确不做（YAGNI）

- **年度归因分解**：首版全窗口累计，交互后置（F05 年度表已覆盖年度视角的收益侧）；
- **Sortino / 信息比率 / 阿尔法贝塔** 等更多风险指标：F08 验收只到夏普/Calmar；
- **回测费用/税/滑点建模、蒙特卡洛、参数寻优**：「简易」边界；
- **回测支持 REITs**：无数据源，模板未用（澄清 #2）；
- **基准行业权重历史重建**：用最近成分快照近似（近似口径文档化）；
- **归因基准切换**（中证500 等）：首版只对沪深300；
- **AI 工具接入**（风险/归因问答）：属后续 M05 扩展，不在本里程碑。

## 附：术语

- **TWR 净值指数**：日链接 `Π(1+R_t)` 的累积序列（首日=1），`R_t` 与 `TwrCalculator` 日子周期同口径（外部现金流日初到账剔除）；
- **MDD**（Maximum Drawdown）：峰值到谷值的最大跌幅；
- **夏普比率**：超额收益均值 ÷ 波动率的年化比值；
- **Calmar**：年化收益 ÷ \|MDD\|；
- **Brinson 归因**：把组合相对基准的超额收益拆为配置效应（行业权重偏离）与选择效应（行业内选股）的框架；
- **回测**：以历史资产收益序列模拟给定权重方案的净值演化，非收益承诺。
