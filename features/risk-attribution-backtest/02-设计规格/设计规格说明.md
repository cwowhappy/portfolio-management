## 二、数学口径（验收标准要求的文档化推导）

### 2.1 TWR 净值指数（三组指标的共同地基）

`Index_0 = 1`；`Index_t = Index_{t−1} × (1 + R_t)`，`R_t = (V_t − F_t) / V_{t−1}`——与 `TwrCalculator.cumulative`（`domain/analytics/TwrCalculator.java`）的日子周期定义逐日同构（`F_t` 为 t 日净外部转入，日初到账）。由 NavSeries + ExternalFlow 构造，不新算 TWR。

### 2.2 最大回撤（F07）

在 §2.1 指数上：`peak_t = max(Index_0..t)`；`MDD = 1 − min_t(Index_t / peak_t)`；峰/谷 = 该最小值对应的峰值日/谷值日；持续天数 = 峰→谷交易日数；恢复日 = 谷后首个 `Index ≥ 峰值` 的日期（可空=进行中）；当前回撤 = `1 − Index_last / peak_last`。序列 < 2 点 → 全部置空。

### 2.3 夏普 / Calmar（F08）

- 日超额 `e_t = R_t − rf_t`，`rf_t = yield1Y_t / 100 / 365`（`yield1Y_t` 为百分数原值，如 1.85 表示 1.85%；`treasury_yield_curve` term='1Y'，缺失日 forward-fill 最近前值；全缺 → rf=0 并在响应标注 `rfFallback=true`）；
- `Sharpe = mean(e) / stdev_{n−1}(e) × √252`（年化因子固定 252 个交易日，样本标准差）；
- `Calmar = annualizedTwr / |MDD|`（复用 `TwrCalculator.annualized` 与 §2.2 结果）；
- 置空：序列 < 2 点、stdev = 0、MDD = 0（仅 Calmar）。

### 2.4 日频子周期 Brinson 累加（F09，对沪深300）

组合每个交易日的超额收益拆解，全窗口逐日累加（日频权重近似，加总残差显式留痕）：

```
R_p,t − R_b,t = Σ_i [ (w_p,i,t−1 − w_b,i,t−1)(R_b,i,t − R_b,t) + w_p,i,t−1(R_p,i,t − R_b,i,t) ] + 现金项 + 残差
                 └────────── 配置贡献_i,t ──────────┘   └────── 选择贡献_i,t（交互并入）──────┘
现金项_t = w_cash,t−1 × (R_cash,t − R_b,t)     // R_cash,t = yield1Y_t/100/365（百分数转小数），全记配置贡献，无选择项
residual = 实际超额 − Σ(配置+选择+现金)          // 超容差(1e-6/日)时响应携带，不隐藏
```

- `w_p,i,t−1`：前一日收盘持仓市值按申万行业分组权重（个股→行业用 `shenwan_mapping` 周更映射；无映射归「未分类」桶，标注不阻断）；
- `w_b,i,t−1`：最近一次 `index_constituent` 沪深300 成分快照按行业聚合权重（**静态近似**——历史成分漂移不重建，文档化口径）；
- `R_b,i,t`：申万一级行业指数日收益（新采集 801xxx，复用 `index_close_history`）；
- `R_p,i,t`：组合内该行业持仓的日收益（replay 产出的个股持仓 × `fetchCloses` 收盘序列分组聚合）；
- 窗口：组合窗口 ∩ 行业指数窗口 ∩ 基准窗口（交集截齐，响应标注）。

### 2.5 配置回测（M07-F06）

四类资产日收益：股 `R_stock,t` = 000300 日收益（已有）；债 = 中证全债 H11001 日收益（新采集）；金 = 518880 日收益（新采集）；现金 = `yield1Y_t/100/365`（既有，百分数转小数）。

日频重放（份额制）：期初按目标权重拆份额；每日 `份额_i × (1+R_i,t)` 演化；再平衡日（季度=每 63 交易日、年度=每 252 交易日、永不=不做）将总资产重置回目标权重。输出模拟净值曲线（首日=1）→ 年化收益（`(1+总收益)^(365/天数)−1`）、MDD（§2.2 同函数）、夏普（§2.3 同函数）。REITs 权重 > 0 → 域层抛 `AllocationException`（新错误码 `REITS_BACKTEST_UNSUPPORTED`）。

## 三、后端设计

### 3.1 域形态（同构既有惯例）

```

  RiskMetricsCalculator        // static: twrIndex(NavSeries, flows) → List<DatedIndex>
                               //        maxDrawdown(List<DatedIndex>) → MddResult
                               //        sharpe(List<BigDecimal> dailyReturns, SortedMap<LocalDate,BigDecimal> rfDaily) → SharpeResult(value, rfFallback)
                               //        calmar(annualizedTwr, MddResult) → BigDecimal?
  AttributionCalculator        // static: attribute(List<DailyRow>) → AttributionResult(rows, cashRow, residual, window)
                               // DailyRow(tradeDate, 组合行业权重, 基准行业权重, 行业收益, 组合行业收益, rf)
  MddResult / SharpeResult / AttributionResult / DatedIndex   // 值对象（record）
```

## 六、错误处理与降级

1. 无流水：`risk-stats`/`attribution` 204（同 overview 先例）；
2. 回测无方案/无权重：400 `NO_ACTIVE_PLAN`；REITs>0：422 `REITS_BACKTEST_UNSUPPORTED`；
3. rf 序列段缺失：forward-fill 最近前值；全缺：rf=0 + `rfFallback=true` 标注（夏普退化为 raw Sharpe）；
4. 行业指数/基准窗口 < 组合窗口：截齐交集 + 响应 `window` 标注（同基准对比先例）；
5. 个股无行业映射：「未分类」桶 + `unmappedValueShare` 标注，不阻断；
6. Brinson 残差超容差：`residual` 字段显式携带（日频权重近似的数学损耗，不隐藏）；
7. 回测区间 > 数据深度：截到最长可用 + `window` 标注。
