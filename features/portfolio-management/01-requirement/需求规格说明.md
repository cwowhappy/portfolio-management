## 一、背景与目标

一期已交付投研信息获取闭环（对话式投研问答 + 行情数据台 + 注册审核制用户体系 + 会话持久化），估值数据底座（MS-01）与市场估值仪表盘（MS-02）已落地，进度 45/105。MVP 阶段目标「判断市场、配置资产」，**持仓组合管理**回答「我买了什么、成本多少、赚了多少、占比合理吗」，是后续资产配置（MS-04）、收益分析（MS-07）、投资决策记录（MS-06）的数据地基。

**交付物**：

1. 新增后端 `domain/portfolio` 域 + `/api/portfolio/**` 接口（需登录）；
2. 新增前端 `/portfolio` 页面：组合总览、持仓列表、资产配置饼图、行业分布图、集中度分析，支持按分组切换；
3. 手工录入持仓与交易（买入/卖出/分红），自动计算成本与盈亏，现金按账户独立记账并自动联动。

## 二、需求澄清汇总

| # | 需求点 | 决策 |
|---|---|---|
| 1 | 特性范围 | MS-03 = M08-F01~F11；F12 CSV 导入属三期，不含 |
| 2 | 成本口径 | MVP 仅**加权平均（摊薄成本）**；买入按笔存、结构兼容未来 FIFO，FIFO 延后二期 |
| 3 | 组合模型 | **单组合/用户**（首次使用自动创建，无需手动建组合） |
| 4 | 分组模型 | 单分组（HoldingGroup，`type` = 账户\|标签），一只持仓属唯一分组；多对多标签延后 |

| 7 | 分红处理 | **降成本**：现金分红降低摊薄成本价，送股按比例增股数、摊薄每股成本 |

| 9 | 标的类型 | A股 + ETF + 现金 |
| 10 | ETF 处理 | 排除行业分布（无申万映射）；资产类别归入「股票/权益」 |
| 11 | 删除语义 | 硬删除级联（删持仓连带删其交易/分红）+ 前端二次确认 |
| 12 | 访问权限 | `/portfolio` 需登录（持仓为私有数据），后端按登录用户隔离，非本人返回 404 |

> 决策 2 相对产品落地计划原文「含两种成本口径的测试用例」有调整：FIFO 延后二期，MVP 验收标准相应改为单一加权平均口径（见「五、验收标准」）。

## 三、功能需求

### A. 持仓录入与交易（M08-F01~F05）

**FR-A1 添加持仓（F01）**

- 搜索标的（复用行情台股票搜索）→ 输入买入日期 / 价格 / 数量 / 手续费 → 创建持仓并生成一条买入交易，自动计算成本。
- 标的选择范围：A股、ETF；代码/名称来自行情服务。
- 添加时须指定所属分组（账户）；创建持仓后自动扣减该账户现金（见 FR-B2）。

**FR-A2 编辑 / 删除持仓（F02）**

- 可修改买入记录的日期 / 价格 / 数量 / 手续费、所属分组；修改后成本与现金联动重算。
- 删除持仓为**硬删除级联**（连带删除其交易与分红记录），前端二次确认；删除后现金联动回冲。

**FR-A3 追加买入与成本计算（F03）**

- 同一标的再次买入（日期 / 价格 / 数量 / 手续费），按**加权平均**重算摊薄成本价。
- 每次买入独立存一条交易记录，结构兼容未来 FIFO（二期）。

**FR-A4 卖出记录与已实现收益（F04）**

- 记录卖出（日期 / 价格 / 数量 / 手续费），按加权平均口径自动匹配成本，计算**已实现收益**。
- 卖出所得（扣除手续费）自动计入所属账户现金。
- 卖出全部持仓后持仓股数归零，不再出现在持仓列表；交易历史保留，已实现收益已在卖出时计入组合总盈亏（不随清仓丢失）。

**FR-A5 分红记录（F05）**

- 记录现金分红（每股金额）与送股（每 10 股送 X 股，或比例）。
- **现金分红**：降低该持仓摊薄成本价；分红金额自动计入所属账户现金。
- **送股**：按比例增加持仓股数，摊薄每股成本，总成本不变。

### B. 组合与分组（M08-F06）

**FR-B1 持仓分组（F06）**

- 分组 `type` 分两类：`账户`（券商账户，如「华泰」「东财」「雪球基金」）与 `标签`（自定义视图分组）。
- 一只持仓归属唯一分组；同一股票可跨账户（不同分组）各持有一条持仓。
- 分组支持增 / 删 / 改名；删除分组前须先清空其下持仓，否则拒绝删除并提示先迁移或删除持仓。

**FR-B2 账户现金（与 F06 联动）**

- 现金按 `type=账户` 的分组**独立记账**：每个账户有自己的现金余额。
- 现金以交易流水记录（转入 / 转出），并随该账户下的买入 / 卖出 / 现金分红**自动联动**：

  ```
  账户现金余额 = 转入 − 转出 + Σ卖出净额 + Σ现金分红 − Σ买入支出
  ```

- `type=标签` 的分组不持有现金、不参与现金联动（纯视图分组）。
- 现金余额可由流水推导，需支持「调整余额」类转入 / 转出录入。

### C. 组合分析与可视化（M08-F07~F11）

**FR-C1 组合总览（F07）**

- 头部汇总卡片：总资产、总成本、总盈亏、今日盈亏。
  - 总资产 = Σ持仓市值 + Σ账户现金
  - 总成本 = Σ累计买入成本
  - 总盈亏 = 浮动盈亏 + 已实现收益（分红已通过「降成本」内含于二者，**不重复加总**）
  - 累计现金分红作为独立信息展示（参考指标）
  - 今日盈亏 = Σ(现价 − 昨收) × 股数（仅股票/ETF，现金不计）
- 盈亏恒等式（ground truth）：总盈亏 = 当前市值 + 累计卖出净额 + 累计现金分红 − 累计买入成本；浮动盈亏 / 已实现收益 / 累计分红的精确拆分口径在设计阶段明确，但须保证与恒等式对账一致。

**FR-C2 持仓列表（F08）**

- 明细表格：名称 / 代码 / 数量 / 成本价 / 现价 / 市值 / 盈亏 / 收益率 / 所属分组。
- 现价来自行情服务（与行情台同源）；支持按分组筛选与切换视角。

**FR-C3 资产配置结构可视化（F09）**

- 按资产类别（股票 / 权益 ETF / 现金）聚合市值绘制饼图。
- MVP 不做「对比目标配置」——该项留待 MS-04（M07 资产组合配置）。

**FR-C4 行业 / 板块分布图（F10）**

- 按申万一级行业分类聚合持仓市值，展示行业分布。
- 仅对个股生效（依赖申万行业分类映射）；ETF 无申万映射，排除并单独标注。

**FR-C5 个股集中度分析（F11）**

- 计算前 5 大重仓占比（占组合总市值），超阈值（默认 20%，可配置）给出风险提示。

## 四、非功能需求（NFR）

| 类别 | 要求 |
|---|---|
| 成本与盈亏口径 | 明确且可解释：加权平均摊薄成本；盈亏恒等式「总收益 = 市值 + 卖出净额 + 分红 − 买入成本」恒成立；口径在页面可查看说明 |
| 数据一致性 | 现金 / 持仓 / 盈亏三者自洽；买卖分红与账户现金联动不留对账缺口；现价与行情台（M04）同源 |
| 安全 | `/portfolio` 需登录；后端按登录用户隔离，非本人组合数据不可见（返回 404 不泄露存在性） |
| 性能 | 现价批量查询（组合可能多只持仓，禁止逐只串行调用行情）；组合分析基于落库数据计算，响应在合理时限内 |
| 可解释性 | 成本价、已实现收益、账户现金余额的计算口径在页面可查看 |
| 数据新鲜度 | 现价/今日盈亏为实时（取行情服务快照），标注数据时间 |

## 五、验收标准

- 买入 / 追加 / 卖出 / 分红全链路成本与盈亏计算正确（**加权平均单一口径**的测试用例，含分红与卖出交错场景）；
- 账户现金余额与「转入转出 + 买卖分红自动联动」对账一致；
- 组合总览与持仓列表数值对账一致，盈亏恒等式成立；
- `/portfolio` 未登录跳转登录；非本人组合不可见；
- 行业分布仅对个股生效、ETF 排除；前 5 大重仓占比与阈值提示正确；
- `make test`（覆盖率 ≥80%）+ `make smoke` + Playwright e2e 通过。

后续实现遵循全程质量门槛（DDD 分包规范、Flyway 迁移、覆盖率 ≥80%、冒烟 + e2e），见产品落地计划「五、全程质量门槛」。

## 六、明确不做（YAGNI）

- FIFO 成本口径（二期）；
- 多对多标签（后续）；
- F12 批量导入 CSV（三期）；
- F09 对比目标配置（MS-04）；
- 港股 / 美股 / 债券 / 黄金等标的（现价数据源未就绪）；
- 现金流水的审计 / 对账 / 多币种 / 外币汇率；
- 交易指令 / 实盘下单 / 券商 API 对接；
- 多组合（家庭 / 个人等多组合模型）。

## 七、依赖与风险

**依赖**

- 现有行情服务（`MarketDataService`）提供标的搜索、现价、昨收（`Quote.prevClose`）；
- 申万行业分类映射（`ShenwanIndustryMapping`，MS-01 已落地）支撑 F10；
- 认证体系（M01）支撑 `/portfolio` 私有与用户隔离。

**风险**

| 风险 | 影响 | 应对 |
|---|---|---|
| ETF 现价数据源支持 | ETF 持仓无现价 | 设计阶段验证行情服务对 ETF 代码的支持，不支持则限定 ETF 范围或补数据源 |
| 分红与卖出交错的成本匹配口径 | 已实现收益算错 | 设计阶段明确加权平均下「分红摊薄后卖出」的精确算法，写已知答案测试 |
| 现金联动的回冲一致性 | 编辑/删除持仓后现金错账 | 现金由流水推导、编辑/删除触发重算，集成测试覆盖 |
| 现价批量查询性能 | 组合多持仓时页面慢 | 设计阶段评估批量行情接口与缓存 |

## 附：术语

| 术语 | 含义 |
|---|---|
| 组合（Portfolio） | 一个用户全部资产的聚合容器，单组合/用户 |
| 分组（HoldingGroup） | 组合内的分组，`type=账户`（券商账户，含现金）或 `type=标签`（视图分组，无现金） |
| 持仓（Position） | 某标的在某分组下的持有，键 = 组合 + 分组 + 股票 |
| 交易（Trade） | 买入 / 卖出记录，含日期 / 价格 / 数量 / 手续费 |
| 摊薄成本价 | （累计买入成本 − 累计现金分红）/ 当前股数，分红降成本后的显示口径 |
| 已实现收益 | 卖出净额（扣除手续费）− 对应成本 |
| 账户现金 | `type=账户` 分组的现金子账，由转入转出 + 买卖分红自动联动推导 |
| 今日盈亏 | （现价 − 昨收）× 股数，仅股票 / ETF |
