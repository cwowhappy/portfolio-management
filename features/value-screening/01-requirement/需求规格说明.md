## 一、背景与目标

一期（36 功能点）+ MS-01~MS-04（市场估值、持仓管理、资产配置）已交付。MS-05 是 MVP 阶段收尾的两个能力，回答两个核心问题：

1. 哪些标的符合价值投资标准？（多条件组合筛选）
2. 哪些行业被低估？（行业估值对比 + 热力图）

**交付物**：

1. **个股基本面数据底座**：新增 tushare 个股估值（日频）与财务指标（季频）采集并持久化，为筛选器提供数据地基；
2. **价值筛选器** `/screener`（公开）：五维 AND 组合筛选 + 结果排序；
3. **行业估值页** `/industry`（公开）：申万 31 行业 PE/PB/ROE/股息率对比 + 估值热力图，点击行业跳转筛选器带入行业条件。

## 二、需求澄清汇总

## 三、功能需求

### A. 个股基本面数据底座

**FR-A1 个股估值日快照**

- 每个交易日收盘后批量抓取全 A 股个股估值与市值流动性数据并落库，字段含：PE-TTM、PB、股息率（`dv_ttm`）、总市值、流通市值、换手率。
- 快照以 (交易日, 股票代码) 为唯一键，同日重复执行幂等。
- 覆盖范围：仅沪深正常交易股（剔除 ST/退市），不含北交所。
- 数据来源：tushare `daily_basic`（按交易日批量单次拉取，无需逐股）。

**FR-A2 个股财务指标季数据**

- 按报告期批量抓取全 A 股财务指标并落库，字段含：ROE、ROA、毛利率、资产负债率、流动比率、营收同比增长率、净利润同比增长率。
- 以 (报告期, 股票代码) 为唯一键，幂等。
- 回填近 3 年季报（约 12 期），支撑未来「连续 N 年」口径扩展。
- 数据来源：tushare `fina_indicator`（按报告期批量单次拉取）。

**FR-A3 行业 ROE/股息率扩展**

- 在既有行业加权估值基础上，用个股 ROE、股息率按市值加权计算行业 ROE、股息率，写入 `industry_valuation` 表的 `roe`/`dividend_yield` 列（当前为空）。

### B. 价值筛选器（`/screener`，公开）

**FR-B1 多条件组合筛选**

- 五个维度自由 AND 组合，未填写的条件不参与筛选：

| 筛选维度 | 具体指标 |
|---|---|
| 估值水平 | PE-TTM < X；PB < X；股息率 > X% |
| 盈利能力 | ROE > X%；ROA > X%；毛利率 > X% |
| 财务健康 | 资产负债率 < X%；流动比率 > X |
| 成长与稳定 | 营收增长率 > X%；净利润增长率 > X% |
| 市值与流动性 | 总市值 > X 亿；换手率 > X% |

- 可选：按申万一级行业限定范围（行业条件）。
- 至少一个筛选条件才触发查询（空表单不查询）。
- 估值口径：PE 用 tushare `pe_ttm`（TTM）、股息率用 `dv_ttm`，页面标注数据源与口径。
- 筛选基于落库个股数据实时 SQL 查询，禁止页面请求时实时抓取外部数据源。

**FR-B2 筛选结果排序**

- 结果表格支持任意列升/降序（PE-TTM/PB/股息率/ROE/ROA/毛利率/资产负债率/流动比率/营收增速/净利增速/总市值/换手率）。
- 结果上限 200 条，MVP 不分页。
- 结果行 MVP 不可点击（跳转行情台留待后续）。

**FR-B3 行业条件带入**

- 从 `/industry` 点击某行业跳转 `/screener` 时，自动带入该行业条件。

### C. 行业估值（`/industry`，公开）

**FR-C1 行业估值对比**

- 展示申万 31 个一级行业 PE/PB/ROE/股息率排名，支持按任意指标排序（与 M06-F07 同一数据源，第二入口）。

**FR-C2 估值热力图**

- 矩阵热力图（行=行业，列=PE/PB/ROE），颜色映射估值高低，一眼识别低估/高估行业。

**FR-C3 跳转筛选器联动**

- 点击某行业 → 跳转 `/screener` 并带入行业条件。

**FR-C4 免责声明**

- `/screener`、`/industry` 页面显著位置展示免责声明：所有数据与指标来自公开数据与算法计算，仅供参考，不构成投资建议。

## 四、非功能需求（NFR）

| 类别 | 要求 |
|---|---|
| 数据新鲜度 | 个股估值日更、财务指标按报告期更新；页面标注数据截止日期 |
| 可靠性 | 采集失败重试；写入幂等；失败可观测（日志） |
| 性能 | 筛选基于落库表实时 SQL，约 5000 行建索引后毫秒级；禁止页面请求时实时扫描外部数据源 |
| 安全 | `/screener`、`/industry` 公开只读，无写操作、不暴露用户数据 |
| 可解释性 | 各筛选指标口径、行业加权 ROE/股息率公式在页面可查看说明 |
| 一致性 | 同页口径统一（筛选器估值+财务均 tushare）；跨页标注数据源与口径（行情台东财 / 市场估值 akshare / 筛选器 tushare 存在差异，属可接受现状） |

## 五、验收标准

- `/screener` 五维条件组合筛选结果抽验正确（含行业限定）；
- 结果任意列排序正确；
- `/industry` 行业 PE/PB/ROE/股息率有真实数据，热力图着色正确；
- 行业点击跳转筛选器正确带入行业条件；
- 连续 5 个交易日个股估值快照正常落库；财务指标按报告期落库；
- 行业加权 ROE/股息率与抽验口径一致；
- `make test`（覆盖率 ≥80%）+ `make smoke` + e2e 全绿。

## 六、明确不做（YAGNI）

- 个股历史 PE/PB 分位（延后二期）；
- 「连续 N 年」多期口径（MVP 取最新一期 N=1）；
- 「经营现金流 > 净利润」条件（延后，需 cashflow 端点）；
- 自选观察列表（M09-F03，二期）；
- 结果导出 CSV（M09-F04，二期）；
- 指数成分股范围限制（M09-F05，二期）；
- 基金筛选（M09-F06，三期）；
- 行业上市公司排名 / 历史分位 / 景气度（M10-F03~F05，二期）；
- 未上市企业画像 / 竞争格局 / 产业链（M10-F06~F12，二期/三期）；
- 筛选结果缓存与清理任务（实时 SQL 已满足性能）；
- 结果行点击跳转行情台（MVP 不可点击）；
- 日均成交额口径（MVP 用换手率替代）。

## 七、依赖与风险

**依赖**

- tushare `daily_basic` / `fina_indicator` 接口与 TUSHARE_TOKEN（`fina_indicator` 需一定积分权限）；
- 后端个股基本面相关表（Flyway 迁移）；
- 申万行业映射 `shenwan_industry_mapping`（MS-01 已落地）；
- 既有 `industry_valuation` 表与 `domain/valuation` 读模型。

**风险**

| 风险 | 影响 | 应对 |
|---|---|---|
| tushare 积分不足（fina_indicator 需较高权限） | 财务指标拉取受限 | 启动前确认 token 积分；降级 akshare 逐股（慢） |
| 财务指标报告期不齐（部分股票缺最新季报） | 筛选漏股 / ROE 缺失 | 按「最新可用报告期」口径；缺数据股票在对应维度不满足条件 |
| 个股估值日更与财务季更时点不一致 | 估值与财务「错配」 | 各自取最新，页面标注数据截止日期 |
| 全市场约 5000 只批量采集时长 | 定时任务超时 | daily_basic / fina_indicator 按日/报告期批量单次拉取，非逐股 |

## 八、术语

| 术语 | 含义 |
|---|---|
| 五维筛选 | 估值水平、盈利能力、财务健康、成长与稳定、市值与流动性五个维度 AND 组合 |
| 个股估值日快照 | 每个交易日对全 A 股估值与市值流动性指标落库的一份结果集 |
| 个股财务指标季数据 | 按报告期落库的个股财务指标（ROE/ROA/毛利率/资产负债率/流动比率/增长率） |
| 行业加权 ROE/股息率 | 行业内个股 ROE/股息率按市值加权的行业汇总值 |
| 估值热力图 | 行=行业、列=PE/PB/ROE，颜色映射估值高低的矩阵图 |
