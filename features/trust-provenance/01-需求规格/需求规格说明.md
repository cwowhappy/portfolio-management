## 一、背景与目标

阶段一/二交付了「数据与记录 + 信息消化与决策流程」闭环（全系统 149/149），Agent 工具返回数据经聊天图表双通道（`ToolResultBlocks`）完整呈现，但 **LLM 文本结论与工具数据之间无强制绑定**：数字性结论无来源标注、陈述数字与工具返回值可能不一致（幻觉）、低置信回答无显式提示、投资建议无统一免责。金融场景下这是合规与信任的准入门槛（阶段三规划 D1·P0）。

本特性（M17，MS-29）交付**可信底座**：每条数据性结论可溯源（数字级角标 → 来源工具+调用参数+数据时间戳）、文本陈述数字与工具实际返回值强制比对（不一致分级处置）、低置信回答机制化显式提示、投资建议 disclaimer 统一双层触发。全部复用既有资产：图表双通道已有全量数据面（溯源只是把「已有数据」与「文本结论」绑定）、`AguiEventNonNullCodec`/`AguiWireJsonConfig` 序列化先例、`chat_message.payload` 预留 JSONB 列（持久化落点）、HITL `Interrupt.metadata` 前端消费先例（`ThreadArea.tsx:414`）、`UserToolkitFactory` 工具装配链（内置 + MCP）。校验器为**规则/数值比对层，不在对话主链引入额外 LLM 调用**（方向规划定位「事实校验 Agent 的单机轻量版」）。

按阶段三规划，MS-29 是关键路径 MS-28 → MS-29 → MS-32 的中间节点：M17-F02 校验器是 MS-32 深度研究「草稿过校验器」的硬依赖。

**立项侦察事实**（2026-10-05 三路，全文见[侦察报告](../09-调研报告/2026-10-05-立项三路侦察.md)）：① AgentScope 2.0.3 TextMessage 事件无 metadata 字段——锚定送达走「当轮 Custom 事件实时渲染 + payload 持久化回灌重建」组合；② 事件级自定义 metadata 刷新后经三处丢弃点必丢，`chat_message.payload` 列已预留恒 null；③ 约半数工具给 LLM 的是格式化中文摘要——F02 比对基线必须是服务侧 DTO 真值；④ DTO 数据时点覆盖良好，唯二透出缺口随本特性补齐。

## 三、功能需求（M17-F01~F03，编号/名称承规划文档，不增删改）

### M17-F01 结论引用锚定

**描述**：Agent 输出文本通道中每个数据性数字，在服务端产出锚定记录（数字在文本中的定位、来源工具名、调用参数、数据时间戳、校验态）；当轮经 AG-UI 流送达前端实时渲染上标角标（决策 #2），点击浮层展示来源详情；同句多数字共享同次工具调用时共用角标编号；锚定记录持久化，刷新/重开/翻历史会话角标全在（决策 #11）。

**业务规则**：

- 锚定对象 = 文本通道中的**数据性数字**（价格/涨跌幅/财务指标/市值/宏观指标等度量值；日期年份、序号编号等非度量数字不锚定，判定式设计规格定）；中文习惯格式「万/亿/百分比」归一化后定位。锚定面宽于比对面：锚定覆盖全部数据性数字（含无工具支撑者——其态为「未溯源」、Agent 二次计算值——有工具上下文但非直接引用，态为「已溯源未校验」）；F02 比对范围仅为「直接引用值 ∩ 内置工具」子集。
- 角标三态（决策 #5/#9/#13）：**已校验**（内置工具返回值比对通过，浮层措辞「数值与工具返回一致」，不暗示陈述已核实）/ **已溯源未校验**（MCP 来源或二次计算值，中性样式）/ **未溯源**（无任何工具数据支撑，弱样式灰/中性、可点可查；比例超阈值由 F03 横幅聚合升级，不逐数警示）。
- 浮层内容：工具名 + 调用参数 + 数据时间戳 + 工具返回原值（辅助人工核对）。时间戳优先级：工具返回自带数据时点（DTO 直读，如 `Quote.time`/`reportDate`/`tradingDay`）> 决策 #17 补齐透出的快照日期 > 调用时刻；`get_market_overview` 类生成时刻时点如实标注「生成时刻」。
- 锚定作用域 = 会话内（决策 #15）：优先配本轮工具调用；本轮无调用则回溯配会话内历史工具调用（歧义取最近一次命中并留痕）；跨会话不追溯。
- 送达通道（决策 #11，通道细节设计规格拍板）：当轮实时走 AG-UI 流自定义载荷（`AguiEvent$Custom`，线协议原生；`Interrupt.metadata` 为前端消费先例）；持久化写 `chat_message.payload` 预留 JSONB 列（按 messageId 关联），`ChatMessageWire` 扩展带回，前端回灌重建角标——两段互不依赖。
- payload 结构**不得依赖 null 值表达缺省，须用缺键**（`AguiEventNonNullCodec` 属性级+内容级双层剥 null，侦察证实）。
- MCP 工具锚定走同一锚定记录结构（来源工具 + 参数 + 调用时刻），校验态固定「已溯源未校验」（决策 #5）。

**边界与异常**：

- 功能上线前的旧消息（无锚定记录）：自然降级不渲染（决策 #7），前端不报错；上线后消息经 payload 回灌全量保留角标。
- 模型对近期用户消息中出现过的数字的**复述**：不锚定、不计入未溯源比例（决策 #16）；据用户数字二次加工的新数字仍按未溯源处理。
- 工具调用失败仍被文本引用的数字：按「未溯源」处理（浮层仅示来源工具与调用参数，无返回值与有效时间戳）。
- 同一数字命中多次工具调用的歧义归因规则在设计规格定（MVP 允许取最近一次命中并留痕）。

### M17-F02 数字一致性校验器

**描述**：轻量规则校验层比对「文本陈述数字 vs 内置只读数据工具实际返回值（服务侧 DTO 真值）」，按分级混合策略（决策 #1）输出三态处置：容差内放行 / 大偏差拦截改写（原位替换呈现，决策 #10）/ 无法比对标注「未溯源」。校验结论写入 F01 锚定记录的校验态字段，是角标渲染与 F03 置信度信号的共同数据源。

**业务规则**：

- 比对范围（MVP，方向决策 #1 + 决策 #5/#6）：仅**直接引用值**（工具返回值被文本原文引用的数字；Agent 二次计算值后置）；仅**文本通道**；仅**内置只读数据工具**（现况 16 个 `@Tool`：`InvestTools` 13 + `UserInvestTools` 3；写工具 `research_draft` 与无返回值比对意义的工具排除，清单设计规格定稿）。
- **比对基线 = 服务侧拦截的结构化 DTO 真值**（决策 #6）：非 LLM 可见摘要文本（约半数工具给 LLM 的是 `ChartSpecs` 格式中文摘要，含 `%.2f` 舍入）；DTO 拦截点（工具装配层/harness 工具结果出口）设计规格对照真实代码定。
- 三级处置（决策 #1/#10/#12）：
  - **容差内** → 静默放行，角标「已校验」；容差语义覆盖舍入（约 15.2 vs 15.23）、万亿/百分比换算（1.9 万亿 vs 19,000 亿）、有效位（1520 vs 1520.00）；绝对+相对组合容差，具体数值入 `InvestProperties` 可配（沿 M15 重要度阈值先例）。
  - **大偏差** → 拦截改写该句：错误数字替换为工具返回值（前端原位替换 + 瞬时高亮），并附「校验修正：原文误述 X」注记（注记持久化，改写痕迹可查）；修正重写轮次有上限护栏（可配），触达上限转降级出口——不再改写、原样放行 + 该处转显式标注 + F03 记「修正失败」信号（决策 #12）；修正执行机制（harness 内改写 vs 事件流后处理）为设计规格首要拍板项。
  - **无法比对** → 原文保留 + 「未溯源」标注（含 MCP 来源数字与非工具来源数字）。
- 中文数字格式归一化（万/亿/百分比/千分位）后进入比对。
- 校验结果计数（拦截数/修正数/未懂数）留痕供 F03 信号与 MS-30 观测看板消费。

**边界与异常**：

- 校验器自身异常**不得阻断对话主链**：降级为「已溯源未校验」态并告警留痕（可信机制自身失效时宁可少标不可错杀）。
- 二次计算值（如据工具价推导涨幅）不在比对范围，其数字按来源工具锚定为「已溯源未校验」——设计规格明确判定式。
- 已知语义边界（决策 #13）：只比数值不比方向词——「下跌 0.8%」配 +0.8% 数字容差内通过；浮层措辞降承诺对冲，方向校验后置 MS-30。
- 空/无数字回答：校验层直通，零开销。

### M17-F03 置信度与免责标准化

**描述**：机制信号推导的低置信消息级横幅（含核实路径建议）+ 双层触发的投资建议 disclaimer 统一模板。

**业务规则**：

- **低置信横幅**（决策 #3）：信号四类——①未溯源数字比例（口径排除用户来源复述数字，决策 #16）②数据时间戳陈旧度（阈值可配）③工具调用失败/降级 ④校验修正次数（含修正失败信号，决策 #12）；组合超阈值 → 消息尾部横幅列明命中信号与核实路径建议。核实路径 v1 为按数据类型的静态映射模板（行情类 → 建议对话内重问最新价或东方财富行情页；公告类 → 巨潮资讯网；宏观类 → 统计局/央行官网）。
- **disclaimer**（决策 #4）：触发 = Agent 自声明 advice 标记（`InvestSystemPrompt` 增约束）∪ 后端词表兜底（词表可配、有测试锚定）；统一模板含「AI 生成、不构成投资建议、市场有风险、独立判断或咨询持牌机构」要素，文案设计规格定稿。
- 横幅与 disclaimer 可同消息并存，互不抑制。
- 提示词新增约束（自声明 + 数字引用规范）纳入提示词资产维护，衔接 MS-30 版本化与 eval 回归。

**边界与异常**：

- 词表兜底扫描仅消息文本，不扫工具返回与图表 spec（工具数据非建议表述）。
- 自声明与词表均未命中的隐晦建议属已知残余风险，留 MS-30 幻觉诱导基线度量（本里程碑不建 eval 基线）。

### 工程随附项：agent/web 域 P3 顺带清理（决策 #8，规划 §8.2 台账）

六项打磨（①反注入总则句 ②draftJson 大小上限 ③`hasSize(16)` 断言易破 ④`TtlCache` 原子性 ⑤Flyway 迁移数守护测试 ⑥FeishuBinding 时区解释）随本里程碑交付清零或留痕降级，交付时逐项勾销；其中 ①反注入总则句与 F03 提示词改动同文件顺带、②draftJson 上限与 F02「内置工具返回值治理」同域，优先随做。

## 四、非功能需求

1. **流式体验**：锚定/校验/横幅机制不明显劣化首字时延与整体流畅度——校验为纯规则数值比对，主链零额外 LLM 调用；大偏差拦截改写的重写轮次须有上限护栏（可配，触达走降级出口决策 #12）。
2. **协议兼容与持久化**：锚定送达 = 当轮 Custom 事件实时渲染 + `chat_message.payload` 预留列持久化回灌（决策 #11；AgentScope 2.0.3 TextMessage 无 metadata 字段，侦察证实）；payload 结构无 null（`AguiEventNonNullCodec` 属性级+内容级双剥除，用缺键表达缺省）；功能上线前旧消息降级；前端对缺失字段防御性渲染。
3. **安全**：不引入新攻击面——锚定浮层内容（工具名/参数/时间戳）均为系统内数据，无用户可控注入路径；P3-①反注入总则句顺带补入 `InvestSystemPrompt`；词表与容差配置入库可管，无 CORS/CSRF 现状变化。
4. **覆盖率与测试**：后端 JaCoCo / 前端 V8 ≥80%，`make test` 三端全绿；校验器容差/归一化/三态处置为纯函数优先（单测密度高）；验收 fixture 走 testFixtures 纯确定性集（决策 #14）；角标三态、原位替换高亮、disclaimer 走 Playwright e2e（真浏览器，沿「e2e 旧构建产物与 mock 盲区」教训——关键前端改动须清 `.next` 后真浏览器验收）。
5. **可观测**：校验拦截/修正/未懂数、低置信横幅触发、disclaimer 触发（自声明/词表分别计）留痕计数，为 MS-30 观测看板与幻觉诱导基线供数。
6. **架构**：校验器与锚定落 `agent` 能力域（规划 §六先例：消费 application/domain，`PackageConventionsTest` 白名单按需登记）；`payload` 列写入走既有 conversation 持久化链路（DDD 分层不变）；`InvestProperties` 承容差/词表/阈值配置。

## 五、验收标准（与规划文档 MS-29 节对齐）

- **溯源可见**：数字性结论点击可见来源与时间戳——e2e 覆盖角标三态渲染与浮层内容（内置/MCP/未溯源三场景）；**刷新页面/重开会话后角标仍在**（payload 持久化回灌验收，决策 #11）。
- **校验有效**：testFixtures 纯确定性 fixture 集（约 30 例，决策 #14）上，直接引用错值检出率（拦截改写+显式标注合计）≥ 90%，正确值误改写率 ≤ 5%；真模型幻觉诱导指标由 MS-30 产出（规划已定归属）。
- **流畅度**：抽检对话（含多工具调用场景）首字时延与往返体验不明显劣化；修正重写不常触发、有上限、上限出口为降级非截断。
- **disclaimer 覆盖**：投资建议类输出全量覆盖（自声明 ∪ 词表井集，词表命中有测试锚定）；非建议类输出不误附。
- **P3 台账**：六项清零或留痕降级（逐项勾销）。
- **门槛**：`make test` 三端全绿（含 ArchUnit / 链接门禁）。

## 六、YAGNI 排除清单（逐条给排除理由）

- **二次计算值校验**——方向决策 #1（2026-10-04 已确认后置）：推导链归因复杂，MVP 先锁直接引用值。
- **方向词语义校验（涨/跌颠倒检测）**——决策 #13：自由文本方向词配对抽取不可靠，后置 MS-30 幻觉诱导基线度量。
- **模型自评置信度**——决策 #3：LLM 过度自信通病，机制信号已覆盖数据维不确定性。
- **MCP 工具数字比对**——决策 #5：异构返回语义未知，值巧合匹配产假「已校验」（漏杀）比不校验更有害。
- **LLM 判定式事实核查（事实校验 Agent 重模式）**——方向规划定位即「单机轻量版」；主链加 LLM 调用伤时延与成本。
- **幻觉诱导 eval 基线与幻觉率指标**——规划归属 MS-30（D4.1），本里程碑只交付校验器本体与供数。
- **D2 研报草稿强制过校验**——MS-32 消费端（M19-F03），本里程碑只保证校验器可被复用。
- **修正版本 diff 视图**——「校验修正：原文误述 X」内联注记已满足透明性；diff 视图无既定消费场景。
- **英文/多语言数字格式**——产品语言为中文，仅归一化中文习惯格式（万/亿/百分比/千分位）。
- **M17 概览登记与模块文档**——立项后续动作（头部注明），随交付回填收口。
