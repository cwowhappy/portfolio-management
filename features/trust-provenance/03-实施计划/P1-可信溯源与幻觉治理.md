## 契约决策（承接设计规格，执行中不再回头确认）

1. **Custom 事件两枚**：`trust.anchors`（PostSummary 末，每 assistant 消息一次，value=`{messageId, payload}`）、`trust.correction`（有大偏差时先发，value=`{messageId, snippet, occ, replacement, note}`）；payload 结构 v1 见设计规格 §2.1，**全字段无 null 用缺键**。
2. **豁免与真值优先序**：数字先配工具真值（verified/sourced）；无真值匹配且值出现在近期 user 消息文本 → 豁免（不锚定不计比例）；其余 → unverified（需求决策 #16 的执行级细化）。
3. **MCP 工具锚定**：装饰器统一记 `state=sourced、asOfKind=call`，不进比对池（决策 #5）。
4. **飞书路径**：hook 照跑、`setSummaryMessage` 生效、Custom 事件静默（无 AG-UI 消费者）；`HarnessAgentInvoker` 不改。
5. **提示词标记**：自声明 = 文末 `<!--advice-->` 行，hook 检测并剥离；剥离后的文本才是最终 Msg/payload 文本。
6. **探针回退线**（设计规格 §八 风险 #1/#2/#3）：B0 三探针任一失败 → 走既定回退（chunkCallback→返回文本+容差；AgentStateMutation→`agent.setMessages`；emitter→Middleware merge），回退结果记入本计划附录注记，不回设计。
7. **提交规范**：每任务红→绿即 commit，前缀 `feat(backend|frontend): MS-29 <任务号> <一句话>`，尾行 `Co-Authored-By: Claude Code <noreply@anthropic.com>`。

## Review Focus（六类最易咬人的模式——任务卡内测试逐条锚定）

1. **流式时序竞态**：correction 与 anchors 事件顺序、400ms 防抖 PUT 必须带修正后最终 payload、替换重校验的重试上限出口；
2. **无 null 契约**：payload/事件 value 序列化后无 null 字段（codec 双剥除行为用契约测试锁定）；
3. **豁免边界**：用户数字与工具真值同值时真值优先（#2）；二次加工数字不豁免；
4. **降级链**：hook 异常直通原文、探针回退、旧消息无 payload、回灌 TrustMeta 缺失——断言静默安全不报错；
5. **共用面隔离**：`MarkdownView` 零改动（wiki/intelligence 四处消费方回归）、飞书路径事件静默；
6. **全删重插一致性**：多标签 union 非空 payload 优先、PUT 非法 JSON 单条降级不整批拒。

| 2 emitter 可得性 | **通过**（可运行测试，双路径验证）：hook `onEvent` 返回 `Mono.deferContextual(ctx -> { AgentEventEmitter.fromContext(ctx).ifPresent(e -> e.emit(new CustomEvent("trust.anchors", Map.of(...)))); return Mono.just(event); })`，Custom 帧实测出现在 `agent.streamEvents()` Flux；POST_SUMMARY（maxIters 耗尽路径）与 POST_CALL（正常收尾路径）均命中。探针3 javap 结论：`fromContext` 读键 **`agentscope.agent.event.emitter`**（`buildAgentStream` 写入，仅非 subagent-bus 上下文；另有转发键 `agentscope.agent.event.forwarding.emitter` 供 `fromForwardingContext`）；`LegacyHookDispatcher.fire()` 以 `Mono.just(event).flatMap(hook::onEvent)` 链式编排进 lifecycle，故 hook Mono 内 deferContextual 可见 emitter | 否（Middleware merge 形态亦实测可用：`onAgent` 中 `next.apply(input).concatWith(Flux.just(customEvent))`，留作保险不启用） |
