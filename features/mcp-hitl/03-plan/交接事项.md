## 1. 待开 ticket：`TestSourceSetConventionsTest` 在全新 clone 下必失败

> ✅ 已开 [#24](https://github.com/cwowhappy/portfolio-management/issues/24)（2026-09-08，含复现输出与修复方向）。

**问题**：`backend/src/test/java/com/portfolio/invest/architecture/TestSourceSetConventionsTest.java:83` 对 `build/classes/java/integrationTest` 做 ArchUnit 检查，但 `test` 任务不编译该源集（integrationTest 是独立 JvmTestSuite，见 `backend/build.gradle` testing 块）。失败场景：全新 clone 后 `cd backend && ./gradlew clean test` 必失败（empty should）。

**归属**：与本特性无关的既有缺陷（引入于 `0fe0ed0`，早于 mcp-hitl 分支）；本机增量开发时因 integrationTest 类已存在而不触发，故 CI/日常开发未暴露。

**建议修复方向**（开 issue 后实施）：让该测试自行保证输入存在（改挂到同时编译两源集的任务，或检查前触发 `integrationTestClasses`），而非依赖外部构建顺序。
