## 3. 上线提醒：打扰面与治理路径

- **全量弹审批是知情选择**（需求决策 1）：当前 MCP 数据源工具大多未标 `readOnlyHint`，本特性上线后其调用将**全部**弹审批，直到治理措施落地。若打扰面不可接受，止血手段是 git revert 本特性（无开关后门，ADR-0010）。
- **治理已列入非目标待立项**：`ConfirmResult.rules` 规则沉淀（「本次会话不再询问」）、provider/endpoint 级只读信任配置、刷新/重启后的中断恢复（见需求规格「非目标」与 ADR-0010「后续治理」）。
- **观察点**：拒绝后 LLM 重试导致的反复弹卡（FR-7 提示词约束收敛，无机械防护）——线上如高频出现，优先考虑治理立项而非补丁。2026-09-09 复跑另观察到反向副作用：会话历史含「拒绝」轮时，LLM 对**新的**同类工具调用也可能预防性放弃并幻觉复述 denied 结果（设计规格 §七 复跑注记 1）；换新会话即恢复正常，暂不处理、上线观察。
