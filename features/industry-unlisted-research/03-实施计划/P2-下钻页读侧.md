> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `/industry/[industryCode]` 下钻页三 tab 化——「未上市与融资」tab 上线全景卡（F06）、策展名单（F07）、融资动态（F08）、竞争格局气泡图（F09）与登录态策展管理（编辑+CSV 导入，F10 卡片随表格行展开）。

**Tech Stack:** Spring Boot 4 / Next.js 15 + zod / ECharts（scatter）/ Playwright。

**Spec:** [01-需求规格](../01-需求规格/需求规格说明.md)（决策 #4/#5/#5b/#7）+ [02-设计规格](../02-设计规格/设计规格说明.md) §四读侧/§六前端/§七口径。
