# P3 · 产业链图谱（MS-10 F11）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 产业链三级数据面（链/环节/成员，V20+2 条种子链）+ 行业派生关联读端点 + 全文档式登录态保存 + ECharts 力导向图谱（上/中/下游分层着色）+ 下钻页「产业链」tab 激活 + MS-10 整体收口。

**Architecture:** `domain/industry` 新增链聚合与端口 + JPA 三件套（两张表两实体）+ `IndustryController` 挂 `GET /{code}/chains`（公开）+ `IndustryCurationController` 挂 chains 全文档三端点（登录）+ 前端 GraphChart 注册与 `buildGraphOption` 纯函数 + ChainTab/ChainEditorDialog。

**Tech Stack:** Spring Boot 4 / JPA + Flyway V20 / ECharts graph（force）/ Playwright。

**Spec:** [01-需求规格](../01-需求规格/需求规格说明.md)（决策 #1/#5/#6/#7）+ [02-设计规格](../02-设计规格/设计规格说明.md) §二 V20/§三/§四/§六图谱/§七链-行业派生口径。

## Global Constraints

- 同 P1/P2 全局约束（测试规约/覆盖率/提交署名/e2e 命令口径）。
- 链-行业关联**成员派生**（设计规格 §九#3）：`findRelatedToIndustry(code)` = 存在成员满足「LISTED 且 stock_code 经 `shenwan_industry_mapping` 属该行业」或「UNLISTED 且其 `industry_unlisted_company.industry_code` = code」——一条 join 查询，无关联表。
- 保存语义**全文档替换**（设计规格 §四：stages+members 嵌套整体替换，收窄 CRUD 面）；级联由 V20 `ON DELETE CASCADE` 保证。
- [ ] 全程约束自查：图数据量级（2~3 链 × 各 ~10 成员）整包返回，不分页不加缓存。
