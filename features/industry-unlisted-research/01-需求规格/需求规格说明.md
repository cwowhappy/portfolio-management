## 一、背景与目标

核心问题：**行业下钻页只有上市公司视角——未上市的潜在对手在哪里、谁在融资、产业链上下游怎么串起来，系统看不见。**

数据源替代裁决（2026-09-26，方案 A）已定的硬约束：

1. **0 元**：不采购任何商业 API；企查查开放平台（0.10 元/次）仅留可选增强接口位，默认关闭、无付费配置时功能完整；
2. **轻量口径**：不做工商全字段（法人/股东/专利/诉讼/经营异常），头部企业人工策展（名称/轮次/最近融资/简介）；
3. **月度粒度**：融资动态为公开新闻流月更（非全量口径留痕，先例 M10-F12 决策 #4、MS-12 F12）；
4. **合规边界**：公开新闻流采集月更低频、频率克制、来源标注；官方公示系统/商业平台不爬（仅人工低频核对）。

## 三、功能需求（按功能点，口径承裁决）

### A. M10-F06 行业全景概览

- 下钻页全景卡：已上市公司数/总市值（库内现成）+ 策展头部企业数 + 融资热度（近 12 月事件数/轮次分布，依赖 F08 数据面）。
- 口径标注：非全量、策展与月度粒度来源说明（开放项 #4 定稿后回填精确口径）。

### B. M10-F07 未上市头部企业画像

- 人工策展名单（每行业 10~30 家）：企业名称、细分赛道（文本标签）、最新融资轮次、最近融资时间、累计融资额（可缺省）、一句话简介、来源标注。
- 列表按轮次/最近融资时间排序；LLM 辅助生成草稿属维护流程（不入产品功能）。

### C. M10-F08 行业融资动态

- 融资事件表：日期、企业名、轮次、金额（可缺省）、投资方（可缺省）、所属行业（申万一级）、细分赛道（可选）、来源标题+URL。
- 月更粒度、非全量口径显著标注（页面 + API 口径字段）。

### D. M10-F09 竞争格局图

- 同框可视化：上市公司市值气泡（库内 board/成员数据）+ 策展企业融资轮次标签（F07 数据面）。
- 气泡图交互：hover 企业名/市值/轮次，点击上市公司跳行情台（M04 联动，承 F10）。

### E. M10-F10 企业详情卡片

- 上市公司：跳转行情台（既有能力）。
- 未上市企业：卡片展示策展字段摘要（轮次/最近融资/累计融资/简介/来源）+ 该企业历史融资事件（若有，取 F08）。

### F. M10-F11 产业链图谱

- 产业链定义：人工维护映射（仓库 YAML：链名/环节（上游/中游/下游）/环节说明），上市成员按申万行业或人工标注自动挂载，未上市成员取策展名单（人工标注归属环节）。
- 挂载入口：行业下钻页（该行业相关产业链）+ 可选独立入口（设计规格定）。

## 四、NFR

1. **口径诚实**：所有非全量/估算/策展数据在页面与 API 显式标注来源与口径（先例：ETF 跟踪误差前端标注）；
2. **覆盖率**：后端 JaCoCo / 前端 V8 ≥80%，`make test` 通过；Playwright e2e 新增用例（公开页面空态/真库数据态双态断言照 industry.spec 先例）；
3. **DDD**：域归属按开放项 #7 定稿后在 `PackageConventionsTest` 登记；
4. **Schema**：新表（融资事件/策展企业/产业链映射）走 Flyway 迁移（V19+）；
5. **性能**：策展与融资数据量级小（百~千行），无缓存需求（YAGNI）；
6. **企查查可选增强**：接口位预留、默认关闭；无付费配置时全功能可用（Feature Flag 式，本期不实现调用逻辑，仅不挡路）。

## 五、明确不做（YAGNI）

- 工商全字段（法人/股东/经营范围/司法/专利/诉讼）——裁决出局；
- 融资事件自动采集/解析（若开放项 #3 定 CSV 导入）；
- 策展内容的管理界面（若开放项 #1 定 YAML 种子）；
- 企查查 API 实际调用逻辑（仅留接口位）；
- 推送/提醒（融资动态提醒、新股上市提醒——M10-F12 决策 #4 已剔除）;
- 场外/非中国市场企业。

## 六、依赖与风险

| 项 | 说明 | 缓解 |
|---|---|---|
| 策展人工投入 | 首批 3~5 行业 × 10~30 家需一次性策展 + 低频维护 | LLM 辅助草稿降低成本；名单可渐进补 |
| 融资数据覆盖 | 月度新闻级非全量，公开源（睿兽分析月报）停更/改版风险 | 多源备选（36氪/投资界/IT桔子公开页）；来源字段留痕 |
| 产业链映射维护 | 无权威免费数据源，纯人工 | 种子链只做 2~3 条示例链，按需补 |
| e2e 数据态 | 策展/融资数据依赖种子 | 种子数据随 Flyway/fixture 提供，空态双态断言 |
