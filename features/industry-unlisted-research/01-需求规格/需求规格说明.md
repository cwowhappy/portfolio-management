# 行业研究·未上市与竞争格局（industry-unlisted-research）需求规格说明

> 创建：2026-09-26 | 里程碑：MS-10（三期） | 模块：M10 行业研究中心（F06~F10 + MS-14 遗留 F11）
> 状态：**grilling 定稿（2026-09-26 两轮 8 项决策，§二）**
> 上游：MS-09 行业研究已交付（`/api/industry/board`、下钻页、行业估值底座）；MS-14 已交付（`industry_watch` 关注集、CSV 导入基建、基金 tab）；[2026-09-26 数据源替代裁决（方案 A）](../09-调研报告/2026-09-26-数据源替代裁决与调研纪要.md)——天眼查出局，改公开流+人工策展轻量口径（0 元）

## 一、背景与目标

核心问题：**行业下钻页只有上市公司视角——未上市的潜在对手在哪里、谁在融资、产业链上下游怎么串起来，系统看不见。**

数据源替代裁决（2026-09-26，方案 A）已定的硬约束：

1. **0 元**：不采购任何商业 API；企查查开放平台（0.10 元/次）仅留可选增强接口位，默认关闭、无付费配置时功能完整；
2. **轻量口径**：不做工商全字段（法人/股东/专利/诉讼/经营异常），头部企业人工策展（名称/轮次/最近融资/简介）；
3. **月度粒度**：融资动态为公开源人工月度摘录（非全量口径留痕，先例 M10-F12 决策 #4、MS-12 F12）；
4. **合规边界**：公开源低频人工摘录+来源标注；官方公示系统/商业平台不爬（仅人工低频核对）。

## 三、功能需求（按功能点，口径承裁决与 grilling）

### A. M10-F06 行业全景概览

- 下钻页全景卡（库内派生，决策 #4）：已上市公司数/总市值（既有成员数据）+ 策展头部企业数 + 融资热度（近 12 月事件数与轮次分布，消费 F08 数据面）。
- 口径标注：非全量、策展与月度粒度来源说明（页面 + API 口径字段）。

### B. M10-F07 未上市头部企业画像

- 策展名单（每行业 10~30 家）：企业名称、细分赛道（文本标签）、最新融资轮次、最近融资时间、累计融资额（可缺省）、一句话简介、来源标注。
- 列表按轮次/最近融资时间排序。
- **管理能力**（决策 #1/#5b）：登录用户在下钻页内嵌编辑——单条增删改 + CSV 批量装载首批名单；未登录只读。

### C. M10-F08 行业融资动态

- 融资事件表：日期、企业名、轮次、金额（可缺省）、投资方（可缺省）、所属行业（申万一级）、细分赛道（可选）、来源标题+URL。
- **CSV 导入**（决策 #3）：模板下载 + all-or-nothing 行级校验（行号+原因清单，照 MS-14 `PortfolioImportService` 模式）+ 人工月度摘录公开源。
- 月度粒度、非全量口径显著标注（页面 + API 口径字段）。

### D. M10-F09 竞争格局图

- 同框可视化（ECharts 气泡）：上市公司市值气泡（库内成员数据）+ 策展企业融资轮次标签（F07 数据面）。
- 交互：hover 企业名/市值/轮次；点击上市公司跳行情台（M04 联动）。

### E. M10-F10 企业详情卡片

- 上市公司：跳转行情台（既有能力）。
- 未上市企业：卡片展示策展字段摘要（轮次/最近融资/累计融资/简介/来源）+ 该企业历史融资事件（若有，取 F08）。

### F. M10-F11 产业链图谱

- 产业链数据面：链定义（链名/说明）+ 环节（上游/中游/下游 + 环节说明）+ 成员映射——上市成员按人工标注挂载（申万行业可预填候选），未上市成员取策展名单。
- 可视化（决策 #6）：ECharts graph 力导向，环节分层着色，hover 成员信息，点击上市成员跳行情台。
- 管理：登录用户增删改链/环节/成员映射；种子 2~3 条示例链（如锂电池链）。
- 入口：行业下钻页展示该行业相关产业链。

## 四、NFR

1. **口径诚实**：所有非全量/策展数据在页面与 API 显式标注来源与口径（先例：ETF 跟踪误差前端标注）；
2. **校验完整性**（承 MS-14 NFR）：CSV 导入每条失败行带行号+人话原因，不允许静默跳过；已知答案样例 CSV domain 单测全覆盖；
3. **鉴权**：读侧端点公开（照 `/api/industry/**` 既有公开段）；写侧/导入端点 authenticated（照 `/api/industry-watch` 先例独立前缀）；
4. **覆盖率**：后端 JaCoCo / 前端 V8 ≥80%，`make test` 通过；Playwright e2e 新增用例（公开空态/真库数据态双态断言照 industry.spec 先例）；
5. **DDD**：`domain/industry` 扩展在分包规范与 `PackageConventionsTest` 既有登记内（新增仓储/服务不跨域依赖）；
6. **Schema**：新表（融资事件/策展企业/产业链定义与映射）走 Flyway 迁移（V19+）；
7. **性能**：策展与融资数据量级小（百~千行），无缓存需求（YAGNI）；
8. **企查查可选增强**：本期不实现调用逻辑，仅保证架构不挡路（后续以 provider 位接入）。

## 五、明确不做（YAGNI）

- 工商全字段（法人/股东/经营范围/司法/专利/诉讼）——裁决出局；
- collector 自动采集/解析融资新闻——决策 #3 定 CSV 导入；
- 全 31 行业预置策展——首批 5 行业，其余空态（决策 #2）；
- 企查查 API 实际调用逻辑（仅留接口位）；
- 推送/提醒（融资动态提醒、新股上市提醒——M10-F12 决策 #4 已剔除）；
- 场外/非中国市场企业；
- 官方统计未上市总量估算——决策 #4 改库内派生。

## 六、依赖与风险

| 项 | 说明 | 缓解 |
|---|---|---|
| 策展人工投入 | 首批 5 行业 × 10~30 家一次性策展 + 低频维护 | CSV 批量装载 + LLM 辅助草稿（维护流程，不入产品功能）；名单渐进补 |
| 融资数据覆盖 | 月度新闻级非全量，公开源（睿兽分析月报）停更/改版风险 | 多源备选（36氪/投资界/IT桔子公开页人工摘录）；来源字段留痕 |
| 产业链映射维护 | 无权威免费数据源，纯人工 | 种子只做 2~3 条示例链，按需补 |
| 下钻页信息密度 | 新增 5 个区块/tab 挤压现有成员排名 | tab 化组织（设计规格定交互细节） |
| e2e 数据态 | 策展/融资数据依赖种子 | Flyway 种子数据 + 空态双态断言 |
