# MS-32 深度研究工作流 实施计划 P1

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付 M19 三功能点——研究页发起的单 Agent 异步多步研报任务流（F01）、关键假设锚点跟踪与打开时过期重查（F02）、草稿 fail-closed 校验门（F03）+ SOP v2 轻量并入 + P3 domain 全域时钟统一。

**Architecture:** 专用端点+异步任务（D1）：web→application(任务/研报/配额/确认)+agent/report(编排：三轮 call+回炉、真值池快照、校验门)；产出落 V8 研报表四张 + 配额表（共五表）；确认走 PENDING 落库+确认卡（D2，HITL 改判）；失败重来（D3）；token 日预算+单任务上限（D7）。

**Tech Stack:** Spring Boot 4 / AgentScope 2.0.3（HarnessAgent Builder.maxIters/hook 公开 API）/ Flyway V8 / Next.js 15 + zod / Playwright。

**Spec:** [设计规格](../02-设计规格/设计规格说明.md)（§节号在任务中引用）+ [需求规格](../01-需求规格/需求规格说明.md)（D1~D8）。**执行者须同时读本计划册首与设计规格对应节。**

## Global Constraints（全任务隐含遵守）

1. **数值默认**（`invest.report.*`，设计规格 §八）：round-timeout 240s / total-timeout 15m / maxIters-per-round 15 / pool-size 2 / daily-token-budget 500000 / per-task-token-cap 400000（Ruling-21 实测校准） / validation relative 0.01·absolute 0.03·price 0.005·unverified-ratio-max 0.10·max-regen-rounds 1 / staleness recheck-ttl 5m·changed-relative 0.02 / draft-max-bytes 131072。
2. **对话链路零变更红线**：`HarnessAgentFactory.build(Long)` 与 `systemPrompt(userId)` 行为零变更（B8 回归测试钉逐字节）；`invest.trust.*` 对话档参数不动；`UserToolkitFactory.build(userId)` MCP 装配路径不动；`POOL_EXCLUDED_TOOLS`（`TrustTurnProcessor.java:35`）不动。
3. **fail-closed**：门内部异常/空真值池/解析失败 → 任务 FAILED，**任何路径不得产出 PENDING_CONFIRM 研报**（B7/B9 测试）。
4. **分层**：编排落 `agent/report/`（消费 application/domain）；`application` 禁依赖 `agent`（启动组合根在 Controller）；新实体落 `domain/research/`（纯 POJO 零注解）；JPA/迁移落 `infrastructure/persistence`。
5. **测试纪律**：GWT 命名 + 中文 `@DisplayName`；后端定向跑 `cd backend && ./gradlew test --tests "<FQCN>" --console=plain`；前端定向 `pnpm vitest run <file>`（**禁** `pnpm test --`，跑全套陷阱）；e2e 定向 `npx playwright test e2e/<spec>.ts`（全路径）；覆盖率 ≥80% 逐任务下沉。
6. **Flyway 配套**：先改 `FlywayMigrationCountGuardTest.EXPECTED_MIGRATION_COUNT` 7→8 再落 V8；`scripts/e2e-cleanup.sh` 同 PR 登记研报五表 DELETE 行。
7. **命名**：全链 `report` 语义（research_report*/report_token_quota 表、ReportTask 类、/report-tasks 路由）；无 `intel` 类缩写混用；中文文案面向用户。
8. **提交**：每任务一 commit（`feat(ms32): ...`/`test(ms32): ...`），先红后绿证据在任务简报回传中留测试输出摘要。
