# P2 · 行业对比（M10-F12）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `/industry` 页内「榜单/对比」视图切换——多行业并排对比表+对比图（零新增数据端点，消费既有 `/api/industry/board`），自定义关注行业（⭐，新表 `industry_watch` 持久化，关注集默认勾选），研究笔记联动复用既有链路。

**Architecture:** `domain/industry` 扩 IndustryWatch 实体+仓储（照 `domain/screening` watchlist 全套先例）；独立前缀 `/api/industry-watch` 端点（需登录，避开 `/api/industry/**` 公开段——照 WatchlistController 类注释先例）；前端 `IndustryBoard` 加视图切换，对比视图消费 board 全量 31 行本地过滤。

**Tech Stack:** 同 P1（无新依赖）。

**Spec:** [01-需求规格](../01-需求规格/需求规格说明.md)（决策 #4/#5/#15）+ [02-设计规格](../02-设计规格/设计规格说明.md) §2。

## Global Constraints

- 继承 P1 全部约束（测试规约/覆盖率/提交信息）。
- 对比维度固定集（决策 #4）：PE/PB/ROE/股息率/PE 5y 分位/PB 5y 分位/景气——不新增后端计算，全部来自 board 响应既有字段。
- `industry_watch` 不设上限（行业 31 只有界）；industry_code 校验用既有 `IndustryRepository.existsIndustry`。
- 关注交互未登录→引导登录（照筛选器 ⭐ 先例跳 `/login?redirect=/industry`）。
