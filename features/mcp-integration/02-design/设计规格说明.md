# MCP 数据源接入 · 设计规格说明

> 对应需求：`01-requirement/需求规格说明.md`（决策已确认 2026-09-06）。
> 技术可行性已预验证：AgentScope 2.0.1 自带 `McpClientBuilder`（streamableHttpTransport + header + timeout）、`Toolkit.registerMcpClient()`、`AguiAgentRegistry.registerFactory()`、可自定义的 `AguiRuntimeContextResolver`（每次请求可拿到原生 HTTP 请求）。

## 一、总体架构

```
前端设置页 /settings/mcp ──► app/api/mcp/** 反代 ──► 后端 REST（CRUD/测试连接/工具列表）
                                                        │ application.mcp 编排
                                                        ▼
                                            PG：mcp_server_config（密钥 AES-GCM 密文）
                                            users.mcp_personal_status（个人权限审核）

对话链路：
浏览器 → /api/copilotkit → 后端 /agui/run
  → 自定义 AguiRuntimeContextResolver：从 SecurityContext 取当前 userId，放入 RuntimeContext
  → 自定义 AgentResolver：resolveAgent("invest", threadId)
      → UserToolkitFactory.build(userId)：
          内置 InvestTools（7 个 @Tool）
        + 全局启用 servers 的工具
        + 本人已获批且启用 servers 的工具
        − 各 server 的 disabled_tools
      → Agent 按 userId 缓存；MCP client 按 (serverId, configVersion) 池化
```

## 二、数据模型（Flyway V10）

```sql
-- users 表加列：个人 MCP 权限审核
ALTER TABLE users ADD COLUMN mcp_personal_status VARCHAR(16) NOT NULL DEFAULT 'DISABLED';
-- DISABLED（未申请/被拒）→ PENDING（已申请）→ APPROVED（已批准）/ REVOKED（已吊销）

CREATE TABLE mcp_server_config (
    id              BIGSERIAL PRIMARY KEY,
    owner_user_id   BIGINT REFERENCES users(id),   -- NULL = 管理员全局配置
    name            VARCHAR(64) NOT NULL,
    url             VARCHAR(512) NOT NULL,          -- 仅 https
    auth_type       VARCHAR(16) NOT NULL DEFAULT 'NONE',  -- NONE / BEARER / HEADER
    auth_header     VARCHAR(64),                    -- HEADER 时的头名（如 em_api_key）
    auth_secret_enc TEXT,                           -- AES-GCM 密文（base64），NONE 时为 NULL
    disabled_tools  JSONB NOT NULL DEFAULT '[]',    -- 禁用的工具名数组
    enabled         BOOLEAN NOT NULL DEFAULT TRUE,
    config_version  INT NOT NULL DEFAULT 1,         -- 任何字段变更 +1，驱动缓存失效
    remark          VARCHAR(255),
    created_at      TIMESTAMPTZ NOT NULL DEFAULT now(),
    updated_at      TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX idx_mcp_server_owner ON mcp_server_config(owner_user_id);
```

## 三、后端模块落位（ArchUnit 合规）

| 包 | 内容 |
|---|---|
| `domain/mcp/` | `McpServerConfig` 实体（纯 POJO）、`AuthType`/`McpPersonalStatus` 枚举、`McpServerRepository` 接口 |
| `application/mcp/` | `McpConfigApplicationService`：CRUD 编排、连接测试、工具清单、权限校验（个人功能需 APPROVED）；`McpServerTester`（真实握手） |
| `infrastructure/persistence/` | JPA 实体 + 仓库实现 + V10 迁移 |
| `infrastructure/security/` | `SecretCipher`（AES-GCM，主密钥 `MCP_SECRET_KEY` 环境变量） |
| `web/` | `McpConfigController`（个人）+ `AdminMcpConfigController`（全局 + 个人权限审核），所有权隔离沿用会话隔离惯例（非本人 404） |
| `agent/` | `UserToolkitFactory`（按用户装配）、`McpClientPool`（池化 + configVersion 失效）、自定义 `InvestAguiRuntimeContextResolver` 与 Agent 缓存 |

## 四、运行时装配（核心机制）

1. **识别用户**：自定义 `AguiRuntimeContextResolver` bean——从原生请求拿 Spring Security 当前用户，写入 `RuntimeContext.userId`。
2. **按用户建 Agent**：`AguiAgentRegistry.registerFactory("invest", supplier)` + 自定义 `AgentResolver`（覆盖 starter 的 `DefaultAgentResolver`）：resolveAgent 时按当前 userId 取/建 Agent 实例（Caffeine/ConcurrentHashMap 缓存，key=userId）。
3. **工具装配**（`UserToolkitFactory`）：
   - 固定注册 `InvestTools`（7 个内置工具）
   - 查库：全局 enabled servers ∪ 本人（且 mcp_personal_status=APPROVED）enabled servers
   - 每个 server 从 `McpClientPool` 取 client（key=(serverId, configVersion)，miss 时 `McpClientBuilder.create(name).streamableHttpTransport(url).header(...).timeout(10s).buildSync()`，失败记日志并跳过该 server）
   - 注册到 Toolkit 时按 `disabled_tools` 过滤（**P0 验证点**：`registerMcpClient` 是否支持工具过滤；不支持则逐个注册 `McpTool` 或注册后移除）
4. **失效**：配置变更 → config_version+1 → 旧 client close 并淘汰；用户级 Agent 缓存同步失效。

并发与安全前提（P0 验证）：同一 userId 的 Agent 实例被多会话并发使用的线程安全性（AgentScope 会话状态机制）；必要时 key 改为 (userId, threadId)。

## 五、SSRF 与密钥安全

- **SSRF 校验**（`McpUrlValidator`，保存与每次连接前都执行）：
  - 仅允许 `https://`
  - 域名解析所有 A/AAAA 记录，拒绝内网/保留段（10/8、172.16/12、192.168/16、127/8、169.254/16、::1、fc00::/7 等）
  - 管理员可选配 `invest.mcp.domain-allowlist`（非空时仅白名单域名可保存）
- **密钥**：AES-GCM（随机 IV 随密文存储）；主密钥 `MCP_SECRET_KEY` 环境变量，缺失时密钥类字段拒绝写入（启动不阻断，写配置时报错）；API 出参永不包含 secret 字段。

## 六、API 设计（web 层，REST）

| 端点 | 说明 |
|---|---|
| `GET/POST /api/mcp/servers`、`PUT/DELETE /api/mcp/servers/{id}` | 个人 CRUD（需 APPROVED 权限，否则 403） |
| `POST /api/mcp/servers/test` | 连接测试（可直接测未保存的草稿配置），返回工具清单+耗时/错误 |
| `GET /api/mcp/servers/{id}/tools` | 已发现工具列表（含启用状态） |
| `PUT /api/mcp/servers/{id}/tools` | 更新 disabled_tools |
| `POST /api/mcp/personal/apply` | 申请开通个人 MCP 权限 |
| `GET/POST/PUT/DELETE /api/admin/mcp/servers[/{id}]` | 管理员全局配置 CRUD（owner_user_id=NULL） |
| `GET /api/admin/mcp/applications`、`POST /api/admin/mcp/applications/{userId}/{approve\|reject\|revoke}` | 个人权限审核 |

## 七、前端

- 新页面 `/settings/mcp`：服务器卡片列表（名称/URL/来源：全局或个人/状态）、新增编辑弹窗（含预置模板选择：妙想/Tushare 自动填 URL 与认证方式）、「测试连接」按钮展示工具清单、工具级开关、申请开通入口与审核状态展示
- `app/api/mcp/**`、`app/api/admin/mcp/**` 反代路由，复用 `lib/proxy.ts` 的 `relay()`
- 对话页无需改动（工具集变化对前端透明，AG-UI 工具调用事件照常渲染）

## 八、提示词策略

`InvestSystemPrompt` 追加静态规约（不随用户配置动态生成）：

- 行情/K线/财务/新闻/大盘/估值 → 优先内置工具
- 内置工具没有的数据（宏观经济、公告、研报、港美股、债券等）→ 可使用 MCP 提供的工具
- MCP 工具调用失败 → 如实告知，不重复重试
