# MCP 数据源接入 · 需求规格说明

> 状态：已确认需求（2026-09-06）。背景调研见 [docs/technology/research/03-金融机构MCP服务参考.md](../../../docs/technology/research/03-金融机构MCP服务参考.md)。
> 设计见 `02-design/设计规格说明.md`。

## 背景与目标

当前投研 Agent 只有 7 个内置 `@Tool`（行情/K线/财务/新闻/大盘/估值），数据能力由开发者硬编码。2026 年国内金融机构的官方 MCP 服务已成型（东财妙想、同花顺 iFinD、Wind AIFin、Tushare 官方等），用户希望把自己有权限的数据源接进 Agent，扩展对话能回答的问题范围（宏观、公告、研报、港美股、债券等）。

**目标**：支持**管理员配置全局 MCP**（全员可用）与**用户配置个人 MCP**（含 Tool 级开关），对话时按用户动态装配 Agent 工具集。

## 关键决策（已与需求方确认，2026-09-06）

1. **两级配置都要**：管理员全局 MCP（所有用户可用）+ 用户个人 MCP（仅本人可用）。
2. **个人 MCP 默认关闭，需管理员审核**：用户申请开通「个人 MCP 配置权限」→ 管理员批准后该用户可自行增删自己的 MCP 服务器（服务器配置不再逐条审核）；管理员可随时吊销。
3. **一期只支持远程 HTTP（Streamable HTTP）传输**，不支持 stdio（服务器上 spawn 用户指定的本地进程风险不可接受）。
4. **本地内置工具优先**：7 个内置工具仍是行情类问题的首选（有缓存/限流/降级链）；MCP 工具定位是扩展能力，提示词写明分工规约。
5. **不接交易类 MCP**（长桥/老虎等支持实盘下单的）：本系统是投研问答，无交易场景；一期在 SSRF 校验之外不做「是否含写工具」的识别，靠提示与用户自负其责。

## 用户故事

- 作为**管理员**，我可以配置全局 MCP 服务器（如东财妙想），填写 URL 与密钥，测试连接看到工具清单，启用后所有用户对话可用。
- 作为**普通用户**，我可以申请开通个人 MCP 配置权限；获批后添加自己的 MCP 服务器（如自己的 Tushare 账号），测试连接、查看工具清单、按工具粒度启用/停用。
- 作为**普通用户**，我未获批或未配置时，对话体验与现在完全一致（只有内置工具）。
- 作为**管理员**，我可以审核/驳回/吊销用户的个人 MCP 权限，可以停用任何一条配置。

## 功能需求

| 编号 | 需求 |
|---|---|
| FR-1 | MCP 服务器 CRUD：名称、URL、认证方式（无 / Bearer Token / 自定义 Header）、密钥、启用开关、备注 |
| FR-2 | 连接测试：保存前可发起真实握手，返回服务器工具清单与耗时；失败给出可读错误 |
| FR-3 | 工具清单与开关：展示该服务器已发现的工具列表，支持单工具启用/停用（默认全启用） |
| FR-4 | 两级可见性：管理员配置全局（owner=系统）；用户配置个人（owner=本人），个人功能需审核开通 |
| FR-5 | 对话时按用户装配：内置 7 工具 + 全局启用的 MCP 工具 + 本人启用且已获批的 MCP 工具，减去被禁用的工具 |
| FR-6 | 故障隔离：任一 MCP 服务器连接失败/超时，不影响对话主流程与内置工具；Agent 侧表现为该工具不可用 |
| FR-7 | 密钥安全：API 密钥加密存储（AES-GCM，主密钥仅存在于服务端环境变量），任何 API 不回显明文 |
| FR-8 | SSRF 防护：仅允许 https；保存与连接时解析域名并拒绝内网/保留 IP 段；管理员可配置域名白名单（开启后仅白名单域名可保存） |
| FR-9 | 预置模板：东财妙想、Tushare 官方 MCP 一键填充 URL 与认证方式，用户只填密钥 |

## 非功能需求

- **性能**：MCP 初始化不阻塞对话首 token——client 池化复用 + 异步预热 + 初始化超时（默认 10s）；配置变更即时生效（缓存失效重建）。
- **可观测**：MCP 连接成功/失败、工具调用失败有日志（不含密钥）。
- **架构合规**：遵循 DDD 分包规范（`domain.mcp` / `application.mcp` / `web` / `infrastructure`），ArchUnit 测试登记新包。

## 验收标准

1. 管理员添加全局 MCP（妙想或 Tushare）并启用后，任意已审核用户对话可使用其工具；停用后立即不可用。
2. 用户未获批时调用个人 MCP 配置 API 返回 403；获批后 CRUD 正常，对话按本人配置装配。
3. 填写内网 URL（如 `https://192.168.x.x`、`https://localhost`）保存被拒绝；非 https 被拒绝。
4. 密钥在 DB 中为密文；列表/详情接口无密钥明文。
5. 配置一个不可达的 MCP 服务器，对话仍正常进行，日志有告警。
6. 覆盖率门槛不降级（后端 JaCoCo ≥80%），ArchUnit 全绿。

## 范围外（一期不做）

- stdio 传输、SSE（旧协议）传输
- 交易类 MCP 的接入与写工具识别
- MCP server 用量统计/计费配额
- 工具调用的用户级审计日志页面
