## Review Focus

- 估值区间下限 ≥ 上限 → API 422 拒绝（DB CHECK 兜底 `ck_strategy_valuation`，domain 先拦）。
- FINALIZED 状态直接 PUT 暂存 → 拒绝，必须先 `revise()` 回 DRAFT（D13 覆盖式两级）。
- 手动 REOPENED 覆盖产物齐套 AUTO → 完成度显示 IN_PROGRESS（手动覆盖优先级：REOPENED > COMPLETED > AUTO 推导）。
- 非本人 projectId 访问全部端点 → 404 而非 403。
- 归档项目出现在默认列表 → 不得（默认滤 `status=ACTIVE`，显式 `?status=ARCHIVED` 可查）。
