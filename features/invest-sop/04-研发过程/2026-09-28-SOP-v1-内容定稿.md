## 阶段① 新分析——发现标的、立项研究

**必须有（缺一不立项转「制定策略」）：**

| 编号 | 检查项 | 要点 |
|---|---|---|
| 1.1 | 能力圈确认 | 能用三句话讲清「这家公司靠什么赚钱」；讲不清 → 记录「能力圈外」并停止立项 |
| 1.2 | 商业模式与生意属性 | 收入来源/客户是谁/复购与提价能力；区分 林奇六类（缓慢增长/稳定/快速增长/周期/困境反转/资产富余） |
| 1.3 | 行业格局与竞争位 | 行业所处阶段、集中度趋势、公司份额与相对地位；波特五力速查 |
| 1.4 | 财务初筛（五年） | ROE 均值与趋势、毛利率/净利率稳定性、经营现金流/净利润比、有息负债率、商誉占比 |
| 1.5 | 护城河初判 | 多尔西五类（无形资产/转换成本/网络效应/成本优势/有效规模）各做有/无标注 |
| 1.6 | 估值方法适配 | 按生意类型选定主估值法（稳定盈利→唐朝式 PE 区间；重资产→PB-ROE；强周期→中位 PE/周期调整；金融→PB） |
| 1.7 | 一票否决项扫描 | 财务疑点（审计非标/大存大贷/应收激增）、治理红旗（实控人高质押/频繁减持）、看不懂的复杂结构 |

**可选项：**

| 编号 | 检查项 | 要点 |
|---|---|---|
| 1.8 | 管理层与股权 | 实控人履历、持股比例、历史言行一致性（段永平：看做对的事、把事做对） |
| 1.9 | 股权激励与股东回报 | 激励行权条件是否进取、分红/回购记录 |
| 1.11 | 历史成因 | 公司上市以来市值长期走势与关键拐点复盘 |

*来源标注：1.1/1.8 巴菲特·芒格（能力圈）；1.2 林奇六分类；1.3/1.5 多尔西《股市真规则》；1.4 格雷厄姆安全思想 + A 股财务排雷实践；1.6 唐朝估值三段式适配。*

## 阶段② 制定投资策略——五字段结构化

**字段一 投资逻辑（必须有全部要素）：**

| 编号 | 要素 | 要点 |
|---|---|---|
| 2.1 | 核心论点一句话 | 「因为<结构性原因>，市场定价错了<什么>，而实际上<真相>」 |
| 2.2 | 论据链（≥3 条独立证据） | 每条注明数据出处与可验证方式；证据之间不得互为因果循环 |
| 2.3 | 反方观点与回应 | 主动列出最强看空论点 + 自己的回应（马克斯第二层思维：价格里已经反映了什么） |
| 2.4 | 时间维度 | 论点预期兑现周期（短/中/长）与持有底线年限 |

**字段二 估值区间（手动填写，D6）：**

| 编号 | 要素 | 要点 |
|---|---|---|
| 2.5 | 计算过程留痕 | 方法、关键假设（增长率/折现率/永续）、敏感性说明——数字手动填，过程必须写 |
| 2.6 | 下限（买点）与上限（卖点预估） | 下限对应预期年化 ≥ 底线回报（如 ≥15%）；建议用「乐观打八折」校验下限 |
| 2.7 | 当前价格所处分位 | 现价相对区间的位置百分比，作为安全边际直观量（前端可辅助计算展示，字段手动确认——与 D19「数据不隐式派生」一致） |

**字段三 仓位计划：**

| 编号 | 要素 | 要点 |
|---|---|---|
| 2.8 | 目标仓位占比与上限 | 单票上限受 PrincipleRule 约束（软提醒，D5）；写明「为什么是这个仓位」 |
| 2.9 | 凯利简化参数（手动，D23） | 主观胜率 p、赔率 b，各写一句依据；f* 系统算术 |
| 2.10 | 分批意图 | 初次建仓比例上限（如目标仓位的 1/3~1/2，剩余留验证仓/补跌仓） |

**字段四 买入条件（可勾选，至少 2 条）：**

| 编号 | 条件示例 | 要点 |
|---|---|---|
| 2.11 | 价格条件 | 现价 ≤ 估值下限（或下限上浮 X% 内） |
| 2.12 | 基本面条件 | 最近财报验证论点未被破坏（营收/利润/现金流达标口径写明） |
| 2.13 | 事件条件 | 大跌非基本面原因（市场恐慌/错杀），且论点不变 |

**字段五 风险与证伪条件：**

| 编号 | 要素 | 要点 |
|---|---|---|
| 2.14 | 证伪谓词 ≥1 条（价格/估值类，D10） | 系统可检测：跌破价格 X / 升破价格 Y（止盈参照）/ PE 超阈 / PB 超阈 |
| 2.15 | 事件类证伪 ≥2 条（人工勾选） | 论点级别的「我错了」判据：如核心产品份额连续两季下滑/关键客户流失/管理层重大变动/财务指标越过红线——**必须具体到可查证** |
| 2.16 | 风险叙述 | 主要风险 3-5 条 + 各自的监测方式（对应 F11 情报订阅关注点） |
| 2.17 | Stop Doing 检查（段永平） | 明确「本策略下绝不做」清单：如不加杠杆、不做 T、跌 50% 以内不动仓位（除非证伪） |

*来源标注：2.1-2.4 芒格多元思维 + 马克斯第二层思维；2.5-2.7 唐朝估值三段式 + 格雷厄姆安全边际；2.8-2.10 凯利简化 + 巴菲特集中投资纪律；2.17 段永平 Stop Doing List。*

## 阶段③ 建仓与持仓——纪律检查单

**买入前检查单（必须有，F10 消费 + 用户 PrincipleRule）：**

| 编号 | 检查项 | 数据来源 |
|---|---|---|
| 3.1 | 能力圈复查 | 立项 1.1 结论复述确认 |
| 3.2 | 论点未破坏 | 最近财报/公告 vs 2.2 论据链逐条核对 |
| 3.3 | 安全边际 | 现价 vs 2.6 下限（偏离超 +20% 需写理由） |
| 3.4 | 估值区间核对 | 现价分位复算（2.7） |
| 3.5 | 单票仓位上限 | PrincipleRule SINGLE_POSITION_RATIO（未设定→「未设定」中性） |
| 3.6 | 行业仓位上限 | PrincipleRule INDUSTRY_POSITION_RATIO（同上） |
| 3.7 | 买入条件满足 | 2.11-2.13 勾选状态逐条确认 |
| 3.8 | 证伪预案在位 | 2.14/2.15 已配置且具体可查证 |

> 免责文案（「检查通过仅为流程确认，不构成投资建议」）为**页面常驻文案**，不作为检查单条目（2026-09-28 评审裁决，落实需求规格 F10 边界）。

**加减仓/卖出前检查（F12，在 3.1-3.8 基础上追加）：**

| 编号 | 检查项 | 要点 |
|---|---|---|
| 3.10 | 证伪条件核对 | 当前命中的证伪条件列表（联动 F15）；命中 → 提示「发起证伪评审」 |
| 3.11 | 卖出理由分类 | 论点破坏（证伪）/估值到位（2.6 上限）/更好标的（写明比较）/仓位再平衡——四选一必填 |
| 3.12 | 情绪自查 | 「因为跌了所以卖」单独标记（复盘纪律遵守度的输入） |

**持仓监控关注点（F11 订阅范围建议）：** 定期财报、业绩预告/快报、重大事项公告、行业政策、核心竞争者动态。

## 阶段④ 复盘——三档模板

**月主模板（默认）字段：**

| 编号 | 维度 | 字段 |
|---|---|---|
| 4.1 | 决策质量 | 本月操作是否执行了检查单（留痕核对）；论点是否有新证据（更新/不变） |
| 4.2 | 结果质量 | 当月盈亏 + 归因圈选区间收益（自动带入，F14） |
| 4.3 | 纪律遵守度 | 越过提醒次数与理由复盘；Stop Doing 违例次数 |
| 4.4 | 归因 | 决策对/结果错（运气坏）vs 决策错/结果对（运气好）四象限归类 |
| 4.5 | 经验条目 | ≤3 条可复用结论（回流 wiki 候选，F16） |

**季深度模板追加：** 4.6 论点全量重检（2.2 论据链逐条重验）；4.7 估值区间重算留痕；4.8 与最初买入时相比「知道的更多了什么」；4.9 持有逻辑是否需要修订（联动策略 revise）。

**周简版字段：** 4.10 本周有无触发证伪条件（勾选）；4.11 有无计划外操作（有则一句话理由）；4.12 下周关注点一条。

*来源标注：4.1-4.5 邱昭良《复盘+》四步法（回顾目标→评估结果→分析原因→总结经验）；4.4 决策/结果四象限为 Annie Duke 思维适配；4.8 芒格「消除愚蠢」导向。*
