# 再平衡与筛选增强（rebalancing-screening）需求规格说明

> 创建：2026-09-16 | 里程碑：MS-08（二期） | 模块：M07 资产组合配置（F04/F05）+ M09 价值投资筛选器（F03/F04/F05）
> 页面：`/allocation`（扩展）/ `/screener`（扩展） | 前置：MS-03/04/05（全部 ✅）

## 一、背景与目标

MS-04 资产配置基础已交付「目标配置 vs 当前持仓」偏离度对比，但止步于**看**；MS-05 筛选器已交付五维筛选，但结果**留不住、带不走、限不了范围**。本特性补齐两侧闭环：

1. **再平衡**（M07-F04/F05）：偏离度从展示升级为行动——提醒（阈值/时间触发）+ 逐类买卖金额建议，回答「该不该调、调多少」；
2. **筛选增强**（M09-F03/F04/F05）：筛选结果可加自选、可导出 CSV、可限定指数成分股范围，回答「筛出来之后怎么用」。

**交付物**：

1. 后端：`domain/allocation` 扩展再平衡读侧计算与 ack 写侧；`domain/screening` 扩展指数限定/自选/搜索/CSV 导出；Flyway V14；
2. 前端：`/allocation` 加 RebalanceCard 与导航红点；`/screener` 加 ⭐/自选标签页/导出按钮/指数下拉。

## 二、需求澄清汇总（2026-09-16 brainstorming 定稿）

| # | 决策点 | 结论 |
|---|--------|------|
| 1 | F04 阈值口径 | **绝对百分点，固定 5pp**：任一类别 \|实际占比−目标占比\| ≥ 5 个百分点即触发；阈值硬编码（同模板库口径，改动走发版） |
| 2 | F04 时间触发 | **方案级周期 + 手动标记**：方案设频率（关闭/季度/半年），`last_rebalanced_at` 为锚点；用户点「已完成再平衡」重置锚点 |
| 3 | F04 提醒载体 | **页内提醒卡 + 导航红点**（`/allocation` 顶部提醒卡 + 导航「配置」入口红点）；无邮件/推送（SMTP 属 MS-15），不建全局提醒中心 |
| 4 | F05 计算输入 | **自动取 M08 持仓聚合**（权益+现金，与偏离度同源），不做手动输入/假设总额模拟 |
| 5 | F03 交互形态 | **页内 ⭐ + 自选标签页**：筛选结果行加 ⭐ 一键加入；`/screener` 加「自选」tab（含手动搜索添加）；未登录点 ⭐ 引导登录 |
| 6 | F04(M09) 导出 | **后端同源导出**：`GET /api/screening/stocks/export` 复用筛选 SQL 与缓存，UTF-8+BOM 中文表头，公开（与页面一致） |
| 7 | F05(M09) 成分股数据 | **collector 拉取落库**（既有 `index_constituent` 表 + 180 天全量刷新任务已在线，本特性纯消费；模块文档「内置静态表」口径随之修正） |
| 8 | F05(M09) 指数范围 | **沪深300 + 中证500，单选**：筛选表单加「指数范围」下拉（全部/沪深300/中证500），不做多选并集 |
| 9 | 再平衡架构 | **读侧即时计算**：提醒状态为纯函数（方案×持仓×频率×锚点×今天），请求时算；零调度、零提醒落库（方案 A） |
| 10 | 自选归属 | **domain/screening 域内扩展 + 独立路径 `/api/watchlist`**：不在公开端点清单即默认需登录，零安全配置改动（方案 A） |

**关键口径随设计定稿**（详见 [02-design](../02-design/设计规格说明.md)）：锚点一列两用（激活方案即视为一次配置确认，重置锚点）；新方案频率默认 OFF（阈值触发不受此开关控制，无条件生效）；空组合（总资产=0）抑制全部提醒与金额建议。

## 三、功能需求

### A. 再平衡提醒（M07-F04）

- **阈值触发**：任一资产类别 `|实际占比 − 目标占比| ≥ 5pp` 触发，提醒明示超限类别与偏离值。
- **时间触发**：方案频率 ∈ {季度(90 自然日), 半年(180 自然日)} 且 `今天 − 锚点日 ≥ 周期` 触发，提醒明示到期天数。
- **提醒展示**：`/allocation` 页内提醒卡（触发原因明细）+ 导航「配置」入口红点（有任一触发即亮）。
- **提醒状态请求时计算**，不落库、不调度；「已完成再平衡」ack 写锚点时间（幂等）。

### B. 再平衡金额计算（M07-F05）

- 对生效方案逐资产类别输出：目标占比/实际占比/偏离(pp)/**目标金额/当前金额/建议金额**（建议 = 目标 − 当前，正数买入、负数卖出，Σ建议 ≡ 0 总额守恒）。
- 总盘子 T = 权益市值 + 账户现金（M08 聚合，与偏离度同源）；债券/黄金/REITs 持仓侧恒 0（沿用 MS-04 口径，页面标注「需场外配置，系统不可见」）。
- 方案编辑支持设置再平衡频率（关闭/季度/半年）。

### C. 自选观察列表（M09-F03）

- 筛选结果每行 ⭐ 一键加入自选（未登录引导登录；重复添加幂等）；自选列表独立 tab 展示。
- 手动搜索添加：代码/名称模糊搜索（候选来自最新估值快照），选中添加。
- 自选列表展示：代码/名称/行业/**实时现价**/PE/PB/股息率/总市值/添加时间/移除按钮（快照收盘口径与实时价混合，页面标注）。
- 上限 100 只/用户；按登录用户隔离。

### D. 结果导出 CSV（M09-F04）

- 「导出 CSV」按钮：按**当前筛选条件（含指数范围）与排序**导出全量结果（上限同 200）。
- 格式：UTF-8 + BOM、中文表头、列 = **代码 + 结果表 13 列**（代码为唯一键，供线下关联分析；结果表现有 13 列无代码列）；文件名含时间戳；浏览器原生下载。
- 与页面结果同源（复用同一查询与缓存），口径必然一致。

### E. 指数成分股范围限制（M09-F05）

- 筛选表单加「指数范围」下拉：全部 / 沪深300（000300）/ 中证500（000905），单选。
- 限定后筛选范围 = 该指数成分股（`index_constituent` 表，collector 每 180 天全量刷新）。
- 单独选指数（无其他条件）= 浏览该指数成分股排行，属合法查询；结果区标注当前范围与成分股刷新口径。

## 四、非功能需求（NFR）

| 类别 | 要求 |
|------|------|
| 计算正确性 | 提醒触发逻辑为纯函数、已知答案单测覆盖（里程碑验收标准原文）；金额建议满足 Σ建议 ≡ 0 守恒断言 |
| 一致性 | 再平衡与偏离度同一持仓聚合链路（不二次取数）；导出与页面同一查询与缓存 |
| 安全 | `/api/watchlist` 需登录、按用户隔离；`/api/screening/stocks/export`、`/api/screening/stocks/search` 公开只读 |
| 性能 | 自选现价一次批量行情调用（≤100 只）；导出复用 5min 条件缓存，不为导出单独加压 |
| 覆盖率 | 后端 JaCoCo / 前端 V8 ≥80%，`make test` 通过 |
| e2e | Playwright 覆盖：再平衡提醒→ack 全链路、⭐加自选/移除、指数限定、CSV 下载断言 |

## 五、验收标准（沿用产品落地计划 MS-08）

1. **偏离度计算与买卖金额建议抽验正确**（含 Σ守恒、BOND/GOLD/REITS 恒 0 建议买入口径）；
2. **提醒触发逻辑有测试覆盖**（5pp/90 天/180 天边界、空组合抑制、无方案空态）；
3. 自选加/查/删/搜索/上限/用户隔离行为正确；
4. 导出 CSV 与页面同源一致（BOM/表头/转义/空结果仅表头）；
5. 指数限定后结果 ⊆ 成分股集合（集成抽验）；
6. `make test`（≥80%）+ Playwright e2e 全绿；`make smoke` 无新增段（无新外部数据源，口径同 MS-07）。

## 六、明确不做（YAGNI）

- **提醒落库与调度**（提醒记录表/已读状态/定时扫描/邮件推送）——读侧纯函数已满足，推送属 MS-15 SMTP 决策后；
- **全局提醒中心**（铃铛/下拉/跨模块提醒聚合）；
- **手动输入/假设总额模拟**的再平衡计算；
- **中证800/上证50/多选并集**的指数范围（表内虽有多指数数据，产品白名单先取 300/500）;
- **自选分组/备注/排序/批量操作**（单列表 + 添加时间倒序）；
- **自选价格预警**（盯价提醒是另一功能域）；
- **导出格式扩展**（Excel/JSON）与异步大导出；
- **AI 工具接入**（M05-F08/F09/F10 属 MS-12）；
- **导航红点跨页实时刷新**（挂载拉一次 + allocation 页操作后事件通知，不做轮询/推送）。

## 七、依赖与风险

| 事项 | 影响 | 对策 |
|------|------|------|
| `index_constituent` 表数据存在性 | F05 限定与 e2e 断言依赖库内有成分股 | 任务已在线（180 天刷新），dev 环境跑一次 `make collector-backfill` 或 seed 兜底；空表时下拉给出「数据未就绪」提示 |
| 反代 relay 未透传 `Content-Disposition`（已核实 `frontend/lib/proxy.ts:50-64`） | CSV 经 Next 反代下载丢 attachment 头 | relay 补透传该头（对 JSON 端点无影响） |
| 现价缺失（停牌/退市） | 自选现价列空 | 显示「—」，不影响其余列与导出（导出不含现价列，保持快照口径） |
| 存量生效方案无锚点 | 时间提醒起算点缺失 | V14 迁移回填 `last_rebalanced_at = now()`（迁移日为基线） |
| 权重精度 | 金额守恒受 BigDecimal 舍入影响 | 统一 BigDecimal（元，2 位小数）舍入；守恒断言容差 ±0.01 元 |

## 附：术语

- **锚点日（anchor）**：`last_rebalanced_at`，时间提醒的起算点；激活方案或 ack「已完成再平衡」时重置（一列两用）；
- **5pp**：5 个百分点（percentage point），绝对偏离单位；
- **建议金额（suggested amount）**：`目标金额 − 当前金额`，正数买入、负数卖出；
- **自选（watchlist）**：登录用户的观察股票列表，与持仓（M08）互不依赖；
- **成分股（constituent）**：指数成分股票，`index_constituent` 表每 180 天全量刷新（tushare index_weight 最新生效权重）。
