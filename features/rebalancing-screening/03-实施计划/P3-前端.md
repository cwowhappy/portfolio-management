# MS-08 P3 前端 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付前端四处——`/allocation` RebalanceCard（提醒横幅 + 金额建议表 + ack）与导航红点、PlanEditor 频率下拉、`/screener` ⭐/自选标签页/搜索添加/导出按钮/指数范围下拉、反代透传 Content-Disposition。

**Architecture:** 全部沿用既有模式：`useState/useEffect`（无 react-query）、`lib/http.ts request<T>` + zod 边界校验、按域 API 客户端（`lib/allocationApi.ts` 等）、Next 同源反代（`app/api/<域>/[...path]/route.ts` → `lib/proxy.ts relay`）；导出用 `<a href>` 直连反代触发浏览器原生下载（**不走** request 的 zod JSON 链路）；导航红点用 `useAuth().user` 判登录态 + 自定义事件刷新（无轮询）。

**Tech Stack:** Next.js 15 App Router + React 19、zod、Vitest + Testing Library（V8 覆盖率 ≥80%）。

**Spec:** [需求规格说明](../01-需求规格/需求规格说明.md) | [设计规格说明](../02-设计规格/设计规格说明.md)——本计划从 spec 论证，执行者须两者都读。后端契约见 P1/P2 的 Produces。

## Global Constraints

- 前端 V8 语句/分支覆盖率 ≥80%（`make test-frontend`）；新组件必须有组件测试（对照 `tests/AllocationBoard.test.tsx` 的 vi.mock API 模式）。
- 不引入 SWR/React Query/新依赖；API 一律经同源反代路径（`/api/...`），不直连 `:8080`。
- zod schema 与后端 record 字段一一对应（Instant → `z.string()`，BigDecimal → `z.number()`，可空字段 `.nullable()`）。
- 登录态用 `useAuth().user`（`frontend/lib/auth.tsx`，AuthProvider 挂载时已拉 `/api/auth/me`）；未登录写操作引导 `/login?redirect=/screener`。
- 金额显示：建议金额用 `toLocaleString("zh-CN", { maximumFractionDigits: 0 })`；正数绿「买入 +2,500」、负数红「卖出 −7,500」（`var(--color-up)`/`var(--color-down)`）。
- 每任务以提交结尾；commit scope `frontend` 或对应域（`feat(frontend): …`）。

```tsx
 *  rebalance-refresh 事件通知重拉。未登录/失败静默（不打扰匿名浏览）。 */
export default function AllocationAlertDot() {
  const { user, loading } = useAuth();
  const [alert, setAlert] = useState(false);

  const refresh = useCallback(() => {
    fetchRebalance()
      .then((v) => setAlert(v.anyAlert))
      .catch(() => setAlert(false)); // 401/网络异常静默
  }, []);

  useEffect(() => {
    if (loading) return;
    if (!user) return; // 未登录不请求
    refresh();
    window.addEventListener("rebalance-refresh", refresh);
    return () => window.removeEventListener("rebalance-refresh", refresh);
  }, [user, loading, refresh]);

  if (!alert) return null;
  return <span data-testid="allocation-alert-dot"
    aria-label="配置提醒" className="absolute -top-0.5 -right-1 h-2 w-2 rounded-full bg-[color:var(--color-down)]" />;
}
```
