# MS-10 数据源替代裁决（方案 A）· 工作简报

> 创建：2026-09-26 | 分支：`feature/ms10-datasource-alternative`
> 背景：天眼查 API 成本太贵（个人项目预算不可持续），MS-10（行业研究·未上市与竞争格局，5 点 + 随行 M10-F11）自 2026-09-23 方案 C 裁决移三期后一直被采购决策阻塞。
> 本文是**裁决记录与冷启动交接简报**：替代方案调研结论、方案 A 定稿口径、文档变更清单与 MS-10 启动时的实施要点。

## 一、裁决结论

**天眼查 API 出局，MS-10 改用方案 A「公开流采集 + 人工策展」（0 元），采购前置解除、里程碑立即解锁。**

用户约束（2026-09-26 澄清）：

| 约束 | 结论 |
|---|---|
| 预算 | 先看方案再定 → 方案 A 0 元启动，付费增强不采购 |
| 数据深度 | 轻量即可（企业名单+行业归属+融资轮次）；工商全字段（法人/股东/专利/诉讼）不要 |
| 合规边界 | 可爬公开网页（频率克制、ToS 风险留痕）；官方公示系统仅低频人工单查 |

## 三、调研纪要（2026-09-26，替代渠道核实）

> 价格为检索时点公开信息；「未查到公开报价」处均已给出可查线索。完整来源见 §五。

### 3.1 低价商业企业信息 API

| 渠道 | 覆盖 | 价格 | 结论 |
|---|---|---|---|
| **天眼查**（基线） | 工商/股东/司法（2.5 亿条）最厚 | ≈0.15 元/次起，组合包 1.0–1.5 元/次；包年 1500 元/万次（explinks 2024-07）；无免费试用 | **出局**：绝对价不高但组合包计费下未上市画像全字段年成本数千元量级 |
| **企查查开放平台** | 工商 3.5 亿实体/300+ 维度（股东/司法/知产/经营异常） | **0.10 元/次（官方挂牌，openapi.qcc.com）**，套餐 1000 元/万次；约 20 次免费试用 | 唯一低价正规 API，留作可选增强 |
| 启信宝 | 股权穿透 12 层最深 | 未查到公开报价（线索 0.015 元/次出自推广性横评，未证实） | 不采信，如需再询价 |
| 爱企查（百度） | C 端查询能力同级 | **无官方 API**（2023 年起即无入口）；SVIP ≈49 元/月 | 仅网页人工核对渠道 |
| 鲸海数据（小厂） | 工商/司法/知产 | 0.05 元/次、1000 次免费（出自推广性横评） | 数据合法性与存续未验证，仅 POC 备选 |

### 3.2 创投/融资数据

- **IT桔子**：无公开 API（正式授权走商务定制）；网页融资事件列表部分免费可见；个人 VIP 有 7 天/30 天/1 年档（年费未查到公开报价，会员页需登录）→ 只用公开页，不买会员。
- **烯牛数据**：请求加密+返回解密、反爬强，不爬；其月度行业投融资观察报告免费公开。
- **鲸准**：并入海尔海创汇，To B 订阅，个人不友好。
- **东财/同花顺/雪球**：免费端均无一级市场融资板块（创投数据在付费 Choice 终端内）——此路不通。
- **免费可用**：创业邦·睿兽分析每月公开发布《中国一级市场融资事件统计》（如 2025-04 全国 632 起）；36氪、投资界（pedaily.cn）、IT桔子公开页融资新闻流。

### 3.3 免费/官方渠道

- **国家企业信用信息公示系统（gsxt.gov.cn）**：官方权威、免费，但**无 API 无开放数据**；极验滑块/点选验证码+JS 混淆+IP 封锁，程序化高频爬取与数安法/网安法冲突 → **仅低频人工单查 + 政府信息公开申请**。
- **国家知识产权局（CNIPA）**：专利检索系统（PSS）免费注册、检索结果批量下载（单批 ≤2 万件）；IPDPS 实名后 FTP 全量；商标有批量下载+开放接口 → 专利/商标计数有免费正规解，按需人工核对。
- **akshare/tushare**：已核对 akshare 全目录（1000+ 接口）——**无企业工商、无创投融资接口**；tushare `stock_company` 仅上市公司工商照面 → 免费库无未上市数据这条路不存在。
- **行业企业总量**：市场监管总局季度/年度经营主体统计 + 国家统计局/地方统计年鉴分行业单位数（免费官方）− 上市公司数 = 未上市企业数估算。

### 3.4 关键合规口径

- 公开新闻流（睿兽分析/36氪/投资界/IT桔子公开页）采集：月更低频、单源并发克制、ToS 风险留痕——在用户「可爬公开网页」边界内。
- gsxt/商业平台（天眼查/企查查/烯牛）程序化爬取：对抗反爬+违反平台协议+数安法三重风险，不做。
- 企查查若启用：走官方开放平台计费调用，一次查询永久缓存，不重复消耗。

## 五、MS-10 启动时实施要点（提示，非定稿）

1. **数据面先行**：策展名单（头部企业）+ 产业链映射的维护机制（种子数据先行，YAML/CSV 或管理入口在设计规格阶段定）；融资事件表 Flyway 迁移（V19+）。
2. **collector**：融资新闻流采集任务（月更，2–3 公开源，频率克制+来源标注）；行业全景官方统计走内置静态数据人工更新，不做采集。
3. **读侧**：`domain/industry` 扩展或新域按 DDD 规格定（`PackageConventionsTest` 登记）；估算/非全量两处口径必须在页面与 API 显式标注。
4. **企查查可选增强**：接口位预留、默认关闭；配置缺失时全功能可用（Feature Flag 式）。
5. **验收口径**：行业全景/格局图以库内+策展数据正确渲染；融资事件带来源与非全量标注；「未上市企业财务数据非公开」边界标注保留；无任何付费配置时功能完整。
