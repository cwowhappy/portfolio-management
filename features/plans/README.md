# plans · 跨特性工程计划

> 不属于任何单一特性的**一次性工程战役**实施计划：测试体系加固、跨端 CodeReview 修复、行情主源切换、文档体系更新、跨域 issue 批量跟进等。落位判据与目录规范见 [features/README.md](../README.md)。

## 约定

- 命名：`YYYY-MM-DD-<主题>.md`（日期为计划落盘日）。
- **头部状态行必填**（对齐特性目录索引三态格式）：
  - `状态：进行中`——冷启动交接类简报可另注「按此继续」；
  - `状态：已完成（YYYY-MM-DD，PR #N）`——PR 合并日回填；checkbox 模板的计划顺带勾框，或注明「任务框未回填，实际全量交付见 PR」；
  - `状态：已取代 / 已取消（一句话去向）`——裁决前提被后续方案取代时用；正文不删改（历史保真），仅头部注记。
- **索引登记**：新计划落盘与交付回填时同步更新下表。
- **归档**：已完成的计划原位保留，靠状态行 + 索引分流；待目录超约 20 份或跨年再议 `archive/`。
- 格式不强制统一（散文式 / superpowers checkbox 式均可），状态行是唯一硬要求。
