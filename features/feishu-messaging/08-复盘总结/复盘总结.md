## 教训与执行注记

1. **外部 API 契约不能按 HTTP 语义直觉假设**（P0 终审 Important-1）：飞书受理失败仍返回 HTTP 200、错误在 body code——不校验即告警静默丢失。属「上游契约与文档/直觉不符」复发模式的飞书实例（dev-process-lessons 复发榜 #8 族）。
2. **Gradle UP-TO-DATE 对 env 门控测试假绿**（P1 实测发现）：`--rerun` 写回计划 Task 6——本仓库该陷阱首例，后经 MS-09/11 复发并固化为「全新证据」收口口径。
3. **修复波也要跑 lint**：P0 `test_alerts` 折行漂移 ruff format 回正（语义零变化，全量格式门会拦）。
4. **验收替代方案要显式声明**：P0 未做 runner 级真实失败实测（CLI 路径不装配告警器），以「生产路径直接实发 + runner 接线单测」组合等效，验证记录中注明理由。
5. **已知 flaky 当期未根治**：frontend ThreadArea 审批横幅断言（PR #72 CI 一次红、rerun 即绿），留台账。
