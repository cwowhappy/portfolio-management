# 飞书接入方式与账号现状（P0 冒烟 / P1 前置操作指引）

- **日期**：2026-09-27（真实端点实测 + 官方文档枚举对照，非转述）
- **背景**：现有自建应用凭证（App ID/Secret）但没有群自定义机器人 webhook，需澄清两种接入方式的关系与各自缺口

## 一、两种接入方式对照

| 维度 | 群自定义机器人（webhook） | 自建应用机器人（API） |
|---|---|---|
| 凭证 | webhook URL（+可选签名 secret）——**只能在客户端群设置里创建，与 App ID/Secret 互不相通** | App ID + App Secret → tenant_access_token（≤2h 自动续） |
| 获取入口 | 飞书客户端：目标群 → 设置 → 群机器人 → 添加 → 自定义机器人 | 开放平台 open.feishu.cn/app（已建：**证券投资助手**） |
| 方向 | **只能发**（text/post/image/卡片），不能收消息、按钮仅跳 URL | 双向：`im/v1/messages` 发（open_id 单聊 / chat_id 群）+ 事件**长连接**收（仅自建应用，免公网入站） |
| 频控 | 100 条/分钟 + 5 条/秒 | App 50 QPS / 1000 每分钟；单用户/单群 5 QPS |
| 安全 | 关键词(≤10)/IP 白名单(≤10)/HMAC-SHA256 签名 | 权限 scope + token；事件长连接建连即鉴权 |
| 本项目用途 | **P0** collector 采集告警（现实现 `FeishuAlerter`） | **P1** 原则预警推送 + **P2** 飞书对话 |

> 关键澄清：**App ID/Secret 换不来 webhook URL**。P0 的 collector 告警通道必须在飞书客户端群里创建自定义机器人；App 凭证服务于 P1/P2。

## 二、当前账号实测状态（2026-09-27）

| 项 | 状态 | 依据 |
|---|---|---|
| tenant_access_token | ✅ 凭证有效 | `auth/v3/tenant_access_token/internal` → code:0 |
| 机器人能力 | ✅ 已开启且**租户启用** | `bot/v3/info` → code:0；`activate_status=2`（官方枚举：2=租户启用） |
| 应用名 | 证券投资助手 | 同上（`app_name`） |
| im:message 发送权限 | ❓ 未验证 | 需后台「权限管理」开通并随版本生效；未开通时调用发消息接口会返回权限错误码 |
| 发送目标（open_id/chat_id） | ❌ 缺 | 机器人尚未被拉入任何群；用户 open_id 未采集 |
| 群自定义机器人 webhook | ❌ 未创建 | P0 现实现必需 |

## 三、三个场景各缺什么

| 场景 | 缺口 | 备注 |
|---|---|---|
| **P0 采集告警** | 群自定义机器人 webhook + 签名 secret（客户端 30 秒创建，见 §四.1） | 备选"改造 FeishuAlerter 走自建应用 API"= 范围变更，不推荐：告警链路独立性（backend/应用故障时照发）是方案 A 的核心理由，且 collector 得引入 token 管理 |
| **P1 原则预警** | ① 开通 im:message 类权限并发布版本（自审）② 把「证券投资助手」拉入告警群拿 chat_id（或取 open_id 走单聊） | 见 §四.2；chat_id/open_id 进 `invest.im.*`（P1 实现时接线） |
| **P2 飞书对话** | P1 基础上 + 事件订阅（长连接模式）+ `im.message.receive_v1` 权限 + owner open_id 白名单 | 3 秒事件时限 → 异步 ack + message_id 幂等（需求规格 FR-C3） |

## 四、操作指引（人工步骤）

### 1. 创建群自定义机器人（P0 冒烟必经）

1. 飞书客户端打开目标群 → 右上角「…」→ **设置** → **群机器人**
2. **添加机器人** → **自定义机器人** → 名称随意（如「采集告警」）
3. 安全设置选**签名校验**（记下密钥）
4. 完成后复制 **Webhook 地址**
5. 两者填 `.env`：`FEISHU_BOT_WEBHOOK` / `FEISHU_BOT_SECRET` → 重启 collector

> 若群设置里没有「群机器人」入口：确认非话题群；组织策略可由管理员（本人）在管理后台放开。

### 2. 自建应用权限与发版（P1 前置，可与 P0 并行）

1. open.feishu.cn/app → 证券投资助手 → **权限管理** → 开通 `im:message`（或 `im:message:send_as_bot`）
2. **版本管理与发布** → 创建版本 → 申请线上发布 → 管理员（本人）自审通过（自建应用免飞书官方审核；测试版免发布自动生效但仅管理员可见）
3. 群设置 → 群机器人 → 添加 → 选「**证券投资助手**」；群设置页复制 **chat_id**（客户端 ≥7.60 可直接看，或 API 调试台一键复制）
4. （可选单聊推送）API 调试台或通讯录接口取本人 **open_id**

## 五、安全注记

- App Secret 已进会话记录与本机 `.env`（git-ignored）：**配置就绪后在后台轮换**；webhook secret 泄露同理可直接重建机器人
- 凭证永不入 git（`.env.example` 只留空模板，NFR-4）
