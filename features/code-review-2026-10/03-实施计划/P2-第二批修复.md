## Review Focus（五类最易咬人的输入/失效模式——对应任务卡内测试已逐条锚定）

1. **并发双写**：同组并发买不同股票（B3）、并发同码验码（B8）、并发激活（B6）、flush 乱序完成（F3）——断言「恰一成功」而非「都不错」；
2. **注入类输入**：LIKE 通配符 `%`/`_`（B7）、`javascript:`/`http:` 外链（F4）、反代 `%2F`/`%3F`/`..` 段（F5）——断言拒绝形态与正常路径不回退；
3. **空数据/无命中边界**：备源节假日空帧（C5）、未映射且无报价持仓（B4）、深链 `?code=` 无命中（F1）、预检接口失败降级（F7）——断言静默安全而非报错；
4. **时钟/时区**：Clock 注入后时间字段可控（B12）、reaper cutoff 边界（C2）、TTL 缓存过期与事件失效（B9）——断言用注入时钟，禁真实 sleep；
5. **降级链自身失效**：邮件通道也未配置时仅 ERROR 不抛（B13/C6）、告警抑制不吞不同错误（C3）、降级发生在 primary 内部重试耗尽之后（#8）——断言链路尽头行为确定。
