4. **B4 parseAsOf**：`agent/trust` 公有静态方法单实现；ConfidenceScorer 与 ReportWorkflowOrchestrator 直引；解析阶梯只存在一份。
5. **B5 @Modifying**：逐条出具结论（补注解 or 加注释），结论写进 commit message；补 clearAutomatically 的条目必须带回归测试。
