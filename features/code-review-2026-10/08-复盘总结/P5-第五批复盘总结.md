## 2. 关键事件：验证波三连抓 bug（方法论沉淀）

统一验证波连续三批抓到执行代理自验（javac/单点测试，纪律禁 Gradle 全量）无法覆盖的问题：

| 批次 | 抓出的问题 | 特征 |
|---|---|---|
| P3 | 两处 ArchUnit 循环（agent↔tools、application↔infrastructure） | 结构规则，javac 不可见 |
| P4 | `NODE_DATA_ITEMS="Data"` 误用于财务接口（实为小写 `data`） | 常量名相近误用，单测覆盖后转绿 |
| P5 | eval 报告 JSON 模板 `"%s"` 引号误用（非法 JSON） | 字符串拼接正确性，只有真跑测试才可见 |

**结论：「行为等价」声明必须以全量测试通过为最终证据**；代理自验口径（javac + 定点测试）对结构规则、常量误用、模板拼接三类问题系统性失明。此条已体现于各批计划的「统一验证波」纪律，值得继续固化。

## 3. 专项决策记录

1. **L2-二期不复用 Raw\***：新浪/腾讯帧与东财有 3 处可观测语义差异（无效价格文案/时间带秒/成交量固定换算），路由进 Raw 组合必改行为——整体解析下沉直接构造 DTO 是正确取舍。
2. **MarketDataSource 端口签名零改动**：实测改签名波及 6 文件（触发退化条件），但 fetch/parse 分离形态下对称加端口即可达成目标，退化反而留残知识。
3. **包体积门槛不修订**：240KB 依据链三环完整（基线实测文档 → 门槛 commit → 规范 §9.3），10% 余量对「树摇回归探测器」用途合理；234KB 持平 20 天无续涨。
4. **glue 单例场景状态重置**：EvalRunSteps 新增实例字段在 Spring 单例 glue 上属模式缺口，@Before 重置与 MockResetHooks 同口径加固。
