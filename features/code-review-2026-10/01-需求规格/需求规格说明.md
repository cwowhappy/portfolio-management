> 性质：跨里程碑工程项（同 collector-design-optimize / agent-testing 先例），归属模块 M14 系统与工程，无页面/路由。

## 1. 背景与目标

2026-10-04 对系统做五路并行全量审查（对话内核 / 后端核心业务域 / 新交付域 MS-20~27 与认证安全 / 前端 / 采集与工程质量），产出 9 项 P1（四簇：金融计算边界、多写端并发、MCP 客户端生命周期、认证面硬化）+ 约 20 项 P2 + 约 20 项 P3。

**本特性目标：第一批 8 项 P1 + 1 项顺手 P2 全部修复落地，全量 `make test` 三端收口。** P2 第二批与 P3 打磨项不在本特性范围。

## 3. 功能需求

- **FR-1（B1）**：非交易日外部流（转入/转出）不得计为收益；TWR 累计、MDD/夏普基底、年度收益三处同口径修复。验收：周六转入 10 万手算已知答案测试（期间无涨跌则 TWR≈0）。
- **FR-2（B2）**：5 处输入框（对话 Composer / 情报关键词 / 情报标的搜索 / 重置密码弹窗 / 绑定邮箱弹窗）IME 组合中 Enter 不提交、不 preventDefault。
- **FR-3（B3）**：管理员轮换 MCP token 后无需重启即生效；挂死端点的 listTools 在 toolTimeout 内抛超时；poolMaxSize 从配置面移除。
- **FR-4（B4）**：同一 username 连续 5 次登录失败锁 5 分钟，锁内正确密码也 429 + Retry-After；成功登录清零；不同用户互不影响。
- **FR-5（B5）**：reset-code 对 不存在/管理员/未绑邮箱/停用 返回逐字节一致的中性文案且不发信；reset-password 不可找回标识与错码同文案。
- **FR-6（B6）**：PUT /messages 携带过期 If-Match → 409 且服务端消息零改动；GET 响应含 updatedAt；前端并发写最终落库为并集（多标签页不互删）。
- **FR-7（B7）**：非白名单主机（含内网 IP/域名）与 http URL 在发起请求前拒绝；302 到白名单外主机拒绝；白名单主机正常抓取回归。
- **FR-8（B8）**：status 响应不含 baseUrl 与异常 message；key 未配置时 keyConfigured=false。
- **FR-9（B9）**：editTrade 日期晚于今日 → 400 INVALID_INPUT（与其他写路径同 errorCode）。

## 4. 非功能需求

- **NFR-1**：严格 TDD——每条修复先写失败测试并确认红（错因正确），再最小实现转绿；行为断言而非实现断言。
- **NFR-2**：覆盖率门槛不破——后端 JaCoCo / 前端 V8 / collector pytest 三端 ≥80% 由全量 `make test` 收口验证，禁止 `| tail` 吞退出码。
- **NFR-3**：架构约束不破——修复不得引入新的跨层依赖（B3 用 Spring 事件保持 application→agent 单向，ArchUnit 不改白名单）。
- **NFR-4**：契约变更全链路同步——README 端点表、模块文档 03-接口设计、e2e 断言、前端 zod schema 同分支更新。
- **NFR-5**：修复并行执行按目录隔离分工，禁止跨区改文件；后端串行（共享 Gradle 构建目录）。

## 5. 验收标准

1. `make test` 三端 EXIT=0（后端 BUILD SUCCESSFUL 含 JaCoCo 门槛 / 前端 129 文件 + lint 零 error / collector pytest ≥80%）。
2. 每个 FR 至少一条先红后绿的测试证据（见 08-复盘总结 的 TDD 符合性清单）。
3. `grep poolMaxSize` 全仓（代码/.env.example/docs）零引用。
4. e2e `conversation.spec.ts` 的 PUT 断言适配新契约（204→200）。

## 6. 明确不做（YAGNI）

- 审查 P2 第二批（重置密码吊销 JSESSIONID、deletePosition 级联确认、analytics N+1、collector reaper/告警抑制/依赖编排、深链断裂、safeUrl、反代编码等）——另行计划。
- 审查 P3 打磨项（虚拟化、aria-live、移动端顶栏、a11y、HSTS 等约 20 项）——随特性迭代捎带。
- reset-code 发信耗时侧信道的人工延迟对齐（低危，成本大于收益）。
- 前端 PUT 强制携带 If-Match（本批为「放行 + 渐进接入」，前端已实际发送，后端保持可选兼容）。
