> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 交付 M15-F15~F18——`/intelligence` 工作台（四 tab：新闻流/公告流/政策库/简报归档，服务端分页过滤 + 双空态）、订阅设置页（推送开关/标的/行业 + 飞书绑定码 UI）、标的情报聚合与三处互跳、简报归档检索；**M16-F11 回接收口**（项目开关端点与 UI、journal 留痕激活）；简报个性化推送升级（open_id 单发 + 「你关注的」附节 + 群兜底）；ADR-0013 回写与全量交付回填。

**Tech Stack:** 同前三册；前端 vitest + Playwright（`frontend/e2e/intelligence.spec.ts`）。

## Global Constraints

（承 P1~P3 全部。追加：）

- **前端纪律**：组件禁直接 fetch（走 `lib/http.ts request<T>` + zod 边界 safeParse + `app/api/intelligence/[...path]` 反代 relay）；页面 = 薄壳 + client 组件（照 app/industry/page.tsx 先例）；e2e 双态门控照 industry.spec（空库 skip + `.or()` 兜底）。
- **TanStack Table v9 陷阱**（若用表格）：`useTable` + `tableFeatures`（v8 `useReactTable` 不存在）；方法挂原型不可解构；数值列 `sortDescFirst:false`。本册列表用简单 div/table 即可，**不强制引入 TanStack**（YAGNI——列表无排序需求时）。
- **echarts 纪律**：若宏观趋势加图，`lib/echarts-setup.ts` 是唯一 `echarts.use()` 注册点，`EChart` 组件显式高度（v1 日历卡与列表**不引图表**，YAGNI）。
- **绑定码安全**：6 位数字、TTL 10 分钟、一次性（used_at 非空即拒）、open_id 已绑他人返回拒绝话术（D8）；生成冲突（PK 撞）重生成 ≤3 次。
- **回接收口语义**（决策 #26）：journal 留痕 title 前缀「【情报】」复用 `RESEARCH_EVENT`；项目开关默认开；union 查询零写入零清理。

## Review Focus

- 四区块同关键词并发切换 → 旧响应不覆盖新 tab（seq 守卫逐 tab 生效，不串台）。
- 分页参数越界（page=0/pageSize=9999）→ 后端夹紧 1..100 不炸，前端不白屏。
- 绑定码过期/已用/发错账号 → 各自明确话术，绝不绑定成功；解绑后旧 open_id 立即不再收推送。
- 未绑定用户简报 → 配置群统一版照发（群兜底不因个性化逻辑回归）；总开关关闭用户零推送（含公告与简报附节）。
- e2e 空库 CI → skip 门控生效不假红；有数据时四 tab 至少一个数据卡或空态卡可见（`.or()` 兜底）。
