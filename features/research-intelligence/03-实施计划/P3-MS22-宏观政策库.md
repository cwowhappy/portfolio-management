# 智能情报实施计划 P3 · MS-22：宏观政策库

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付 M15-F11~F14——宏观指标序列采集（CPI/PPI/PMI/LPR/社融，社融不稳自动降 M2 留痕）、四部委政策事件库（采集 + LLM 结构化：方向/力度/影响领域/低置信标注）、`macro_brief` 工具（指标现状 + 近期政策 + 数据截止期别）、宏观日历（静态种子 + 发布日提醒）。

**Architecture:** collector `MacroPageSource`（参数化每指标取数页）与 `PolicySiteSource`（参数化部委列表页）落 `intelligence_macro_series` / `intelligence_policy_raw`；backend `PolicyExtractionService`（每日 09:10）LLM 结构化落 `intelligence_policy_event`；`MacroHealthService`（08:05）按 D19 判社融连续 2 发布期失败 → `intelligence_source_switch` 留痕 + 一次性告警；`macro_brief` 挂 InvestTools（事实仅取本库，缺失显式声明）。国债收益率复用既有 `treasury_yield_curve` 任务与表，**不重复建**。

**Tech Stack:** 同 P1/P2（无新依赖——HTML 解析用 Python 标准库 `html.parser` 或已依赖的 pandas.read_html，以 collector 现有依赖清单为准，不新增三方库）。

**Spec:** [需求规格说明 v1.0](../01-需求规格/需求规格说明.md) F11~F14 + 决策 #12/#25；[设计规格说明 v1.0](../02-设计规格/设计规格说明.md) D19/D22/§6。

## Global Constraints

（承 P1/P2 全部。追加：）

- **macro_brief 事实纪律**（需求 F13/NFR 口径诚实）：指标数值与政策事件**必须来自本库结构化数据**，仅「市场含义」层可调 LLM；缺失项显式列出，结果必须带数据截止期别标注——工具测试必须覆盖「指标缺失不编造」。
- **社融降级口径**（决策 #25 + 设计 D19）：采集侧 selector 双源（socfin 主/M2 备）；留痕侧连续 2 发布期终态 failed → source_switch + 告警一次（状态变化才告警）；切换与回主为 selector 自动行为，backend 不改任务 enabled。
- **政策来源边界**（决策 #13）：仅央行/证监会/财政部/统计局四部委官网；领导活动/转载类由规则（标题关键词黑名单）+ LLM 过滤，误收录标低置信。

## Review Focus

- 统计局页面改版致解析失败 → 告警 + 人工适配（源抛 SourceError 走既有告警），历史数据不丢。
- 社融源连续两期失败 → M2 自动接管（selector）、source_switch 恰一行留痕、告警恰一次；源恢复后自动回社融且**不再告警**。
- 政策页非政策动态（领导活动/媒体转载）→ 不入库或低置信标注，不混入正常事件检索结果。
- CPI 停更/未发布 → macro_brief 显式列「CPI：最新 2026-08（9 月未发布）」，不编造不省略。
- LPR 日频（period=日）与 CPI 月频（period=月）混查 → 序列按 indicator+period_type 正确分组，不串行。
