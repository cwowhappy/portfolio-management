## 1. 东财 7×24 快讯（新闻主源）

### 1.1 请求样本

```bash
curl -s 'https://np-listapi.eastmoney.com/comm/web/getFastNewsList?client=web&biz=web_724&fastColumn=102&sortEnd=&pageSize=20&req_trace=1'
# 实测：HTTP 200，~0.15s。UA 无要求（curl 默认 UA 亦 200）；未触发频控（探测期 ~10 次）
# 参数：fastColumn=102（既定栏目值；实测传空/103 亦返回数据，沿用 102）
#       sortEnd 为翻页游标：首页传空，其后传上一响应的 data.sortEnd（向更旧方向翻页）
```

### 1.2 响应样本（实测原文截取，pageSize=5）

```json
{
  "req_trace": "1757431863044", "code": "1", "message": "success",
  "data": {
    "sortEnd": "1790642838057217", "index": 1, "total": 5000, "size": 5,
    "fastNewsList": [
      {
        "summary": "【锦波生物调整定增方案 养生堂新增10亿元增持承诺】9月28日晚，……",
        "code": "202609293885865083", "titleColor": 0, "realSort": "1790643189065083",
        "showTime": "2026-09-29 08:53:09", "title": "锦波生物调整定增方案 养生堂新增10亿元增持承诺",
        "share": 0, "pinglun_Num": 0, "stockList": ["150.161027", "0.920982"], "image": []
      }
    ]
  }
}
```

注意：`code` 顶层是接口状态码字符串 `"1"`（成功），与条目级 `code`（新闻唯一 id）重名，解析时勿混淆。

### 1.3 字段映射表（→ `intelligence_news_raw`）

| 响应字段 | 类型/样本 | 映射目标 | 说明 |
|---|---|---|---|
| `fastNewsList[].code` | `"202609293885865083"` | `external_id`（业务键之一，source=`eastmoney_724`） | 当日日期开头的唯一 id，实测无重复 |
| `fastNewsList[].title` | `"锦波生物调整定增方案…"` | `title` | summary 前缀【】内的短标题 |
| `fastNewsList[].summary` | `"【标题】正文…"` | `summary` | 全文（含【标题】前缀，入库可原样保留） |
| `fastNewsList[].showTime` | `"2026-09-29 08:53:09"` | `published_at` | 北京时间，无时区后缀，解析按 Asia/Shanghai |
| `fastNewsList[].stockList` | `["1.600825","0.920982","90.BK0437","150.161027"]` | `stock_tags`（原样 JSONB） | 前缀语义见下 |
| `fastNewsList[].realSort` | `"1790643189065083"` | —（游标用） | 16 位 **UTC 微秒时间戳**，与 showTime 一一对应（1790643189.065s = 当日 08:53:09+08:00） |
| `data.sortEnd` | `"1790641740049795"` | 翻页游标 | **恒等于本页末条 realSort** |
| `titleColor` / `share` / `pinglun_Num` / `image` | `0~3` / int / int / [] | 不采 | |

**stockList 前缀实测分布**（20 条样本 + 5 条样本合计）：`1.`=沪市个股（1.600825）、`0.`=深市/北交所个股（0.920982 锦波生物）、`90.BK`=东财板块/行业码（90.BK0437）、`150.`=基金（150.161027）。采集侧建议：`stock_tags` 原样入库；解析标签时仅取 `0./1.` 前缀且代码段匹配 A 股规则（`60/68/00/30/92` 开头 6 位）与 `90.BK` 行业码（与行业中心 BK 码同源），`150.` 基金忽略。**注意 `0.` 前缀段混有深市基金代码**（实测 0.161032 为 LOF），必须用代码正则过滤而非仅看前缀。

**详情 URL**：接口无 URL 字段。实测 `https://finance.eastmoney.com/a/{code}.html` 返回 200（`kuaixun.eastmoney.com/{code}.html` 为 404）。`url` 列按此模板拼接，跳转失败不阻塞（仅元数据）。

### 1.4 增量策略建议

- 常规增量（`news_fast` */10 分钟）：首页拉 `pageSize=20`、`sortEnd` 传空，按 `external_id` UPSERT 幂等去重；连续拉取至命中库内已存 id 即停（单轮最多翻 2~3 页足够覆盖 10 分钟间隔）。
- 历史回填（backfill）：以 `data.sortEnd` 为游标向更旧方向翻页。实测 3 页各 20 条**零重叠**、时间严格递减（08:53 → 07:41），游标语义可靠。
- `news_night` 低频档（0-6 点每 2 小时）：同款请求，间隔大时翻页至已见 id 为止。

### 1.5 稳定性风险

| 风险 | 实测依据 | 缓解 |
|---|---|---|
| 无独立 URL 字段，详情页模板可能变 | finance.eastmoney.com/a/{code}.html 现 200 | url 仅作回溯元数据，失败不告警 |
| stockList 前缀语义非官方文档 | 前缀分布由样本归纳 | 原样存 `stock_tags`，解析规则放插件常量可调 |
| 字段漂移（快讯无公告接口稳定） | 设计规格 §九-1 已列 | 沿 collector 既有告警 + 人工适配 |

### 2.3 字段映射表（→ `intelligence_news_raw`）与东财差集

| 新浪字段 | 映射目标 | 与东财差异 |
|---|---|---|
| `feed.list[].id` | `external_id`（source=`sina_zhibo`） | 整型自增；东财为日期字符串 |
| `feed.list[].rich_text` | `title` 取【】内段 + `summary` 取全文 | **无独立 title 字段**，需从 rich_text 剥离 |
| `feed.list[].create_time` | `published_at` | 字段名/格式同 showTime（北京时间无时区） |
| `ext`(JSON 字符串) → `stocks[]` | `stock_tags` | **藏在字符串内需二次解析**；结构 `{market, symbol, key}` |
| `feed.list[].docurl`（移动版）/ `ext.docurl`（www 版） | `url` | 东财无 URL 字段需拼接，新浪自带 |
| `feed.list[].tag[]` | 可入 summary 侧栏/不采 | 东财无栏目概念 |

**ext.stocks.market 实测分布**（100 条样本 179 个标的）：`cn`×55（A 股，symbol 形如 `sz002369`，key=中文名）、`fund`×56、`us`×45、`foreign`×31、`hk`×20、`commodity`×7、`global`×8、`globalbd`×6、`worldIndex`×7、`CFF`×8、`uk`×2、`sb`×1。**只取 `market=cn`**，symbol 去市场前缀得 6 位代码。**tag 栏目实测清单**：1=宏观、102=国际、3=公司、5=市场、6=观点、7=央行、8=其他、9=焦点。

### 2.4 增量策略建议

- 页码分页：`page=N` 递增，实测 page1/page2 **零重叠**且边界精确衔接（p1.min_id=5117469，p2.max_id=5117468）；`feed.max_id/min_id` 可用于校验翻页完整性。
- 增量轮次：`page=1` 起，按 `id` 降序拉至命中已存 id 即停；按 `(source, external_id)` UPSERT。

### 2.5 稳定性风险

| 风险 | 实测依据 | 缓解 |
|---|---|---|
| ext 为 JSON 字符串，解析失败会丢标的标签 | 样本结构固定 | 解析 try/except，失败置空数组不阻塞 |
| 历史上新浪接口偶发整点抽风（社区经验） | 本次探测全 200 | 它是备源：selector 东财失败才落此，恢复自动回主（D1/D2） |
| `is_delete/top_value` 等编辑态字段 | 实测样本均为 0 | 不采，忽略 |

## 3. 巨潮公告（公告主源，P2 前瞻）

### 3.1 请求样本

```bash
curl -s -X POST 'https://www.cninfo.com.cn/new/hisAnnouncement/query' \
  -H 'Content-Type: application/x-www-form-urlencoded; charset=UTF-8' \
  -H 'X-Requested-With: XMLHttpRequest' \
  -d 'pageNum=1&pageSize=30&column=szse&tabName=fulltext&stock=000858,gssz0000858&searchkey=&secid=&plate=sz&category=&trade=&seDate=2026-09-01~2026-09-29'
# 实测：HTTP 200，~0.17s。探测期累计 ~50 请求无频控封禁
```

**column/plate 三市场实测**（全市场口径，seDate=2026-09-26~2026-09-29）：

| column | plate | 返回 |
|---|---|---|
| `szse`（深） | `sz` | totalRecordNum=1246 |
| `sse`（沪） | `sh` | totalRecordNum=885 |
| `bj`（北交所） | `bj` | totalRecordNum=62 |

三市场合计 **2193 条**（窗口 2026-09-26~09-29 共 4 个自然日、含周末，粗估约 700+ 条/工作日）。**重要坑**：简报草案示例命令（沪股 600519 配 `column=szse&plate=sz`）返回 0 条——**column/plate 必须与股票所属市场一致**；且空结果 ≠ 参数错误（茅台 9 月恰无公告，7 月起有 7 条）。

**个股查询的 orgId 规则（实测关键发现）**：`stock` 参数必须精确 `"{code},{orgId}"`，**错/缺 orgId 静默返回 0 条**。orgId 是巨潮内部代理号、**前缀异构不可推导**，实测样本：

| 股票 | orgId | 出处 |
|---|---|---|
| 五粮液 000858（深） | `gssz0000858` | `new/data/szse_stock.json`（6258 只，公开可下） |
| 锦波生物 920982（北） | `gfbj0832982`（**旧码** 832982，非新 92xxxx） | `new/data/bj_stock.json`（601 只，公开可下） |
| 贵州茅台 600519（沪） | `gssh0600519` | topSearch 接口 |
| 工商银行 601398（沪） | `jjxt0000019`（同模式推导 gssh0601398 实测 **0 条**，错误） | topSearch 接口 |

沪市 orgId **无公开清单文件**（`sse_stock.json`/`sh_stock.json` 等 404），权威查询口为搜索联想接口：

```bash
curl -s -X POST 'https://www.cninfo.com.cn/new/information/topSearch/detailOfQuery' \
  -d 'keyWord=601398&maxSecNum=10&maxListNum=5'
# 返回 keyBoardList[]: {code, orgId, plate, zwjc, category, delisted}
# 实测 601398,jjxt0000019 回查 hisAnnouncement → 36 条，正确
```

**采集侧建议**：股票→orgId 映射表本地缓存（orgId 长期稳定），启动/日切时对自选+持仓池标的经 topSearch 补全，深/北可直接用两个 stock.json 全量清单。

### 3.5 增量策略建议

- 双源归并键（东财公告流 art_code 与巨潮 announcementId 不同源）：按 `(stock_code, published_at 日期, title)` 相似归并、以巨潮为法定准源（需求 F06 已裁，设计期归并键照此备案）。

## 4. 东财公告流（公告备源，补充探测）

```bash
curl -s 'https://np-anotice-stock.eastmoney.com/api/security/ann?sr=-1&page_size=20&page_index=1&ann_type=A&client_source=web&stock_list=600519&f_node=0&s_node=0'
# 实测 200。字段：art_code（唯一）/codes[]{stock_code,market_code,short_name}/columns[]{column_code,column_name 中文}
#        /notice_date(日)/display_time("2026-08-14 20:41:29:276" 毫秒精度)/title
```

- **f_node 一级栏目实测**：1=财务报告（报告全文/摘要/分配方案）、2=发行（首发）、3=含月度经营情况、4=治理（董事会/高管变动）、5=重大事项（借贷/投资/签订协议）、6=股本变动（**回购实施公告/回购进展情况**）、7=持股变动（**股东/实际控制人股份增持**）；8/9/10 茅台样本为空。
- **column_name 中文栏目词表**（全市场 100 条样本实测，节选）：`半年度报告全文/摘要`、`增发预案/增发提示性公告/增发终止`、`权益变动报告书`、`股权激励计划/摘要`、**`关联交易`**、`收购出售资产/股权`、`诉讼仲裁`、`停牌公告`、`分配方案实施`、`回购实施公告/回购进展情况`、`股东/实际控制人股份增持`、`首发招股说明书`、`月度经营情况`、`高管人员任职变动`、`管理办法/制度`、`保荐/核查意见`、`法律意见书` 等。
- 备源映射：column_name 含「报告全文/摘要」→PERIODIC_REPORT、「业绩预告」→EARNINGS_FORECAST、「业绩快报」→EARNINGS_FLASH、「增发/配股」→PLACEMENT、「股权激励」→EQUITY_INCENTIVE、「退市/风险警示」→DELISTING_RISK、「增持」→INCREASE_HOLD、「减持」→DECREASE_HOLD、「回购」→BUYBACK、「关联交易」→RELATED_TRANSACTION。
- 增量：`sr=-1` 首页翻页至已见 art_code；`stock_list` 支持多股逗号分隔。注意 `total_hits=50000` 为显示封顶值，勿当真实总量。

### 5.1 统计局数据发布页（CPI/PPI/PMI 主源）
