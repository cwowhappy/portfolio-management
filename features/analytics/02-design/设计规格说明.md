## 一、总体链路

```
collector（Python/tushare）                        backend（Spring）                    frontend（Next.js）
├─ stock_valuation_daily ──加 close 列──┐          domain/analytics（纯计算域）         /analytics 单页
├─ index_close 任务 ──→ index_close_history ──┐    ├─ 净值重建（流水×收盘价）           AnalyticsBoard
└─ 一次性回填脚本 ──────────────────────┤    ├── TWR / XIRR / 年度 / 交易统计      ├ OverviewCards
                                        ↓    ↓ │                                    ├ NavChart（EChart）
                              StockCloseAdapter / IndexCloseAdapter（读侧端口实现）  ├ AnnualTable
                                        ↑    ↑ │                                    └ TradeStatsCards
          portfolio 流水（Trade/Dividend/CashTransaction）+ MarketDataService（今日实时 quote）
```

- **读侧重算**：请求时从流水 + 收盘价历史现算净值与指标，零 analytics 落库表；交易回溯编辑天然正确。
- **今日值**：close 未落库的当日用 `MarketDataService.quoteBatch` 实时价补。

### 2.2 净值重建（NavReconstructor）

自用户首笔流水日起逐交易日 `t`（至今）：

- **持仓数量** `qty(stock, t)`：`tradeDate ≤ t` 的 BUY/SELL 与 `exDate ≤ t` 的送股（比例×数量）累积；当日卖出即减、当日买入即有——与 `Position.applyBuy/applySell/applyStockDividend` 镜像。
- **市值** `marketValue(t) = Σ qty × close(stock, t)`；close 缺失（停牌/回填未及）取最近前收盘；今日未落库用实时 quote。
- **现金** `cash(t) = Σ(转入−转出) + Σ卖出(价×量−fee) + Σ现金股息(每股现金×除息日数量) − Σ买入(价×量+fee)`，全部按 `≤t` 计。
- `totalValue(t) = marketValue + cash`；窗口起点前已有的存量持仓视作以首日收盘「期初建仓」。
- 序列日期 = 收盘价数据实际存在的交易日。

### 2.3 指标口径（纯函数，已知答案校验）

| 指标 | 定义 |
|------|------|
| TWR 累计 | 日频链接：`R_t = (V_t − F_t) / V_{t−1}`（`F_t` 为 t 日净外部转入，**日初到账**惯例——当日转入不参与当日收益）；累计 = `Π(1+R_t) − 1` |
| TWR 年化 | `(1+TWR累计)^(365/天数) − 1` |
| XIRR | 投资者视角现金流（出资 −、提现 +、终值 `+totalValue(今日)` +）ACT/365 贴现求 NPV=0；**二分法**，区间 [−0.999, 10]，容忍 1e-9，迭代上限 200；无外部现金流退化为累计收益率（响应标注口径） |
| 年度收益 | 年内日 TWR 几何链接；并列三基准同年收益与超额（组合−基准） |
| 交易统计 | 「单笔」= 每笔 SELL 的 `realizedPnl`（对加权平均成本，含分红降成本效应）；持有期 = 卖出日 − **数量加权平均买入日**（维护与 avgCost 同步滚动的加权买入日期状态）；胜率/盈亏比（平均盈利÷平均亏损绝对值）/平均持有天数/最佳最差单笔；未清仓不入 |

### 2.4 API（REST，`/api/analytics`）

| 端点 | 用途 | 返回 |
|------|------|------|
| `GET /overview` | 总览卡 | TWR 累计/年化、IRR、当前总资产、三基准同期收益与超额 |
| `GET /nav` | F04 走势图 | `totalValue` 绝对值日序列 + 三基准收盘序列（归一化留前端） |
| `GET /annual` | F05 年度表 | 年份 ×（组合、三基准、超额） |
| `GET /trade-stats` | F06 卡片 | §2.3 统计量 |

错误处理：无流水 → `NO_DATA`（204 语义沿 allocation 最新结果先例）；基准数据不足 → 序列截齐到可用窗口并在响应标注；错误码 `AnalyticsErrorCode` 常量类 + `GlobalExceptionHandler` 统一转 `ApiError`。

## 五、错误处理与降级

1. 无流水：`NO_DATA` / 204，前端空态引导去 `/portfolio` 录入；
2. 个股某日 close 缺失：forward-fill 最近前收盘；窗口首日即缺失则自首个可得日起算；
3. 基准窗口不一致：截到最晚起点，响应 `window` 字段标注；
4. 今日实时 quote 失败：序列止于昨日，响应标注（不阻断整页）；
5. 无外部现金流：TWR=简单收益、XIRR 退化累计收益，均标注口径。
