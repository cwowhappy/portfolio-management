## 6. eval 数据隔离专项评估（独立测试表方案）

**问题**：部署机无 Docker（发布方案 v1 明言），`EvalPostgresSupport` 硬依赖 Testcontainers（`EvalPostgresSupport.java:14-21`）不可用；候选「同库独立 schema」。

**有利事实**：
- eval datasource **单点注入**：`EvalRunner.java:120-124` 命令行参数（url/user/pass + hikari 5/1）；首跑曾因 properties 优先级被 application.yml 压掉而静默连本机 dev 库（:113-115 注释记录），故守卫断言 :136-139 硬绑定容器 URL——换方案须同步改。
- 全仓 65 表 DDL/JPA 实体/无命名序列**全部非 schema 限定**（49 个 @Table 零 schema=、IDENTITY 生成零 @SequenceGenerator、迁移无非限定名）→ URL `?currentSchema=eval_schema` 单旋钮即让 Flyway（自动迁移到新 schema，history 表随之）/JPA/JdbcTemplate 全落 eval schema，**生产上下文零改动**（连接级隔离，无角色级设置）。
- pg_trgm（V3:10）同库已装幂等零成本；独立 database 方案则须 trusted extension 可装（大概率可行需验证）。
- eval 上下文 Flyway 全量迁移建齐 65 表不可避免；当前流程实际写 4-5 张（app_user 直插 + mcp 三表 seed + skill_user_config 读）；conversation/chat_message 当前不写（AGUI 会话记忆是文件态 stateStore，state-root 已重定向）。
- 抽取轨（`ExtractionEvalRunner`）**完全无 DB**（import 无 Repository/JdbcTemplate，Model 直构）——定时化零数据库改造。

**发现的雷（持久化隔离方案共有）**：eval 起的是完整生产装配（`SpringApplicationBuilder().sources(InvestAgentApplication.class, ...)` `EvalRunner.java:117-119`）——`@EnableScheduling` + 全部 10 个 @Scheduled cron + `AdminSeedRunner`（读环境变量种管理员）在 eval 上下文活着。容器一次性时代看不见；持久 schema 后**新闻抽取批会在 eval 环境真调 LLM 外呼**、seeder 拿生产 env 写数据。→ 需求落死边界「eval 上下文禁一切生产副作用任务」（机制归设计规格：profile/条件装配/参数开关）。

**宿主形态结论**：
- 进程内第二 Spring 上下文障碍：`System.exit`（EvalRunner.main :49-52 / ExtractionEvalRunner :181-194）+ `run()` private；相对路径依赖（build/reports、build/eval-agent/state、EnvSupport.repoRoot 向上找 .env——部署机裸进程均不成立需参数化）；agentscope ModelRegistry 等库级静态双上下文互扰仓库内无法验证；双调度器问题同上。
- **bootJar 不含 eval 源集**（build.gradle 无 jar 定制，Boot 插件默认只打 main.output）——无论进程内/子进程都需动 build.gradle（eval 类进 bootJar / 挪 main / eval 发行物，设计规格定）。
- 子进程 = 单上下文，规避上述全部；@Scheduled 只任触发器 + 收割器（结果落库 + 告警）。

**方案对比**：

| 方案 | 改动面 | 结论 |
|---|---|---|
| A 同库独立 schema | datasource 单点改 + 守卫改 + EvalPostgresSupport 退役（41 行）+ 副作用任务禁用；一次性 `CREATE SCHEMA` | **采纳**（决策 #2） |
| B 独立 database | 同源但免 schema 参数；须验 pg_trgm trusted；多一库对象（备份/监控） | 次选 |
| C 保持 Testcontainers | 代码零改动，但部署机不可行，定时跑无法闭环 | 否 |

**伴生决策**：每轮 DROP-CREATE 重置（复原容器级干净度，AguiDriver 每题随机用户名后缀本不撞键，但重置免清理策略）；守卫断言改为指向 eval schema。
