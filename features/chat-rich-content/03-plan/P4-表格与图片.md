# 表格与图片（DataTable + markdown img 防御） 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `get_financials` 的 table 变体从降级折叠卡升级为 TanStack Table v9 交互表格（可排序 + sticky 表头）；react-markdown 图片/链接定制为防御性展示（懒加载、no-referrer、尺寸约束、https 门控）——FR-5/FR-6 收口。

**Architecture:** `components/chat/charts/DataTable.tsx`（headless useTable + 原生 sticky CSS，消费 `TableSpec`）；`ChartCard` 的 table 分支从降级卡换成 DataTable；`toolRenderers` 补注册 `get_financials`；`ThreadArea` 的 ReactMarkdown `components` 追加 img/a 定制 + `urlTransform` https 门控。P3 已让后端 emit TableSpec，本计划接通前端最后一环。

**Tech Stack:** `@tanstack/react-table` **v9**（`useTable`+`tableFeatures`，**非 v8 的 `useReactTable`**；v9 方法挂原型**不可解构**）· react-markdown 10.1.0 · vitest + @testing-library/react

**Spec:** `features/chat-rich-content/02-design/设计规格说明.md`（§三.4/§三.5）与 `docs/technology/research/05-富文本场景技术方案.md`（§4.7 表格、§4.8 图片）。执行者须先读两节。

## Global Constraints

- 表格按**来源路由**（2026-09-11 澄清）：工具 TableSpec → DataTable；模型 markdown 表 → GFM 直渲（现状）。行数不是路由依据。
- 图片是**纯防御性基建**（本期无工具产图）：不加载 `http:`/协议异常见外域，懒加载 + `referrerPolicy="no-referrer"` + 尺寸约束；同源 `/…` 与 `https://` 放行。
- DataTable 外壳沿用 `.tool-card` 视觉体系（border/背景走 CSS 变量），容器 `max-w-[560px]` 与 ChartCard 同宽。
- v8 风格代码（`useReactTable`/`getCoreRowModel`）一律不用——网上资料多为 v8，以 tanstack.com/table/latest 为准（05 §4.7）。
- 所有命令在 `frontend/` 下执行；`pnpm test` = `vitest run --coverage`；提交 conventional + 中文，一个 Task 一个 commit。

- [ ] **Step 4: 实现 `DataTable.tsx`**

```tsx
"use client";
// TanStack Table v9（useTable + tableFeatures；v8 的 useReactTable 不存在）。
// ⚠ v9 方法挂原型，不可解构（const { getValue } = row 会丢 this）。
import { useMemo } from "react";
import {
  useTable, tableFeatures, rowSortingFeature, createSortedRowModel,
  sortFn_alphanumeric, flexRender,
} from "@tanstack/react-table";
import type { TableSpec } from "@/lib/chart-spec";

const FEATURES = tableFeatures({
  rowSortingFeature,
  sortedRowModel: createSortedRowModel(),
  sortFns: { alphanumeric: sortFn_alphanumeric },   // 只注册用到的（树摇）
});

export function DataTable({ spec }: { spec: TableSpec }) {
  const columns = useMemo(
    () => spec.columns.map((c) => ({
      id: c.key,
      header: c.label,
      accessorKey: c.key,
      sortFn: c.sortable === false ? undefined : "alphanumeric",
    })),
    [spec],
  );
  const table = useTable({ features: FEATURES, columns, data: spec.rows });
  const alignOf = (key: string) => spec.columns.find((c) => c.key === key)?.align;
  return (
    <div className="my-1 max-h-[360px] w-full max-w-[560px] overflow-auto rounded-md border border-[color:var(--color-line-soft)]">
      <table className="w-full text-xs">
        <thead>
          <tr>
            {table.getHeaderGroups()[0].headers.map((h) => (
              <th
                key={h.id}
                onClick={h.column.getToggleSortingHandler()}
                className="sticky top-0 z-10 cursor-pointer bg-[color:var(--color-panel-2)] px-2 py-1.5 font-medium text-[color:var(--color-ink-dim)]"
                style={{ textAlign: alignOf(h.id) ?? "left" }}
              >
                {flexRender(h.column.columnDef.header, h.getContext())}
                {{ asc: " ▲", desc: " ▼" }[h.column.getIsSorted() as string] ?? ""}
              </th>
            ))}
          </tr>
        </thead>
        <tbody>
          {table.getRowModel().rows.map((r) => (
            <tr key={r.id} className="border-t border-[color:var(--color-line-soft)]">
              {r.getVisibleCells().map((c) => (
                <td key={c.id} className="px-2 py-1 text-[color:var(--color-ink)]">
                  {flexRender(c.column.columnDef.cell, c.getContext())}
                </td>
              ))}
            </tr>
          ))}
        </tbody>
      </table>
    </div>
  );
}
```

- [ ] **Step 3: 实现（ThreadArea 的 ReactMarkdown 配置追加）**

```tsx
            <ReactMarkdown
              remarkPlugins={[remarkGfm]}
              urlTransform={(url) => {
                // FR-6：默认 transform 已拦 javascript:/data:；再拦 http:（明文外域）。
                // 同源相对路径与 https 放行——本期无工具产图，纯防御 LLM 幻觉 URL。
                if (url.startsWith("/") || url.startsWith("https://")) return url;
                return "";
              }}
              components={{
                pre: (p) => <>{p.children}</>,          // 既有
                code: ({ className, children }) => { /* 既有不动 */ },
                img: ({ src, alt, title }) => (
                  <img
                    src={src} alt={alt ?? ""} title={title}
                    loading="lazy" decoding="async" referrerPolicy="no-referrer"
                    className="my-2 max-h-[420px] max-w-full rounded-md border border-[color:var(--color-line-soft)]"
                  />
                ),
                a: ({ href, children }) => (
                  <a href={href} target="_blank" rel="noopener noreferrer" className="underline decoration-[color:var(--color-ink-faint)] underline-offset-2">
                    {children}
                  </a>
                ),
              }}
            >
```
