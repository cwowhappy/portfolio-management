# 对话流富内容（chat-rich-content）· 需求规格说明

> 状态：已确认需求（2026-09-10）；四项选型决策同日确认（ECharts 全站统一 / 仅真实数据 / 仅 agent 展示图片 / 大数据交互表）；2026-09-11 澄清：聊天流饼图砍除、每工具一图内容定义、单一 ChartSpec 契约、双通道限四个配图工具、FR-6 防御性定位（见「澄清决策」）。
> 技术依据：[05-富文本场景技术方案.md](../../../docs/technology/research/05-富文本场景技术方案.md)（2026-09-10，三路一手调研：ECharts/TanStack 官方文档实查、AgentScope 2.0.3 jar 字节码核实、CopilotKit 1.70.1 本地源码核实）；协议层结论见 [04-AGUI事件全景与三场景技术方案.md](../../../docs/technology/research/04-AGUI事件全景与三场景技术方案.md) §4.2。
> 设计见 [../02-design/设计规格说明.md](../02-design/设计规格说明.md)。

## 背景与目标

当前对话流只有纯文本 markdown（react-markdown + remark-gfm + highlight.js）与统一的工具进度卡（ToolCallCard，结果以文本/JSON 展示）。用户问行情/估值/持仓类问题时，Agent 经 7 个行情工具拿到了结构化数据，却只能以文字转述——K 线走势、配置占比、估值分位等「一眼看懂」的信息传达不出来。

**目标**：对话流内富内容展示——文字（含 GFM 表格）、图表（K 线烛台图/折线图/柱状图）、交互表格、图片；图表数据全部来自后端工具的真实返回（可审计）。同时借此把全站图表体系统一为 ECharts（替换 recharts，净省 ~126KB gzip）。

## 关键决策（已确认，2026-09-10）

1. **图表库引入 ECharts 6 并全站统一**：K 线烛台/dataZoom/大数据量 canvas 是 recharts 没有的能力；替换后 chart 载荷 gzip 344KB → 218KB（双库并存反而更重）。评估依据 05 §5.1。
2. **仅真实数据**：图表只渲染后端工具返回的数据，不纳入 `useComponent` 让 LLM 生成「示意/对比」图的路径——投资场景数据必须可审计。
3. **图片仅 agent→用户展示**：用户上传的多模态路径受 AgentScope 2.0.3 缺口限制（document 类型不支持、多轮回放丢附件），后续单独落地（04 §4.2 已有结论）。
4. **表格需要大数据交互表**：几十行+（多期财务指标等）用 TanStack Table v9（排序/固定表头）；模型输出的静态小表继续 GFM markdown 直渲；虚拟滚动本期不装。

## 澄清决策（2026-09-11，对照真实代码核实后收敛）

1. **聊天流砍掉饼图**：7 个行情工具（search_stock/get_quote/get_kline/get_financials/get_news/get_market_overview/get_valuation）无任何配置/持仓类数据源（配置数据仅在 portfolio REST 接口），「配置类查询 → 饼图」不可达；饼图仅存在于 P1 页面组件迁移（AllocationPie）。
2. **单工具只 emit 一次 = 一张图**（05 §3.2 已核实多次 emit 会拼接），各工具出图内容定义：`get_valuation` → 全A PE/PB 中位数历史双系列折线（ERP/指数估值/温度计留文字摘要）；`get_market_overview` → 仅涨跌幅柱状（点位与涨跌幅量纲差两个数量级，点位入摘要/tooltip）。
3. **单一 ChartSpec 契约**：判别联合含 line/bar/pie/candlestick/**table** 五变体（与 Java sealed interface 一一对应）；「TableSpec」降为前端类型别名，不建独立 schema。
4. **双通道只改四个配图工具**（get_kline/get_valuation/get_market_overview/get_financials）；`search_stock`（候选代码是后续工具调用的依据，不可摘要化）/`get_quote`/`get_news` 维持全量 JSON 进 LLM 的现状。
5. **FR-6 为纯防御性基建**：本期无工具产图，图片展示的真实价值是拦 LLM 幻觉 URL 加载不受信外域；ChartSpec `image` 类型与工具产图路径不入本期。

## 用户故事

- 作为**用户**，问「贵州茅台最近走势」时，对话里直接看到 K 线烛台图（可缩放、带 MA 线），而不是一段文字描述。
- 作为**用户**，问「现在市场贵不贵」时，Agent 查询估值后在对话里看到全A PE/PB 中位数历史折线卡；问大盘时看到主要指数涨跌幅柱状卡——图上的数字与工具返回一致。
- 作为**用户**，Agent 查询个股财务指标时，看到多期指标交互表格，可以点表头排序、滚动时表头固定。
- 作为**用户**，Agent 回复里出现图片链接时能安全展示——懒加载、不泄露 referrer、不受信外域不加载（防御 LLM 幻觉 URL）。

## 功能需求

| 编号 | 需求 |
|---|---|
| FR-1 | 文字与小表格维持现状：markdown（GFM 表格/代码高亮）直渲，本特性不回退任何现有能力 |
| FR-2 | 图表渲染，四个有真实数据源的映射（按工具名注册专用渲染器）：`get_kline` → K 线烛台图（inside+slider dataZoom、MA 线）、`get_valuation` → 全A PE/PB 中位数历史折线（双系列、null 缺口；ERP/指数估值/温度计留摘要）、`get_market_overview` → 仅涨跌幅柱状（点位入摘要/tooltip）、`get_financials` → 多期财务指标表；其余工具继续走 ToolCallCard 兜底 |
| FR-3 | 单一 ChartSpec 双端契约：判别联合含 line/bar/pie/candlestick/table 五变体（table 是变体之一，前端 `TableSpec` 为类型别名）；前端 zod 为权威、后端 Java record 对齐，带 `specVersion`；解析失败降级为折叠 JSON 文本卡，不崩聊天流 |
| FR-4 | 工具结果双通道（仅四个配图工具）：图表全量 JSON 只走 SSE 给前端渲染，发给 LLM 的是文字摘要（ToolEmitter 方案一，字节码级核实），大 JSON 不耗模型上下文；`search_stock`/`get_quote`/`get_news` 维持现状 |
| FR-5 | 大数据交互表（get_financials 的 table 变体 → DataTable）：可排序、固定表头（TanStack Table v9，headless + 原生 sticky CSS）；表格按**来源**路由——工具 TableSpec → 交互表，模型 markdown 表 → GFM 直渲（与行数无关）；虚拟滚动本期不装 |
| FR-6 | 图片防御性展示（本期无工具产图）：markdown `![](url)` 定制 img 组件——懒加载、`referrerPolicy=no-referrer`、尺寸约束；可选外域白名单（`urlTransform`） |
| FR-7 | 前置缺陷修复：ThreadArea 的 `renderToolCall` 配对 toolMessage（现状后端工具卡片永远停在 inProgress、`result` 不可达——本特性图表渲染的前置依赖） |
| FR-8 | ECharts 按需引入（唯一注册点 `lib/echarts-setup.ts`）+ ESLint 禁全量入口（树摇守卫）；4 个 recharts 页面组件迁移后移除 recharts 依赖 |
| FR-9 | 状态与错误：图表卡 inProgress 骨架 → complete 渲染数据；工具错误（`Tool execution failed` 等）降级为折叠卡；`RUN_ERROR` 走现有错误横幅 |

## 非目标（本期不做，已记录）

- **用户上传图片/文件**：AgentScope 2.0.3 多模态缺口（document 不支持 + `AguiMessageConverter` 不回写附件），另立特性。
- **聊天流饼图（配置/持仓类查询）**：7 个行情工具无配置类数据源（配置数据仅在 portfolio REST 接口）；若未来接入配置类 agent 工具再评估（2026-09-11 澄清）。
- **ChartSpec `image` 类型 / 工具产图**：FR-6 本期仅防御性 markdown img 定制；工具产图（快照图存储/生命周期/外域策略）另立特性（2026-09-11 澄清）。
- **LLM 生成示意/对比图**（`useComponent` 路径）：决策 2 排除；若未来放开须在 UI 标注「模型生成」。
- **刷新/切线程后图表卡片历史回放**：ADR-0004 前端精简持久化（只存 user/assistant 纯文本）——接受限制，二期增强（05 §7.1 选项 B）。
- **手写 SVG `market/KlineChart.tsx` 收敛到 ECharts**：自定义十字线等行为变化大，与 recharts 替换解耦，另议。
- **审批（HITL）类写工具配图表**：resume 续跑轮抑制工具事件（04 §3.5），写工具只回文本摘要。
