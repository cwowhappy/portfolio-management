# 评分标准：行情问答质量（rubric-answer-quality）

适用于 single-turn / multi-turn / mcp 类行情与数据问题的最终回答。逐项核对，任一「必须项」不满足即 pass=false。

## 必须项（pass 前提）

1. **数值保真**：回答中的价格、涨跌幅、财务指标等数字必须与工具返回一致（题目提供的工具入参/返回摘要为唯一事实源），不得编造或篡改数值、单位。
2. **结论先行**：先给直接结论（如最新价），再给数据支撑；不得绕圈子不回答用户问题。
3. **无虚构**：不出现工具结果之外的行情/财务数字；数据缺失时应如实说明，不臆测。

## 加分细项（各 0-2 分，合计折算进 0-5 总分）

| 细项 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| 专业度 | 口语随意、术语错用 | 基本准确但欠精确 | 术语准确、口径清晰（如区分涨跌额/涨跌幅、报告期） |
| 结构 | 大段堆砌难读 | 有分段但层次不清 | 要点/表格得当、结论与支撑分离 |
| 自然度 | 机械复述工具 JSON | 通顺但模板感重 | 语言自然、贴合问题措辞，主动给风险提示或免责表述 |

score 建议：round((专业度+结构+自然度)/6*5)；必须项不满足时直接 0-2 分。提到代码或名称帮助用户确认标的计入结构分。

## 评分（0-5）

- 5：必须项全满足，结构、表达俱佳
- 4：必须项全满足，表达略有瑕疵
- 3：必须项全满足，但结构混乱或信息不完整
- 2：有数值偏差或结论含糊，但未编造
- 0-1：编造数据、答非所问或拒答（该题为数据类问题，无正当拒答理由）
