# 复盘 SOP——三档模板

## 目标
把「操作的留痕」变成「认知的沉淀」：按月（默认）/季/周三档模板逐维度复盘，区分决策质量与结果质量，产出 ≤3 条可复用经验回流 wiki 候选。

## 必须有清单

**月主模板（默认）字段：**

| 编号 | 维度 | 字段 |
|---|---|---|
| 4.1 | 决策质量 | 本月操作是否执行了检查单（留痕核对）；论点是否有新证据（更新/不变） |
| 4.2 | 结果质量 | 当月盈亏 + 归因圈选区间收益（自动带入，F14） |
| 4.3 | 纪律遵守度 | 越过提醒次数与理由复盘；Stop Doing 违例次数 |
| 4.4 | 归因 | 决策对/结果错（运气坏）vs 决策错/结果对（运气好）四象限归类 |
| 4.5 | 经验条目 | ≤3 条可复用结论（回流 wiki 候选，F16） |

**季深度模板追加：** 4.6 论点全量重检（2.2 论据链逐条重验）；4.7 估值区间重算留痕；4.8 与最初买入时相比「知道的更多了什么」；4.9 持有逻辑是否需要修订（联动策略 revise）。

**周简版字段：** 4.10 本周有无触发证伪条件（勾选）；4.11 有无计划外操作（有则一句话理由）；4.12 下周关注点一条。

*来源标注：4.1-4.5 邱昭良《复盘+》四步法（回顾目标→评估结果→分析原因→总结经验）；4.4 决策/结果四象限为 Annie Duke 思维适配；4.8 芒格「消除愚蠢」导向。*

## 引导流程
1. 确认档位与区间：月（MONTHLY，默认）/季（QUARTERLY）/周（WEEKLY），及复盘起止日期。
2. 按档位逐维度收集：月档收 4.1-4.5；季档在月档基础上追加 4.6-4.9；周档只收 4.10-4.12。4.2 结果质量的当月盈亏与归因圈选区间收益由系统自动带入（F14），引导时引用页面数据即可，不要求用户手抄。
3. **每完成一档收集，调用一次 `research_draft` 回显草稿**：

   ```
   research_draft(stage="REVIEW", draftJson={
     "tier": "MONTHLY",
     "periodStart": "2026-09-01",
     "periodEnd": "2026-09-30",
     "narrative": "决策质量：检查单 4/4 执行，论点新证据 1 条（更新）；结果质量：+3.2%（系统带入）；纪律遵守度：越过 1 次（理由已复盘）；归因：决策对/结果对；经验：① … ② … ③ …"
   })
   ```

4. 收口 4.5 经验条目时提醒「≤3 条、须可复用」；回流 wiki（F16）由用户在确认时选择。

## 纪律提醒
- 先归因后结论：4.4 四象限归类先行，结果好不等于决策对，结果差不等于决策错。
- 经验条目 ≤3 条且可复用，宁缺毋滥——不是每期都必须产出新经验。
- 季档 4.7 估值区间重算留痕：数字手动填，过程必须写（同 2.5 口径）。
- 证伪评审（F15）的结论可作复盘输入，复盘不复核评审本身。
- 本 Skill 只引导与回显草稿，保存复盘由用户在前端草稿卡确认，不自动落库。
