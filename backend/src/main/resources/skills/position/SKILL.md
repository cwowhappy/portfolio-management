# 建仓与持仓 SOP——纪律检查单

## 目标
把策略落成仓位前的纪律关口：买入前逐项核对检查单（3.1-3.8），加减仓/卖出前在买入前检查单基础上追加核对（3.10-3.12）；检查未过不催促下单，越过必留理由。本 Skill 引导逐项确认并回显建仓计划草稿。

## 必须有清单

**买入前检查单（必须有，F10 消费 + 用户 PrincipleRule）：**

| 编号 | 检查项 | 数据来源 |
|---|---|---|
| 3.1 | 能力圈复查 | 立项 1.1 结论复述确认 |
| 3.2 | 论点未破坏 | 最近财报/公告 vs 2.2 论据链逐条核对 |
| 3.3 | 安全边际 | 现价 vs 2.6 下限（偏离超 +20% 需写理由） |
| 3.4 | 估值区间核对 | 现价分位复算（2.7） |
| 3.5 | 单票仓位上限 | PrincipleRule SINGLE_POSITION_RATIO（未设定→「未设定」中性） |
| 3.6 | 行业仓位上限 | PrincipleRule INDUSTRY_POSITION_RATIO（同上） |
| 3.7 | 买入条件满足 | 2.11-2.13 勾选状态逐条确认 |
| 3.8 | 证伪预案在位 | 2.14/2.15 已配置且具体可查证 |

**加减仓/卖出前检查（F12，在买入前检查单 3.1-3.8 基础上追加）：**

| 编号 | 检查项 | 要点 |
|---|---|---|
| 3.10 | 证伪条件核对 | 当前命中的证伪条件列表（联动 F15）；命中 → 提示「发起证伪评审」 |
| 3.11 | 卖出理由分类 | 论点破坏（证伪）/估值到位（2.6 上限）/更好标的（写明比较）/仓位再平衡——四选一必填 |
| 3.12 | 情绪自查 | 「因为跌了所以卖」单独标记（复盘纪律遵守度的输入） |

**持仓监控关注点（F11 订阅范围建议）：** 定期财报、业绩预告/快报、重大事项公告、行业政策、核心竞争者动态。

## 引导流程
1. 确认前提：已有定稿策略（五字段齐备）；从项目的建仓计划或交易意图发起检查。
2. 逐项核对买入前检查单（3.1-3.8）：现价与分位用内置行情工具取数；PrincipleRule 未设定时如实记「未设定」（中性，不阻断）；每项记录「通过 / 未通过 / 越过（附理由）」。
3. **每完成一节检查（买入前一套、加减仓/卖出一套），调用一次 `research_draft` 回显建仓计划草稿**（字段缺失允许，逐步补全）：

   ```
   research_draft(stage="POSITION", draftJson={
     "batches": [
       {"priceLow": 12.5, "priceHigh": 13.2, "quantity": 500, "ratio": 0.35}
     ],
     "winRate": 0.6,
     "payoffRatio": 2.0,
     "note": "首批建仓目标仓位的 1/3；3.1-3.8 已核（3.3 偏离 +12% 通过）"
   })
   ```

4. 加减仓/卖出意图：在 3.1-3.8 基础上追加 3.10-3.12——3.11 卖出理由四选一必填；3.12 若命中「因为跌了所以卖」单独标记。
5. 检查全部通过 → 提示可在前端草稿卡确认保存建仓计划；任一未通过 → 如实呈现缺口并留痕，不催促、不代答。

## 纪律提醒
- 检查未过不劝进：呈现事实与缺口，越过与否及理由由用户决定并留痕（复盘纪律遵守度的输入）。
- 3.10 证伪条件命中 → 提示「发起证伪评审」，不直接给卖出指令。
- 3.12 情绪自查对事不对人：「因为跌了所以卖」如实标记即可，不评判。
- PrincipleRule 未设定 → 记「未设定」中性提示，不视为未通过、不替用户设定。
- 本 Skill 只引导与回显草稿，保存建仓计划由用户在前端草稿卡确认，不自动落库。
