# 制定投资策略 SOP——五字段结构化

## 目标
把新分析结论收敛为一份可执行、可证伪的结构化策略文档：五个字段（投资逻辑/估值区间/仓位计划/买入条件/风险与证伪条件）逐要素收集，全部要素齐备方可定稿。估值数字一律用户手动填写，系统不代算。

## 必须有清单

**字段一 投资逻辑（必须有全部要素）：**

| 编号 | 要素 | 要点 |
|---|---|---|
| 2.1 | 核心论点一句话 | 「因为<结构性原因>，市场定价错了<什么>，而实际上<真相>」 |
| 2.2 | 论据链（≥3 条独立证据） | 每条注明数据出处与可验证方式；证据之间不得互为因果循环 |
| 2.3 | 反方观点与回应 | 主动列出最强看空论点 + 自己的回应（马克斯第二层思维：价格里已经反映了什么） |
| 2.4 | 时间维度 | 论点预期兑现周期（短/中/长）与持有底线年限 |

**字段二 估值区间（手动填写，D6）：**

| 编号 | 要素 | 要点 |
|---|---|---|
| 2.5 | 计算过程留痕 | 方法、关键假设（增长率/折现率/永续）、敏感性说明——数字手动填，过程必须写 |
| 2.6 | 下限（买点）与上限（卖点预估） | 下限对应预期年化 ≥ 底线回报（如 ≥15%）；建议用「乐观打八折」校验下限 |
| 2.7 | 当前价格所处分位 | 现价相对区间的位置百分比，作为安全边际直观量（前端可辅助计算展示，字段手动确认——与 D19「数据不隐式派生」一致） |

**字段三 仓位计划：**

| 编号 | 要素 | 要点 |
|---|---|---|
| 2.8 | 目标仓位占比与上限 | 单票上限受 PrincipleRule 约束（软提醒，D5）；写明「为什么是这个仓位」 |
| 2.9 | 凯利简化参数（手动，D23） | 主观胜率 p、赔率 b，各写一句依据；f* 系统算术 |
| 2.10 | 分批意图 | 初次建仓比例上限（如目标仓位的 1/3~1/2，剩余留验证仓/补跌仓） |

**字段四 买入条件（可勾选，至少 2 条）：**

| 编号 | 条件示例 | 要点 |
|---|---|---|
| 2.11 | 价格条件 | 现价 ≤ 估值下限（或下限上浮 X% 内） |
| 2.12 | 基本面条件 | 最近财报验证论点未被破坏（营收/利润/现金流达标口径写明） |
| 2.13 | 事件条件 | 大跌非基本面原因（市场恐慌/错杀），且论点不变 |

**字段五 风险与证伪条件：**

| 编号 | 要素 | 要点 |
|---|---|---|
| 2.14 | 证伪谓词 ≥1 条（价格/估值类，D10） | 系统可检测：跌破价格 X / 升破价格 Y（止盈参照）/ PE 超阈 / PB 超阈 |
| 2.15 | 事件类证伪 ≥2 条（人工勾选） | 论点级别的「我错了」判据：如核心产品份额连续两季下滑/关键客户流失/管理层重大变动/财务指标越过红线——**必须具体到可查证** |
| 2.16 | 风险叙述 | 主要风险 3-5 条 + 各自的监测方式（对应 F11 情报订阅关注点） |
| 2.17 | Stop Doing 检查（段永平） | 明确「本策略下绝不做」清单：如不加杠杆、不做 T、跌 50% 以内不动仓位（除非证伪） |

*来源标注：2.1-2.4 芒格多元思维 + 马克斯第二层思维；2.5-2.7 唐朝估值三段式 + 格雷厄姆安全边际；2.8-2.10 凯利简化 + 巴菲特集中投资纪律；2.17 段永平 Stop Doing List。*

## 引导流程
1. 确认前提：新分析必须有清单（1.1-1.7）已齐；未齐先回补新分析，不跳阶段。
2. 逐字段收集，**每完成一个字段，调用一次 `research_draft` 回显草稿**（字段缺失允许，逐步补全）：
   - 字段一（投资逻辑）完成后：

     ```
     research_draft(stage="STRATEGY", draftJson={
       "thesis": "因为<结构性原因>，市场定价错了<什么>，而实际上<真相>；论据 3 条（各附出处）；反方最强论点与回应；兑现周期 3 年"
     })
     ```

   - 字段二（估值区间）完成后：补用户手动填写的下限/上限；

     ```
     research_draft(stage="STRATEGY", draftJson={
       "thesis": "…（同上）",
       "valuationLow": 12.5,
       "valuationHigh": 18.0
     })
     ```

   - 字段三（仓位计划）完成后：补 `positionPlan`（目标占比与上限、凯利参数各一句依据、分批意图）。
   - 字段四（买入条件）完成后：补 `buyConditions`（勾选的 2.11-2.13 条目及口径）。
   - 字段五（风险与证伪条件）完成后：补 `riskItems`（2.14 价格/估值类谓词 + 2.15 事件类，`threshold` 用数字）：

     ```
     research_draft(stage="STRATEGY", draftJson={
       "thesis": "…",
       "valuationLow": 12.5,
       "valuationHigh": 18.0,
       "positionPlan": "目标 8%（上限 10%）；胜率 0.6、赔率 2.0；首批建仓 1/3",
       "buyConditions": "2.11 现价 ≤ 12.5；2.12 最近财报营收/现金流达标",
       "riskItems": [
         {"kind": "PRICE", "predicate": "跌破估值区间下限", "threshold": 12.5, "note": "对应 2.6 下限"},
         {"kind": "EVENT", "predicate": "核心产品份额连续两季下滑", "note": "2.15，季报可查证"}
       ]
     })
     ```

3. 引导不强制线性：用户带着现成估值/仓位来时直接落到对应字段，缺什么补什么。
4. 五字段全部齐备 → 提示用户在前端草稿卡确认保存定稿；定稿后的修改走修订。

## 纪律提醒
- **估值区间不自动派生默认证伪条件（D19：数据不隐式派生）**——但建议在证伪条件中勾选「跌破估值区间下限」模板项（如上例 `riskItems` 第一条，`threshold` 取 2.6 下限）；是否采纳由用户确认，系统不代填。
- 估值数字（2.5-2.7）与凯利参数（2.9）一律用户手动填写并留一句依据，Agent 不编造数字；需要测算时把计算过程摆出来请用户确认。
- 2.15 事件类证伪必须具体到可查证，不收「基本面恶化」这类空判据。
- 买入条件至少 2 条（2.11-2.13 勾选），不足则提醒补齐再定稿。
- 本 Skill 只引导与回显草稿，保存定稿由用户在前端草稿卡确认，不自动落库。
