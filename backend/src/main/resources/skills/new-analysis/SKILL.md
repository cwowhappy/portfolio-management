# 新分析 SOP——发现标的、立项研究

## 目标
立项前的第一道关口：确认标的「看得懂、生意成立、财务干净、估值方法适配」，必须项缺一即不立项、不转「制定投资策略」。本 Skill 引导用户逐项收集要素并回显草稿；纯价值投资主线（技术面/趋势项不入 v1）。

## 必须有清单

**必须有（缺一不立项转「制定策略」）：**

| 编号 | 检查项 | 要点 |
|---|---|---|
| 1.1 | 能力圈确认 | 能用三句话讲清「这家公司靠什么赚钱」；讲不清 → 记录「能力圈外」并停止立项 |
| 1.2 | 商业模式与生意属性 | 收入来源/客户是谁/复购与提价能力；区分 林奇六类（缓慢增长/稳定/快速增长/周期/困境反转/资产富余） |
| 1.3 | 行业格局与竞争位 | 行业所处阶段、集中度趋势、公司份额与相对地位；波特五力速查 |
| 1.4 | 财务初筛（五年） | ROE 均值与趋势、毛利率/净利率稳定性、经营现金流/净利润比、有息负债率、商誉占比 |
| 1.5 | 护城河初判 | 多尔西五类（无形资产/转换成本/网络效应/成本优势/有效规模）各做有/无标注 |
| 1.6 | 估值方法适配 | 按生意类型选定主估值法（稳定盈利→唐朝式 PE 区间；重资产→PB-ROE；强周期→中位 PE/周期调整；金融→PB） |
| 1.7 | 一票否决项扫描 | 财务疑点（审计非标/大存大贷/应收激增）、治理红旗（实控人高质押/频繁减持）、看不懂的复杂结构 |

**可选项：**

| 编号 | 检查项 | 要点 |
|---|---|---|
| 1.8 | 管理层与股权 | 实控人履历、持股比例、历史言行一致性（段永平：看做对的事、把事做对） |
| 1.9 | 股权激励与股东回报 | 激励行权条件是否进取、分红/回购记录 |
| 1.11 | 历史成因 | 公司上市以来市值长期走势与关键拐点复盘 |

*来源标注：1.1/1.8 巴菲特·芒格（能力圈）；1.2 林奇六分类；1.3/1.5 多尔西《股市真规则》；1.4 格雷厄姆安全思想 + A 股财务排雷实践；1.6 唐朝估值三段式适配。*

## 引导流程
1. 先问标的：代码/名称/所属行业，以及用户已经了解什么。
2. 从 1.1 起逐项核对必须有清单：每项先听用户讲，讲不清的用内置行情/财务工具取数辅助核验再记录结论；引导不强制线性流程，用户想先聊哪项都可以。
3. **每完成一节要素收集，调用一次 `research_draft` 回显草稿**（字段缺失允许，逐步补全）：

   ```
   research_draft(stage="NEW_ANALYSIS", draftJson={
     "symbol": "600519",
     "companyName": "贵州茅台",
     "industry": "白酒",
     "checklistDone": ["1.1 能力圈：三句话已讲清", "1.2 商业模式：高端白酒复购提价"],
     "summary": "必须项已核 2/7，下一项 1.3 行业格局"
   })
   ```

4. 可选项（1.8/1.9/1.11）视用户意愿收集，不做强制。
5. 必须有 7 项全齐 → 提示可转「制定投资策略」（sop-strategy）；任一缺失或 1.1 即失败 → 明确指出缺口或如实记录「能力圈外」，不代填、不催促。

## 纪律提醒
- 1.1 讲不清就停：「能力圈外」是结论不是缺陷，记录后停止立项。
- 1.7 命中任一红旗 → 建议放弃立项，不做「先立项再说」。
- 清单结论须有依据：财务与行情数据用内置工具取数核验，不凭印象打勾；取数失败如实告知，不伪造。
- 本 Skill 只引导与回显草稿，保存到研究项目由用户在前端草稿卡确认，不自动落库。
