# 01 · 产品概览

## 1. 产品名称与定位

- **产品名**：九和 · 价值投资与资产配置系统（页面标题与导航品牌为「九和」）
- **项目名**：portfolio-management · 证券投资与分析系统
- **定位**：面向个人投资者的 **A股投研对话助手**起步，现已扩展为「投研 + 估值 + 配置 + 持仓 + 复盘」的一体化系统——自然语言查行情、看估值、筛标的，配合仪表盘与管理页完成投资闭环。

## 2. 目标用户

个人 / 团队自用的 A股投资者。使用门槛低：无需懂数据接口，也无需手动翻找财报与新闻，直接以「聊天」的方式获取基于实时公开数据的分析结论。

## 3. 核心价值

1. **自然语言即查询**：说「帮我看看贵州茅台最近的走势和估值」，Agent 自动完成「搜索代码 → 拉行情/K线/财务 → 汇总分析」的完整链路，并直接在对话里给出 K线烛台图、估值折线、财务指标交互表等图表卡。
2. **数据实时、来源公开**：行情秒级、财务/新闻分钟级，数据来自公开行情接口，无需注册 token；另可启用系统内置 MCP 数据源（妙想/Tushare/Wind）扩展宏观、公告、研报等范围。
3. **过程透明可信**：前端可视化展示 Agent 的「思考过程」与每次「工具调用（调了什么、返回了什么）」，分析结论可追溯，且系统要求「数据必须来自工具、禁止编造」；写性质工具调用须经用户逐次审批（HITL）。
4. **开箱即用**：Docker Compose 一键部署；不填 LLM Key 时行情数据台、估值仪表盘、筛选器仍可独立使用。

## 4. 功能全景

系统由 **13 个前端路由页面**与**一个内置 AI 投研助手**构成：

| 分类 | 页面 | 路由 | 说明 |
|------|------|------|------|
| 对话与 AI | 对话式投研问答 | `/` | 问行情 · 看走势 · 读财报（含图表卡、审批卡；需登录） |
| | MCP 数据源设置 | `/settings/mcp` | 启用/停用内置 MCP provider 与工具级开关 |
| | Skill 设置 | `/settings/skills` | 启用/停用内置 Skill（tushare_data / wind_finance） |
| 行情与估值 | 行情数据台 | `/market` | 指数 · 搜索 · 报价 · K线 · 财务 · 新闻（公开访问） |
| | 市场估值仪表盘 | `/valuation` | 全A PE/PB 中位数、ERP、温度计、行业估值对比（公开访问） |
| 投资管理 | 持仓组合管理 | `/portfolio` | 持仓/交易/分红记录，盈亏与结构分析 |
| | 资产组合配置 | `/allocation` | 目标配置模板、与持仓偏离对比 |
| | 价值投资筛选器 | `/screener` | 多条件 AND 筛选，任意列排序（公开访问） |

## 5. 功能清单

### 5.1 对话式投研问答（首页 `/`）

| 能力 | 说明 |
|---|---|
| 多会话管理 | 新建 / 切换 / 删除会话，历史服务端持久化（归属账号，换设备可见） |
| 流式对话 | 逐字流式输出，可中途停止 |
| 思考过程 | AI 推理内容可折叠展示 |
| 工具调用进度 | 每次工具调用以卡片展示名称、参数、结果，运行中有动画 |
| 富文本渲染 | Markdown（含表格）、代码块高亮与复制、行内代码 |
| 回答反馈 | 每条回答可 👍 / 👎 |
| 示例问题 | 空状态提供 3 个示例问题一键填入 |
| 系统状态 | 侧栏实时显示「系统就绪 / 行情源异常 / 未配置模型 Key」 |

详见 [modules/03-对话式投研问答.md](modules/03-对话式投研问答.md)。

### 5.2 行情数据台（`/market`）

| 能力 | 说明 |
|---|---|
| 指数速览 | 上证 / 深证成指 / 创业板指，30 秒自动刷新 |
| 股票搜索 | 名称/代码模糊搜索，下拉候选含市场归属 |
| 实时报价 | 最新价、涨跌、盘口指标、市盈率/市净率 |
| K线走势 | 前复权，日/周/月切换，MA5/MA20，成交量，悬停明细 |
| 财务指标 | 报告期、营收、净利润、ROE、毛利率、EPS 表格 |
| 个股新闻 | 标题（可跳转）、摘要、来源、时间 |

详见 [modules/04-行情数据台.md](modules/04-行情数据台.md)。

### 5.3 AI 投研能力

内置投研助手可查询 **7 类数据**：股票搜索、实时行情、K线、财务指标、个股新闻、大盘速览、估值（全A/指数 PE、PB 中位数及分位），并遵循「结论先行、数据来自工具、区分事实与观点、附免责声明」的回答规范。2026-09 增强批次另交付 **MCP 动态数据源**（妙想/Tushare/Wind，用户按 provider 启用，写工具触发对话内审批）与 **内置 Skill**（tushare_data / wind_finance）。详见 [modules/05-AI投研能力.md](modules/05-AI投研能力.md)。

### 5.4 用户管理与会话持久化

| 能力 | 说明 |
|---|---|
| 注册 / 登录 | 用户名 + 密码（≥8 位含字母数字）；「记住我」30 天 |
| 管理员审核 | 注册进入「待审核」，管理员通过后方可使用 AI；可拒绝（被拒可重新注册） |
| 用户管理 | 管理员查看列表、审核、停用/启用、重置密码 |
| 会话持久化 | AI 对话历史存服务端、归属账号，换设备可见 |

AI 对话需登录（管理员审核通过后）；行情数据台、市场估值仪表盘、价值投资筛选器、行业估值对比公开访问。详见 [modules/01-用户与认证.md](modules/01-用户与认证.md)。

## 6. 范围

**In（已交付）**：对话式投研问答（含图表卡与 HITL 审批）、7 类内置数据工具 + MCP 动态数据源 + 内置 Skill、行情数据台、市场估值仪表盘、资产组合配置、持仓组合管理、价值投资筛选器、行业估值对比、投资决策记录、用户管理（注册/登录/审核/停用/重置）、会话服务端持久化、Docker Compose 部署。

**Out（后续期）**：收益与风险分析 / 再平衡 / AI 持仓分析（二期进行中）；行业研究未上市部分（二期）；批量导入导出 / 基金筛选（三期）；多租户 / 交易指令 / 回测 / 找回密码、邮箱短信验证（后续期）；实时推送、移动端。
