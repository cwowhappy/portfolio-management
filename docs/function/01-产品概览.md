# 01 · 产品概览

## 1. 产品名称与定位

- **产品名**：砚台 · A股投研助手（页面标题与导航品牌为「砚台」）
- **项目名**：portfolio-management · 证券投资与分析系统（一期：AI Agent Web 服务）
- **定位**：面向个人投资者的 **A股投研对话助手**，让用户用自然语言即可查询行情、走势、财务与新闻，由 AI 自动组织数据并给出分析。

## 2. 目标用户

个人 / 团队自用的 A股投资者。使用门槛低：无需懂数据接口，也无需手动翻找财报与新闻，直接以「聊天」的方式获取基于实时公开数据的分析结论。

## 3. 核心价值

1. **自然语言即查询**：说「帮我看看贵州茅台最近的走势和估值」，Agent 自动完成「搜索代码 → 拉行情/K线/财务 → 汇总分析」的完整链路。
2. **数据实时、来源公开**：行情秒级、财务/新闻分钟级，数据来自公开行情接口，无需注册 token。
3. **过程透明可信**：前端可视化展示 Agent 的「思考过程」与每次「工具调用（调了什么、返回了什么）」，分析结论可追溯，且系统要求「数据必须来自工具、禁止编造」。
4. **开箱即用**：Docker Compose 一键部署；不填 LLM Key 时行情数据台仍可独立使用。

## 4. 功能全景

系统由**两个前端页面**与**一个内置 AI 投研助手**构成：

```
┌───────────────────────────────────────────────────────────┐
│                        浏览器 UI                           │
│  ┌─────────────────────┐   ┌───────────────────────────┐  │
│  │  对话式投研问答（/）  │   │   行情数据台（/market）     │  │
│  │  问行情 · 看走势 ·   │   │   指数 · 搜索 · 报价 ·      │  │
│  │  读财报              │   │   K线 · 财务 · 新闻        │  │
│  └──────────┬──────────┘   └─────────────┬─────────────┘  │
└─────────────┼─────────────────────────────┼────────────────┘
              │ AI 投研助手（自动调用 6 类数据工具）          │
              ▼                                             │
   行情 / K线 / 财务 / 新闻 / 大盘 数据（公开接口）            │
```

## 5. 功能清单

### 5.1 对话式投研问答（首页 `/`）

| 能力 | 说明 |
|---|---|
| 多会话管理 | 新建 / 切换 / 删除会话，历史服务端持久化（归属账号，换设备可见） |
| 流式对话 | 逐字流式输出，可中途停止 |
| 思考过程 | AI 推理内容可折叠展示 |
| 工具调用进度 | 每次工具调用以卡片展示名称、参数、结果，运行中有动画 |
| 富文本渲染 | Markdown（含表格）、代码块高亮与复制、行内代码 |
| 回答反馈 | 每条回答可 👍 / 👎 |
| 示例问题 | 空状态提供 3 个示例问题一键填入 |
| 系统状态 | 侧栏实时显示「系统就绪 / 行情源异常 / 未配置模型 Key」 |

详见 [02-对话式投研问答.md](02-对话式投研问答.md)。

### 5.2 行情数据台（`/market`）

| 能力 | 说明 |
|---|---|
| 指数速览 | 上证 / 深证成指 / 创业板指，30 秒自动刷新 |
| 股票搜索 | 名称/代码模糊搜索，下拉候选含市场归属 |
| 实时报价 | 最新价、涨跌、盘口指标、市盈率/市净率 |
| K线走势 | 前复权，日/周/月切换，MA5/MA20，成交量，悬停明细 |
| 财务指标 | 报告期、营收、净利润、ROE、毛利率、EPS 表格 |
| 个股新闻 | 标题（可跳转）、摘要、来源、时间 |

详见 [03-行情数据台.md](03-行情数据台.md)。

### 5.3 AI 投研能力

内置投研助手可查询 **6 类数据**：股票搜索、实时行情、K线、财务指标、个股新闻、大盘速览，并遵循「结论先行、数据来自工具、区分事实与观点、附免责声明」的回答规范。详见 [04-Agent-能力.md](04-Agent-能力.md)。

### 5.4 用户管理与会话持久化

| 能力 | 说明 |
|---|---|
| 注册 / 登录 | 用户名 + 密码（≥8 位含字母数字）；「记住我」30 天 |
| 管理员审核 | 注册进入「待审核」，管理员通过后方可使用 AI；可拒绝（被拒可重新注册） |
| 用户管理 | 管理员查看列表、审核、停用/启用、重置密码 |
| 会话持久化 | AI 对话历史存服务端、归属账号，换设备可见 |

AI 对话需登录（管理员审核通过后）；行情数据台公开。详见 [05-用户管理.md](05-用户管理.md)。

## 6. 范围

**In（已交付）**：对话式投研问答、6 类数据查询、独立行情数据台、用户管理（注册/登录/审核/停用/重置）、会话服务端持久化、Docker Compose 部署。

**Out（后续期）**：持仓组合管理 / 选股策略 / 定时监控（二期）；多租户 / 交易指令 / 回测 / 找回密码、邮箱短信验证（后续期）；实时推送、移动端。
