## 一、模块定位

内置投研助手的产品能力：面向个人投资者的 **A股投资研究助手**——用户用自然语言提问行情、走势、财务与新闻，助手自动调用数据工具获取实时数据并给出结构化分析。一期交付 7 个内置 `@Tool`（行情/K线/财务/新闻/大盘/估值）；2026-09 增强批次（MS-16/17）补齐 **MCP 动态数据源**（系统内置目录，用户按 provider 启用，写工具触发审批）与 **内置 Skill**（`tushare_data` / `wind_finance` 指令集按需启用）；2026-09-23 MS-12 二期收口 **F08~F12 五个增强工具**（筛选/持仓/配置/财报/行业），AI 参与完整投资闭环——对话可消费估值、筛选、持仓、配置、行业五块数据。

## 三、功能点详情

### F01 股票搜索工具 ✅

- **用户会问**：「茅台」「600519 是哪只」。
- **返回**：候选股票代码、名称、市场归属。

### F02 实时行情工具 ✅

- **用户会问**：「茅台现在多少钱」。
- **返回**：最新价、涨跌额/幅、今开/最高/最低/昨收、成交量/额、市盈率、市净率、行情时间。

### F03 K线走势工具 ✅

- **用户会问**：「茅台最近走势怎么样」。
- **返回**：历史 K线（日/周/月），用于趋势、均线、成交量分析。

### F04 财务指标工具 ✅

- **用户会问**：「茅台估值高不高、赚钱能力如何」。
- **返回**：每股收益、每股净资产、营收、净利润、加权 ROE、毛利率，及市盈率/市净率。

### F05 个股新闻工具 ✅

- **用户会问**：「茅台最近有什么消息」。
- **返回**：近期新闻标题、摘要、来源、时间。

### F06 大盘速览工具 ✅

- **用户会问**：「今天大盘怎么样」。
- **返回**：上证指数、深证成指、创业板指的点位与涨跌幅。

### F07 估值查询工具 ✅

- **设计意图**：查询个股/指数 PE、PB 及其历史分位值，回答「现在贵不贵」。
- **依赖**：M06 市场估值仪表盘的估值数据定时持久化（M14-F07）。
- **落地**：后端 `InvestTools.get_valuation`（消费 `ValuationApplicationService`）+ 前端 `ToolCallCard` 标签「估值查询」。

### F08 筛选器调用工具 ✅（MS-12）

- **设计意图**：自然语言执行 M09 筛选器的多条件筛选，如「帮我找 ROE 大于 15%、PE 小于 20 的股票」。
- **落地**：`InvestTools.screen_stocks`（`@Tool`，15 维可空条件 + 行业码 + 指数白名单 + 排序，`ScreeningCriteria` 直映射）；至少一条件守卫、排序白名单校验、空结果不 emit；结果表格卡（`ChartSpecs.screeningTable`）+ 命中摘要。

### F09 持仓分析工具 ✅（MS-12）

- **设计意图**：读取 M08 用户持仓数据，分析结构、集中度、估值水平。
- **落地**：`UserInvestTools.analyze_portfolio`（**userId 经 `UserToolkitFactory.build` 构造注入，不进 LLM 上下文**）；一次取齐 overview/allocation/industryDistribution/concentration；资产配置饼图卡（`ChartSpecs.portfolioPie`）+ 要点摘要；空持仓返回引导文本不 emit。

### F10 资产配置建议工具 ✅（MS-12）

- **设计意图**：基于用户风险偏好（M07 风险测评结果）推荐配置方案。
- **落地**：`UserInvestTools.suggest_allocation`；匹配面 = `RiskProfile.recommendedWeights`（保守/平衡/进取三档内置权重）对照 `PortfolioApplicationService.allocation` 当前分布（`AllocationSliceCategory` EQUITY/CASH 映射 AssetClass）；推荐 vs 当前 vs 偏离对照表卡 + 摘要（有活跃方案时附 `deviation` 偏离）；无测评返回引导不虚构建议。

### F11 财报解读工具 ✅（MS-12）

- **设计意图**：杜邦分析、多年趋势分析、结构化财报解读。
- **落地**：`InvestTools.analyze_financials`；数据底座 `FinancialRecordRepository`（`stock_financial` 库表读侧端口，JdbcTemplate 直查，12 季降序）+ 东财 live 两源合并（`FinancialQueryService`，live 不可用对称降级）；杜邦三因子纯函数 `DuPontAnalysis`（净利率=净利/营收【live】、周转率=ROA/净利率、权益乘数=1/(1−资产负债率)，缺因子部分降级）；12 季趋势表卡 + 杜邦摘要；库表空降级提示。**不扩 collector**（推导口径，期不一致处标注报告期）。

### F12 行业分析工具 ✅（MS-12）

- **设计意图**：查询 M10 行业估值排名、头部企业、融资动态。
- **落地**：`InvestTools.analyze_industry` 双形态——无参返回全行业估值板面表（PE/PB 及分位），带申万码下钻该行业估值位 + 头部企业表（市值降序 top15）；板面空库/码无数据安全摘要。**口径调整留痕**：功能文档原列「融资动态」无数据源（collector 无此采集），本期降为「估值排名 + 头部企业」，待后续数据源引入再补。

### F13 MCP 动态数据源 ✅（MS-16）

- **定位**：7 个内置工具之外的可扩展数据面——接入国内金融机构官方 MCP 服务（一期内置 3 provider：东财妙想 / Tushare 官方 / Wind AIFin，Wind 按 6 个域拆 endpoint），扩展宏观、公告、研报、港美股、债券等对话可答范围。
- **系统内置目录**：provider（鉴权/Token 维度）+ endpoint（域维度）两级，一期经迁移脚本预置，用户不可自定义服务器；系统 Token 统一管理，用户无需填写。
- **用户配置**（`/settings/mcp`）：按 provider 启用/停用 + 工具级开关（默认全启用）；支持对 provider 发起真实握手连接测试（返回工具清单与耗时）。
- **对话装配**：内置 7 工具 + 本人启用的 endpoint 工具 − 禁用工具；同名工具按「内置 > provider 顺序 > 域顺序」去重；任一 endpoint 故障自动隔离，不影响对话。
- **写工具审批**：写性质工具（未标 `readOnlyHint`）触发 M03-F11 审批卡，逐次批准/拒绝。
- **落地**：`domain.mcp` / `application.mcp` 新增域（V10 迁移），ArchUnit 全绿。

### F14 内置 Skill ✅（MS-17）

- **定位**：把「如何组合工具完成一类分析」的过程知识做成系统内置 Skill 目录（Markdown 指令集 `SKILL.md`），不新增工具调用面、不写新工具代码——Skill 只进提示词，Agent 经自动注册的 viewer tool 按需读取后用现有工具执行。
- **首批 2 个内置 Skill**（默认停用，按需启用）：`tushare_data`（Tushare 全品类金融数据补充）、`wind_finance`（Wind 机构级金融数据与文档）；引用数据时强制标注来源。
- **用户配置**（`/settings/skills`，与 `/settings/mcp` 并列）：每用户保存启用状态，无显式选择时回落目录默认值；配置即时生效（下次对话即变化）。
- **技能面收敛**：白名单装配（`SkillFilter.only`），技能面 = 系统内置目录 ∩ 用户启用；未启用任何 skill 时对话体验与原先一致。
- **落地**：`domain.skill` 新增域（V11 迁移 `skill_user_config`），目录内容随服务发布（classpath 只读）。

## 四、回答规范（横切，已生效）

- **结论先行**：先给结论，再列数据支撑；适当使用要点或表格。
- **数据真实**：所有数据必须来自工具调用结果，**禁止虚构价格、涨跌幅或财务数字**；工具因数据源不可用返回错误时如实说明，不编造。
- **多维度分析**：结合价格趋势、成交量、估值、消息面，并指出风险点。
- **事实与观点分离**：明确区分事实与观点。
