# M08 · 持仓组合管理

> **状态**：🚧 部分交付 | **进度**：11/12 | **目标版本**：MVP（批量导入 ⏳ 三期）
> **页面**：`/portfolio`

## 一、模块定位

> 核心问题：我买了什么、成本多少、赚了多少、占比合理吗？

手工录入持仓与交易，自动计算成本与盈亏，并从资产配置、行业分布、集中度三个维度做结构分析。

## 三、功能点详情

### F01 添加持仓 ⏳

- **设计意图**：搜索标的 → 输入买入日期/价格/数量/手续费 → 自动计算成本。

### F02 编辑/删除持仓 ⏳

- **设计意图**：修改买入记录的各项字段或整条删除。

### F03 追加买入与成本计算 ⏳

- **设计意图**：同一标的多次买入，支持加权平均成本或 FIFO 两种成本口径。

### F04 卖出记录与收益计算 ⏳

- **设计意图**：记录卖出（日期/价格/数量），系统自动匹配成本计算已实现收益。

### F05 分红记录 ⏳

- **设计意图**：记录现金分红/送股，自动反映到成本与收益计算。

### F06 持仓分组 ⏳

- **设计意图**：按账户（股票/基金/养老金）或自定义标签对持仓分组管理。

### F07 组合总览 ⏳

- **设计意图**：总资产 / 总成本 / 总盈亏 / 今日盈亏的头部汇总卡片。

### F08 持仓列表 ⏳

- **设计意图**：名称 / 数量 / 成本 / 现价 / 市值 / 盈亏 / 收益率的明细表格，现价来自行情服务。

### F09 资产配置结构可视化 ⏳

- **设计意图**：按资产类别聚合市值画饼图，并与 M07 目标配置对比偏离度。

### F10 行业/板块分布图 ⏳

- **设计意图**：按申万一级行业分类展示持仓分布，依赖申万行业分类映射数据。

### F11 个股集中度分析 ⏳

- **设计意图**：计算前 5 大重仓股占比，超阈值给出风险提示。

### F12 批量导入（CSV）⏳

- **设计意图**：CSV 格式历史交易记录批量导入，校验并落库。

## 四、数据模型（规划）

```
Portfolio（组合）
  └── HoldingGroup（分组）
        └── Position（持仓标的）
              ├── Trade（交易记录：买入/卖出）
              └── Dividend（分红记录）
```

## 五、关联

- **上游**：M07 资产组合配置（目标配置对比）。
- **下游**：M11 投资决策记录（买卖备忘关联持仓）、M12 收益与风险分析（基于交易流水计算 TWR/IRR）。
- **AI 入口**：M05-F09 持仓分析工具。
