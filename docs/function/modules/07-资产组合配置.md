## 一、模块定位

> 核心问题：我的钱应该怎么分配？股债比例多少合适？

提供经典配置模板、自定义方案与风险测评，并支持再平衡提醒与金额建议。

## 三、功能点详情

### F01 配置模板库 ✅

- **设计意图**：内置经典模板——股债 60/40、永久组合（25%×4）、全天候、巴菲特 90/10，一键套用。

### F02 自定义资产配置方案 ✅

- **设计意图**：用户自定义资产类别 + 目标权重，资产类别覆盖 A股/港股/美股/债券/黄金/现金/REITs。

### F03 风险测评问卷 ✅

- **设计意图**：5-8 题问卷 → 输出保守/稳健/平衡/成长/进取五档风险偏好 → 推荐对应配置方案。
- **交付说明**（2026-09-15）：单页 8 题三类维度（承受能力·客观 / 容忍意愿·主观 / 经验），加权总分按切点定档五档；测评卡按档位推荐权重并支持一键创建 ASSESSMENT 方案；结果落库 `risk_assessment`（Flyway V12，upsert 重测覆盖）；三端点（问卷下发 / 提交评分 / 最新结果 204 语义），e2e 覆盖答题定档到按推荐建方案全链路。

### F04 再平衡提醒 ✅

- **设计意图**：阈值触发（偏离 ±5%）或时间触发（季度/半年），到期/超限提醒用户。
- **交付说明**（2026-09-17，MS-08）：读侧纯函数即时计算（零调度零提醒落库）——`RebalanceCalculator` 已知答案单测覆盖 5pp/90/180 天边界与空组合抑制；阈值口径为**绝对百分点固定 5pp**（任一类别 |实际占比−目标占比|≥5pp）；时间触发为方案级频率（关闭/季度/半年，默认关闭），锚点 `last_rebalanced_at` 一列两用（激活方案或 ack「已完成再平衡」时重置，编辑权重不重置）。展示为 `/allocation` 页内提醒卡 + 导航「配置」红点（`GET /api/allocation/rebalance` 共用，事件刷新无轮询）。

### F05 再平衡金额计算 ✅

- **设计意图**：输入当前各类资产市值 → 对比目标配置 → 计算每类资产需买入/卖出的金额。
- **交付说明**（2026-09-17，MS-08）：当前市值自动取 M08 持仓聚合（权益+账户现金，与偏离度同源），不做手动输入模拟；逐类建议 = 目标金额 − 当前金额（正买负卖，Σ建议≡0 总额守恒，BigDecimal 元 2 位）；债券/黄金/REITs 持仓侧恒 0（场外配置不可见，页面标注口径）；总资产为 0 时金额与提醒全抑制。

### F06 配置回测（简易）⏳

- **设计意图**：基于历史数据回测配置方案：年化收益、最大回撤、夏普比率。
