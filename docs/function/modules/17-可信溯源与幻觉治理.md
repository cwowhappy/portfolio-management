## 一、模块定位

把 LLM 文本结论与工具数据**强制绑定**：每条数据性结论可溯源（数字级角标 → 来源工具+调用参数+数据时间戳）、陈述数字与工具实际返回值强制比对（不一致分级处置：容差内放行 / 大偏差原位替换+注记 / 无法比对标未溯源）、低置信回答机制化显式提示、投资建议 disclaimer 双层触发。一句话：答「结论可不可信」，是金融场景的合规准入门槛与 MS-32 深度研究的可信底座（校验器为 M19-F03 硬依赖）。

## 三、功能点详情（MS-29 单里程碑，交付说明 2026-10-06 PR #98）

- **F01 结论引用锚定**：后端 `RecordingAgentToolDecorator`（extends ToolBase，同名覆盖注册 16 工具零侵入——纯 AgentTool 装饰会令 MCP 写工具 HITL 审批静默失效，集成测试焊死）捕获工具真值；`TrustAgentHook` 在回合末轮发 `trust.anchors`/`trust.correction` 两 Custom 事件（AgentScope TextMessage 无 metadata 字段的替代通道）；前端 `trustStore` + remark 插件渲染角标（定位器与后端替换逐语义同构）；持久化走 `chat_message.payload` 预留 JSONB 列（零迁移）+ 前端 PUT 携带（union 非空优先）+ GET 回灌 rebuild——「用户看到的=持久化的」单一事实源。角标浮层三通道可达（click 受控/focus 键盘/hover 保留）+ aria 关联。
- **F02 数字一致性校验器**：`NumberExtractor`（中文数字判定式：万/亿/万亿/百分比/千分位归一，年份/日期/序号/代码/ISO 碎片排除）+ `ConsistencyValidator`（两级配对：同单位优先+有效数字同源跨度≤4；字面 mcp 标志分桶——MCP 恒 sourced 不比对；research_draft 排除清单防回显污染）；大偏差确定性替换+重试上限 2+降级出口（宁可少标不可断流）；比对基线=服务侧 DTO 真值（时点透出：screening tradeDate / industry tradingDay / overview 生成时刻 / macro 期别）。
- **F03 置信度与免责**：`ConfidenceScorer` 四信号（未溯源比例→「N 处」计数优先、三族陈旧度、工具失败、修正计数，Clock 注入）任一命中出横幅（含核实路径静态映射）；`AdviceDetector` 自声明 `<!--advice-->` 标记（剥离先于校验）∪ 14 词词表（否定窗口豁免）井集触发 disclaimer（文案后端配置透传）；`CorrectionNotes` 修正注记块可见化（改写痕迹可查）。

## 四、关键机制与约束

- **锚点=POST_REASONING 末轮**（字节码证实 POST_CALL 的 setFinalMessage 不达 stateStore——详见 [01-Agent实现 §7](../../technology/modules/01-Agent实现.md)）；Hook 系 2.0.3 已标 forRemoval，升级 agentscope 须迁移（文档已记义务）。
