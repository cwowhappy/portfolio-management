## 三、功能点详情

### F01 Docker Compose 一键部署 ✅

- `docker-compose.yml` 一键起全栈（PostgreSQL 16 + 后端 + 前端）；`make up` / `make down` 管理。

### F02 Flyway 数据库迁移 ✅

- schema 由 Flyway 管理（`ddl-auto: none`），迁移脚本在 `backend/src/main/resources/db/migration/`（当前 V1–V11：V10 MCP 配置、V11 Skill 用户配置）。

### F03 端到端冒烟测试 ✅

- `make smoke`：真实行情 + AI 对话的端到端冒烟验证。

### F04 Playwright E2E 测试 ✅

- `cd frontend && pnpm test:e2e`，浏览器级端到端用例。

### F05 ArchUnit DDD 分包规范 ✅

- `PackageConventionsTest.java` 断言 DDD 分层依赖方向（web → application → domain 等），违反即构建失败；新增能力域需登记依赖白名单。规范全文见 [01-后端DDD分包规范.md](../../technology/conventions/01-后端DDD分包规范.md)。

### F06 覆盖率门槛 ≥80% ✅

- 后端 JaCoCo 指令/分支覆盖、前端 V8 语句/分支覆盖，均要求 ≥80%；`make test` 不达标即失败。

### F07 估值数据定时抓取任务 ✅

- **设计意图**：每日收盘后抓取全市场个股估值数据，计算全 A 股 PE/PB 中位数、破净股数量、各行业加权估值并持久化快照。
- **落地**：已由 Python 采集服务 `collector/` 实现（akshare + tushare + APScheduler），见 [04-数据采集服务架构](../../technology/architecture/04-数据采集服务架构.md)。
- **关联**：是 M06 市场估值仪表盘（F01/F04/F06）与 M10 行业估值对比的前置数据底座。

### F08 MCP 数据源接入工程 ✅（MS-16，PR#19）

- 新增 `domain.mcp` / `application.mcp` 分包（provider/endpoint 内置目录、用户配置、连接测试），V10 迁移；ArchUnit 依赖白名单登记，全绿。
- 系统 Token 经迁移 seed 预置（二期 admin UI 配置时 AES-GCM 加密），任何 API 与日志不回显明文。
- 性能：MCP client 池化复用 + 初始化超时（默认 10s），不阻塞对话首 token；单次工具调用超时（默认 30s）按故障隔离降级。

### F09 内置 Skill 机制工程 ✅（MS-17，PR#20）

- 新增 `domain.skill` 分包，V11 迁移（`skill_user_config` 只存用户显式选择）；Skill 目录为 classpath 资源（`ClasspathSkillRepository` 单例，dev classpath 与 fat jar 均可枚举）。
- 白名单装配（`SkillFilter.only`）收敛技能面，配置变更即时生效；覆盖率门槛不降级（JaCoCo ≥80%）。

### F10 HITL 权限审批工程 ✅（MS-18，PR#22/#23，修复 PR#28/#30）

- AgentScope 升级 2.0.3 恢复 MCP 工具真实读写语义：`readOnlyHint` 缺省视为写，触发权限确认中断（AG-UI interrupt 契约经集成测试四场景钉住）。
- 无回退开关（不留 `FORCE_READONLY` 绕过后门），回滚路径 = git revert；多卡逐张已处理反馈经真实浏览器 e2e 钉住（PR#30）。

### F11 对话富内容与 ECharts 统一 ✅（MS-19，PR#29）

- 单一 ChartSpec 双端契约（line/bar/pie/candlestick/table 五变体，前端 zod 为权威、后端 Java record 对齐）；解析失败降级折叠卡不崩聊天流。
- 工具结果双通道：图表全量 JSON 只走 SSE 给前端渲染，发给 LLM 的是文字摘要，大 JSON 不耗模型上下文。
- ECharts 6 按需引入全站统一（替换 recharts，chart 载荷 gzip 344KB → 218KB）；唯一注册点 + ESLint 禁全量入口 + 载荷体积 CI 断言三道树摇守卫。

### F12 PIT/Descartes 变异测试 ✅（PR#31）

- PIT 1.20.2 指令级变异测试（gregor 引擎）：非阻塞手动诊断，不设门槛、不挂 check；只变异核心域三类（成本盈亏引擎 `Position` / 估值应用服务 / 行情解析器）控制单次运行时长。
- Descartes 1.3.4 extreme mutation 常态化粗筛任务（`pitestDescartes`）：方法级定位 pseudo-tested 方法清单（METHODS/ISSUES 报告），与主任务并行存在、报告独立目录；PIT 版本降级对齐其 SPI 基线。
