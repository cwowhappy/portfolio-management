## 三、功能点详情

### F01 Docker Compose 一键部署 ✅

- `docker-compose.yml` 一键起全栈（PostgreSQL 16 + 后端 + 前端）；`make up` / `make down` 管理。

### F02 Flyway 数据库迁移 ✅

- schema 由 Flyway 管理（`ddl-auto: none`），迁移脚本在 `backend/src/main/resources/db/migration/`（当前 V1、V2）。

### F03 端到端冒烟测试 ✅

- `make smoke`：真实行情 + AI 对话的端到端冒烟验证。

### F04 Playwright E2E 测试 ✅

- `cd frontend && pnpm test:e2e`，浏览器级端到端用例。

### F05 ArchUnit DDD 分包规范 ✅

- `PackageConventionsTest.java` 断言 DDD 分层依赖方向（web → application → domain 等），违反即构建失败；新增能力域需登记依赖白名单。规范全文见 [01-后端DDD分包规范.md](../../technology/conventions/01-后端DDD分包规范.md)。

### F06 覆盖率门槛 ≥80% ✅

- 后端 JaCoCo 指令/分支覆盖、前端 V8 语句/分支覆盖，均要求 ≥80%；`make test` 不达标即失败。

### F07 估值数据定时抓取任务 ✅

- **设计意图**：每日收盘后抓取全市场个股估值数据，计算全 A 股 PE/PB 中位数、破净股数量、各行业加权估值并持久化快照。
- **落地**：已由 Python 采集服务 `collector/` 实现（akshare + tushare + APScheduler），见 [02-数据采集服务架构](../../technology/architecture/02-数据采集服务架构.md)。
- **关联**：是 M06 市场估值仪表盘（F01/F04/F06）与 M10 行业估值对比的前置数据底座。
