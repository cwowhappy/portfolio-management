# M09 · 价值投资筛选器

> **状态**：⏳ 未开始 | **进度**：0/6 | **目标版本**：MVP → 二期 → 三期
> **页面**：`/screener`（规划中）

## 一、模块定位

> 核心问题：当前市场中有哪些标的符合价值投资标准？

多维度指标 AND 组合筛选，结果可排序、可加自选、可导出。

## 三、功能点详情

### F01 多条件组合筛选 ⏳

- **设计意图**：以下条件自由 AND 组合：

| 筛选维度 | 具体指标 |
|----------|---------|
| 估值水平 | PE-TTM < X；PB < X；股息率 > X%；PE 分位 < X% |
| 盈利能力 | ROE > X%（连续 N 年）；ROA > X%；毛利率 > X% |
| 财务健康 | 资产负债率 < X%；流动比率 > X；经营现金流 > 净利润 |
| 成长与稳定 | 营收增长率 > X%（连续 N 年）；净利润增长率 > X% |
| 市值与流动性 | 总市值 > X 亿；日均成交额 > X 亿 |

### F02 筛选结果排序 ⏳

- **设计意图**：结果表格支持任意列升/降序。

### F03 自选观察列表 ⏳

- **设计意图**：筛选结果一键加入自选，也支持手动搜索添加；自选列表独立展示。

### F04 结果导出 CSV ⏳

- **设计意图**：筛选结果导出 CSV 供线下分析。

### F05 指数成分股范围限制 ⏳

- **设计意图**：把筛选范围限定在沪深 300 / 中证 500 等成分股内；依赖内置成分股静态表（每半年更新）。

### F06 基金筛选 ⏳

- **设计意图**：扩展筛选对象到基金——费率、跟踪误差、规模等维度。

## 四、联动设计

- M06/M10 的「行业估值对比」中点击某行业 → 筛选器自动带入该行业条件。
- M10 行业研究中心点击「该行业上市公司」→ 跳转筛选器展示该行业全部上市公司。
- AI 入口：M05-F08 筛选器调用工具（自然语言执行筛选）。
