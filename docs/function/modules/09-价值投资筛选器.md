## 一、模块定位

> 核心问题：当前市场中有哪些标的符合价值投资标准？

多维度指标 AND 组合筛选，结果可排序、可加自选、可导出。

## 三、功能点详情

### F01 多条件组合筛选 ✅

- **已实现**：以下条件自由 AND 组合（`/api/screening/stocks`，前端表单与接口参数一一对应）：

| 筛选维度 | 具体指标 |
|----------|---------|
| 估值水平 | PE-TTM < X；PB < X；股息率 > X% |
| 盈利能力 | ROE > X%；ROA > X%；毛利率 > X% |
| 财务健康 | 资产负债率 < X%；流动比率 > X |
| 成长与稳定 | 营收增速 > X%；净利增速 > X% |
| 市值与流动性 | 总市值 > X 亿；换手率 > X% |
| 行业限定 | 申万一级行业下拉（全部/指定行业） |

### F02 筛选结果排序 ✅

- **设计意图**：结果表格支持任意列升/降序。

### F03 自选观察列表 ✅

- **设计意图**：筛选结果一键加入自选，也支持手动搜索添加；自选列表独立展示。
- **交付说明**（2026-09-17，MS-08）：`domain/screening` 扩展 + 独立路径 `/api/watchlist`（默认需登录，零安全配置改动）；筛选结果行 ⭐ 一键加入（未登录引导登录）、/screener「自选」标签页含防抖搜索添加（最新快照候选）；列表展示实时现价（quoteBatch 批量）+ 收盘快照口径（PE/PB/股息率/总市值）并标注混合口径；上限 100 只/用户、重复添加幂等、按用户隔离。

### F04 结果导出 CSV ✅

- **设计意图**：筛选结果导出 CSV 供线下分析。
- **交付说明**（2026-09-17，MS-08）：`GET /api/screening/stocks/export`（公开）与筛选页复用同一查询与 5min 条件缓存——导出口径与页面必然一致；UTF-8+BOM、RFC 4180 转义、中文表头，列 = 代码 + 结果表 13 列（总市值换算亿元）；前端 `<a download>` 直连反代原生下载（relay 补透传 Content-Disposition）。

### F05 指数成分股范围限制 ✅

- **设计意图**：把筛选范围限定在沪深 300 / 中证 500 等成分股内；依赖内置成分股静态表（每半年更新）。
- **交付说明**（2026-09-17，MS-08）：**口径修正**——原「内置成分股静态表」改为 **collector 拉取落库**：复用既有 `index_constituent` 表（V4）与 `index_constituent` 采集任务（tushare index_weight，180 天全量刷新），本功能纯消费（SQL 子查询限定）；筛选表单「指数范围」单选下拉（全部/沪深300/中证500，白名单校验），单独选指数=浏览成分股排行属合法查询；结果区标注范围与刷新口径。

### F06 基金筛选 ✅

- **设计意图**：扩展筛选对象到基金——费率、跟踪误差、规模等维度。
- **交付说明**（2026-09-26，MS-14）：对象口径**仅场内 ETF**（场外开放基金与产品定位错配，不纳入）。`/screener` 第三 tab「基金」四维筛选（费率（管理+托管年化%）/ 规模（亿元）/ 跟踪误差/ 类别（宽基/行业/商品/债券/QDII 等六桶下拉）），全列可排序（默认跟踪误差 ASC、NULLS LAST）；`GET /api/screening/funds` + `/funds/export`（并入个股筛选域 `FundScreeningCriteria`，导出与筛选同参同缓存）。**跟踪误差为收盘价口径自算**（近 1 年 ETF 与跟踪指数日收益 std×√252，样本 <120 置 null，指数缺失或样本不足显示「—」不阻断）——读数系统性高于官方净值口径，表单与表头常驻标注「收盘价口径（含分红/折溢价噪声），与官方净值口径不可直接对比」。结果支持 ⭐ 加自选（复用 `/api/watchlist`，ETF 代码直存、幂等/上限全复用）与导出 CSV。数据面：`etf_basic` V18（目录/费率/规模/跟踪指数，1685 只）+ 日线复用 `index_close_history` + collector 日更重算。
