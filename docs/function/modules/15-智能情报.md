## 一、模块定位

把公开财经信息流（新闻/公告/政策/宏观）采集落库，经 LLM 结构化抽取成**可检索、可过滤、可推送**的情报资产：对话侧 `search_news` 等 Agent 工具按关键词/标的/行业/重要度检索，后台每日盘前自动生成情报摘要推送飞书。一句话：让「最近发生了什么、对我的持仓意味着什么」从刷新闻变成查结构化情报。

架构裁决（阶段二规划 + 需求规格）：**弃用 RAG**（决策 #4）——不做 embedding/向量检索/文档问答，检索 = 结构化字段过滤（`pg_trgm` 辅助标题近似）；采集归 collector（复用调度/落库/告警），抽取/汇总归 backend 定时任务（复用 DeepSeek 通道，决策 #14）；新闻仅 90 天滚动保留，政策/宏观长期保留。

### F01 新闻采集（collector）

- 双 YAML 任务：`news_fast`（`*/10 7-23 * * *` 日间快采）+ `news_night`（`0 0-6/2 * * *` 夜间低频）；源实现 `collector/sources/news.py`（`EastmoneyFastNewsSource` 主源 sortEnd 游标 + `SinaZhiboNewsSource` 降级源页码翻页，主源失败自动降级）。
- 幂等落库：`UNIQUE(source, external_id)` 冲突跳过；跨服务契约表 `intelligence_news_raw`（backend 只读）。

### F02 AI 结构化抽取（backend）

- 双批任务 `NewsExtractionService`（cron `0 40 7,16 * * *`，Asia/Shanghai）：当日待抽取全量过批 → 逐条 `NewsExtractor`（`NewsExtractPrompt` JSON Schema：event_type/stock_codes/industry_codes/summary/direction/key_numbers/importance）→ `INSERT … ON CONFLICT` 置换写入 `intelligence_news_extract`；单条失败隔离（FAILED 留档不阻塞批次）。
- 护栏：当日 token 内存累计，超 `dailyTokenGuardrail`（默认 2,000,000）一次飞书告警即停批（D16）；批量批次大小 15。
- 质量回归（D21）：`make eval-extraction` 直调生产同款 LLM 通道跑固定题库（`backend/src/eval/resources/extraction`），报告 `backend/build/reports/eval-extraction`；2026-09-29 基线（deepseek-flash，10 题）：parse 成功率 10/10、stock 命中率 10/10、direction 一致率 6/6、importance 档位严格 7/10（阈值 ±10 容差 10/10）、总体 PASS 10/10。

### F03 search_news 工具（agent + 前端）

- `InvestTools.searchNews` 只读工具：q（标题 trgm+LIKE）/stock（JSONB containment）/industry/from/to/minImportance/limit（夹紧 1..20）七参组合过滤；条目视图 AI 摘要优先、无抽取行退化源站摘要；空结果返回 90 天保留期话术。系统提示词、前端工具卡（ToolCallCard）、参数 schema 三处接线。
- 与 `get_news`（源站原始新闻流）互补：本工具是抽取后结构化情报。BDD 四场景覆盖（`intelligence/news-search.feature`：结构化条目契约/重要度下限过滤/未抽取退化/空结果信封）。

### F04 盘前简报（backend + 飞书）

- 生成 `BriefGenerationService`（交易日 08:00，`TradingCalendarPort` 交易日历双判定）：`BriefSelectionPolicy` 纯函数选取（昨夜今晨窗口候选，MAJOR 档 importance≥80 全选，WATCH 档 50~79 按节顺序补足至 min、超 max 按重要度截断）→ 5+1 节 markdown（`BriefSection` 决策 #20：宏观与政策/行业与板块/公司要闻与公告/资金与市场/海外与大宗 + 其他要闻）+ `top_stocks` 检索快照（stock_codes 频次 top 20，决策 #23）；三态归档 `GENERATED`/`EMPTY_SIMPLE`/`FAILED`（生成失败/空简版同留档可查）。
- 推送 `BriefPushService`（交易日 08:30）：配置群群推版；`FeishuClient` open_id 单发能力已落，按用户路由待 P4 F16 订阅回接；`IntelligencePushPort` 留痕 `intelligence_push_log`。

### F05 存储模型与域

- `V3__intelligence.sql`：15 新表（news_raw/news_extract/公告四表/政策两表/宏观序列+日历/社融降级留痕/简报/订阅三表/飞书绑定+绑定码/推送留痕）+ `pg_trgm` 扩展与 GIN 索引 + `research_project.intelligence_alert_enabled` 加列（D13，M16-F11 接口位）+ 宏观日历 seed 75 行。

#### F07 业绩类公告要点抽取（backend）

- `AnnouncementExtractionService` 双批（cron `0 40 22 * * MON-FRI` / `0 40 6 * * MON-FRI`，Asia/Shanghai，抽取批批末触发 F10 推送）：`findPendingForExtraction` 3 日窗游标取待抽取 → `PdfFetcher` 下载 `pdf_url`（HttpClient 10s 超时，头快判降级）→ `AnnouncementPdfTextPort`（pdfbox 3.0.x）抽文本层 → `AnnouncementExtractor` 一次 LLM + Jackson 解析、失败重试 1 次（temperature 0 端口钉死），token 护栏与新闻抽取共用日累计。
- **六字段 metrics 契约**（`AnnouncementMetrics`）：营收/归母净利/归母净利同比/扣非/毛利率/分红描述，**未披露字段 null 且字段名进 undisclosed，严禁编造**（提示词、解析、落库三处同守）；非业绩类公告六字段全 null 全进 undisclosed。PDF 正文仅喂前 8000 字符（摘要/主要会计数据节在前）。
- **PDF 零落盘**（决策 #4/#15）：原文不留存，仅元数据 + `pdf_text` 抽取文本留痕（D18），工具侧只返回要点字段 + 链接。

#### F08 公告分类标签
