沉淀投资原则、读书笔记与核心概念，让纪律可见、可被系统引用（如原则预警）。

## 三、功能点详情

### F01 投资原则与纪律设定 ✅

- **设计意图**：用户自定义纪律规则（如「单票不超过 20%」「PE 高于 40 不买」）；三期由系统据此做**投资原则预警**。
- **交付说明**（2026-09-22，MS-11）：参数化规则——4 指标枚举（`PrincipleMetric`：单票仓位上限 / 单行业仓位上限 / 个股 PE 上限 / 个股 PB 上限）+ 阈值 + 启停 + 说明；`principle_rule` 表（Flyway V16），每用户每指标至多一条（`UNIQUE(user_id, metric)`，前端重复指标置灰）；ratio 类指标以 0~1 存储、表单按 % 录入自动换算。枚举即三期 MS-15 预警消费的稳定契约。

### F02 读书笔记 ✅

- **设计意图**：投资经典书籍的读书笔记，Markdown 格式。
- **交付说明**（2026-09-22，MS-11）：`/wiki` 读书笔记 tab——列表 + 编辑器/预览切换 + 详情渲染；Markdown 渲染抽共享组件 `MarkdownView`（react-markdown，chat 富内容同源复用）。内容落 `wiki_entry` 单表三类型（BOOK_NOTE / CONCEPT / RESEARCH_NOTE），用户可增删改。

### F03 价值投资概念速查 ✅

- **设计意图**：护城河 / 安全边际 / 能力圈 / Mr. Market 等核心概念的速查条目。
- **交付说明**（2026-09-22，MS-11）：应用层首次访问 seeding 预置 10 条概念（护城河/安全边际/能力圈/市场先生/内在价值/复利效应/均值回归/ROE/PE/PB）；`wiki_seed_state` 幂等标记——每用户只 seed 一次，删光不复活；预置与用户条目同表同权限，可增删改。
