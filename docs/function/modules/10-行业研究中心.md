# M10 · 行业研究中心

> **状态**：🚧 部分交付 | **进度**：6/12 | **目标版本**：MVP（估值对比）→ 二期（上市公司深化）→ 三期（未上市与竞争格局、产业链/对比）
> **页面**：`/industry`（已上线）、`/industry/[industryCode]`（下钻页，2026-09-18 上线）

## 一、模块定位

> 核心问题：这个行业有哪些玩家？竞争格局如何？未上市的潜在对手在哪里？

分三步走：MVP 先做数据就绪的已上市企业估值对比；二期深化上市公司研究（排名/分位/景气度）；三期以**公开源+人工策展**做未上市企业画像与竞争格局，并做产业链图谱与跨行业对比（2026-09-23 二期门槛方案 C 裁决：原二期未上市部分因天眼查预算未决整体移三期；2026-09-26 数据源替代裁决：天眼查成本出局，改方案 A 轻量口径，里程碑解锁，见 [MS-10 数据源替代裁决](../../../features/plans/2026-09-26-MS-10数据源替代裁决.md)）。

## 三、功能点详情

### F01 行业估值对比 ✅

- **设计意图**：申万 31 个一级行业 PE/PB/ROE/股息率排名，可按任意指标排序；与 M06-F07 为同一能力的两个入口。

### F02 估值热力图 ✅

- **设计意图**：矩阵热力图（行=行业，列=PE/PB/ROE，颜色=估值高低），一眼看出哪些行业低估/高估。

### F03 上市公司排名 ✅

- **设计意图**：行业内上市公司按市值/营收/ROE 排名列表。
- **交付说明**（2026-09-18，MS-09）：下钻页 `/industry/[industryCode]` 成员排名表（`GET /api/industry/{industryCode}/stocks`，排序白名单市值/营收/ROE、limit ≤1000，前端 50/页本地分页）。**营收 = 最新报告期的累计营业收入**（报告期角标展示）：collector 由 tushare `income` 并入 `stock_financial.revenue`（V15 加列），合并报表口径（`report_type=1`）、单位元——接口实测校准见 [features/industry-listed-research/09-调研报告/2026-09-17-income接口校准.md](../../../features/industry-listed-research/09-调研报告/2026-09-17-income接口校准.md)。

### F04 历史分位对比 ✅

- **设计意图**：各行业当前 PE/PB 所处近 5 年/10 年分位；依赖历史估值快照数据。
- **交付说明**（2026-09-18，MS-09）：board 表新增「PE 5y 分位 / PB 5y 分位」列（`GET /api/industry/board`）。**分位 = 近 5 年经验分布**（窗口化，序列不足 250 交易日（约一年）返回 null 显示「—」，10 年窗口预留未做）；**历史按当前申万 2021 成分回溯**——历史行由 collector 重算任务 `industry_valuation_backfill`（周更、只补缺失日期、幂等）自算写入，口径与每日快照的 `IndustryValuationCalc` 双实现一致。历史数据经 `make industry-stock-backfill`（5 年分段回填）+ 重算任务落地：dev 库已覆盖 2016-01-04 起 10.6 年（31 行业 × 2595 交易日），实跑记录见 [2026-09-17-回填实跑记录](../../../features/industry-listed-research/09-调研报告/2026-09-17-回填实跑记录.md)。

### F05 景气度提示 ✅

- **设计意图**：基于 ROE 趋势、营收增速的简易景气标注（上行/平稳/下行）。
- **交付说明**（2026-09-18，MS-09）：行业级（board 景气列）与个股级（下钻页景气列）双粒度。规则纯函数 `Prosperity.of`：**上行 = ROEΔ ≥ +1pp 且 营收增速 ≥ +10%（且，防单指标噪声）；下行 = ROEΔ ≤ −1pp 或 增速 ≤ −10%（或，更敏感；且/或不对称为有意设计）**；任一输入缺失不标注。ROEΔ = 近 4 季 ROE 均值 − 前 4 季均值，营收增速取最新报告期同比。**行业档位由成员中位数聚合**（ROEΔ 中位数、营收增速中位数），样本数透出供 tooltip 解释。

### F06 行业全景概览 ⏳

- **设计意图**：某行业已上市公司数/总市值 vs 未上市企业数的全景对比。
- **口径（2026-09-26 裁决）**：未上市企业数为**估算值**（官方统计的分行业企业户数 − 上市公司数），页面显著标注估算口径；官方统计内置静态数据、季度/年度人工更新，不做采集。

### F07 未上市头部企业画像 ⏳

- **设计意图**：展示行业内值得关注的头部未上市企业。
- **口径（2026-09-26 裁决）**：**人工策展**每行业 10~30 家——名称/最新融资轮次/最近融资时间/累计融资额/一句话简介；LLM+搜索生成草稿、人工核对（爱企查网页/官方公示系统低频单查），专利计数可选用 CNIPA PSS 免费渠道按需核对。**不做工商全字段**（法人/股东/经营范围/司法诉讼/经营异常——原天眼查依赖出局）。

### F08 行业融资动态 ⏳

- **设计意图**：近期融资事件列表（轮次、金额、投资方）。
- **口径（2026-09-26 裁决）**：公开新闻流**月更采集**（睿兽分析月度统计 + 36氪/投资界/IT桔子公开页，频率克制、来源标注）——月度粒度新闻级事件流，**非全量口径**留痕（降口径先例：M10-F12 grilling 决策 #4、MS-12 F12）。

### F09 竞争格局图 ⏳

- **设计意图**：已上市（市值气泡）+ 未上市（融资轮次标签）同框可视化展示。
- **口径（2026-09-26 裁决）**：完整保留——上市气泡取库内市值，未上市标签取 F07 策展名单的融资轮次。

### F10 企业详情卡片 ⏳

- **设计意图**：点击任意企业——上市公司跳转行情台（M04），未上市企业展示摘要卡片。
- **口径（2026-09-26 裁决）**：未上市展示**策展字段摘要**（轮次/最近融资/简介，轻量口径，无工商全字段）。

### F11 产业链图谱 ⏳

- **设计意图**：上中下游企业映射（如「锂电池」→ 锂矿/材料/电池/整车）。
- **口径（2026-09-26 裁决）**：解除天眼查依赖——人工维护产业链映射（仓库内数据面）+ 上市成员按行业自动挂载 + 未上市成员取 F07 策展名单，随 MS-10 交付。

### F12 行业对比 ✅

- **设计意图**：两个行业的估值/增速/融资热度横向对比；配套支持自定义关注行业（标记关注、推送融资动态/新股上市）与研究笔记联动（行业分析结论保存至 M13 投资知识库）。
- **交付说明**（2026-09-26，MS-14）：`/industry` 页内「榜单/对比」视图切换——对比视图为行业多选（申万一级 31 只，搜索过滤）+ 并排对比表 + 对比图，**关注集默认勾选**；对比维度固定集（PE/PB/ROE/股息率 + PE/PB 5y 分位 + 景气度），零新增数据端点、消费既有 `/api/industry/board`。自定义关注行业 ⭐ 落地：V17 `industry_watch`（user_id+industry_code 唯一、幂等）+ 独立前缀 `/api/industry-watch` 三端点（list/watch/unwatch，需登录，避开 `/api/industry/**` 公开段），未登录点 ⭐ 引导登录；刷新后关注集默认勾选保持（持久化）。**口径收窄**（grilling 决策 #4）：融资热度/推送融资动态/新股上市提醒剔除（天眼查阻塞 + 主动对比定位），研究笔记联动复用既有行业下钻页研究结论入口（M13 知识库）。

## 四、现实约束

- 未上市企业**财务数据（营收/利润）通常非公开**，系统无法强制获取。
- 行业研究对未上市企业的价值更多体现在**竞争格局识别**（有多少玩家、谁融资了、谁专利多）而非财务估值。
- 未上市企业数据走**轻量口径**（2026-09-26 数据源替代裁决：天眼查付费 API 出局，改公开流采集+人工策展，0 元）——工商全字段不做，头部企业人工策展、融资动态月度新闻级，是个人项目数据获取成本与维护人工的折中；企查查开放平台（0.10 元/次）留**可选增强**接口位（默认关闭，重点行业需工商深度时再启用），裁决依据见 [MS-10 数据源替代裁决](../../../features/plans/2026-09-26-MS-10数据源替代裁决.md)。
