## 一、模块定位

把 AI 长期记忆从「不可解释的黑盒」变为「透明可控 + 授权注入」：已落盘记忆对用户可见、可编辑、可删除（删除不复活）；个人投资画像（风格/关注行业/自选股/持仓汇总）经用户**逐段授权**注入系统提示，让回答携带个人上下文；调仓/分红/日志等投资事件自动摘要写入记忆。一句话：金融场景里「AI 记得我什么」必须由用户说了算——这是个性化（MS-32 深度研究增益）与隐私信任的前提。

## 三、功能点详情（MS-31 单里程碑，交付说明 2026-10-11）

- **F01 记忆管理界面**：`/settings/memory` 下半区。管理对象 = harness 库落盘的工作区记忆文件（`<workspace>/<userId>/MEMORY.md` 策展层 + `memory/yyyy-MM-dd.md` 当期日账本；archive 与隐藏文件排除）；后端 `WorkspaceMemoryPort`（application/memory 端口）+ `WorkspaceMemoryFileAdapter`（infrastructure/workspace，同目录 temp 文件 + `ATOMIC_MOVE` 原子写、单次读快照保证 hash 与行同源）。REST `/api/memory/**` 六端点（本人隔离——全部按认证 userId 寻址，无跨用户对象 id）；删除走**两层同步**：删策展层行后跨日账本清除归一化同源 bullet 行（strip + 全角→半角 + 空白折叠互为子串、行体 ≥12 字符），计数如实回执（「策展层不复活」硬保证 /「日账本尽力清除」软保证，残余由用户节级手删兜底）；乐观并发三层校验（整文件 sha-256 冲突 409 / 行漂移 410 / 只读标题行 400），前端 409/410 自动刷新提示。
- **F02 画像注入**：上半区四开关（投资风格/关注行业/自选股/持仓汇总），默认全关（opt-in），disabled 段也出预览（「先看再开」）；段渲染收敛 `domain/memory/ProfileSectionRenderer` 纯函数——预览（`ProfileConfigApplicationService`）与注入（`agent/ProfileContextBuilder`）双方消费同一函数，「所见即所注入」由同路径保证。注入点 `HarnessAgentFactory.build`：sysPrompt = `InvestSystemPrompt.TEXT + "\n\n" + <user_profile> 画像块`（AG-UI 与飞书两调用方同走 build，飞书同权自动成立）；授权全关/全无数据/渲染失败 → 画像块缺位，sysPrompt 与现状**逐字节一致**（回归红线，测试焊死）。护栏：`InvestSystemPrompt` 条款 11 扩展为禁止把用户私有数据（工具返回 + 注入画像）作为参数传给 MCP 工具；模板骨架登记版本资产 `system.invest.profile`（实际注入内容 DB 派生不入版本链）；自选段截断 `invest.profile.watchlist-limit`（默认 30）、整块限长 800 字符。
- **F03 事件驱动记忆**：`MemoryDigestScheduler`（cron 21:07 Asia/Shanghai 字面量；`invest.profile.digest-enabled` 开关；`DEEPSEEK_API_KEY` 缺席静默跳过）逐 enabled 用户取 journal timeline 窗口事件 → 复用 `IntelligenceChatPort` 摘要为 ≤5 条 bullet（系统 key，失败/无 key 返回 empty 跳过）→ `appendExternalEvent` 写当日账本「## 外部事件摘要 — 日期（窗口起 ~ 止）」节（文件不存在则创建）；管理界面按节头前缀出「事件摘要」徽标可回溯。全局单行游标 `memory_digest_cursor`（V7）：**批执行完成即推进**（批首 now 一次取定贯穿窗口止/节头/游标），单用户失败 WARN 跳过不挡批，次日窗口扩大自动重试（at-least-once）。

## 四、关键机制与约束

- **单一写入者契约不破**：管理链只写 MEMORY.md 与当期日账本，不碰 `.consolidation_state`/archive/sessions——库 consolidation 自然吸收日账本（下周期合并进策展层），两侧并发窗口由「读快照 + hash 三层校验 + 原子写」收敛。
- **数字来源纪律**：持仓段各值直接取 `PortfolioOverviewView` 字段 `toPlainString()`，不二次计算（预览与注入同源同形）。
- **schema**：V7__ms31_memory_personalization.sql 两表——`user_profile_config`（单行四列/用户，无行 = 全关）+ `memory_digest_cursor`（全局单行 `CHECK(id=1)` seed）。
- **测试锚**：BDD 中文两场景（删除不复活 / 授权后模型上下文含画像段——假 Model 录制判读）；e2e `memory.spec.ts`（fs 直种工作区真浏览器：分栏/kind 徽标/行删节删持久/授权预览保存/空态 + P3③ K 线失败还原）；`HarnessAgentFactory` sysPrompt 逐字节回归红线。
