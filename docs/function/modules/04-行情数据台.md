> **状态**：✅ 一期已交付 | **进度**：6/6
> **页面**：`/market`（公开访问，无需登录） | **技术文档**：[04-接口](../../technology/modules/03-接口设计.md)、[03-行情数据服务](../../technology/modules/02-行情数据服务.md)

## 一、模块定位

无需模型 Key 即可独立使用的行情浏览页，覆盖「指数 → 搜索 → 报价 → K线 → 财务 → 新闻」的完整看盘链路。与对话页**同源数据**（同一套行情数据服务）：对话页由 AI 自动编排数据，行情台由用户手动浏览原始数据，互为补充。

## 二、页面结构

自上而下：

1. **指数速览条**（3 张指数卡片，30 秒自动刷新）
2. **股票搜索框**（防抖搜索，下拉候选）
3. 选中股票后依次展示：**报价头** → **K线走势** → **财务指标表 + 近期新闻**（左右两栏）

## 四、功能点详情

### F01 指数速览 ✅

- 展示**上证指数 / 深证成指 / 创业板指**三张卡片：名称、点位、涨跌额、涨跌幅。
- 涨红跌绿着色（A股惯例）；每 **30 秒**自动刷新；加载中显示骨架屏。

### F02 股票搜索 ✅

- 输入名称或代码（如「茅台」「600519」），**防抖 300ms** 后搜索。
- 下拉候选展示：名称、代码、市场归属（沪市 / 深市 / 北交所）。
- 仅返回 A股（已剔除指数 / 板块 / 基金 / 债券 / 期货条目）。

### F03 实时报价 ✅

- 选中股票后，报价、K线、财务、新闻**并行加载**；快速连续切换时丢弃过期响应，不串数据。

| 区域 | 字段 |
|---|---|
| 主信息 | 名称、代码、行情时间、最新价、涨跌额、涨跌幅 |
| 盘口指标 | 今开、最高、最低、昨收、成交量（万手）、成交额（亿/万亿） |
| 估值 | 市盈率（PE）、市净率（PB） |

### F04 K线走势 ✅

蜡烛图（前复权）：

- **周期切换**：日K / 周K / 月K，切换即时刷新；切换失败保持旧图。
- **均线**：MA5（琥珀色）、MA20（蓝色），图例随附。
- **成交量**：蜡烛下方柱状图，红涨绿跌；最新价虚线 + 价格刻度。
- **悬停明细**：高亮对应 K 线，浮层显示 日期 / 开 / 收 / 高 / 低 / 量。

### F05 财务指标表 ✅

表格展示最近 **6 个报告期**：报告期、营收（亿元格式化）、归母净利润（正负着色）、加权 ROE、毛利率、EPS。

### F06 个股新闻列表 ✅

- 标题（外链可跳转原文）、摘要（去 HTML 截断 120 字、两行显示）、来源 + 时间。

### 加载与错误状态（横切）

- **加载**：选中后报价头 + K线区域骨架屏；**错误**：琥珀色错误条提示；**空状态**：未选中时显示「搜索一只股票，查看行情、走势、财务与新闻」。
