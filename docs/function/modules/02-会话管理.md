# M02 · 会话管理

> **状态**：✅ 一期已交付 | **进度**：4/4
> **页面**：`/`（Sidebar 会话列表） | **技术文档**：[ADR-0008](../../technology/decisions/0008-conversation-persistence.md)

## 一、模块定位

会话是对话的隔离单元，每个会话独立保存历史。AI 对话历史**服务端持久化、归属账号**，换设备可见；非本人访问一律 404，不泄露存在性。

## 三、功能点详情

### F01 多会话创建/切换/删除 ✅

- **新建**：点击「＋新对话」；运行中禁用，防止流式输出串写。
- **切换**：点击会话条目；切换时先停止旧回答再载入新会话。
- **删除**：悬停条目出现 ✕，删除该会话及其全部消息；删除当前会话则自动新建一个。

### F02 会话标题自动生成 ✅

- 取首条用户消息的前 24 字作为标题；无消息时显示「新会话」。

### F03 会话时间排序展示 ✅

- 按更新时间倒序排列；展示相对时间「刚刚 / N 分钟前 / N 小时前 / N 天前」。

### F04 服务端持久化与归属隔离 ✅

- **存储模型**：领域实体 `Conversation`（`conversation` 表），`id` 复用 AG-UI 协议层 `threadId`；消息存 `chat_message` 表（精简历史：仅 user/assistant 纯文本，`payload` 预留工具调用扩展）。
- **交互模型**：「前端工作内存 + 服务端存储」——前端持有当前对话消息作为工作内存、每轮携带全量历史到 `/agui/run`；每轮 assistant 回复完成后 **PUT 全量消息**到服务端，打开会话时 **GET 回灌**。
- **归属隔离**：所有会话读写校验 `user_id`，非本人一律返回 404。
- **并发策略**：多端同时编辑同一会话 = 后写覆盖，不做并发合并。
