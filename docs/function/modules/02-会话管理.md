## 一、模块定位

会话是对话的隔离单元，每个会话独立保存历史。AI 对话历史**服务端持久化、归属账号**，换设备可见；非本人访问一律 404，不泄露存在性。

## 三、功能点详情

### F01 多会话创建/切换/删除 ✅

- **新建**：点击「＋新对话」；运行中禁用，防止流式输出串写。
- **切换**：点击会话条目；切换时先停止旧回答再载入新会话。
- **删除**：悬停条目出现 ✕，删除该会话及其全部消息；删除当前会话则自动新建一个。

### F02 会话标题自动生成 ✅

- 取首条用户消息的前 24 字作为标题；无消息时显示「新会话」。

### F03 会话时间排序展示 ✅

- 按更新时间倒序排列；展示相对时间「刚刚 / N 分钟前 / N 小时前 / N 天前」。

### F04 服务端持久化与归属隔离 ✅

- **存储模型**：领域实体 `Conversation`（`conversation` 表），`id` 复用 AG-UI 协议层 `threadId`（ADR-0012：刷新/重开续用同线程，前端发送前置回灌闸门防串线）；消息存 `chat_message` 表（user/assistant 纯文本；`payload` 列自 MS-29 起承载 assistant 消息的**信任锚定 JSON**——引用文本/工具数据/校验结果，不再只是预留）。
- **交互模型（服务端记忆，ADR-0011）**：`agentscope.agui.server-side-memory: true`——会话历史由**服务端 HarnessAgent `stateStore` 持久化**；前端每轮**只发最新一条用户消息**到 `/agui/run`（不再携带全量历史），服务端从 stateStore 恢复上下文。前端仍保留一份工作内存用于渲染与 PUT 保存。
- **保存与并发**：每轮回复完成后 **PUT 全量消息**（`If-Match` 头可选乐观校验，基于 GET 返回的 `updatedAt`，冲突返回 409 提示刷新）；打开会话时 **GET 回灌**（`{updatedAt, messages}`）。多端并发编辑不再是无提示的后写覆盖。
- **归属隔离**：所有会话读写校验 `user_id`，非本人一律返回 404。
