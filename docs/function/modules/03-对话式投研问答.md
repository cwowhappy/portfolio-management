## 一、模块定位

系统核心入口：用户以自然语言向 A股投研助手提问，AI 自动调用数据工具并流式输出分析。过程透明可信——思考过程与每次工具调用（调了什么、返回了什么）都可视化。

## 四、功能点详情

### F01 流式对话输出 ✅

- 走 AG-UI 协议（前端 CopilotKit → 后端 `POST /agui/run` SSE 事件流），正文逐字增量渲染。
- 助手就绪后才可发送；支持多行文本。

### F02 发送 / 停止 / 失败提示 ✅

- **发送**：Enter 或点击「发送」；**换行**：Shift+Enter，输入框自适应增高（最高 160px）。
- **停止**：运行中点击「■ 停止」中断本次流式输出。
- **失败**：顶部弹出琥珀色错误条（可关闭），提示错误原因或「请求失败，请稍后重试」。

### F03 思考过程折叠展示 ✅

- AI 推理内容渲染为折叠区（`<details>`），标题显示「思考过程（N 字）」，展开可查看推理原文。

### F04 工具调用进度卡片 ✅

AI 每次调用数据工具渲染一张进度卡片，让「数据从哪来」可见：

- **名称**：中文标签（搜索股票 / 实时行情 / K线走势 / 财务指标 / 个股新闻 / 大盘速览 / 估值查询）；用户启用 MCP 数据源后，其工具也以同款卡片展示（F10）。
- **参数摘要**：如「600519 · day · 近 120 根」。
- **状态**：运行中脉冲动画；完成 ✓ / 失败 !。
- **结果**：点击展开查看工具返回数据（超长截断）。

### F05 Markdown 富文本渲染 ✅

- 支持标题、列表、表格、代码块；行内代码单独样式。

### F06 代码块复制与高亮 ✅

- 代码块带「复制」按钮与语法高亮。

### F07 回答 👍/👎 反馈 ✅

- 每条助手回答下方提供 👍/👎 按钮，点击后高亮当前选择并记录在本地。
- 属一期轻量反馈，**未上报服务端**。

### F08 空状态与示例问题 ✅

- 无消息时展示引导页，标题「问行情 · 看走势 · 读财报」。
- 3 个示例问题一键填入并发送：`帮我看看贵州茅台最近的走势和估值` / `今天大盘表现怎么样？` / `搜索一下宁德时代最近的新闻`。
- 未配置模型 Key 时提示「行情数据页仍可正常浏览」。

### F09 系统状态实时检测 ✅

- 每 60 秒检测一次后端状态，Sidebar 页脚实时展示：

| 状态 | 显示 |
|---|---|
| 模型已配 + 行情源正常 | 🟢 系统就绪 |
| 模型已配 + 行情源异常 | 🟠 行情源异常 |
| 未配置模型 Key | 🟠 未配置模型 Key |
| 检测中 | ⚪ 连接中… |

- 页脚附免责声明「数据来自公开行情接口，仅供参考，不构成投资建议」。

### F10 MCP 动态工具调用 ✅（MS-16）

- **能力**：对话可调用用户在 `/settings/mcp` 启用的 MCP 数据源工具（妙想 / Tushare / Wind，见 M05-F13）；对话时按「内置 7 工具 + 本人启用的 provider 工具 − 禁用工具」动态装配。
- **未启用任何 MCP 时**，对话体验与原先一致（仅 7 个内置工具）。
- **故障隔离**：任一 endpoint 连接失败/超时不影响对话主流程与内置工具，Agent 侧表现为该工具不可用。

### F11 写工具审批卡（HITL）✅（MS-18）

- **触发**：Agent 调用写性质 MCP 工具（未标 `readOnlyHint` 或为 `false`，按 MCP 规范缺省视为写）时逐次弹出审批，工具在审批前不执行；只读工具与 7 个内置投研工具不弹审批。
- **卡片**（`InterruptApprovalCard`）：展示工具名 + 可展开的入参 JSON + 说明文案，提供「批准 / 拒绝」两个动作。
- **多卡逐张应答**：多个工具同时待审时全部铺开，每张卡片点击后立即显示「已批准 / 已拒绝，等待其余确认…」，全部应答后 Agent 续跑。
- **拒绝防拉锯**：系统提示约束「被拒绝的工具调用不原样重试，改走替代方案或说明无法完成」；上游契约错误文案已中文化并引导开新对话。

### F12 聊天图表卡 ✅（MS-19）

- **四个配图工具自动出图**（数据全部来自工具真实返回，可审计）：
  - `get_kline` → K线烛台图（inside + slider dataZoom、MA 线、成交量副图）
  - `get_valuation` → 全 A 股 PE/PB 中位数历史双系列折线（ERP/指数估值/温度计留文字摘要）
  - `get_market_overview` → 主要指数涨跌幅柱状图（点位入摘要/tooltip）
  - `get_financials` → 多期财务指标交互表格
- **交互表格**（`DataTable`，TanStack Table v9）：点击表头排序（▲/▼）、滚动时表头固定（sticky）。
- **降级**：图表数据解析失败或工具报错时降级为折叠的原始 JSON 文本卡，不中断聊天流；纯文本小表仍走 Markdown 直渲。
- **图片防御性展示**：回答中的图片懒加载、`no-referrer`、不受信外域不加载。
