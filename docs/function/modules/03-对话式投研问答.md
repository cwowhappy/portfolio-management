系统核心入口：用户以自然语言向 A股投研助手提问，AI 自动调用数据工具并流式输出分析。过程透明可信——思考过程与每次工具调用（调了什么、返回了什么）都可视化。

## 四、功能点详情

### F01 流式对话输出 ✅

- 走 AG-UI 协议（前端 CopilotKit → 后端 `POST /agui/run` SSE 事件流），正文逐字增量渲染。
- 助手就绪后才可发送；支持多行文本。

### F02 发送 / 停止 / 失败提示 ✅

- **发送**：Enter 或点击「发送」；**换行**：Shift+Enter，输入框自适应增高（最高 160px）。
- **停止**：运行中点击「■ 停止」中断本次流式输出。
- **失败**：顶部弹出琥珀色错误条（可关闭），提示错误原因或「请求失败，请稍后重试」。

### F03 思考过程折叠展示 ✅

- AI 推理内容渲染为折叠区（`<details>`），标题显示「思考过程（N 字）」，展开可查看推理原文。

### F04 工具调用进度卡片 ✅

AI 每次调用数据工具渲染一张进度卡片，让「数据从哪来」可见：

- **名称**：中文标签（搜索股票 / 实时行情 / K线走势 / 财务指标 / 个股新闻 / 大盘速览）。
- **参数摘要**：如「600519 · day · 近 120 根」。
- **状态**：运行中脉冲动画；完成 ✓ / 失败 !。
- **结果**：点击展开查看工具返回数据（超长截断）。

### F05 Markdown 富文本渲染 ✅

- 支持标题、列表、表格、代码块；行内代码单独样式。

### F06 代码块复制与高亮 ✅

- 代码块带「复制」按钮与语法高亮。

### F07 回答 👍/👎 反馈 ✅

- 每条助手回答下方提供 👍/👎 按钮，点击后高亮当前选择并记录在本地。
- 属一期轻量反馈，**未上报服务端**。

### F08 空状态与示例问题 ✅

- 无消息时展示引导页，标题「问行情 · 看走势 · 读财报」。
- 3 个示例问题一键填入并发送：`帮我看看贵州茅台最近的走势和估值` / `今天大盘表现怎么样？` / `搜索一下宁德时代最近的新闻`。
- 未配置模型 Key 时提示「行情数据页仍可正常浏览」。

### F09 系统状态实时检测 ✅

- 每 60 秒检测一次后端状态，Sidebar 页脚实时展示：

| 状态 | 显示 |
|---|---|
| 模型已配 + 行情源正常 | 🟢 系统就绪 |
| 模型已配 + 行情源异常 | 🟠 行情源异常 |
| 未配置模型 Key | 🟠 未配置模型 Key |
| 检测中 | ⚪ 连接中… |

- 页脚附免责声明「数据来自公开行情接口，仅供参考，不构成投资建议」。
