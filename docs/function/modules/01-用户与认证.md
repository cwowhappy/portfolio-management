# M01 · 用户与认证

> **状态**：✅ | **进度**：6/6 | **目标版本**：一期（注册/审核/管理）→ 三期（邮箱验证/找回密码，2026-09-27 交付）
> **页面**：`/login`、`/register`、`/forgot-password`、`/admin` | **技术文档**：[ADR-0007](../../technology/decisions/0007-user-auth.md)

## 一、模块定位

AI 对话消耗 LLM token，需**注册并审核通过**后方可使用；行情数据本身公开，保持免登录。引入用户名+密码的轻量用户体系，管理员审核把关，支持停用与密码重置。

## 三、功能点详情

### F01 用户注册 ✅

- **入口**：`/register`，仅需用户名 + 密码。
- **密码策略**：≥8 位且同时含字母与数字，前后端双重校验，BCrypt 哈希存储。
- **状态机**：注册 → `PENDING`（待审核）；审核通过 → `APPROVED`；拒绝 → `REJECTED`。
- **被拒重注册**：`REJECTED` 用户重新注册时复用原用户名记录（更新密码、置回 `PENDING`）。

### F02 用户登录/登出 ✅

- **入口**：`/login`，用户名 + 密码 + 可选「记住我」。
- **登录条件**：`status=APPROVED AND enabled=true`，待审/被拒/停用均不能登录。
- **会话形态**：同源 Cookie（`JSESSIONID`，HttpOnly + SameSite=Lax）；勾选「记住我」发 30 天令牌，否则关浏览器失效。
- **登录态展示**：顶部导航显示当前用户；未登录访问对话页跳转 `/login`。

### F03 管理员审核 ✅

- `/admin` 待审列表逐一「通过 / 拒绝」；通过后方可使用 AI 对话。

### F04 管理员用户管理 ✅

- 全部用户列表（用户名 / 角色 / 状态 / 启用）。
- **停用即时生效**：受保护接口每次请求校验用户状态，无需等会话过期。
- **重置密码**：管理员代为重置，同样校验密码强度。
- **保护规则**：内置管理员账号不可被审核/停用/重置。

### F05 内置管理员种子 ✅

- 系统无初始账号时，由 `AdminSeedRunner` 按 env `ADMIN_USERNAME` / `ADMIN_PASSWORD` **启动幂等创建** ADMIN 账号（不存在才创建）。
- 未配置则不创建（此时无法审核注册用户，需补配后重启）。

### F06 邮箱验证 / 找回密码 ✅

- **交付**：2026-09（MS-15 / 特性 account-email，分支 feat/account-email）。SMTP 已裁决为**阿里云企业邮箱**（465 SSL，opt-in——未配置时发码端点返回「系统未配置邮件服务」，注册/登录/管理其余功能不受影响）。
- **注册三段式**：`/register` 用户名 + 密码 + 邮箱 + **6 位验证码前置**（先发码验码再落库，用户状态机零改动——注册成功仍为 `PENDING` 待审核）；60s 倒计时防重发。
- **自助找回**：`/forgot-password` 以用户名或邮箱定位账号（仅 USER、已通过、启用且已绑邮箱），向已验证邮箱发码重置密码；**重置成功吊销该账号全部 remember-me 令牌**。
- **管理员代填**：`/admin` 全部用户表「绑定邮箱」——绑定即视为已验证，并向该邮箱尽力发送告知邮件（失败仅记 warn，不影响绑定）。
- **端点三枚**：`POST /api/auth/register-code`、`/api/auth/reset-code`、`/api/auth/reset-password`（均为公开端点）。
- **数据**：V21——`users.email`（归一化小写 + 唯一约束）与 `verification_code` 表（**BCrypt 哈希落库**、用后即焚）。
- **频控**：同邮箱 60s 冷却 / 每日 10 次上限；验证码 5 分钟 TTL，验码 5 次失败即作废。
