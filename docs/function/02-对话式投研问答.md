# 02 · 对话式投研问答

> 页面：`/`（首页）。核心入口，用户以自然语言向 A股投研助手提问，AI 自动调用数据工具并流式输出分析。
> 技术实现见 [docs/technology/02-Agent-实现.md](../technology/02-Agent-实现.md)。

## 2. 会话管理（Sidebar）

会话是对话的隔离单元，每个会话独立保存历史。

| 功能 | 交互 | 说明 |
|---|---|---|
| 新建对话 | 点击「＋新对话」 | 运行中禁用（防止流式输出串写） |
| 切换会话 | 点击会话条目 | 运行中禁用；切换时会先停止旧回答再载入新会话 |
| 删除会话 | 悬停条目出现 ✕ | 删除该会话及其消息历史；删除当前会话则自动新建 |
| 会话标题 | 自动 | 取首条用户消息前 24 字，无消息显示「新会话」 |
| 时间排序 | 自动 | 按更新时间倒序，展示「刚刚 / N 分钟前 / N 小时前 / N 天前」 |

历史持久化于服务端（归属账号，换设备可见），详见 [05-用户管理.md](05-用户管理.md)。

## 3. 提问与流式回答

| 功能 | 交互 | 说明 |
|---|---|---|
| 发送 | Enter 发送 / 点击「发送」 | 支持多行文本；助手就绪后才可发送 |
| 换行 | Shift+Enter | 输入框自适应增高（最高 160px） |
| 停止 | 运行中点击「■ 停止」 | 中断本次流式输出 |
| 流式输出 | 自动 | 逐字渲染，正文增量显示 |

**发送失败**：顶部弹出琥珀色错误条（可关闭），提示错误原因或「请求失败，请稍后重试」。

## 4. 消息渲染

按消息角色分三类渲染：

| 角色 | 渲染 |
|---|---|
| 用户 | 右对齐气泡 |
| 助手 | 左对齐，含工具进度卡片 + Markdown 正文 + 反馈按钮 |
| 思考过程 | 折叠区（`<details>`），显示「思考过程（N 字）」，展开查看推理原文 |

**Markdown 渲染**：支持标题、列表、表格、代码块；代码块带「复制」按钮与语法高亮，行内代码单独样式。

## 5. 工具调用进度

AI 每次调用数据工具，都渲染一张进度卡片，让「数据从哪来」可见：

- **名称**：中文标签（搜索股票 / 实时行情 / K线走势 / 财务指标 / 个股新闻 / 大盘速览）。
- **参数摘要**：如「600519 · day · 近 120 根」。
- **状态**：运行中脉冲动画；完成 ✓ / 失败 !。
- **结果**：点击展开查看工具返回数据（超长截断）。

## 6. 回答反馈

每条助手回答下方提供 👍 / 👎 按钮，点击后高亮当前选择并记录在本地。属一期轻量反馈，未上报服务端。

## 7. 空状态与示例问题

无消息时展示引导页：

- 标题「问行情 · 看走势 · 读财报」。
- 3 个示例问题：`帮我看看贵州茅台最近的走势和估值` / `今天大盘表现怎么样？` / `搜索一下宁德时代最近的新闻`，点击即填入并发送。
- 若未配置模型 Key，显示提示「未检测到 DEEPSEEK_API_KEY…行情数据页仍可正常浏览」。

## 8. 系统状态（Sidebar 页脚）

每隔 60 秒检测一次后端状态，页脚实时展示：

| 状态 | 显示 |
|---|---|
| 模型已配 + 行情源正常 | 🟢 系统就绪 |
| 模型已配 + 行情源异常 | 🟠 行情源异常 |
| 未配置模型 Key | 🟠 未配置模型 Key |
| 检测中 | ⚪ 连接中… |

页脚附免责声明「数据来自公开行情接口，仅供参考，不构成投资建议」。
