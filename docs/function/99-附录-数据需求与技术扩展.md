# 99 · 附录：数据需求与技术扩展

> 从功能全景中剥离的参考性内容：数据从哪来、后端/前端如何扩展、定时任务规划。

## 一、数据需求与来源

### 已有数据（一期 ✅）

| 数据 | 用途 | 来源 |
|------|------|------|
| 个股实时行情 | 报价/K线/盘口 | 东方财富公开接口 |
| 个股财务指标 | PE/PB/ROE/营收/净利润 | 东方财富公开接口 |
| 个股新闻 | 新闻列表 | 东方财富公开接口 |
| 主要指数点位 | 指数速览 | 东方财富公开接口 |

### 新增数据需求

| 数据 | 用途 | 来源方案 | 优先级 |
|------|------|---------|:------:|
| 全 A 股 PE/PB 日快照 | 市场估值仪表盘 | 每日收盘后抓取全部个股计算中位数 | **高** |
| 指数 PE/PB 历史 | 指数估值分位 | 东财/中证指数公司 | **高** |
| 10 年期国债收益率 | 股债利差计算 | 中国债券信息网/公开 API | **高** |
| 申万行业分类映射 | 行业分布/行业估值对比 | 内置静态表（定期更新） | **高** |
| 行业个股加权估值 | 行业 PE/PB 计算 | 基于个股估值数据按市值加权 | **高** |
| 指数成分股列表 | 筛选范围限制 | 内置静态表（每半年更新） | 中 |
| 个股历史 PE/PB | 个股估值分位 | 基于财报和股价日数据计算 | 低 |
| 未上市企业工商数据 | 行业研究中心未上市部分 | 天眼查 API | 二期 |
| 未上市企业融资数据 | 融资动态/竞争格局 | 天眼查 / IT桔子 | 二期 |
| 企业专利/诉讼/风险 | 未上市企业画像 | 天眼查 API | 二期 |

## 二、技术架构扩展（规划）

### 后端新增领域（遵循 DDD 分层）

```
domain/
  valuation/          # 估值域：市场估值快照、指数估值、行业估值、历史数据
  portfolio/          # 组合域：持仓、交易记录、分红、分组
  allocation/         # 配置域：资产配置方案、模板、再平衡规则
  screening/          # 筛选域：筛选条件定义、结果、缓存
  journal/            # 日志域：买卖备忘录、复盘记录、研究笔记
  industry/           # 行业研究域：行业分类、上市企业聚合、未上市企业缓存
```

> 新增域需在 `PackageConventionsTest.java` 中登记依赖白名单，规范见 [docs/technology/conventions/01-后端DDD分包规范.md](../technology/conventions/01-后端DDD分包规范.md)。

### 前端新增页面

```
app/
  (dashboard)/
    valuation/        # 市场估值仪表盘（含行业估值对比）
    portfolio/        # 持仓组合管理
    allocation/       # 资产配置
    screener/         # 价值投资筛选器
    industry/         # 行业研究中心
    journal/          # 投资日志
    analytics/        # 收益分析
    wiki/             # 投资知识库
```

### 定时任务

| 任务 | 频率 | 说明 |
|------|------|------|
| 估值快照抓取 | 每日收盘后 | 已落地（Python collector）：计算全 A 股 PE/PB 中位数、破净股数量、各行业加权估值等 |
| 筛选结果缓存清理 | 每周 | 清理过期缓存 |
| 未上市企业数据同步 | 每日/每周 | 同步天眼查关注的行业企业数据（二期） |
