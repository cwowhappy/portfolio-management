# 99 · 附录：数据需求与技术扩展

> 从功能全景中剥离的参考性内容：数据从哪来、后端/前端如何扩展、定时任务规划。

## 一、数据需求与来源

### 已有数据（一期 ✅）

| 数据 | 用途 | 来源 |
|------|------|------|
| 个股实时行情 | 报价/K线/盘口 | 东方财富公开接口（一期调研时点方案；2026-09-25 起主源已切腾讯，东财/新浪兜底，见 ADR-0003 变更记录） |
| 个股财务指标 | PE/PB/ROE/营收/净利润 | 东方财富公开接口 |
| 个股新闻 | 新闻列表 | 东方财富公开接口 |
| 主要指数点位 | 指数速览 | 东方财富公开接口（一期调研时点方案；2026-09-25 起主源已切腾讯，东财/新浪兜底，见 ADR-0003 变更记录） |

### 新增数据需求

| 数据 | 用途 | 来源方案 | 优先级 |
|------|------|---------|:------:|
| 全 A 股 PE/PB 日快照 | 市场估值仪表盘 | 每日收盘后抓取全部个股计算中位数 | **高** |
| 指数 PE/PB 历史 | 指数估值分位 | 东财/中证指数公司 | **高** |
| 10 年期国债收益率 | 股债利差计算 | 中国债券信息网/公开 API | **高** |
| 申万行业分类映射 | 行业分布/行业估值对比 | 内置静态表（定期更新） | **高** |
| 行业个股加权估值 | 行业 PE/PB 计算 | 基于个股估值数据按市值加权 | **高** |
| 指数成分股列表 | 筛选范围限制 | 内置静态表（每半年更新） | 中 |
| 个股历史 PE/PB | 个股估值分位 | 基于财报和股价日数据计算 | 低 |
| 未上市企业工商数据 | 行业研究中心未上市部分 | ~~天眼查 API~~ → 人工策展名单+LLM 辅助核对（2026-09-26 裁决，轻量口径 0 元；企查查 0.10 元/次留可选增强） | 三期 |
| 未上市企业融资数据 | 融资动态/竞争格局 | 人工月度摘录公开源（睿兽分析月报等）→ CSV 导入（月度粒度非全量，不做自动采集） | 三期 |
| 企业专利计数（可选富化） | 未上市企业画像 | CNIPA PSS 免费渠道按需人工核对（工商/诉讼全字段不做） | 三期 |

## 二、技术架构扩展

### 后端新增领域（遵循 DDD 分层，均已上线）

```
domain/
  valuation/          # 估值域：市场估值快照、指数估值、行业估值、历史数据（V3/V4）
  portfolio/          # 组合域：持仓、交易记录、分红、分组（V5）
  allocation/         # 配置域：资产配置方案、模板、再平衡规则（V6）
  screening/          # 筛选域：筛选条件与结果（消费 V7 个股基本面底座，无独立表）
  journal/            # 日志域：买卖备忘录、复盘记录、研究笔记（V8）
  mcp/                # MCP 域：provider/endpoint 内置目录、用户配置、鉴权建模（V10）
  skill/              # Skill 域：用户启用配置（目录内容在 classpath，V11）
```

> industry/（行业研究域，含未上市企业缓存）随二期行业研究深化落地；新增域需在 `PackageConventionsTest.java` 中登记依赖白名单，规范见 [docs/technology/conventions/01-后端DDD分包规范.md](../technology/conventions/01-后端DDD分包规范.md)。

### 前端页面（已上线 / 规划）

```
app/                  # 路由根：全站共 13 个已上线页面路由（含一期 /、/market、/login、/register、/admin）
  valuation/          # 市场估值仪表盘（含行业估值对比）
  portfolio/          # 持仓组合管理
  allocation/         # 资产组合配置
  screener/           # 价值投资筛选器
  industry/           # 行业研究中心
  journal/            # 投资日志
  settings/mcp/       # MCP 数据源设置
  settings/skills/    # Skill 设置
                      # 规划
  analytics/          # 收益分析（二期）
  wiki/               # 投资知识库（二期）
```

### 定时任务

| 任务 | 频率 | 说明 |
|------|------|------|
| 估值快照抓取 | 每日收盘后 | 已落地（Python collector）：计算全 A 股 PE/PB 中位数、破净股数量、各行业加权估值等 |
| 筛选结果缓存清理 | 每周 | 清理过期缓存 |
| 融资事件导入 | 按需（月度节奏） | 人工摘录公开源（睿兽分析月报等）→ CSV 导入端点，月度粒度非全量口径（三期 MS-10，grilling 决策 #3：不做 collector 自动采集）；策展企业/产业链映射走管理界面与 CSV 装载，不设同步任务 |
