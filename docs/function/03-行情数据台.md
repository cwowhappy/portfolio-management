# 03 · 行情数据台

> 页面：`/market`。无需模型 Key 即可独立使用的行情浏览页，覆盖「指数 → 搜索 → 报价 → K线 → 财务 → 新闻」的完整看盘链路。
> 数据接口见 [docs/technology/04-接口.md](../technology/04-接口.md)。

## 1. 页面结构

自上而下：

1. **指数速览条**（3 张指数卡片，30 秒自动刷新）
2. **股票搜索框**（防抖搜索，下拉候选）
3. 选中股票后依次展示：
   - **报价头**（价格 + 涨跌 + 盘口指标）
   - **K线走势**（日/周/月切换 + 均线 + 成交量）
   - **财务指标表** + **近期新闻**（左右两栏）

## 2. 指数速览

- 展示 **上证指数 / 深证成指 / 创业板指** 三张卡片：名称、点位、涨跌额、涨跌幅。
- 涨红跌绿着色（A股惯例）。
- 每 **30 秒**自动刷新一次；加载中显示骨架屏。

## 3. 股票搜索

- 输入股票名称或代码（如「茅台」「600519」），**防抖 300ms** 后搜索。
- 下拉候选展示：名称、代码、市场归属（沪市 / 深市 / 北交所）。
- 仅返回 A股（已剔除指数 / 板块 / 基金 / 债券 / 期货条目）。

## 4. 实时报价（报价头）

选中股票后，并行加载报价、K线、财务、新闻四类数据；快速连续切换时不串数据（丢弃过期响应）。

报价头展示：

| 区域 | 字段 |
|---|---|
| 主信息 | 名称、代码、行情时间、最新价、涨跌额、涨跌幅 |
| 盘口指标 | 今开、最高、最低、昨收、成交量（万手）、成交额（亿/万亿） |
| 估值 | 市盈率（PE）、市净率（PB） |

## 5. K线走势

蜡烛图（前复权），能力：

- **周期切换**：日K / 周K / 月K，切换即时刷新。
- **均线**：MA5（琥珀色）、MA20（蓝色），图例随附。
- **成交量**：蜡烛下方柱状图，红涨绿跌。
- **最新价虚线** + 价格刻度。
- **网格线** + 最高/最低价刻度 + 首/中/末日期标签。
- **悬停明细**：鼠标移动高亮对应 K 线，浮层显示 日期 / 开 / 收 / 高 / 低 / 量。

## 6. 财务指标

表格展示最近 **6 个报告期**：

| 列 | 字段 |
|---|---|
| 报告期 | 报表日期 |
| 营收 | 营业收入（亿元格式化） |
| 净利润 | 归母净利润（亿元格式化，正负着色） |
| ROE | 加权净资产收益率（%） |
| 毛利率 | 销售毛利率（%） |
| EPS | 每股收益 |

## 7. 个股新闻

列表展示近期新闻：

- **标题**：外链，可跳转原文。
- **摘要**：去 HTML 后截断 120 字，两行显示。
- **来源 + 时间**。

## 8. 加载与错误状态

- **加载**：选中后报价头 + K线区域显示骨架屏。
- **错误**：数据拉取失败时琥珀色错误条提示；K线周期切换失败保持旧图。
- **空状态**：未选中时显示「搜索一只股票，查看行情、走势、财务与新闻」。
