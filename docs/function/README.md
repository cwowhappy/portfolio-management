## 一句话定位

面向个人价值投资者的 **投研 + 配置 + 持仓 + 复盘** 一体化管理系统：

- **一期（✅ 已交付）**：A股投研对话助手 + 行情数据台——用自然语言提问行情、走势、财务与新闻，AI Agent 自动调用数据工具获取实时公开行情数据，流式输出分析结论
- **MVP（⏳ 待开发）**：市场估值仪表盘 + 资产配置 + 持仓组合管理 + 价值投资筛选器
- **二期（⏳ 待规划）**：行业研究中心（未上市部分）+ 投资日志 + 收益分析 + 再平衡 + AI 持仓分析
- **三期（⏳ 待规划）**：产业链图谱 + 风险指标 + 收益归因 + 配置回测

## 维护约定

- 新增功能点：先登记到对应模块文档的「功能点列表」与「功能点详情」，再同步 [00-功能模块概览.md](00-功能模块概览.md) 的看板与统计。
- 功能点状态流转（⏳→🚧→✅）以代码实际交付为准，改状态同时更新模块进度（n/m）与概览统计。
- 新增模块：在 `modules/` 下编号续接，并登记到概览看板与本索引。
