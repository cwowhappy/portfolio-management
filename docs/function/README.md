# 产品功能目录（docs/function）

> 本目录从**产品功能**视角梳理「砚台 · A股投研助手」（证券投资与分析系统一期）的能力，
> 供产品、设计、测试与新成员快速建立对系统的整体认知。
> 技术实现见 [docs/technology/](../technology/)，架构设计见 [docs/plans/](../plans/2026-08-18-投资分析AI-Agent一期设计.md)，
> 技术决策见 [docs/adr/](../adr/)。

## 一句话定位

面向个人投资者的 **A股投研对话助手**：用自然语言提问行情、走势、财务与新闻，
AI Agent 自动调用数据工具获取实时公开行情数据，流式输出分析结论，
并配套一个可直接浏览的**行情数据台**。

## 范围速览

**已交付（In）**

- 对话式投研问答（A股），流式交互（需登录）
- AI 内置 6 类数据查询能力
- 独立行情数据台（公开）
- 用户管理：注册/登录、管理员审核、停用/启用、重置密码
- 会话服务端持久化、归属账号、换设备可见
- Docker Compose 一键部署 / 本地开发流

**暂不包含（Out，后续期）**

- 持仓组合管理、选股策略、定时监控提醒（二期）
- 多租户、交易指令执行、回测、找回密码/邮箱短信验证（后续期）
- 实时推送、移动端
