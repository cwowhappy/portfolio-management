# 00 · 功能模块概览（第一层）

> 版本：v2.0（2026-08-26）
> 定位：**全部功能模块的总览与进度看板**。本文件只回答两个问题——系统有哪些功能模块、每个模块做到哪了。
> 单模块的功能点清单与逐个功能点的详细说明，请进入各模块文档（第二层、第三层）。

---

## 一、产品定位

**产品名**：砚台 · 价值投资与资产配置系统（项目名 portfolio-management）

面向个人价值投资者的「投研 + 行业研究 + 配置 + 持仓 + 复盘」一体化管理系统：从「查信息」进化为「看行业、管资产、做决策、验结果」的完整投资闭环。

**技术栈**：Spring Boot 4 + PostgreSQL/Flyway + Next.js 15 + CopilotKit + AgentScope Java + DeepSeek
