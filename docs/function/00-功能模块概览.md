---

## 一、产品定位

**产品名**：九和 · 价值投资与资产配置系统（项目名 portfolio-management）

面向个人价值投资者的「投研 + 行业研究 + 配置 + 持仓 + 复盘」一体化管理系统：从「查信息」进化为「看行业、管资产、做决策、验结果」的完整投资闭环。

**技术栈**：Spring Boot 4 + PostgreSQL/Flyway + Next.js 15 + CopilotKit + AgentScope Java + DeepSeek
