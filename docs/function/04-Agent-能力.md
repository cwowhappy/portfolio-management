# 04 · AI 投研能力

> 内置投研助手的产品能力：能查询哪些数据、遵循什么回答规范。
> 技术实现（Agent 装配、模型配置、工具代码）见 [docs/technology/02-Agent-实现.md](../technology/02-Agent-实现.md)。

## 1. 角色定位

一位面向个人投资者的 **A股投资研究助手**：用户用自然语言提问行情、走势、财务与新闻，助手自动调用数据工具获取实时数据，并给出结构化分析。

## 2. 可查询的数据（6 类）

| 能力 | 用户会问什么 | 返回什么 |
|---|---|---|
| 股票搜索 | 「茅台」「600519 是哪只」 | 候选股票：代码、名称、市场归属 |
| 实时行情 | 「茅台现在多少钱」 | 最新价、涨跌额/幅、今开/最高/最低/昨收、成交量/额、市盈率、市净率、行情时间 |
| K线走势 | 「茅台最近走势怎么样」 | 历史 K线（日/周/月），用于趋势、均线、成交量分析 |
| 财务指标 | 「茅台估值高不高、赚钱能力如何」 | 每股收益、每股净资产、营收、净利润、加权 ROE、毛利率，及市盈率/市净率 |
| 个股新闻 | 「茅台最近有什么消息」 | 近期新闻：标题、摘要、来源、时间 |
| 大盘速览 | 「今天大盘怎么样」 | 上证指数、深证成指、创业板指的点位与涨跌幅 |

## 3. 回答规范

助手被要求遵守：

- **结论先行**：先给结论，再列数据支撑；适当使用要点或表格。
- **数据真实**：所有数据必须来自工具调用结果，**禁止虚构价格、涨跌幅或财务数字**；工具因数据源不可用返回错误时如实说明，不编造。
- **多维度分析**：结合价格趋势、成交量、估值、消息面，并指出风险点。
- **事实与观点分离**：明确区分事实与观点。

## 4. 与行情数据台的关系

助手查询的数据与行情数据台**同源**（同一套行情数据服务）。区别在于：对话页由 AI 自动编排数据并生成分析，行情台由用户手动浏览原始数据，两者互为补充。

## 5. 免责声明

数据来自公开行情接口，可能存在延迟或误差；所有分析由 AI 生成，仅供参考，**不构成任何投资建议**。市场有风险，投资需谨慎。
