# 证券投资分析系统一期 · AI Agent Web 服务设计文档

> 状态：已确认（2026-08-18）· 目标：交付可运行的 A股投研对话 Agent Web 服务

## 1. 目标与范围

**一期目标**：个人/团队自用的 A股投研助手。用户在网页用自然语言提问（行情、走势、财务、新闻），
AI Agent 自动调用数据工具获取实时数据，以流式方式输出分析回答，并在界面上展示工具调用进度。

**一期范围（In）**
- 对话式投研问答（A股市场），AG-UI 流式交互
- 6 个 Agent 工具：股票搜索、实时行情、K线、财务指标、个股新闻、大盘速览
- 独立行情 REST API（供 Agent 工具与前端页面共用）
- Next.js 聊天界面 + 行情速览页
- Docker Compose 一键部署；本地 Makefile 开发流

**非目标（Out，后续期）**
- 持仓组合管理、选股策略、定时监控提醒（二期）
- 用户鉴权/多租户、交易指令执行、回测（三期+）
- 实时推送（WebSocket）、移动端

## 2. 总体架构

- 浏览器 UI（聊天 + 行情页）→ 同源反代 → frontend（Next.js 15/React 19）
  - /api/chat 透传 AG-UI SSE；/api/market 反代 REST
- frontend → HTTP → backend（Spring Boot 4.0.3）
  - AG-UI 官方 starter 端点 + ReActAgent + InvestTools(6个工具)
  - MarketDataService（TTL 缓存 + 限流 + 降级）
- backend → DeepSeek API（api.deepseek.com）
- backend → 东方财富/新浪公开接口（push2.eastmoney.com 等）

## 4. Agent 设计

### 4.1 工具集（一期 6 个 @Tool）

| 工具名 | 参数 | 说明 | 缓存 |
|---|---|---|---|
| search_stock | query | 名称/代码模糊搜索，返回候选列表 | 10min |
| get_quote | code | 实时行情：价格/涨跌幅/量额/高低开 | 15s |
| get_kline | code, period(day/week/month), limit | K线历史，用于趋势判断 | 5min |
| get_financials | code | 营收/净利/ROE/EPS/PE/PB 等指标 | 1h |
| get_news | code, limit | 个股新闻：标题/摘要/来源/时间 | 5min |
| get_market_overview | - | 上证/深成/创业板指数速览 | 15s |

### 4.2 Agent 配置
- ReActAgent：中文系统提示词（投研助手人设 + 免责声明 + 数据时效说明 + 工具使用规范）
- 模型：deepseek:<model>（ModelRegistry 自动读 DEEPSEEK_API_KEY，专用 DeepSeek formatter）
- maxIters=10（默认）；工具并发执行关闭（parallelToolCalls=false，行情工具串行更稳）

## 5. 交互协议（AG-UI）

采用 AG-UI 标准协议（ag-ui-protocol），由 AgentScope 官方 agentscope-agui-spring-boot-starter
自动注册端点并完成 AgentEvent → AG-UI 事件 映射。

- 前端 POST /agui（可配 path-prefix），body 为 RunAgentInput：
  { "threadId": "会话UUID", "runId": "本轮UUID", "messages": [...], "state": {}, "tools": [], "forwardedProps": {} }
- 响应为 AG-UI SSE 事件流：RUN_STARTED → TEXT_MESSAGE_START/CONTENT/END（正文增量）、
  REASONING_MESSAGE_*（思考，可选开启）、TOOL_CALL_START/ARGS/END + TOOL_CALL_RESULT（工具进度）、
  CUSTOM(token_usage 等) → RUN_FINISHED / RUN_ERROR
- 会话模型：server-side-memory=false —— 前端持有完整消息历史并以 threadId 标识会话
  （本地 localStorage 持久化），每轮发送全部历史；后端无会话文件状态，重启即恢复，与 OpenAI 语义一致
- 前端 /api/chat 路由透传 SSE（force-dynamic）；/api/market/[...path] 反代 REST

## 6. 数据服务设计

- MarketDataService（WebClient，超时 5s）：quote/kline/search/financials/news/overview
- 本地 TTL 缓存（ConcurrentHashMap + 过期时间，见上表）
- 限流：令牌桶 5 req/s（保护免费接口，避免被封）
- 降级：东财失败 → 新浪行情兜底；最终失败返回结构化错误文本给模型（Agent 会换问法）
- DTO 与工具返回均为 JSON 文本；SSE 中 tool_result 截断防超长

## 7. 错误处理

- 未配置 DEEPSEEK_API_KEY：/api/agent/health 报告 llm.keyConfigured=false；
  聊天端点返回友好中文错误事件（RUN_ERROR + message）
- 行情源异常：工具返回结构化错误（错误码+建议），不抛裸异常
- 前端：SSE 断线提示重试；同 threadId 可续传；输入防抖

## 8. 测试策略

- 后端单测：行情响应解析器（离线 fixture，不依赖网络）、工具参数校验、健康检查
- 后端集成：Spring 上下文冒烟（无 LLM key 也能启动）
- 端到端：scripts/smoke.sh（健康检查→行情接口→有 key 时跑真实对话）
- 前端：SSE 事件解析器、ToolCallCard 组件单测；其余人工冒烟
