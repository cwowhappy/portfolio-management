# 一期 AI Agent Web 服务实施计划

> 依据设计文档 docs/plans/2026-08-18-投资分析AI-Agent一期设计.md

**目标**：交付可运行的 A股投研对话 Agent Web 服务（backend + frontend + Compose）。

**技术栈**：Spring Boot 4.0.3 / Java 21 / Gradle 9 / AgentScope Java 2.0.1 / DeepSeek /
Next.js 15 / React 19 / TS / 东方财富+新浪数据源。

---

## 阶段 A：后端骨架
- A1 目录与构建：backend/（settings.gradle、build.gradle、Gradle wrapper 9.x、application.yml、.env 支持）
- A2 健康检查：/api/agent/health（LLM key 状态 + 行情源连通性）
- A3 Spring 上下文冒烟测试（无 LLM key 可启动）

## 阶段 B：行情数据服务
- B1 MarketDataClient：东方财富 quote/kline/search/financials/news/overview + 新浪兜底（WebClient，5s 超时）
- B2 解析器 + DTO（JsonNode 解析，防御空值）
- B3 解析器单测（离线 fixture：src/test/resources/fixtures/*.json）
- B4 TTL 缓存 + 令牌桶限流
- B5 MarketController：/api/market/* REST（search/quote/kline/financials/news/overview）

## 阶段 C：Agent 装配
- C1 依赖：agentscope-core、extensions-model-openai、agui-spring-boot-starter
- C2 ModelConfig：deepseek:<model> 解析（DEEPSEEK_API_KEY，模型名可配）
- C3 InvestTools：6 个 @Tool 方法（调用 MarketDataService，返回 JSON 文本；异常返回结构化错误文本）
- C4 AgentConfig：ReActAgent（中文 sysPrompt、toolkit、maxIters、关闭并行工具调用）
- C5 AG-UI 端点配置（agentscope.agui.*：path-prefix /agui、server-side-memory=false、emit-reasoning）

## 阶段 D：前端
- D1 脚手架：Next.js 15 + TS + Tailwind，目录 app/ components/ lib/
- D2 lib/agui：AG-UI SSE 事件解析器（fetch + ReadableStream，逐行解析 event/data）
- D3 lib/api：/api/chat 反代（透传 SSE）+ /api/market/[...path] 反代
- D4 聊天页：会话列表（localStorage）、消息流渲染、Markdown、思考折叠区
- D5 ToolCallCard：工具进度卡片（tool_start→args 摘要→result 折叠）
- D6 行情速览页：指数卡片 + 搜索 + 报价 + K线（轻量 SVG）
- D7 单测：agui 解析器、ToolCallCard（vitest）

## 阶段 E：联调与交付
- E1 scripts/smoke.sh：健康检查 → 行情接口 → 有 key 时真实对话
- E2 docker-compose.yml + Dockerfile×2 + .env.example + Makefile（dev/test/up/down）
- E3 README.md（快速开始 + 架构图 + 截图位）+ 收尾整理、git 提交
