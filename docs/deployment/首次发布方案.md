# 三服务首次发布方案（Ubuntu 直接部署，无 Docker）

> 环境：阿里云 Ubuntu 服务器 + 已有 Nginx（HTTPS）。三个服务以本机进程 + systemd 方式直接部署，不用 Docker。

## 一、架构

```
浏览器 ─HTTPS─► Nginx(:443) ──► frontend(node :3000)
                                  └─ /api/** 同源反代 → backend(java :8080)
backend ──► postgresql(:5432)
collector(python 定时) ──► postgresql(:5432)
```

- 唯一对外入口是 **frontend**（`/api/**` 由它反代到 backend）；backend/collector 只监听 localhost。
- 三个服务各一个 **systemd 单元**；PostgreSQL 用 apt 自带服务。

## 二、安装运行时（一次性）

```bash
# JDK 21（后端构建 + 运行）
sudo apt install -y openjdk-21-jdk-headless

# Node 22 + pnpm（前端）
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt install -y nodejs
corepack enable && corepack prepare pnpm@11.22.0 --activate

# Python 3.12（collector）
sudo apt install -y python3.12 python3.12-venv

# PostgreSQL（Ubuntu 24.04 默认 16；更老版本需 PGDG 源）
sudo apt install -y postgresql postgresql-contrib

# 运行用户 + 目录
sudo useradd -r -m -d /opt/invest invest
sudo mkdir -p /opt/invest/{backend,frontend,collector}
```

## 三、准备数据库

```bash
sudo -u postgres psql <<'SQL'
CREATE USER invest WITH PASSWORD '你的强密码';
CREATE DATABASE invest OWNER invest;
SQL
```

## 四、构建产物（服务器上 git clone + 构建）

```bash
sudo git clone <仓库地址> /opt/invest/src
cd /opt/invest/src

# 1) 后端 bootJar
cd backend && sudo ./gradlew bootJar --no-daemon
sudo cp build/libs/*.jar /opt/invest/backend/app.jar

# 2) 前端 standalone（next.config 已 output: "standalone"）
cd ../frontend && sudo pnpm install --frozen-lockfile && sudo pnpm build
sudo cp -r .next/standalone/. /opt/invest/frontend/
sudo cp -r .next/static /opt/invest/frontend/.next/static
sudo cp -r public /opt/invest/frontend/public

# 3) collector venv + 源码
cd ../collector
sudo python3.12 -m venv /opt/invest/collector/.venv
sudo /opt/invest/collector/.venv/bin/pip install -r requirements.txt
sudo cp -r collector migrations tasks /opt/invest/collector/

sudo chown -R invest:invest /opt/invest
```

## 六、systemd 三个单元

**`/etc/systemd/system/invest-backend.service`**

```ini
[Unit]
Description=Invest Agent Backend
After=network.target postgresql.service

[Service]
User=invest
WorkingDirectory=/opt/invest/backend
EnvironmentFile=/opt/invest/.env
ExecStart=/usr/bin/java -jar /opt/invest/backend/app.jar
Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target
```

**`/etc/systemd/system/invest-frontend.service`**

```ini
[Unit]
Description=Invest Agent Frontend
After=network.target

[Service]
User=invest
WorkingDirectory=/opt/invest/frontend
Environment=PORT=3000
Environment=BACKEND_URL=http://localhost:8080
ExecStart=/usr/bin/node /opt/invest/frontend/server.js
Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target
```

**`/etc/systemd/system/invest-collector.service`**

```ini
[Unit]
Description=Invest Agent Collector
After=network.target postgresql.service

[Service]
User=invest
WorkingDirectory=/opt/invest/collector
EnvironmentFile=/opt/invest/.env
ExecStart=/opt/invest/collector/.venv/bin/python -m collector.scheduler.jobs
Restart=on-failure
RestartSec=5

[Install]
WantedBy=multi-user.target
```

## 七、Nginx（`/etc/nginx/conf.d/invest.conf`）

```nginx
server {
    listen 80;
    server_name <你的域名>;
    return 301 https://$host$request_uri;
}
server {
    listen 443 ssl http2;
    server_name <你的域名>;
    ssl_certificate     /etc/letsencrypt/live/<域名>/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/<域名>/privkey.pem;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_buffering off;          # 关键：AI 对话 SSE 流式
        proxy_read_timeout 300s;
        proxy_send_timeout 300s;
    }
}
```

## 八、启动 + 迁移

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now invest-backend invest-frontend invest-collector
sudo systemctl status invest-backend invest-frontend invest-collector --no-pager
```

**首次启动自动完成**：backend Flyway V1–V9 建表 + `AdminSeedRunner` 种子管理员；collector `alembic upgrade head` 建采集表。

## 九、验证

```bash
curl -s http://127.0.0.1:8080/api/agent/health                    # 后端 liveness
curl -s http://127.0.0.1:3000/api/market/overview | grep 上证指数   # 前端反代
curl -s https://<域名>/api/market/overview | grep 上证指数          # HTTPS 全链路
# 浏览器 https://<域名> → 登录 → 发 AI 对话（验 SSE 流式）
# collector 数据落地：
journalctl -u invest-collector -f | grep -iE "success|rows"
```

> 数据新鲜度：collector 是定时增量，首次跑满一个周期前，估值/持仓页显示「数据积累中」属正常。

## 十、回滚与运维

```bash
# 回滚：git 切旧 commit → 重新构建对应产物 → 重启对应服务
cd /opt/invest/src && sudo git checkout <旧commit>
cd backend && sudo ./gradlew bootJar --no-daemon && sudo cp build/libs/*.jar /opt/invest/backend/app.jar
sudo systemctl restart invest-backend

# 日志
journalctl -u invest-backend -f
journalctl -u invest-collector -f

# 数据库备份
sudo -u postgres pg_dump invest > backup_$(date +%F).sql

# 升级（后续发布）
cd /opt/invest/src && sudo git pull && （重新构建受影响服务）&& sudo systemctl restart <服务>
```
