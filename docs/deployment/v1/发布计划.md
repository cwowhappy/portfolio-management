- 三期功能全部收口（2026-09-27，115/115），CI 四 job（backend/frontend/collector/e2e）绿，`make smoke` §1~§6 脚本齐备——**代码侧发布条件已具备，但从未在部署机实际执行过**。

## 三、阶段 A：发布前工程收口（仓内代码工作）

### A1 Flyway 迁移 squash（对应决策 D2/D3）

现状：`backend/src/main/resources/db/migration/` 下 V1~V21 共 22 个文件（含 V19.1 点版本，成因为 dev 库不可原地改 checksum）。

动作：

1. **合并为单一 `V1__baseline.sql`**，合并细则：
   - V4 中间表消除：`treasury_yield` 建了再删 → 直接建最终 `treasury_yield_curve` 结构；
   - V19 + V19.1 种子合并为相对日期版（`CURRENT_DATE` 偏移；V19.1 本就是把 V19 固定日期改为相对日期的补丁，合并即取补丁后语义）；V20 的按公司名引用与末尾 `setval()` 保持；
   - V10 MCP seed（`auth_secret_enc` NULL 占位）原样保留，部署后手工 UPDATE 口径不变（方案 §十）；
   - **验收基准：squash 后空库跑出的 schema 与 squash 前逐表一致**（列/类型/约束/序列）。
2. **删除 22 个旧文件**（D3：git 历史即归档）。
3. **硬编码引用同步**（三处代码 + docs 全量）：
   - `backend/src/integrationTest/java/com/portfolio/invest/migration/FlywayMigrationIntegrationTest.java`：版本序列断言 `containsExactly("1", …, "21")` 改为 `containsExactly("1")`；各表 schema 契约断言不动；
   - `collector/tests/conftest.py`：`FLYWAY_SQL_FILES` 六文件清单改为基线单文件，"V3→V4 顺序不可颠倒"注释随之作废（`ALL_TABLES` 不变，表都还在基线里）；
   - docs 全量同步：`grep -rn "db/migration/V\|V1–V\|V1-V" docs/` 逐处改为"V1 基线（原 VN__xxx）"口径——已知热点：`technology/architecture/01-系统架构.md`、`02-技术栈与工程结构.md`（V1–V13/28 张表表述）、`technology/research/06-证券数据来源与存储管理梳理.md`（V1-V20 多处）、`technology/modules/12-资产配置域.md`、`14-收益分析域.md`（引用具体迁移文件名）。
4. **本地 dev 库重建**：drop/create `invest` → 重启后端（Flyway 跑基线）→ collector 启动自动 `alembic upgrade head`。

验收：CI 四 job 绿（e2e 66 用例内含依赖 V19 系种子落在"近 12/24 月窗口"的断言，相对日期语义合并后不变）；本地 dev 库重建后 smoke §1~§4 绿。

## 六、阶段 D：发布验收（发布日）

- **D1 自动冒烟**：部署机 `/opt/invest/src` 跑 `make smoke`，§1~§6 **全绿且无跳过**——§5 需 `DEEPSEEK_API_KEY`+`ADMIN_*`（真 LLM）；§6 需 `MAIL_SMTP_HOST/USERNAME/PASSWORD/FROM` 四变量（真 SMTP 发信至 `MAIL_FROM`；脚本对固定码环境自动跳过，**跳过≠通过**）。
- **D2 人工清单**：
  1. 浏览器 HTTPS：登录（含"记住我"）→ AI 对话 SSE 流式 → 至少一次工具调用；
  2. 注册页邮箱验证码真实收信 + 忘记密码全流程走通；
  3. 飞书：手动触发一次采集任务看终态告警卡片到达；单聊对话往返一条；
  4. `journalctl -u invest-collector` 看首日任务落地（rows_written）；估值/持仓页首日"数据积累中"属正常（定时增量，见方案 §九注记）；
  5. 页面走查：估值/筛选/持仓/收益分析/投资日志/设置（MCP 开关、Skill 开关）。
- **D3 回滚预案**：发布日操作前 `pg_dump` 基线备份一次；代码回滚 = git checkout 旧 commit 重建重启对应服务（方案 §十一）。

| smoke opt-in 段假绿（跳过被误读为通过） | §6 固定码/半配置守卫已内建；验收时人工确认"真发"输出 |
| 飞书 wss 长连接出站受阻 | C3 探测含长连接出站口径；P2 实施文档连通性 checklist |
| SSE 经 Nginx 卡顿/断流 | 方案 §七 已配 `proxy_buffering off` + 300s 超时；D2-1 人工复核 |
| `.env` 值含 `#` 时三种加载器语义分歧：make（`-include`）把 `#` 后当注释**截断**、bash（`source`）保留、systemd（`EnvironmentFile`）保留——2026-09-28 实测本地 `make dev` 起 bootRun 拿截断 SMTP 密码 → 526 拒登 → smoke §6 假红 | 凭证值避免 `#`（企业邮箱侧重置为纯字母数字最稳）；部署机 systemd 不剥行内 `#` 不受影响；本地排查此类问题先比对 make/bash 两套加载值；Makefile 加载改造另行排期 |
| 一步到位连锁延期（凭证是关键路径） | B 阶段与 A 并行启动；任一凭证未齐 → 发布日整体顺延，不做半功能上线 |
