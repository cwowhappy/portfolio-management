## 一、调研背景与目的

本项目（A 股投研对话助手）v1 已于 2026-10-03 收官：一期 MS-00~19 共 115 功能点 + 阶段二 MS-20~27 共 34 功能点全部交付，系统进入「v1 后打磨期」。下一个问题自然是：**下一步往哪迭代？**

本报告收集 2025–2026 金融投研 Agent 的行业发展趋势，对照本系统现状基线做差距分析；功能迭代与完善方向单独成册（见上链接），供里程碑规划（MS-28 及以后）参考。

## 二、行业趋势分析（2025–2026）

### T1. 2026 成为「金融智能体元年」，从试点走向规模化验证

- 业内将 2026 年视为「金融智能体元年」：多家券商半年报披露 AI 战略，AI 深度嵌入财富管理、投研、投行、合规风控核心流程；行业判断 2026 是券商 AI Agent **从试点走向规模化验证的关键节点**（[东方财富 2026-08-08](https://finance.eastmoney.com/a/202608083835587139.html)、[雪球 2026-09-30](https://www.xueqiu.com/1184824257/411015368)）。
- 券商从「自研内用」迈向「生态开放」：密集接入互联网平台智能体生态——Kimi 进入中信建投投研会议室、腾讯 WorkBuddy 帮广发证券合规岗自动筛查尽调报告、阿里千问/火山引擎相继布局金融赛道（[搜狐 2026-09-28](https://m.sohu.com/a/1081625070_122066679?scm=10001.325_13-325_13.0.0-0-0-0-0.5_1334)）。
- 金融机构采购侧已全面铺开：2026 年银行/券商/保险智能体招标聚焦投研、投顾、合规风控、客户营销四大场景，且要求**可治理的企业级 Agent 统一入口**（[21 财经 2026-06-24](https://m.21jingji.com/article/20260624/herald/adcc033a708823ffd32749bf979fc96b.html)）。

### T2. 多智能体协同成为复杂投研的主流架构

- 行业共识：单一问答 Agent 难以覆盖复杂投研全流程，正在走向**分工式多 Agent 集群**——文档解析 Agent、数据计算 Agent、事实校验 Agent、报告生成 Agent 各司其职，由调度层协同，并内置专门的事实校验 Agent 持续抑制幻觉（[数商云 2026](https://m.shushangyun.com/article-43121.html)）。
- 学术侧同步验证：AlphaAgents 等多智能体协同的股票组合构建框架（[arXiv 2508.11152](https://arxiv.org/html/2508.11152v1)）。
- 技术演进节奏：2025 年证明单 Agent 可行（「Agent 元年」），2026 年的主题是**多 Agent 协作与专业化分工**（[2025-2026 Agent 技术进展报告](https://zaobi.tech/pages/ai-tech/agent-tech-report-2025/index.html)、[Multi-Agent Frameworks 2026 Predictions](https://medium.com/@akaivdo/multi-agent-frameworks-in-2025-and-2026-predictions-eaf7a5006f24)）。

### T3. DeepResearch 类自主深度研究：分钟级产出专业报告

- Deep Research 智能体综合大量在线信息自主完成多步骤分析，数分钟生成原本需数小时/数天的专业报告（[知乎专栏](https://zhuanlan.zhihu.com/p/1938525208395879422)）。
- 落地案例：火山引擎深度研究 Agent 实现「财报数据联网搜索 → 结构化报告生成」全流程自动化（[火山引擎 2026-04](https://www.volcengine.com/article/39102)）。
- 智能研报写作的具体形态已清晰：报告框架智能生成、段落生成、**关键假设数据跟踪**、**图表数据自动刷新**、仿写历史研报（[AI Agent 在金融领域应用现状，雪球 2026-01](https://xueqiu.com/3225384427/371055835)）。

### T4. 幻觉治理与合规成为商用准入门槛

- 监管定型：2026 年被称为大模型「安全可信与事实可控的治理定型之年」，国家金融监督管理总局发布**首份人工智能全流程专项监管文件**；模型安全与幻觉治理成为高合规场景准入的**核心前置门槛**（[金融大模型词条（百度百科）](https://baike.baidu.com/item/%E9%87%91%E8%9E%8D%E5%A4%A7%E6%A8%A1%E5%9E%8B/68607404)、[模型安全年度报告 2026](https://max.book118.com/html/2026/0623/6043113224012151.shtm)）。
- 技术路线：幻觉治理不再依赖后处理过滤，而需贯穿**数据层、架构层、推理层、评估层**的协同防御；RAG 可信锚定——强制所有生成引用可验证的外部来源（[SITS2026 幻觉风险分级白皮书](https://blog.csdn.net/CompiGap/article/details/160079458)）。
- 量化背景：主流模型幻觉率普遍在 3.3%–23.5%，2026 年全球幻觉率最低 TOP25 模型才压到 8% 以下——**金融场景的容错要求远超模型当前能力**（[2026 幻觉抑制研究](https://www.baogaobox.com/insights/260126000025103.html)、[金融科技 GEO 合规实践](https://sheepgeo.com/blog/fintech-geo-compliance-ai-hallucination-reduction-2026)）。
- 运营治理要求：投研智能体上线后需持续监控幻觉、定期风险评估、**严禁随意扩大业务边界**、按监管要求留存全套文档（[数商云选型要点](https://m.shushangyun.com/article-43117.html)）。
- 券商工程实践印证：华泰「AI 涨乐」采用 ReAct 推理引擎 + **合规校验网关**，Agent 生成的交易计划须经合规校验（[CSDN Agent 社区 2026-07](https://agent.csdn.net/6a6c8400662f9a54cb96a8e6.html)）。

### T5. 上下文工程与长期记忆成为 Agent 基础设施

- 行业从「提示词工程」走向「**上下文工程**」：LangGraph 有状态运行时/checkpoint/长短期记忆、Letta（MemGPT）Memory Blocks 等记忆基础设施成熟（[稀土掘金 2026-08](https://juejin.cn/post/7670903905525678106)）。
- 记忆成为独立赛道：State of AI Agent Memory 2026 显示长期记忆 + 个性化成为 Agent 产品差异化核心（[mem0 2026-09](https://mem0.ai/blog/state-of-ai-agent-memory-2026)）。

### T6. MCP 成为事实标准，工具生态与安全并重

- MCP 已是连接 Agent 与工具/数据的事实标准，Tool-Call 普遍化，LLM 从「对话者」变为「执行者」（[2025-2026 Agent 技术进展报告](https://zaobi.tech/pages/ai-tech/agent-tech-report-2025/index.html)）。
- 规模预判：Gartner 预计 2026 年底 40% 企业应用将嵌入任务型 AI Agent（2025 年不足 5%）（[7 Agentic AI Trends 2026](https://machinelearningmastery.com/7-agentic-ai-trends-to-watch-in-2026/)）。
- 安全暗面：MCP 管线成为 Agent 供应链安全的新攻击面，prompt injection 从单轮聊天机器人转向 Agentic 系统（[Black Hat Arsenal 2026 Preview](https://safeguard.sh/resources/blog/black-hat-arsenal-2026-preview)）。

### T7. 工程化与评测：Agent 从 demo 走向生产

- Agent 工程师能力路线图已将 **evals、长程可靠性、安全**列为生产化核心 station（[Agentic AI Engineer Roadmap 2026](https://vibeengines.com/roadmap/agentic-ai-engineer)）。
- 金融领域实证研究综述（84 篇论文）确认 LLM 在股票市场的应用已从信号生成走向完整工作流，但**可解释性与验证**是共同瓶颈（[LLMs in equity markets, PMC 2025](https://pmc.ncbi.nlm.nih.gov/articles/PMC12421730/)）。

## 三、本项目现状基线与差距对照

> 基线来源：README、`features/README.md`、产品落地计划（2026-10-03 全量收官）、模块技术文档。

| 维度 | 本系统现状 | 行业趋势 | 差距评估 |
|---|---|---|---|
| Agent 架构 | 单 Agent（AgentScope HarnessAgent ReAct）+ 16 个只读工具 | T2 多 Agent 协同 | **架构代差**：无任务编排/子任务分工；但工具集与数据源已备，具备升级素材 |
| 深度研究 | `research_draft` 工具 + SOP 四阶段状态机 + 情报 LLM 结构化 | T3 DeepResearch 工作流 | 组件齐备、未成工作流；无自动跟踪/刷新 |
| 可信 AI | 图表双通道全量数据呈现；文本结论**无强制引用、无数字校验** | T4 幻觉治理是准入门槛 | **最大短板**：恰是金融场景第一道门槛 |
| 记忆 | 服务端记忆 + 上下文压缩 + 长期记忆落盘 | T5 记忆个性化 | 机制已有但用户不可见不可管，无画像注入 |
| 评测 | agent-testing eval 基线已建（防 LLM 升级漂移） | T7 evals 生产化 | 起步早于行业平均水平，需扩充指标与 CI 挂钩 |
| 工具生态 | MCP client（妙想/Tushare/Wind 8 端点）+ HITL 审批 | T6 MCP 事实标准 | 方向正确；MCP 是 client 非 server，供应链安全未审计 |
| 数据源 | 东财/新浪/腾讯公开源（无授权）+ 公告 PDF 抽取文本 | T1 多模态、可治理数据 | 行情源合规是单点风险；文档解析刚起步 |
| 模型 | DeepSeek 单供应商 | T4 幻觉率模型间差异大 | 无路由/无冗余；升级即全量风险敞口 |
| 交互形态 | 问答式对话 + 盘前摘要飞书推送 | T1 主动式/生态开放 | 被动问答为主，主动触达刚起步 |

**总判断**：本系统的数据域广度（行情/估值/持仓/配置/筛选/日志/情报/SOP/wiki）已超过多数同类单体项目，Agent 内核是当前的短板集中区——**可信性（T4）、工作流（T2/T3）、个性化（T5）三个方向既是行业大势，也是本项目从「数据平台 + 问答壳」进化为「可信投研助手」的关键跳跃**。据此整理的 8 个功能迭代方向与 P0–P3 路线图见 [投研 Agent 功能迭代方向规划](../roadmap/2026-10-04-投研Agent功能迭代方向规划.md)。
