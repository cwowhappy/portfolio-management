## 四、盘点观察（趋势判断）

1. **MCP 已成金融数据商的标配出口**：2026-03-11/12 万得（WindClaw+MCP）、同花顺（iFinD MCP+iFinDClaw）、东财（Skills）三天内同期官宣，标志数据厂商从「卖终端」转向「喂 Agent」（与趋势文档 T6 印证）。
2. **国家队入场打合规牌**：新华财经 MCP 服务矩阵以「权威可信、合规基座」定位，切中金融机构 AI 数据合规痛点——合规可信已成为数据服务的差异化卖点（呼应 T4）。
3. **社区层重复度高、生产可用性低**：AKShare/Tushare 封装项目 star 数低（头部 50★ 左右）、维护不稳定、作者自曝「akshare 接口不适合 MCP 化」；且底座多为无授权爬虫，**供应链与合规双风险**——不适合直接进入生产 provider 目录。
4. **自然语言查询成为商业 MCP 的标配入口**：iFinD `smart-query`、聚源「自然语言多步检索规划」均把 NL→数据路由作为核心能力，值得本项目的工具设计借鉴。

## 五、对本项目的对接建议（衔接 D6 数据源方向）

1. **已内置三家覆盖行情/财务/宏观/公告全品类，当前缺口**：
   - **资讯/政策/研报**：新华财经 MCP 服务矩阵（资讯公告+政策研报两类与本项目情报域、wiki 域直接互补）；
   - **自然语言数据查询体验**：iFinD MCP 的 smart-query 模式可作工具语义设计参照，也可评估接入；
   - **高频/另类数据**：Datayes（视定价与额度）。
2. **候选优先级建议**：新华财经（补情报域合规内容）＞ iFinD MCP（工具体验标杆）＞ 聚源数据地图（偏机构，重）＞ Datayes（按定价）。
3. **社区 MCP 不进 provider 目录**（akshare/tdx/tushare 封装）：理由——无授权爬虫底座 + 供应链安全（趋势文档 T6 安全面）+ 与 collector 既有能力重叠；可在 agent-testing 环境作为联调 mock 使用。
4. **工程配套先行**（与 D6 功能点一致）：provider 目录化扩展流程化（现状需改 DB + 发版）、token 轮换免重启、工具 readOnlyHint 标注规范、MCP 调用结果接入 D1 溯源锚定。
