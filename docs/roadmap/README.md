## 文档格式约定

每份规划文档头部统一含（blockquote 引用块，与正文分隔）：

```
> 创建：<日期> | 前置基线/依据：<上游文档与已决事项>
> 用途：<本规划回答什么问题、服务什么决策>
> 状态：<整体进度一句话>
```

里程碑级文档正文结构：里程碑总览表 → 里程碑详情（目标/交付范围复选框/前置/验收/风险/交付状态注记）→ 全程质量门槛 → 风险与决策点 → 变更记录。方向规划类文档（D1–D8）为轻量结构：方向清单（趋势依据/现状差距/功能点/优先级）→ 路线图 → 风险与边界。

## 维护约定

- **交付收口三处同步回填**：里程碑总览表状态与进度、详情节交付状态注记、变更记录新行（先例：阶段二 2026-10-03「状态对账回填」变更行）。
- 功能点口径以各特性 `01-需求规格/` 定稿为准，规划文档中的点数为规划口径。
- 阶段间口径：一期 115 点基线不含平台增强批次与阶段二功能点；阶段二 34 点不计入一期基线。
