# 03 · 行情数据服务

> 后端行情数据的获取与保护能力：多数据源降级、代码规范化、缓存/限流、数据格式。
> 对外接口见 [04-接口.md](04-接口.md)。
> 对应代码：`backend/src/main/java/com/portfolio/invest/market/`（EastmoneyClient / SinaClient / TencentClient / MarketDataService / MarketDataParser / TtlCache / RateLimiter / StockRef）。

## 1. 数据源与降级

| 数据类型 | 主源（东方财富） | 兜底源 |
|---|---|---|
| 实时行情 | `push2.eastmoney.com` | 新浪行情 |
| K线 | `push2his.eastmoney.com` | 腾讯 K线 |
| 股票搜索 | `searchapi.eastmoney.com` | —（无兜底） |
| 财务指标 | `datacenter.eastmoney.com`（F10） | — |
| 个股新闻 | `search-api-web.eastmoney.com`（JSONP） | — |
| 指数速览 | `push2.eastmoney.com` | 新浪指数 |

- 主源失败自动降级（`withFallback`），两者均失败抛出领域异常，由上层统一转结构化错误。
- 客户端分层：`EastmoneyClient` / `SinaClient` / `TencentClient` 仅负责 HTTP 与原始 JSON；解析集中在纯函数 `MarketDataParser`（离线 fixture 可测）。

## 2. 股票代码规范化（StockRef）

支持 `600519`、`sh600519`、`600519.SH` 等写法，归一化为 `code`（6位）、`market`、`secid`、`sinaPrefix`、`secuCode`：

| 代码前缀 | 市场 | 东财 secid | 新浪前缀 | secuCode |
|---|---|---|---|---|
| `6` / `9` | 沪市 | `1.xxxxxx` | `sh` | `xxxxxx.SH` |
| `4` / `8` | 北交所 | `0.xxxxxx` | `bj` | `xxxxxx.BJ` |
| 其他 | 深市 | `0.xxxxxx` | `sz` | `xxxxxx.SZ` |

非法代码抛 `INVALID_CODE`（400）。

## 3. 数据保护机制

### 3.1 TTL 缓存（TtlCache）

本地有界 LRU（`maxEntries` 默认 10000，`access-order` + `removeEldestEntry`），读时惰性过期：

| 数据 | TTL |
|---|---|
| 实时行情 / 指数速览 | 15 s |
| K线 / 新闻 | 5 min |
| 股票搜索 | 10 min |
| 财务指标 | 1 h |

### 3.2 令牌桶限流（RateLimiter）

默认 **5 次/秒**，在每次真实 HTTP 请求前获取令牌，短暂等待（上限 `acquireTimeoutMillis=2000`）拿不到则 `RATE_LIMITED`（429）。

### 3.3 超时与重试

连接超时 3s、读取超时 5s；最大尝试 3 次、退避 300ms。

## 4. 数据格式要点

- **成交量归一化**：东财 `f47` 单位不稳定（手/股），用成交额反推统一为股；K线成交量统一 ×100（手→股）。
- **估值自算**：东财 `f162`/`f167` 偶发缺失 PE/PB 时，从财务指标自算（PB=价格/最新 BPS，PE=价格/TTM EPS）。
- **财务数值单位**：东财返回原始元，工具层换算为亿元（保留 2 位）。
- **新闻**：去 HTML 标签、摘要截断 120 字；关键词优先用股票名称。
- **时区**：行情时间统一 `Asia/Shanghai`，格式 `yyyy-MM-dd HH:mm`。
