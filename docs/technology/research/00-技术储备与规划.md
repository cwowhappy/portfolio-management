## 二、后续版本技术规划

### 2.1 MVP（价值投资基础）需要新增的技术能力

| 技术事项 | 支撑功能模块 | 候选方案 / 待评估点 |
|---------|-------------|-------------------|
| **定时任务调度** | M14-F07 估值数据定时抓取 → M06/M10 | Spring `@Scheduled`（单机够用）vs Quartz（持久化任务）；每日收盘后触发 |
| **全市场估值批量抓取** | M06 市场估值仪表盘 | 全 A 股约 5000+ 只个股的 PE/PB 抓取：需批量接口或分页遍历 + 限流策略设计；估值快照表（Flyway 新迁移） |
| **申万行业分类数据** | M08 行业分布、M10 行业研究 | 内置静态映射表 + 定期更新机制 |
| **国债收益率数据源** | M06-F02 股债利差 | 中国债券信息网/公开 API 调研与接入 |
| **图表组件** | M06/M08/M12 走势图、饼图、热力图 | 当前 K线为自绘 SVG；评估引入轻量图表库（如 ECharts / lightweight-charts） |
| **多资产类别行情** | M07 配置（港股/美股/债券/黄金/REITs） | 现有行情源仅 A股；评估扩展数据源 |

### 2.2 二期（决策闭环）需要新增的技术能力

| 技术事项 | 支撑功能模块 | 候选方案 / 待评估点 |

| **AI 工具扩展机制** | M05-F07~F12 | `InvestTools` 增加估值/筛选/持仓/配置/行业工具；注意工具数量对 LLM 上下文的影响 |

### 2.3 三期（深度分析）需要新增的技术能力

### 2.4 技术债与持续事项

- **覆盖率门槛维护**：新模块开发需同步补测试（JaCoCo/V8 ≥80%）。
- **ArchUnit 白名单登记**：每个新领域包（valuation/portfolio/allocation/screening/journal/industry）需在 `PackageConventionsTest.java` 登记依赖白名单，并同步 [../conventions/01-后端DDD分包规范.md](../conventions/01-后端DDD分包规范.md)。
- **Jackson 2 约束**：AgentScope AG-UI 模型基于 Jackson 2 注解，升级 Spring 生态时需保持 `spring-boot-jackson2` 排除链不被破坏。
- **Testcontainers Ryuk 禁用**：本地 Colima 等环境的既有约束，CI 迁移时复核。

## 三、新增技术决策的流程

1. 在 [decisions/](../decisions/) 下按编号新建 ADR（背景 / 选项 / 结论 / 影响）。
2. 落地类规范同步到 [modules/](../modules/) 对应模块文档。
3. 若引入新领域包，同步分包规范与 ArchUnit 白名单。
