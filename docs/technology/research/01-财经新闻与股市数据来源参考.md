# 财经新闻与股市数据来源参考

> 外部数据来源调研汇总，作为后续扩展数据能力的参考资料。
> **调研核实日期：2026-09-06**。免费公开接口均为非官方网页接口，会无预警变更，使用前建议重新实测。
> 标注约定：**已实测** = 调研当日实际请求验证；**未核实** = 只有间接证据，使用前必须验证。
> 与本仓库现有选型的关系：运行期行情（东财/新浪/腾讯）与 collector 采集（tushare/akshare）的现状见 [architecture/05-数据类型与来源.md](../architecture/05-数据类型与来源.md)，本文档是其外延的「可选来源全景」。

## 一、股市行情数据

### 1.1 Python 数据库

#### akshare（免费，无注册）

- 定位：开源财经数据聚合库，2000+ 接口，底层抓取东方财富/新浪/腾讯/同花顺/巨潮等公开接口。`pip install akshare`。
- 常用行情接口：
  - `stock_zh_a_spot_em()` — 全 A 实时行情快照（一次全市场，较慢，>15s），底层东财
  - `stock_zh_a_hist(symbol, period="daily|weekly|monthly", start_date, end_date, adjust="qfq|hfq|")` — 个股 K 线
  - `stock_zh_index_daily_em()` / `stock_zh_index_spot()` — 指数日线/实时
  - `stock_board_industry_name_em()` / `stock_board_industry_cons_em()` — 行业板块及成分
- 限制：本质是爬虫，快速轮询触发反爬（空 DataFrame、封 IP、验证码页）；服务器/云函数环境更易被风控。

#### tushare / tushare pro（积分制）

- 定位：注册得 token，**积分是门槛制（不消耗）**。官方[积分与频次表](https://tushare.pro/document/1?doc_id=290)：
  - 120 分（免费注册）：仅非复权日线等基础接口，50 次/分钟、8000 次/天
  - 2000 分（约 ¥200/年）：200 次/分钟、10 万次/API/天
  - 5000 分（约 ¥500/年）：500 次/分钟、常规数据无上限
  - 分钟/实时/港美股**不走积分、单独付费**：历史分钟 ¥2000/年、实时日线 ¥200/月、美股日线 ¥2000/年
- 关键接口门槛（官方文档核实）：
  - `daily`（日线）：基础积分即可，单次 6000 条（[doc_id=27](https://tushare.pro/document/2?doc_id=27)）
  - `daily_basic`（PE/PB/市值/股息率/换手率）：**≥2000 分**（[doc_id=32](https://tushare.pro/document/2?doc_id=32)）
  - `index_dailybasic`（大盘指数每日指标）：≥2000 分（[doc_id=128](https://tushare.pro/document/2?doc_id=128)）
  - `fina_indicator`（财务指标）：**≥2000 分**，单次 ≤100 条、按单股取；按季度全市场批量用 `fina_indicator_vip`（≥5000 分）（[doc_id=79](https://tushare.pro/document/2?doc_id=79)）
  - `moneyflow`（资金流向）：社区称需 5000 分，**未核实**
- 调用方式：Python SDK `tushare.pro_api()`，或 HTTP POST `http://api.tushare.pro`（`api_name`+`params`+`fields`）。

#### baostock（完全免费，免注册）

- 定位：匿名 `bs.login()`，返回 DataFrame。**仅 A 股，无实时行情**。
- 覆盖（官方知识库核实）：日/周/月 K 线 1990-12-19 至今；5/15/30/60 分钟线 1999-07-26 至今；指数日/周/月 2006 年起；财务数据 2007 年起。日 K 当日 17:30 入库。
- 示例：`bs.query_history_k_data_plus("sh.600519", fields="date,open,high,low,close,volume", start_date, end_date, frequency="d", adjustflag="2")`；`bs.query_all_stock()`。

#### efinance（免费，东财封装）

- `ef.stock.get_realtime_quotes()`（实时快照，注意分页 200 条问题）、`ef.stock.get_quote_history(code)`、`ef.stock.get_kl_data(code, klt=101/102/103)`。
- 限制同 akshare：受东财反爬影响，批量拉 K 线易 `RemoteDisconnected`。

### 2.2 东方财富新闻接口（已实测 2026-09-06）

- **新闻搜索**（本仓库在用）：`https://search-api-web.eastmoney.com/search/jsonp?cb=cb&param=…`，实测可用（个股 keyword 返回 hitsTotal 数百条，字段 date/title/content/mediaName/url，JSONP 需剥壳）。建议 `https://` + 浏览器 UA。
- **7×24 全球快讯**：`https://np-weblist.eastmoney.com/comm/web/getFastNewsList?client=web&biz=web_724&fastColumn=102&pageSize=N` — 已实测 200 OK。坑：Referer 不对触发 WAF（567 + 验证页），带 `https://kuaixun.eastmoney.com/7_24.html` 或省略即正常。
- **栏目资讯（财经早餐等）**：`https://np-listapi.eastmoney.com/comm/web/getNewsByColumns?column=1207&page_size=200&fields=…`（akshare `stock_info_cjzc_em` 即 column=1207；换 column 取其他栏目）— 未实测。

### 2.3 财联社 cls.cn

- **无公开官方免费 API**（官方数据服务为商业授权）。
- 可用端点：`https://www.cls.cn/v1/roll/get_roll_list?app=CailianpressWeb&os=web&sv=8.4.6&rn=20&sign=…`，签名 `md5(sha1(urlencode(params)))` 可本地零 key 计算 —— **已实测 2026-09-06 可用**，返回 `data.roll_data[]`（title/content/ctime/level）。
- 旧端点 `/nodeapi/telegraphList` **已实测 404 失效**，网上旧教程大量引用，注意甄别。

### 2.4 其他门户

- **新浪**：7×24 快讯 `https://zhibo.sina.com.cn/api/zhibo/feed?zhibo_id=152`（已实测可用）。老式 RSS（finance.sina.com.cn/rss/*）**已实测 404 失效**。
- **腾讯财经**：行情接口稳定，但**未找到可靠的新闻列表接口**。
- **雪球**：所有 API 必须带 Cookie（`xq_a_token`，匿名访问首页可获取），否则 `error_code: 400016`（已实测复现）；风控严，仅作情绪向补充。
- **华尔街见闻**：官方 RSS 已失效（实测返回 HTML）。快讯可用非官方 `https://api-one.wallstcn.com/apiv1/content/lives?channel=global-channel&limit=N`（已实测 200 OK）。深度文章有付费墙。
- **金十数据**：付费开放平台 [open.jin10.com](https://open.jin10.com/)（REST：快讯/日历/行情）；网页抓取需对抗反爬。
- **Tushare**：`news` 接口聚合 sina/wallstreetcn/10jqka/eastmoney 等快讯（单次 1500 条、6 年+历史，需单独开权限）；`major_news` 长篇通讯（单次 400 条、8 年+）。（[doc_id=143](https://tushare.pro/document/2?doc_id=143)、[doc_id=195](https://tushare.pro/document/2?doc_id=195)）

### 2.5 RSS 与 RSSHub

- 官方 RSS 大面积萎缩：路透 `feeds.reuters.com` 2020 年起停、新浪/华尔街见闻已失效、财新 feed 返回跳转页（未核实）。FT 中文网 RSS 有文档记录但更新滞后，本次网络未连通未验证。
- **RSSHub 自建是主路线**：`docker run -p 1200:1200 diygod/rsshub`，财经路由含 `/cls/telegraph`、`/jin10`、`/wallstreetcn/…`、`/eastmoney/…`、`/caijing/roll`、`/ft/chinese/…`（[RSSHub finance 路由](https://rsshub.netlify.app/zh/routes/finance)）。公共实例限流且部分路由失效，生产用建议自建。

### 2.6 通用新闻聚合 API

- **NewsAPI.org**：支持 `language=zh` 但无 A 股垂直源（无财联社/东财），免费档 100 req/天 + 文章延迟 24h，对 A 股价值有限。
- **GDELT 2.1**：免费、全球近实时，DOC API 支持 `sourcelang:chinese`；适合宏观/海外舆情兜底，不适合 A 股快讯。

## 三、基本面 / 估值 / 宏观数据

### 3.1 财务数据

- **tushare**（生产首选）：`income`/`balancesheet`/`cashflow`（三大表）、`fina_indicator`（150+ 指标）、`forecast`（业绩预告）、`express`（业绩快报）、`dividend`（分红）。均为 2000 积分档（单股取）；按季全市场批量用 `*_vip`（5000 分）。公告、券商研报是独立付费权限（¥1000/年、¥500/年），不走积分。
- **akshare**（免费兜底，接口名已对照 1.18.94 官方文档核实）：
  - `stock_financial_abstract`（新浪关键指标）、`stock_financial_abstract_new_ths`（同花顺重要指标）
  - `stock_financial_analysis_indicator_em`（东财 F10 主要指标，单股全历史约 140 列）
  - 三大表（东财）：`stock_balance_sheet_by_report_em` / `stock_profit_sheet_by_report_em` / `stock_cash_flow_sheet_by_report_em`
  - 业绩类：`stock_yjbb_em`（业绩报表）、`stock_yjkb_em`（快报）、`stock_yjyg_em`（预告）；分红 `stock_fhps_em`/`stock_fhps_detail_em`；盈利预测 `stock_profit_forecast_em`/`_ths`
- **东方财富 datacenter API**（akshare `_em` 财务接口的底层，HTTP 直连模式）：
  ```
  GET https://datacenter-web.eastmoney.com/api/data/v1/get
      ?reportName=RPT_XXX&columns=ALL&filter=(REPORT_DATE='2025-12-31')
      &pageNumber=1&pageSize=50&sortTypes=-1&sortColumns=REPORT_DATE
      &source=WEB&client=WEB
  ```
  需带 UA 与 `Referer: https://data.eastmoney.com/`。F10 类走 `datacenter.eastmoney.com/securities/api/data/v1/get`（`source=HSF10&client=PC`）。
  常用 reportName：`RPT_LICO_FN_CPD`（业绩报表）、`RPT_FCI_PERFORMANCEE`（快报）、`RPT_PUBLIC_OP_NEWPREDICT`（预告）、`RPT_DMSK_FN_INCOME`/`BALANCE`/`CASHFLOW`（三大表）、`RPT_F10_FINANCE_MAINFINADATA`（F10 主要指标，本仓库在用）、`RPT_F10_EH_HOLDERNUM`（股东户数）。

### 3.2 估值与市场宽度

- **中证指数官网（csindex，官方一手）**：`stock_zh_index_value_csindex(symbol)`（PE1/PE2/股息率1/2，每日收盘后更新）+ `index_stock_cons_csindex` / `index_stock_cons_weight_csindex`；官方 XLS：`https://oss-ch.csindex.com.cn/static/html/csindex/public/uploads/file/autofile/indicator/{代码}indicator.xls`。**只给近期值，不自带历史百分位**；仅中证系指数。
- **乐咕乐股 legulegu（akshare `_lg` 系列）**：`stock_index_pe_lg`/`stock_index_pb_lg`（12 个宽基，2005 年起）、`stock_a_ttm_lyr`（全 A PE）、`stock_a_all_pb`、`stock_a_below_net_asset_statistics`（破净统计）、`stock_a_high_low_statistics`（新高新低）、`stock_a_congestion_lg`（拥挤度）、`stock_buffett_index_lg`（巴菲特指标）、`stock_ebs_lg`（**股债利差 ERP 全历史**）、`stock_a_gxl_lg`（股息率）。
  - **稳定性警告**：`_lg` 系列反复「失效—修复」（2024-03 大面积失效、2026-04 `stock_index_pe_lg` 仍有 open issue）。**只作辅助/交叉验证，不作唯一生产源**。
- **理杏仁 lixinger**：付费 SaaS + 开放 API（`open.lixinger.com`），提供现成的**估值历史百分位**（省去自建长历史），约 ¥518/年。
- **国债收益率（ERP 分母）**：
  - akshare `bond_zh_us_rate`（本仓库在用；上游标注中债信息网/东财两说并存，建议加空值监控）
  - tushare `yc_cb`（中债国债收益率曲线，即期+到期，[doc_id=201](https://tushare.pro/document/2?doc_id=201)）
  - 官方页：中债信息网 `yield.chinabond.com.cn/cbweb-mn/yield_main`、中国货币网收盘曲线（每工作日 17:15 发布），均无公开 API，需爬网页
- **ERP 建议自算**：`ERP = 指数 PE-TTM 倒数 − 10Y 国债收益率`（`index_dailybasic` + `bond_zh_us_rate`），可控可复现，legulegu 仅作交叉验证。

### 3.3 宏观经济（akshare `macro_china_*`，免费全历史）

- 总量：`macro_china_gdp`、`macro_china_gyzjz`（工业增加值）、`macro_china_gdzctz`（固投）、`macro_china_consumer_goods_retail`（社零）
- 物价/景气：`macro_china_cpi`、`macro_china_ppi`、`macro_china_pmi`、`macro_china_cx_pmi_yearly`（财新）
- 货币信贷：`macro_china_shrzgm`（社融）、`macro_china_new_financial_credit`、`macro_china_supply_of_money`（M0/M1/M2）、`macro_china_lpr`、`macro_china_shibor_all`
- 其他：`macro_china_hgjck`（进出口）、`macro_china_urban_unemployment`（失业率）、`macro_cnbs`（宏观杠杆率）
- 兜底：**国家统计局**事实标准接口 `https://data.stats.gov.cn/easyquery.htm?m=QueryData&dbcode=hgyd|hgjd|hgnd&…`（需 Referer/Cookie，指标树先爬 `getTree` 拿 zb 编码；有验证码风控，仅作兜底与口径核对）。

### 3.4 行业数据（申万）

- **tushare**：`index_classify(src="SW2021")` + `index_member`（本仓库在用，[doc_id=181](https://tushare.pro/document/2?doc_id=181)）。
- **akshare**：乐咕源 `sw_index_first_info`/`sw_index_second_info`/`sw_index_third_info`；**申万宏源官网源** `index_realtime_sw`、`index_hist_sw`、`index_component_sw`、**`index_analysis_daily_sw`（申万指数分析报表，含行业 PE/PB，可按日区间拉取 —— 免费获取申万行业估值最直接的通道）**。

### 3.5 公告与研报

- **巨潮资讯网（cninfo，法定披露平台，免费官方）**：
  ```
  POST http://www.cninfo.com.cn/new/hisAnnouncement/query
  表单: stock=000001,gssz0000001&category=category_ndbg_szsh
        &seDate=2025-01-01~2026-09-06&pageNum=1&pageSize=30&column=sse
  ```
  返回 JSON（标题 + adjunctUrl，PDF 全文 `http://static.cninfo.com.cn/<adjunctUrl>`），30 条/页，区间最长约 1 年。akshare 封装 `stock_zh_a_disclosure_report_cninfo`（2026-07 修过列名 bug，需新版）。
- **券商研报**：东财研报中心 `reportapi.eastmoney.com/report/list`（分页 JSON，含评级/盈利预测摘要），akshare 封装 `stock_research_report_em`；tushare 研报库独立权限 ¥500/年。

## 四、推荐组合速查

| 需求 | 首选 | 兜底/补充 |

## 五、风险与合规注意

- **稳定性**：所有免费接口均为非官方网页接口，会无预警变更/加签名/加 WAF（东财 567 验证页、cls 换端点、legulegu 反复失效均为实例）。需要监控告警 + 多源降级。
- **频率**：东财/新浪高频抓取封 IP；建议缓存 + 请求间隔 ≥0.3s + 浏览器 UA/Referer。
- **合规**：抓取内容仅限内部研究/个人使用；新闻全文有版权，对外展示只给标题+摘要+原文链接；商用需购买授权（财联社/金十/见闻均有商业数据服务）。
- **未核实项备忘**：tushare `moneyflow` 及 `forecast`/`express`/`dividend` 积分门槛；`bond_zh_us_rate` 真实上游；东财分红 reportName 确切写法；cninfo 开放平台额度；Polygon/Massive 免费层现状；FT 中文网 RSS 可用性；`stock_a_indicator_lg` 维护状态。
