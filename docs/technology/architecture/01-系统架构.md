- **前端**：同源反代，浏览器不直连后端，规避 CORS；所有反代透传 Cookie 头与 Set-Cookie（登录态落地）。
- **后端**：按「DDD 洋葱分层 + 独立能力域」组织（见 [ADR-0009](../decisions/0009-backend-ddd-layering.md)）；`agent` 保持独立能力域，其余业务域走 DDD 分层。
- **认证**：Spring Security 7 会话认证（`JSESSIONID` + 记住我）；`ActiveUserFilter` 每次受保护请求校验用户状态，停用/被拒即时失效（见 [ADR-0007](../decisions/0007-user-auth.md)）；`/agui/run` 经 `InvestAguiRuntimeContextResolver` 从会话解析用户并注入 Agent 运行上下文。
- **持久化**：PostgreSQL + Flyway 建表，V1 基线（squash 自原 V1~V21，2026-09-28）+ 增量 V2（research 域）~V8（MS-32 深度研究），全量共 **76 张表**（2026-10-17 实测）——基线含用户/会话（`app_user`/`conversation`/`chat_message`…）、估值类（`valuation_snapshot`/`stock_valuation_daily`/`etf_basic`…）、持仓类、MCP 与技能、`wiki`/`watchlist`/行业链/`verification_code` 等 39 张；V2 research 11 张（SOP 研究项目域）；V3 intelligence 15 张（情报域，含抽取与订阅推送）；V4 索引清理；V5/V6 评测观测 4 张；V7 记忆 2 张；V8 深度研究 5 张（研报表 + `report_token_quota`）。另有 collector 自管的运维表（5 张，见 [04-数据采集服务架构.md](04-数据采集服务架构.md)）。

## 2. 请求链路

**对话（AG-UI SSE）**

```
用户输入 → ThreadArea.send()
  → agent.addMessage() + copilotkit.runAgent({ agent })
  → CopilotKit 运行时 /api/copilotkit（useSingleEndpoint=false，REST 传输）
  → HttpAgent POST {BACKEND}/agui/run（转发会话 Cookie；反代把全量渲染历史
    裁剪为最新一条 user 消息——见第 3 节服务端记忆）
  → InvestAguiRuntimeContextResolver 解析登录用户 → CurrentUserHolder
  → AgentScope AG-UI starter（server-side-memory）：按（用户, threadId）取/建 HarnessAgent
  → HarnessAgent 装配（详见 [modules/01-Agent实现.md](../modules/01-Agent实现.md)）：
    循环调用 InvestTools 13 个 @Tool + UserInvestTools 4 个用户工具
    + 用户启用的 MCP 工具与内置技能
  → AG-UI SSE 事件流（TEXT_MESSAGE_* / REASONING_* / TOOL_CALL_* / RUN_*）
  → CopilotKit → useAgent 状态更新 → 逐字渲染
```

**行情（REST）**

```
页面 fetch /api/market/** → Next.js 反代 → 后端 /api/market/**
  → MarketDataService（缓存命中直接返回，未命中走限流 + 数据源 + 降级）
  → 返回 DTO（前端 zod 校验）
```

其余业务页面（持仓/调配/日志/筛选/估值/行业/管理/设置）同为 REST 反代链路，走各域 Controller → ApplicationService → Repository 端口实现。

## 3. 会话模型

- **领域实体** `Conversation`（`conversation` 表），`id` 复用 AG-UI 协议层 `threadId`；UI 转写消息存 `chat_message` 表（user/assistant 纯文本；`payload` JSONB 自 MS-29 起承载 assistant 消息信任锚定 JSON）。
- **agent 记忆服务端化**（`agentscope.agui.server-side-memory=true`）：starter 的 `ThreadSessionManager` 按（用户, threadId）维护 agent 会话实例；`HarnessAgentFactory` 为用户构建 `HarnessAgent`，以 `JsonFileAgentStateStore`（`stateRoot` 可配）把会话历史落盘，并附带压缩（CompactionConfig）与节流落盘（MemoryConfig）。前端每轮**只发最新一条用户消息**——CopilotKit/HttpAgent 总是携带全量渲染历史，由 `/api/copilotkit` 反代边界裁剪后再转发 `/agui/run`；agent 历史由服务端 stateStore 恢复，不再整段重传。决策记录见 [ADR-0011](../decisions/0011-server-side-agent-state.md)。
- **UI 转写持久化**沿用 ADR-0008 的「前端工作内存 + 服务端存储」模型：前端持有当前渲染消息，每轮回复完成后防抖 **PUT 全量纯文本消息**到 `/api/conversations/{id}/messages`，打开会话时 **GET 回灌**——该记录只服务列表与跨设备回显，不再作为 agent 上下文来源。
- **归属隔离**：会话读写按 `user_id` 过滤，非本人 404；多端并发编辑经 PUT `If-Match` 乐观校验（冲突 409）。

详见 [ADR-0008 会话持久化](../decisions/0008-conversation-persistence.md)（取代 ADR-0004；其中 agent 上下文部分已由服务端记忆取代，转写存储仍有效）。
