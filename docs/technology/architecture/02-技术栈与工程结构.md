# 02 · 技术栈与工程结构

> 技术选型版本定版与代码工程结构。总体架构与请求链路见 [01-系统架构.md](01-系统架构.md)。

## 1. 技术栈（版本定版）

| 组件 | 版本 | 说明 |
|---|---|---|
| 后端框架 | Spring Boot 4.0.3 | 与 AgentScope 官方 starter 对齐 |
| JDK | 21 字节码 | Spring Boot 4 基线 Java 17+ |
| 构建 | Gradle 9.x（Wrapper） | 系统 Gradle 过旧，用 wrapper |
| 安全 | Spring Security 7.0.3 | 会话认证 + remember-me；CSRF 关闭（同源 JSON API，[ADR-0007](../decisions/0007-user-auth.md)） |
| 持久化 | Spring Data JPA + Flyway | `ddl-auto: none`，schema 由 Flyway 管理（V1/V2） |
| 数据库 | PostgreSQL 16 | 本地 / docker-compose；集成测试用 Testcontainers |
| Agent 框架 | AgentScope Java 2.0.1（io.agentscope） | core + extensions-model-openai（DeepSeek）+ agui-spring-boot-starter |
| LLM | DeepSeek（`deepseek-v4-flash` 默认） | `DEEPSEEK_API_KEY` 环境变量 |
| 前端 | Next.js 15.5 · React 19.1 · TypeScript 5.8 | App Router；`output: standalone` |
| 前端 UI | Tailwind 4 · react-markdown · highlight.js | 自绘「研报终端」设计体系 |
| 前端框架 | CopilotKit v2 1.68.1 · @ag-ui/client 0.0.57 | AG-UI 运行时 + HttpAgent |
| 数据源 | 东方财富公开接口（主）+ 新浪 / 腾讯（兜底） | 免费公开 HTTP，无需 token |
| 部署 | Docker Compose（db + backend + frontend） | 本机 compose 已验证 |

## 2. 目录结构

```
backend/    Spring Boot 4 + Spring Security 7 + Spring Data JPA（DDD 洋葱分层）
  src/main/java/com/portfolio/invest/
    web/              接入层：AuthController / UserAdminController / ConversationController /
                      MarketController / HealthController / GlobalExceptionHandler
    application/      应用层：auth / useradmin / conversation / market 用例编排（*ApplicationService）
    domain/           领域层：user / conversation / market（纯 POJO + 仓库端口，零 Spring/JPA）
    infrastructure/   基础设施：persistence（JPA 实体+仓库实现+Flyway）/ security /
                      seed（管理员种子）/ market（客户端+缓存/限流装饰器）
    agent/            独立能力域：AgentConfig / InvestSystemPrompt / InvestTools
    config/           InvestProperties（仅配置属性，ArchUnit 强制）
  src/main/resources/  application.yml / application-prod.yml / db/migration/(V1__init, V2__conversation)

frontend/   Next.js 15（App Router）
  app/        页面（/ /market /login /register /admin）与 API 路由（api/*）
  components/ chat/*（对话）· market/*（行情台）· auth/*（登录/注册/守卫）
  lib/        api.ts / schemas.ts / types.ts / auth.tsx / conversations.ts / proxy.ts

docs/        function/ 产品功能 · technology/ 技术文档（架构/模块/决策/储备）· plans/ 设计计划
features/    specs/（设计规格）· plans/（实施计划）
scripts/     smoke.sh 冒烟脚本
```

## 3. 部署拓扑

Docker Compose 三服务：`db`（PostgreSQL 16）+ `backend`（Spring Boot，`output: bootJar`）+ `frontend`（Next.js standalone）。本机开发用 `make dev`（后端 :8080 + 前端 :3000，需先 `docker compose up -d db`）。
