## 1. 技术栈（版本定版）

| 组件 | 版本 | 说明 |

## 3. 部署拓扑

Docker Compose 四服务：`db`（PostgreSQL 16）+ `backend`（Spring Boot，`output: bootJar`）+ `frontend`（Next.js standalone）+ `collector`（Python 采集，依赖 db/backend 健康后启动）。本机开发用 `make dev`（后端 :8080 + 前端 :3000，需先 `docker compose up -d db`）；collector 本机开发直连同一 PostgreSQL（见 [04-数据采集服务架构.md](04-数据采集服务架构.md) 第八节）。
