# 02 · 技术栈与工程结构

> 技术选型版本定版与代码工程结构。总体架构与请求链路见 [01-系统架构.md](01-系统架构.md)。

## 1. 技术栈（版本定版）

| 组件 | 版本 | 说明 |
|---|---|---|
| 后端框架 | Spring Boot 4.0.3 | 与 AgentScope 官方 starter 对齐 |
| JDK | 21 字节码 | Spring Boot 4 基线 Java 17+ |
| 构建 | Gradle 9.x（Wrapper） | 系统 Gradle 过旧，用 wrapper |
| 安全 | Spring Security 7.0.3 | 会话认证 + remember-me；CSRF 关闭（同源 JSON API，[ADR-0007](../decisions/0007-user-auth.md)） |
| 持久化 | Spring Data JPA + Flyway | `ddl-auto: none`，schema 由 Flyway 管理（V1–V11，26 张业务表） |
| 数据库 | PostgreSQL 16 | 本地 / docker-compose；集成测试用 Testcontainers |
| Agent 框架 | AgentScope Java 2.0.3（io.agentscope）四构件 | core + extensions-model-openai（DeepSeek）+ agui-spring-boot-starter + harness（HarnessAgent/技能/状态存储） |
| LLM | DeepSeek（`deepseek-v4-flash` 默认） | `DEEPSEEK_API_KEY` 环境变量 |
| 前端 | Next.js 15.5.4 · React 19.1 · TypeScript 5.8 | App Router；`output: standalone` |
| 前端 UI | Tailwind 4 · react-markdown · highlight.js · ECharts | 自绘「研报终端」设计体系 |
| 前端框架 | CopilotKit v2 1.70.1 · @ag-ui/client 0.0.59 | AG-UI 运行时 + HttpAgent |
| 数据源 | 东方财富公开接口（主）+ 新浪 / 腾讯（兜底）；collector 另接 Tushare Pro / akshare / 中债（经 akshare） | 免费公开 HTTP 无需 token；Tushare 需积分（见 [05-数据类型与来源.md](05-数据类型与来源.md)） |
| 采集服务 | Python 3.12 · APScheduler · psycopg3 · pandas · akshare/tushare · alembic | 独立 `collector/`，见 [04-数据采集服务架构.md](04-数据采集服务架构.md) |
| 部署 | Docker Compose（db + backend + frontend + collector） | 本机 compose 已验证 |

## 3. 部署拓扑

Docker Compose 四服务：`db`（PostgreSQL 16）+ `backend`（Spring Boot，`output: bootJar`）+ `frontend`（Next.js standalone）+ `collector`（Python 采集，依赖 db/backend 健康后启动）。本机开发用 `make dev`（后端 :8080 + 前端 :3000，需先 `docker compose up -d db`）；collector 本机开发直连同一 PostgreSQL（见 [04-数据采集服务架构.md](04-数据采集服务架构.md) 第五节）。
