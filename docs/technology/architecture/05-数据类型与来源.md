# 数据类型与来源

> 全景梳理系统中所有证券相关数据的**类型**与**来源**（含具体接口）。
> 实现细节见 [modules/02-行情数据服务.md](../modules/02-行情数据服务.md)（运行期行情链路）与 [architecture/04-数据采集服务架构.md](04-数据采集服务架构.md)（collector 落库链路）。

## 总览

系统的证券数据分两条链路：

- **运行期实时数据**：后端 `domain.market` 值对象，实时从东方财富公开接口拉取（新浪/腾讯兜底），**只走 TTL 缓存，不落库**。经 HTTP `/api/market/*` 与 Agent `@Tool` 对外暴露。
- **落库的估值/基本面数据**：由 Python collector 经 Tushare Pro / akshare 定时采集写入 PostgreSQL（schema 为后端 Flyway 管理的跨服务契约），后端经 `ValuationApplicationService` **只读**。

## 一、数据类型

### 1. 运行期实时数据（`com.portfolio.invest.domain.market`，纯 record 值对象，无表）

| 数据类型 | 模型 | 关键字段 | 对外暴露 |
|---|---|---|---|
| 实时行情快照 | `Quote` | 价/涨跌/涨跌幅、开高低、昨收、成交量/额、PE、PB、时间 | `GET /api/market/quote/{code}`、`get_quote` |
| K 线 | `KlineBar` | 日期、开收高低、量、额、振幅（日/周/月，前复权） | `GET /api/market/kline/{code}`、`get_kline` |
| 指数行情 | `IndexQuote` | 代码、名称、点位、涨跌、涨跌幅 | 随大盘速览返回 |
| 大盘速览 | `MarketOverview` | 上证/深成/创业板三指数快照 + 时间 | `GET /api/market/overview`、`get_market_overview` |
| 财务指标 | `FinancialIndicator` / `Financials` | 报告期、EPS、BPS、营收、净利、ROE、毛利率 + PE/PB（缺失时按 TTM 本地推算） | `GET /api/market/financials/{code}`、`get_financials` |
| 个股新闻 | `NewsItem` | 标题、摘要（120 字截断去 HTML）、来源、日期、URL | `GET /api/market/news/{code}`、`get_news` |
| 股票搜索 | `StockHit` | 代码、名称、市场（过滤指数/板块/基金/债/期货） | `GET /api/market/search?q=`、`search_stock` |

辅助值对象：`StockRef`（代码规范化：secid / sinaPrefix / secuCode，统一沪/深/北判定）。

### 2. 落库的估值/基本面数据（PostgreSQL，写方 = collector，后端只读）

| 数据类型 | 表（Flyway 迁移） | 内容 |
|---|---|---|
| 全 A 估值快照 | `valuation_snapshot`（V3） | 交易日、PE/PB 中位数、破净数/占比 |
| 申万行业估值 | `industry_valuation`（V3） | 行业 PE/PB/ROE/股息率（市值加权） |
| 指数估值历史 | `index_valuation_history`（V3） | 上证50/沪深300/中证500/创业板指/科创50 的 PE/PB/股息率 |
| 国债收益率曲线 | `treasury_yield_curve`（V4） | 1Y/3Y/5Y/10Y/30Y 收益率 |
| 指数成分股 | `index_constituent`（V4） | 成分股代码、名称、权重（先删后插全量快照） |
| 申万行业映射 | `shenwan_industry_mapping`（V3） | 股票 → SW2021 一级行业 |
| 个股估值日快照 | `stock_valuation_daily`（V7） | PE_TTM、PB、股息率、总/流通市值（元）、换手率 |
| 个股财务季数据 | `stock_financial`（V7） | ROE/ROA/毛利率/资产负债率/流动比率/营收净利同比（近 12 季） |
| 交易日历 | `trading_calendar`（collector alembic） | 运维数据，用于任务交易日门控 |

落库数据经 Agent 工具 `get_valuation`（唯一走 DB 的工具）对外：全 A PE/PB 中位数及历史分位、破净占比分位、ERP（沪深300股息率 − 10Y 国债）及分位、5 大指数估值+分位、情绪温度计。

## 三、降级链与数据治理

- **降级链**（`OrchestratingMarketDataService.withFallback`，仅 `MarketDataException` 触发）：
  - 实时行情：东财 → 新浪
  - K 线：东财 → 腾讯
  - 大盘速览：东财 → 新浪
  - 搜索/财务/新闻：仅东财，无兜底（财务 PE/PB 缺失时本地按 TTM 推算）
- **collector 选源**：仅全 A 估值配了备源（东财 akshare → tushare），其余任务单源；按任务 YAML `source_ids` 声明顺序 + 健康分选择，连续失败 3 次熔断 600s。
- **缓存**（`CachedMarketDataService`，TTL）：行情 15s、K线/新闻 5m、搜索 10m、财务 1h、速览 15s；估值 DB 查询应用级缓存 5min。
- **限流与重试**：后端三客户端共享令牌桶（默认 5 次/秒）；HTTP 层 4xx 不重试、IO/5xx 退避重试 3 次。
- **采集调度**（APScheduler，详见 [04-数据采集服务架构.md](04-数据采集服务架构.md)）：估值类任务交易日 15:30–15:45 陆续执行；指数成分股 180 天、申万映射 7 天、交易日历每月 1 日刷新；冷启动对从未成功的任务立即补跑，支持手动 backfill。
