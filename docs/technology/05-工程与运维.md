# 05 · 工程与运维

> 配置、部署、错误处理、可观测性、测试与代码规范。

## 1. 配置项

| 环境变量 | 默认 | 说明 |
|---|---|---|
| `DEEPSEEK_API_KEY` | — | 必填（AI 对话）；不填则仅行情数据台可用 |
| `DEEPSEEK_MODEL` | `deepseek-v4-flash` | 模型名（亦支持 `deepseek-v4-pro`） |
| `DEEPSEEK_BASE_URL` | `https://api.deepseek.com` | 兼容代理可覆盖 |
| `PORT` | `8080` | 后端端口 |
| `BACKEND_URL` | `http://localhost:8080` | 前端反代目标 |
| `NPM_REGISTRY` | `https://registry.npmjs.org/` | 构建前端镜像时的 npm 源 |

业务配置集中于 `invest.*`（`InvestProperties`）：LLM 供应商/模型，行情超时、限流、重试，以及各数据 TTL。

## 2. 部署

**方式一：Docker Compose（推荐）**

```bash
cp .env.example .env   # 填入 DEEPSEEK_API_KEY
docker compose up -d --build
```

- `backend`（:8080）：带健康检查 `curl /api/agent/health`，就绪后前端才启动。
- `frontend`（:3000）：`output: standalone`，依赖后端健康通过（`depends_on: service_healthy`）。

**方式二：本地开发**

```bash
make dev   # 后端 :8080 + 前端 :3000（.env 自动加载）
```

依赖 JDK 21+、Node 20+、pnpm。入口见根目录 `Makefile`（`dev` / `test` / `build` / `up` / `down` / `smoke`）。

## 3. 错误处理

后端 `GlobalExceptionHandler` 统一异常出口：

| 场景 | 处理 |
|---|---|
| 行情领域异常 | 错误码映射 HTTP 状态（400/429/502），返回结构化 `{code, message}` |
| Agent 未注册（无 Key） | 503 + 友好提示「请设置 DEEPSEEK_API_KEY 后重启服务」 |
| AG-UI 协议异常 | 400 + `AGUI_ERROR` |
| 客户端断开 SSE（停止/关页） | 静默忽略（`AsyncRequestNotUsableException` / `ClientAbortException`），不记 ERROR、不写已关闭的流 |
| 其他未处理异常 | 500 + `INTERNAL_ERROR` |

前端边界防护：行情响应经 `zod` 校验（schema drift 边界报错而非深渲染崩溃）、发送失败弹错误条、SSE 断连可重试。

## 4. 可观测性

- **健康检查**：`/api/agent/health`（LLM 配置 + 行情源连通性 + 延迟），供 Compose 健康探测与前端状态页脚轮询（60s）。
- **Actuator**：暴露 `health`、`info`；生产环境关闭健康详情。
- **日志**：行情降级（info）、工具失败（warn）、未处理异常（error）分级记录；AgentScope MVC 控制器的无害噪音日志被关闭（`AguiMvcController: OFF`）。

## 5. 测试与冒烟

| 层 | 方式 | 说明 |
|---|---|---|
| 后端单测 | Gradle `test` | 行情解析器（离线 fixture）、工具、限流、缓存、异常映射；含 ArchUnit 分包规范强制 |
| 后端覆盖率 | JaCoCo | 指令/分支 ≥ 80% 门槛 |
| 前端单测 | Vitest | 组件（ChatPage/ToolCallCard/KlineChart/MarketBoard/Sidebar 等）+ lib 纯函数 |
| 前端覆盖率 | V8 | 语句/分支 ≥ 80% 门槛 |
| 端到端冒烟 | `make smoke` | 健康检查 → 行情接口 → 有 Key 时真实对话 |
| 浏览器 e2e | Playwright | 导航 / 行情台 / AI 对话（AI 用例需 Key，自动拉起前后端） |

## 6. 代码规范约束

- **后端分包规范**：`config` 只放配置属性、`agent` 放 Agent 装配、`market` 放数据能力、`web` 放控制器，由 ArchUnit 强制（见 [docs/backend-package-conventions.md](../backend-package-conventions.md)）。
- **前端**：领域类型与后端 DTO 对齐（`lib/types.ts`），响应 schema 与类型分离（`lib/schemas.ts`）。

## 7. 已知限制

- 会话历史仅存浏览器 localStorage（清缓存即丢失；后端无状态，见 ADR-0004）。
- 每轮请求重传全部历史，一期会话规模小可接受，二期引入记忆压缩时再评估。
- 行情数据来自免费公开接口（非官方契约），存在变更或限流风险，已用缓存 + 限流 + 多源降级缓解。
