# 01 · 系统架构与技术栈

## 1. 总体架构

```
┌─────────────────────────────────────────────────────────────────────┐
│                          浏览器 UI                                    │
│  对话（/，需登录）· 行情台（/market，公开）· 登录/注册 · 管理（/admin）   │
└──────────┬──────────────┬──────────────┬──────────────┬──────────────┘
           │ /api/copilotkit │ /api/market/** │ /api/auth/**  │ /api/admin/** /api/conversations/**
           │ (AG-UI SSE)     │ (REST)          │ (REST)        │ (REST)
┌──────────▼────────────────▼────────────────▼──────────────▼──────────┐
│                   Next.js 15 前端（同源反代，透传 Cookie/Set-Cookie）   │
│  /api/copilotkit → HttpAgent → POST /agui/run（转发会话 Cookie）        │
│  /api/market|auth|admin|conversations → 后端对应路径                     │
└──────────┬───────────────────────────────────────────────┬───────────┘
           │ POST /agui/run                                │ REST（会话/认证）
┌──────────▼───────────────────────────────────────────────▼───────────┐
│        Spring Boot 4 + Spring Security 7（DDD 洋葱分层）               │
│  web/        Auth·UserAdmin·Conversation·Market·Health 控制器          │
│  application/ auth·useradmin·conversation·market 用例编排              │
│  domain/     user·conversation·market 纯 POJO（零 Spring/JPA）         │
│  infrastructure/ persistence(JPA+Flyway)·security·seed·market(客户端+缓存)│
│  agent/      独立能力域：AgentConfig·InvestTools(6 @Tool)              │
└──────┬──────────────┬──────────────┬──────────────────────────────────┘
       │ DeepSeek API │ PostgreSQL 16│ 东方财富（主）/ 新浪 / 腾讯（兜底）
```

- **前端**：同源反代，浏览器不直连后端，规避 CORS；所有反代透传 Cookie 头与 Set-Cookie（登录态落地）。
- **后端**：按「DDD 洋葱分层 + 独立能力域」组织（见 [ADR-0009](../adr/0009-backend-ddd-layering.md)）；`agent` 保持独立能力域，`market`/`user`/`conversation` 走 DDD 分层。
- **认证**：Spring Security 7 会话认证（`JSESSIONID` + 记住我）；`ActiveUserFilter` 每次受保护请求校验用户状态，停用/被拒即时失效（见 [ADR-0007](../adr/0007-user-auth.md)）。
- **持久化**：PostgreSQL + Flyway 建表（`app_user`/`persistent_logins`/`conversation`/`chat_message`）。

## 4. 请求链路

**对话（AG-UI SSE）**

```
用户输入 → ThreadArea.send()
  → agent.addMessage() + copilotkit.runAgent({ agent })
  → CopilotKit 运行时 /api/copilotkit（useSingleEndpoint=false，REST 传输）
  → HttpAgent POST {BACKEND}/agui/run（RunAgentInput）
  → AgentScope AG-UI starter：ReActAgent 循环调用 6 个工具
  → AG-UI SSE 事件流（TEXT_MESSAGE_* / REASONING_* / TOOL_CALL_* / RUN_*）
  → CopilotKit → useAgent 状态更新 → 逐字渲染
```

**行情（REST）**

```
页面 fetch /api/market/** → Next.js 反代 → 后端 /api/market/**
  → MarketDataService（缓存命中直接返回，未命中走限流 + 数据源 + 降级）
  → 返回 DTO（前端 zod 校验）
```

## 5. 会话模型（ADR-0008）

- **领域实体** `Conversation`（`conversation` 表），`id` 复用 AG-UI 协议层 `threadId`；消息存 `chat_message` 表（精简历史：仅 user/assistant 纯文本，`payload` JSONB 预留工具调用扩展）。
- **交互模型「前端工作内存 + 服务端存储」**：`server-side-memory=false` 保留——前端以 `threadId` 标识会话、每轮携带全量历史到 `/agui/run`；每轮 assistant 回复完成后 **PUT 全量消息**到服务端，打开会话时 **GET 回灌**。
- **归属隔离**：会话读写按 `user_id` 过滤，非本人 404；多端同时编辑同一会话为后写覆盖。

详见 [docs/adr/0008-conversation-persistence.md](../adr/0008-conversation-persistence.md)（取代 ADR-0004）。
