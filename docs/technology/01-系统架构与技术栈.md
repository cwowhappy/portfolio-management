# 01 · 系统架构与技术栈

## 1. 总体架构

```
┌─────────────────────────────────────────────────────────────┐
│                        浏览器 UI                             │
│  ┌───────────────────────┐   ┌───────────────────────────┐  │
│  │  对话式投研问答（/）    │   │   行情数据台（/market）     │  │
│  └───────────┬───────────┘   └─────────────┬─────────────┘  │
└──────────────┼──────────────────────────────┼────────────────┘
               │ /api/copilotkit（AG-UI SSE） │ /api/market/**（REST 反代）
┌──────────────▼──────────────────────────────▼────────────────┐
│                Next.js 15 前端（同源反代）                     │
│  /api/copilotkit → HttpAgent → 后端 POST /agui/run           │
│  /api/market/[...path] → 后端 /api/market/**                  │
│  /api/agent/health    → 后端 /api/agent/health                │
└──────────────┬──────────────────────────────┬────────────────┘
               │ POST /agui/run               │ REST
┌──────────────▼──────────────────────────────▼────────────────┐
│           Spring Boot 4 + AgentScope Java 2.0.1              │
│  ReActAgent「invest」 + InvestTools(6 @Tool)                  │
│  MarketDataService（TTL 缓存 + 令牌桶限流 + 多源降级）          │
│  web 层：MarketController / HealthController / 全局异常处理    │
└──────────┬─────────────────────────┬─────────────────────────┘
           │ DeepSeek API            │ 东方财富（主）/ 新浪 / 腾讯（兜底）
```

- **前端**：同源反代，浏览器不直连后端，规避 CORS；行情 REST 与 AG-UI 对话均经 Next.js 路由中转。
- **后端**：Agent 工具与行情 REST **共用同一 `MarketDataService`**，仅返回形态不同（工具返回 JSON 文本给模型，REST 返回 DTO 给页面）。

## 4. 请求链路

**对话（AG-UI SSE）**

```
用户输入 → ThreadArea.send()
  → agent.addMessage() + copilotkit.runAgent({ agent })
  → CopilotKit 运行时 /api/copilotkit（useSingleEndpoint=false，REST 传输）
  → HttpAgent POST {BACKEND}/agui/run（RunAgentInput）
  → AgentScope AG-UI starter：ReActAgent 循环调用 6 个工具
  → AG-UI SSE 事件流（TEXT_MESSAGE_* / REASONING_* / TOOL_CALL_* / RUN_*）
  → CopilotKit → useAgent 状态更新 → 逐字渲染
```

**行情（REST）**

```
页面 fetch /api/market/** → Next.js 反代 → 后端 /api/market/**
  → MarketDataService（缓存命中直接返回，未命中走限流 + 数据源 + 降级）
  → 返回 DTO（前端 zod 校验）
```

## 5. 会话模型（ADR-0004）

`server-side-memory=false`：前端以 `threadId`（UUID）标识会话，在 localStorage 持久化消息历史，每轮请求携带全部历史；后端不维护会话状态。详见 [docs/adr/0004-session-model.md](../adr/0004-session-model.md)。
