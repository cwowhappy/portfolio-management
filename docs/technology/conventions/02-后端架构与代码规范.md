# 02 · 后端架构与代码规范

> 适用范围：`backend/`（Spring Boot 4 + Spring Security 7 + Spring Data JPA + Flyway + AgentScope Java）。
> 与 [01-后端DDD分包规范](01-后端DDD分包规范.md) 的分工：01 管"类放哪、依赖朝哪"，本文管"类怎么写"。
> 每条规则含：理由 / 佐证 / 约束方式（人工评审 / 测试强制 / ArchUnit 强制）。标注【决策】的条目为已拍板的设计取舍。

## 一、分层与依赖

**A1. web 层只出入 View/Wire DTO，不直接暴露领域对象。**
出参 `XxxView.from(domain)`、入参 `XxxWire.toDomain()` 是既定手法。理由：协议演进不影响领域；领域字段（如密码哈希）外泄风险归零。佐证：`ConversationController.java:33-56`。约束：人工评审。

**A2. 事务边界收敛在 application 层，repository 实现不挂 `@Transactional`。【决策】**
事务是用例语义，双挂造成边界歧义。佐证：`ConversationApplicationService.java:27,48,63`。约束：**ArchUnit 强制**（`@Transactional` 只允许出现在 `..application..`）。

**A3. 业务代码的时间与阻塞必须可注入，不直接调 `System.currentTimeMillis()` / `Thread.sleep()`。**
理由：可确定性测试，杜绝 flaky。佐证：`RateLimiter.java:23`、`ValuationApplicationService.java:41`。约束：**ArchUnit 强制**（domain/application 禁调 `System.currentTimeMillis`/`nanoTime`/`getenv`）。

**A4. 领域对象不可变：record 值对象；有行为的实体用 `final class` + 静态工厂 + copy 方法。**
佐证：`Quote`（record）、`Conversation.java:25-45`（`create`/`reconstitute`/`touch`）。约束：人工评审。

## 二、面向接口编程（端口与适配器）【决策：方案 A】

**I1. 三处边界必须面向接口：**
- domain/application 需要的外部资源（持久化、行情源、令牌存储）一律定义端口接口，infrastructure 实现、config 装配；application/domain 禁止出现 infrastructure 类型；
- 需要装饰器/多实现/可替换性的应用服务（如 `MarketDataService` 的缓存装饰）在 application 层定义接口；
- 接口签名只允许出现 domain/application 类型，不得泄漏 JPA 实体。

**I2. 不强制"每类一接口"。** 单一实现、无装饰需求的 `*ApplicationService` 保持具体类，web 直接注入。**触发规则：出现第二实现/装饰/替换需求时立即抽接口，不提前。**
理由（YAGNI + 可测试性双重论证）：
- 接口买的四样东西——mock 接缝、多实现、包解耦、框架要求——对用例服务全部不成立：没有任何测试需要 mock 服务层；四个服务均无第二实现；接口仍放 application 包、包依赖不变；Boot 默认 class-based AOP 不需要接口；
- 服务层可测试性由**构造器注入 + 端口接口**保证（`new Service(mock(port))`）；具体类可直接被 Mockito inline mock maker mock（本项目实证：`ValuationControllerTest` mock 具体类 `ValuationApplicationService` 2 次）；
- 推迟成本分钟级（IDE 提取接口），`MarketDataService` 就是需求出现后才抽接口的成功先例；提前抽象是持续税（双文件同步、头文件式接口反模式、误导扩展点信号）。

**I3. 端口接口是测试边界**：单测 mock 端口接口，不得 mock 具体实现类；web 层测试优先 MockMvc + 真实服务的行为断言，避免退化为 verify 交互风格。

佐证：`MarketDataService`（接口）→ `OrchestratingMarketDataService` + `CachedMarketDataService`（装饰）；`RememberMeTokenStore`（domain 端口）。约束：人工评审 + ArchUnit 包规则兜底。

## 三、异常与错误模型

**B1. 每域一个 `XxxException extends RuntimeException`，携带稳定 code + 用户可读中文 message；异常→HTTP 状态映射只允许在 `GlobalExceptionHandler`。** 约束：ArchUnit（@RestControllerAdvice 只在 web，已有）。

**B2. 错误码定义为每域常量（`XxxErrorCode`），抛点/handler/测试同引一处。【决策】** 消除字符串三处漂移；不上 enum（switch 按字符串的现状改动最小）。约束：人工评审。

**B3. 基础设施异常不得穿过 application 层原样冒泡；竞态类约束违例在发生点精确翻译（如 USERNAME_TAKEN），全局兜底 `DataIntegrityViolationException → 400`。** 佐证：`AuthApplicationService.java:44-47`、`GlobalExceptionHandler.java:52-57`。

**B4. 已知"正常失败"不记 ERROR 日志（SSE 断连记 debug）；未知异常才 `log.error` 带堆栈。** 佐证：`GlobalExceptionHandler.java:77-88`。

**B5. 错误体统一 `ApiError(code, message)`，不迁 RFC 7807 ProblemDetail。【决策】** 前端契约已稳定，迁移无收益。

**B6. Agent 工具方法失败返回结构化错误文本，不向 LLM 抛异常。** 佐证：`InvestTools.java:134-144`。

## 四、数据访问与迁移

**C1. schema 只由 Flyway 管（`ddl-auto: none`）；跨服务共享表（collector 写入）在迁移头部注释声明契约，变更需双端同步。** 佐证：`V3__valuation.sql:2`。

**C2. JPA 实体只在 `infrastructure.persistence`，经显式映射器转换；assigned `@Id` 聚合的 save→merge 语义陷阱必须注释。** 佐证：`ConversationApplicationService.java:34-38`。约束：**ArchUnit 强制**（`@Entity` 只在 `..infrastructure.persistence..`）。

**C3. 精确计算（分位、利率、金额）用 `BigDecimal` + 显式 `RoundingMode`；展示型行情快照可用 double。** 佐证：`ValuationApplicationService.java:135,181`。

**C4. 写路径优先幂等设计（重复请求返回既有结果）。** 佐证：`ConversationApplicationService.java:30-33`。

## 五、安全

**E1. 授权规则集中在 `SecurityConfig` 一处（lambda DSL），不分散使用 `@PreAuthorize`。【决策】** 单点可审计；端点增多后若膨胀再评估。约束：人工评审 + `SecurityConfigTest`。

**E2. 新增 `permitAll` 端点必须回答"匿名刷它消耗什么"：外呼上游/DB 全表扫描/LLM token 的必须带缓存或限流。** 佐证：健康检查烧配额、估值匿名全表扫描两次事故（`docs/code-review-2026-08-29.md`）。

**E3. liveness 探针零外呼、零 DB、零限流消耗；业务状态探活走独立端点（health/status 拆分）。**

**E4. 秘密只经 env → `application.yml` 占位符 → `InvestProperties` 进入代码；业务代码禁止 `System.getenv`、禁止硬编码 key。** 约束：**ArchUnit 强制**（`System.getenv` 零调用）。

**E5. 归属资源一律"按归属查询、查无返 404"，不用 403 泄露存在性。** 佐证：`ConversationApplicationService.requireOwned`。

**E6. 安全行为（会话固定防护、remember-me 失效、停用即时生效）必须有回归测试。** 佐证：`AuthControllerIntegrationTest` session 轮换断言。

## 六、并发与资源

**F1. 等待/休眠不持锁；并发状态用小粒度 `synchronized` + 纳秒时钟。** 佐证：`RateLimiter.java:37-58`。

**F2. 缓存必须有界（maxEntries）且 TTL 来自配置；application 层需要缓存时定义端口接口、infrastructure 注入实现，禁止自造 mini-cache。【决策】** 佐证：`ValuationApplicationService` 曾因分层限制自造缓存。

**F3. 所有外呼必须有连接/读超时与重试上限，限流在每次尝试前获取（重试不绕过限流）。** 佐证：`HttpExecutor.java:46-51`。

## 七、测试

**G1. 测试四层：单元证「逻辑对」、切片证「接线对」、集成证「依赖对」、BDD 证「流程对」。**

| 类型 | 职责 | 边界 | Source Set | 命名 |
|---|---|---|---|---|
| 单元 | 纯业务规则与编排 | 零 Spring/零真实 I/O，mock 只打端口接口 | `test` | `*Test` |
| 切片 | 单层与框架的装配契约（绑定/校验/序列化/安全规则/异常映射） | `@WebMvcTest`/`@JsonTest`/`@DataJpaTest` 部分上下文，无 Docker | `test`（持久化切片 `@DataJpaTest` 归 `integrationTest`，见 G7） | `*SliceTest` |
| 集成 | 跨层与真实依赖协同（事务/约束/并发/迁移/装配/SSE 流） | Testcontainers 真实 PG，窄端到端 | `integrationTest` | `*IntegrationTest` |
| BDD | 中文 Gherkin 锁定关键用户旅程 | Cucumber JVM + 真实 PG + 假 Model | `bdd` | `*Steps` + `*.feature` |

共享基座 `PostgresTestSupport`（JVM 单例容器）放 `testFixtures`，被 integrationTest / bdd 依赖。分工红线：**切片验接线、单测验逻辑、集成验真实依赖、BDD 只锁核心旅程不贪多**——同一行为不跨层重复断言。运行：`make test-backend-unit` / `test-backend-integration` / `test-backend-bdd`（全量 `make test-backend` = `./gradlew check`，聚合三层 exec 后统一卡 ≥80% 门槛）。

**G2. 涉事务/约束/连接/序列化的行为，至少一条真实依赖窄端到端测试（integrationTest 层），不得只 mock。**（collector P0 被 MagicMock 掩盖的教训）

**G3. 时间相关测试注入假时钟，禁止真实 sleep。** 佐证：`RateLimiterTest`、`TtlCacheTest`。

**G4. 每个 bug 修复必须附回归测试；断言锁结构与关键字段，不只断言状态码。**

**G5. Boot 4 测试 API 要点：**
- Spring 上下文内 mock 用 `@MockitoBean`（`@MockBean`/`@SpyBean` 已随 Boot 4 删除），固定替换用 `@TestBean`；
- `@WebMvcTest` 需类路径有 `spring-boot-starter-security-test` 才挂安全过滤器链（否则 401/403 断言失真），依赖已声明，勿删；
- `@SpringBootTest` 下 MockMvc 需显式 `@AutoConfigureMockMvc`（自动配置已迁至 `spring-boot-starter-webmvc-test`）。

**G6. 测试方法名用中文描述行为。**

**G7. 切片选型：**

| 场景 | 选型 | 说明 |
|---|---|---|
| web 接线 + 安全规则 | `@WebMvcTest` + `@MockitoBean` 服务 | 模板：`PortfolioControllerSliceTest`、`SecuritySliceTest` |
| DTO wire 契约 | `@JsonTest` + Jackson 2 `ObjectMapper` | Jackson 2 项目直接注入 `@JsonTest` 自动配置的 Jackson 2 `ObjectMapper` 做序列化断言（`Jackson2Tester` 在 Boot 4 已 `@Deprecated(forRemoval)`，勿用）；模板：`web/dto/DtoJsonContractTest` |
| 持久化切片 | `@DataJpaTest` + `@ServiceConnection` + `Replace.NONE` | 复用 testFixtures 单例容器，**今后新增持久化测试的优先写法**；模板：`integrationTest` 下 `*RepositoryImplTest` |

**G8. BDD 准入：Cucumber 中文 Gherkin（`# language: zh-CN`）只锁关键用户旅程（当前 5 个，见 `src/bdd/resources/features/`），新增场景需回答"这是用户级旅程还是技术细节"——后者归单测/集成。** 约定：JUnit Platform Suite 入口 `CucumberRunnerTest`；steps 复用 ApplicationService + 真实 PG + `@TestBean` 假 Model，每场景经 `MockResetHooks` 复位。已知补丁：`src/bdd/java/io/cucumber/core/runner/Runner.java` 遮蔽 Cucumber 7.34.7 中文方言 Locale bug（`zh-CN` 含区域子标签触发 `IllformedLocaleException`，上游未修），仅作用于 bdd 类路径；**上游修复后删除该类**。

## 八、命名与风格

**H1. 后缀约定**：`Controller` / `ApplicationService` / domain 端口 `XxxRepository`/`*Store`/`*Source` / infra 三件套 `XxxRepositoryImpl`+`XxxJpaRepository`+`XxxJpaEntity` / 入参 `XxxWire`（或 `Command`）、出参 `XxxView` / 域异常 `XxxException` / 错误码 `XxxErrorCode`。

**H2. 构造器注入、依赖字段 `final`；多构造器时显式 `@Autowired` 标注注入入口。** 禁止字段/setter 注入。

**H3. `Optional` 只作查询返回值，不作字段、不作方法参数。**

**H4. 魔法值进 `InvestProperties` 或具名常量；与 DB 约束联动的上限注释对应迁移文件。** 佐证：`ChatMessageWire.java:10-11`（"与 V2 VARCHAR(64) 对齐"）。

**H5. 注释解释"为什么"而非"是什么"；坑与反直觉决策必须注释。**

**H6. import 不使用内联全限定名；同包冲突时重命名类。**

**H7. 业务代码只用 Jackson 2（`com.fasterxml.jackson.*`），禁止 Jackson 3（`tools.jackson.*`）——AgentScope AG-UI 模型依赖 Jackson 2 注解。** 约束：**ArchUnit 强制**（禁依赖 `tools.jackson..`）。类路径同步排除 Jackson 3：`spring-boot-starter-webmvc`（生产）与 `spring-boot-starter-webmvc-test`（测试）均在 `build.gradle` exclude `spring-boot-starter-jackson`，否则 Jackson 3 消息转换器会抢占 AG-UI 入参反序列化。

**H8. wire DTO 的结构性校验（非空/长度）用 Bean Validation 注解（`@NotBlank`/`@Size` + `@Valid`），业务规则（白名单等）留 application 层手写。【决策】** 依赖 `spring-boot-starter-validation` 已引入，禁止继续裸 `Map` 入参。
