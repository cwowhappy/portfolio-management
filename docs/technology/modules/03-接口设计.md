# 04 · 接口

> 后端对外接口：认证、管理员、会话、行情 REST、AG-UI 对话、健康检查。
> 数据获取与保护见 [02-行情数据服务.md](02-行情数据服务.md)；认证与会话模型见 [ADR-0007](../decisions/0007-user-auth.md) / [ADR-0008](../decisions/0008-conversation-persistence.md)。
> 对应代码：`backend/src/main/java/com/portfolio/invest/web/`（AuthController / UserAdminController / ConversationController / MarketController / HealthController / GlobalExceptionHandler）。

前端统一经 Next.js 同源反代访问（`/api/auth/**`、`/api/admin/**`、`/api/conversations/**`、`/api/market/**`、`/api/agent/health`、`/api/copilotkit`），反代透传 Cookie 头与 Set-Cookie（登录态落地浏览器）。

## 1. 认证接口

统一前缀 `/api/auth`：

| 端点 | 权限 | 说明 |
|---|---|---|
| `POST /api/auth/register` | 公开 | 注册（`{username, password}`）→ 201 待审核 |
| `POST /api/auth/login` | 公开 | 登录（`{username, password, rememberMe}`）；成功 200 + `UserView`，并落地会话/记住我 Cookie |
| `POST /api/auth/logout` | 登录 | 登出（Security 过滤器处理，清 JSESSIONID + 记住我） |
| `GET /api/auth/me` | 登录 | 当前用户 `{id, username, role, status, enabled, createdAt}`；未登录 401 |

**登录状态分流**（认证成功后按用户状态，返回 403 + 不同 code）：

| 状态 | HTTP / code |
|---|---|
| 待审核 PENDING | 403 `ACCOUNT_PENDING` |
| 已拒绝 REJECTED | 403 `ACCOUNT_REJECTED` |
| 已停用（enabled=false） | 403 `ACCOUNT_DISABLED` |
| 用户名或密码错误 | 401 `BAD_CREDENTIALS` |

## 2. 管理员接口

统一前缀 `/api/admin/users`，需 `ADMIN` 角色：

| 端点 | 说明 |
|---|---|
| `GET /api/admin/users` | 用户列表（含状态） |
| `POST /api/admin/users/{id}/approve` | 审核通过 |
| `POST /api/admin/users/{id}/reject` | 拒绝 |
| `POST /api/admin/users/{id}/enable` | 启用 |
| `POST /api/admin/users/{id}/disable` | 停用 |
| `POST /api/admin/users/{id}/reset-password` | 重置密码（`{newPassword}`） |

对 ADMIN 账号执行审核/停用/重置 → 403 `FORBIDDEN`（保护内置管理员）。

## 3. 会话接口

统一前缀 `/api/conversations`，需登录，按归属隔离（非本人 404）：

| 端点 | 说明 |
|---|---|
| `GET /api/conversations` | 我的会话列表 `[{id, title, updatedAt}]` |
| `POST /api/conversations` | 新建会话（`{id}` = threadId）→ 201 |
| `GET /api/conversations/{id}/messages` | 加载消息 `[{id, role, content, createdAt}]` |
| `PUT /api/conversations/{id}/messages` | 全量替换保存消息 → 204 |
| `DELETE /api/conversations/{id}` | 删除会话 → 204 |

`saveMessages` 会取首条 user 消息前 24 字生成会话标题（幂等）；会话 id 非本人访问返回 404（不泄露存在性）。

## 4. 行情 REST 接口

统一前缀 `/api/market`（公开）：

| 端点 | 说明 | 关键参数 |
|---|---|---|
| `GET /api/market/search?q=茅台` | 股票搜索 | `q` 必填 |
| `GET /api/market/quote/{code}` | 实时行情 | — |
| `GET /api/market/kline/{code}` | K线 | `period=day/week/month`（默认 day）；`limit` 默认 120，范围 [5, 500] |
| `GET /api/market/financials/{code}` | 财务指标 + PE/PB | — |
| `GET /api/market/news/{code}` | 个股新闻 | `limit` 默认 10，范围 [1, 20] |
| `GET /api/market/overview` | 指数速览 | — |

**错误码 → HTTP 状态**（`GlobalExceptionHandler`）：

| 错误码 | HTTP |
|---|---|
| `INVALID_CODE` / `INVALID_PERIOD` / `INVALID_QUERY` | 400 |
| `RATE_LIMITED` | 429 |
| 其他行情错误 | 502 |

## 5. AG-UI 对话接口

- **端点**：`POST /agui/run`（AgentScope AG-UI starter 自动注册），需登录。
- **请求**：`RunAgentInput`（`threadId`、`runId`、`messages`、`state`、`tools`、`forwardedProps`）。
- **响应**：AG-UI SSE 事件流 —— `RUN_STARTED` → `TEXT_MESSAGE_*`（正文增量）、`REASONING_MESSAGE_*`（思考）、`TOOL_CALL_START/ARGS/END` + `TOOL_CALL_RESULT`（工具进度）、`CUSTOM`（token_usage 等）→ `RUN_FINISHED` / `RUN_ERROR`。

前端经 CopilotKit 运行时 `/api/copilotkit` 反代到此端点（反代转发会话 Cookie，否则 401）。端点配置见 [01-Agent实现.md](01-Agent实现.md) 第 6 节。

## 6. 健康检查接口

`GET /api/agent/health`（公开）：

```json
{
  "status": "up | degraded",
  "llm": { "provider": "deepseek", "model": "...", "baseUrl": "...", "keyConfigured": true },
  "market": { "ok": true, "latencyMs": 123, "message": "..." }
}
```

- `status=up` 需 LLM Key 已配 **且** 行情源连通，否则 `degraded`。
- `market.ok` 通过真实请求一次 `600519` 行情并计时（绕过缓存）判断。
- 生产环境（`SPRING_PROFILES_ACTIVE=prod`）关闭健康详情外泄（`show-details: never`）。
