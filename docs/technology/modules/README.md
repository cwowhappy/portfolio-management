## 编号与登记约定

- **编号**：篇号 = 文件名前缀，按现有序列（01–14）续排。当前 01–08 为通用机制篇、09–14 为业务域篇；后续新增延续当前序列取下一个空号，机制/业务域的归属在登记时注明，不做 1x/2x 重编号。
- **登记**：新增模块文档归入本目录并在本索引登记一行（与 [../README.md](../README.md) 的维护约定一致）。
- **篇内结构**（新篇统一）：篇首「对应代码」真实路径 → 概述 → 架构/数据流 → 关键类与配置 → 端点（如有）→ 测试 → 已知限制。
