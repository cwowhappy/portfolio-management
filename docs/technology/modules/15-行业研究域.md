# 15 · 行业研究域

> 行业研究中心（`/industry` 板面 + `/industry/[industryCode]` 下钻页）的后端读侧域：行业板面聚合（四指标 + 近 5 年分位 + 景气标注）与行业成员排名（市值/营收/ROE）。
> 功能口径与 [../../function/modules/10-行业研究中心.md](../../function/modules/10-行业研究中心.md) 同源；行业估值表与估值域共享（见 [09-估值域.md](09-估值域.md)），成员查询底座与筛选域同构（见 [10-筛选域.md](10-筛选域.md)）；数据来源与采集节奏（`income` 并入、重算任务、分段回填）见 [../architecture/05-数据类型与来源.md](../architecture/05-数据类型与来源.md)。
> 对应代码：`backend/src/main/java/com/portfolio/invest/domain/industry/`（`IndustryValuationRow`、`IndustryValuationPoint`、`IndustryStock`、`IndustryProsperitySnapshot`、`WindowedPercentile`、`Prosperity`、`IndustryRepository`、`IndustryErrorCode`/`IndustryException`）、`application/industry/`（`IndustryApplicationService` + `IndustryBoardView`）、`web/IndustryController.java`、`infrastructure/persistence/IndustryRepositoryImpl.java`（JdbcTemplate 原生 SQL，无 JPA 实体——跨域共享表不重复映射）；迁移 `db/migration/V3__valuation.sql`（industry_valuation，既有）、`V7__stock_fundamental.sql`（既有）、`V15__stock_financial_revenue.sql`（revenue 列）；前端 `frontend/app/industry/`、`frontend/components/industry/`（MS-09 交付）。

## 1. 概述

两公开只读端点（`/api/industry/` 在 `PublicEndpointPaths.PREFIXES` 公开前缀清单中，无用户态）：

- **行业板面** `GET /api/industry/board`：31 个申万一级行业 × {PE/PB/ROE/股息率（最新快照日）+ PE/PB 近 5 年分位 + 景气三档 + 景气原始输入（中位数与样本数，供前端 tooltip 解释）}——单请求同时喂 F01 估值表、F02 热力图与 F04/F05 新列；
- **行业成员排名** `GET /api/industry/{industryCode}/stocks`：行业内上市公司按总市值/营收/ROE 排序（排序白名单 + limit ≤1000），每行带个股景气标注。

域为**纯读模型**（无聚合根、无写路径）：`industry_valuation` 表与估值域共享——跨域读先例同 `shenwan_industry_mapping`（估值域/持仓域均读）；不 import `domain/valuation`（域间零依赖，分位语义一致性由单测同输入同输出锚定）。

## 2. 架构与数据流

### 2.1 数据底座（collector 写、后端读）

| 表 | 迁移 | 粒度 | 本域消费 |
|---|---|---|---|
| `industry_valuation` | V3 | 交易日 × 行业（`UNIQUE(trading_day, industry_code)`） | 最新快照日四指标（`findLatestIndustries`）+ 5 年历史 pe/pb 序列（`findValuationHistorySince`）。**历史行由 collector 重算任务 `industry_valuation_backfill` 写入（MS-09），roe/股息率为 NULL**（仅每日快照路径产出）——本域分位只算 pe/pb |
| `stock_valuation_daily` ⋈ `stock_financial` ⋈ `shenwan_industry_mapping` | V7 + V15 + V3 | 个股 | 成员排名：估值日快照取**库内最新交易日**主表（市值/PE/PB/股息率）+ `stock_financial` 经 `DISTINCT ON ... ORDER BY report_date DESC` 取每股**最新报告期**（ROE + `revenue` 营收绝对额，单位元、报告期累计，V15 新列）+ 申万映射限定行业 |

取数口径与筛选域 `BASE_SQL` 同构（见 [10-筛选域.md](10-筛选域.md) §2.1）；财务列缺失（LEFT JOIN null）排序时 `NULLS LAST`、展示为「—」。

### 2.2 分位与景气计算

**分位（`WindowedPercentile.of`）**：**近 5 年经验分布**——应用层 `findValuationHistorySince(今天 − 5 年)` 全量拉取（约 31 行业 × 1200+ 交易日）后按行业分组，当前值在窗口序列中**严格小于它的占比 × 100**（BigDecimal，2 位 HALF_UP）；窗口序列**非空值不足 250 交易日（约一年）返回 null**（「数据积累中」，前端「—」）。语义对齐估值域 `Percentile.of` 但为独立实现（窗口化 + 门槛是其扩展）。

**历史数据的成分口径**：`industry_valuation` 历史行由重算任务**按当前申万 2021 成分回溯**自算（SQL 口径与每日快照 `IndustryValuationCalc` 双实现一致：pe 分子剔除 pe≤0、pe 分母仅计有效成分市值，**pb 分母无条件 Σ市值**；roe/股息率历史为 NULL 不产出）——即历史分位不含已退出行业分类的成分变迁（口径注记，非缺陷）。

**景气（`Prosperity.of`，行业级与个股级同一规则）**：双输入 = ROEΔ（近 4 季 ROE 均值 − 前 4 季均值，pp）与营收增速（最新报告期同比，%），由 repository 的 8 季窗口 CTE（`ROW_NUMBER() OVER (PARTITION BY stock_code ORDER BY report_date DESC)`）预计算：

```
UP   ⇔ ROEΔ ≥ +1 且 营收增速 ≥ +10   （且：防单指标噪声）
DOWN ⇔ ROEΔ ≤ −1 或 营收增速 ≤ −10   （或：更敏感；且/或不对称为有意设计）
其余 → FLAT；任一输入缺失 → null（不标注）
```

**行业级聚合**：成员 ROEΔ 与营收增速各取**中位数**（`PERCENTILE_CONT(0.5)`）再判定；样本数 0 或快照缺失 → 景气 null，但 `prosperityInputs` 原始值仍透出（含 `sampleSize=0`）供前端提示「样本不足」。个股级直接以该股两输入判定，随成员行返回。

### 2.3 缓存

两端点共享应用层缓存端口 `ApplicationCache`：key `industry:board:{当日日期}` 与 `industry:{code}:stocks:{sortBy}|{dir}|{limit}`，TTL 默认 5 分钟（`invest.app-cache.ttl`）。缓存实现见 [02-行情数据服务.md](02-行情数据服务.md) 应用级缓存部分。

## 4. 端点（统一前缀 `/api/industry`，公开只读——`PublicEndpointPaths` 前缀 `/api/industry/`）

| 端点 | 说明 |
|---|---|
| `GET /api/industry/board` | 31 行业板面：`pe`/`pb`/`roe`/`dividendYield` + `pePercentile`/`pbPercentile`（5y 窗口，可 null）+ `prosperity`（UP/FLAT/DOWN，可 null）+ `prosperityInputs`（roeDeltaMedian/revenueYoyMedian/sampleSize） |
| `GET /api/industry/{industryCode}/stocks?sortBy=total_mv&sortDirection=DESC&limit=1000` | 行业成员排名；`sortBy` ∈ `total_mv`（默认）/`revenue`/`roe`，`sortDirection` ASC/DESC（NULLS LAST），`limit` 1~1000；返回 `IndustryStock[]`（含 `revenue`/`revenueReportDate` 报告期角标与个股 `prosperity`） |

错误码（`GlobalExceptionHandler` 映射）：`INDUSTRY_NOT_FOUND` → 404（industryCode 不在申万映射）、`INDUSTRY_INVALID_SORT` / `INDUSTRY_INVALID_LIMIT` → 400。

## 6. 已知限制

- **分位窗口固定近 5 年、无日期参数**：不能查任意历史时点的分位（如「2023 年末银行 PE 分位」），也不能切换 10 年窗口（常量预留未做）；序列不足 250 交易日输出 null。
- **景气仅当前档、无历史序列**：行业/个股景气都是「当前快照的标注」，无景气历史走势；ROE 不足 8 季的个股不参与中位数、自身不标注。
- **历史估值按当前申万 2021 成分回溯**：`industry_valuation` 历史行不反映行业分类变迁（历史分位口径注记，见 §2.2）；roe/股息率历史为 NULL，故分位仅 pe/pb 两指标。
- **board 单请求聚合、历史全量内存分组**：5 年历史（约数万行）一次性拉取后按行业分组，依赖 31 行业 × 日频数据量可控，无分页/裁剪。
- **成员查询无分页 offset**：只有 `limit ≤ 1000` 截断，前端 50/页为本地分页（同筛选器「一次拉全量」先例）。
- **营收 = 最新报告期累计、混合报告期**：成员各行报告期可不同（角标展示）；income 未披露的个股 revenue 为 null 排序沉底。
