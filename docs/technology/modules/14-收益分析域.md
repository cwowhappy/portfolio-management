# 14 · 收益分析域

> 收益分析读侧重算（MS-07）：一次取数把持仓流水（交易/分红/现金存取）重放成每日总资产序列，融合收盘价（个股 `stock_valuation_daily.close` + 基准 `index_close_history`，今日未落库用 quoteBatch 实时价补位），再调 domain/analytics 纯函数算 TWR/IRR/基准对比/年度收益/交易统计。MS-13 追加风险指标与归因：`RiskMetricsCalculator`（TWR 净值指数/最大回撤/夏普/Calmar）与 `AttributionCalculator`（日频子周期 Brinson 对沪深300）两组纯函数 + 归因数据面三端口。六个只读端点，零落库。
> 持仓流水唯一来源见 [11-持仓域.md](11-持仓域.md)；功能视角见 [../../function/modules/12-收益与风险分析.md](../../function/modules/12-收益与风险分析.md)。
> 对应代码：`backend/src/main/java/com/portfolio/invest/domain/analytics/`（`TwrCalculator`、`IrrCalculator`、`AnnualReturnCalculator`、`TradeStatsCalculator`、`NavReconstructor`、`RiskMetricsCalculator`、`AttributionCalculator`、`NavSeries`/`DailyPoint`/`StockEvent`/`CashEvent`/`ExternalFlow`/`DatedAmount`/`DatedIndex`/`DatedReturn`、读侧端口 `StockClosePort`/`IndexClosePort`/`RiskFreeRatePort`/`IndustryMappingPort`/`BenchmarkIndustryWeightPort`）、`application/analytics/`（`AnalyticsApplicationService` + `OverviewView`/`NavSeriesView`/`AnnualReturnRow`/`TradeStatsView`/`RiskStatsView`/`AttributionView`）、`web/AnalyticsController.java`、`infrastructure/persistence/StockCloseAdapter.java`、`IndexCloseAdapter.java`、`RiskFreeRateAdapter.java`、`IndustryMappingAdapter.java`、`BenchmarkIndustryWeightAdapter.java`；迁移 `db/migration/V13__analytics_close.sql`；collector 任务 `tasks/index_close.yaml`、`tasks/industry_index_close.yaml`；前端 `frontend/app/analytics/page.tsx` + `components/analytics/`（含 MS-13 `RiskStatsCards`/`AttributionSection`）、同源反代 `frontend/app/api/analytics/[...path]/route.ts`。

## 1. 概述

分析与记账彻底分离：**portfolio 域只管写流水，analytics 域每次请求全量重放重算**，没有任何分析结果落库（对照估值域快照表的另一极端）。设计要点：

- **零落库读侧重算**：`AnalyticsApplicationService` 四方法均走同一 `replay(userId)`——取 portfolio/positions/groups → 逐持仓按「同日 BUY→分红→SELL、再按 createdAt/id 稳定序」重放真实 `Position` 聚合（`applyBuy/applySell/apply*`，realizedPnl 取前后差值，与记账侧单一事实源）；分组现金流水同时产出 TWR 外部流（剔除）与 XIRR 投资者流（出资 −/回收 +）。
- **收盘价两源融合**（spec §五-4）：个股与基准收盘从 DB 读区间序列；**今日 close 未落库时用 `MarketDataService.quoteBatch` 实时价补位**（单只失败仅止于昨日，不阻断——quoteBatch 本身逐只 catch 跳过）。
- **无流水 → 204**：overview/nav/trade-stats 无数据返回 204 空体（沿 allocation `latestAssessment` 先例），annual 恒返回数组（空数组即空态）。
- 全部端点需登录（不在 `PublicEndpointPaths` 公开清单），按 userId 归属隔离；方法不加事务注解（对照 portfolio 读方法惯例）。

## 2. 架构与数据流

### 2.1 数据底座（V13，collector 写、后端读的跨服务契约）

| 变更 | 内容 | 写入方 |
|---|---|---|
| `stock_valuation_daily` 加列 `close NUMERIC(12,4)` | 个股收盘价（tushare `daily_basic` 同源字段，加列向后兼容，老行 NULL 读侧 forward-fill 跳过） | 既有 `stock_valuation_daily` 任务（converter 增映射 `close`） |
| 新表 `index_close_history` | 基准指数收盘：`UNIQUE(trading_day, index_code)` + `idx_index_close_history_code`；三只基准 000300/000905/930950 | 新任务 `index_close`（tushare `index_daily`，cron 工作日 15:40，交易日门控，min_rows=3 硬校验） |

### 2.2 一次请求的计算链（以 overview 为例）

```
replay(userId)                     # 流水重放（StockEvent/CashEvent/ExternalFlow/投资者流/BuyLot/SellLot）
  → reconstruct(...)               # NavReconstructor：事件日 ∪ 收盘日为轴，收盘 forward-fill，
                                   #   「date ≤ t」事件逐日生效 → List<DailyPoint>(mv, cash, totalValue)
  → TwrCalculator.cumulative       # 日频子周期几何链接 Π(1+R_t)−1，现金流日初到账剔除
  → TwrCalculator.annualized       # (1+TWR)^(365/窗口天数)−1
  → IrrCalculator.xirr             # 投资者流 + 期末终值，二分求解；无解/无外部流 → null
  → benchmarkTwr                   # 三基准收盘合成无外部流 NavSeries 走同一 TwrCalculator（≥2 点才算得出）
```

序列窗口 = [首事件日（含现金流水）, 今日]；点位日期 = 全部 close 日期并集（个股 ∪ 实时补位），事件按序生效，收盘价 forward-fill。

### 2.3 前端归一化（NavChart）

后端给绝对值序列；前端 `toNormalizedNav` 把组合与各基准按**日期交集**对齐后各除以自身窗口首值 ×1000（首日恒 1000，消绝对规模），与组合窗口完全无重叠的基准剔除（防一条坏基准清空整图）。

## 6. 已知限制

- **回溯精度依赖 close 历史**：`stock_valuation_daily.close` 只从 V13 落地后开始积累（此前老行 NULL），早期窗口点位稀疏——分析正确性不受影响（forward-fill），但长回溯走势图的逐日密度受限于回填进度。
- **今日值依赖实时行情**：当日 close 未落库前（collector 15:35/15:40 跑完前）净值序列末点取 quoteBatch 实时价，盘后与收盘价可能有细微差异；实时价取不到则序列止于昨日。
- **分红/费率口径**：现金分红按 exDate 当日全量现金计（未做除权价调整），买卖费率参与现金流但不单独建模。
- **归因基准行业权重为静态近似**（MS-13）：取最近一次 `index_constituent` 沪深300 成分快照按行业聚合，历史成分漂移不重建；组合行业权重为前一日收盘快照（日频近似），residual 字段显式携带该近似的数学损耗。
- **行业指数源依赖申万官网**：`industry_index_close` 走 akshare `index_hist_sw`（tushare `sw_daily` 积分门槛不可得的换源裁决，见 [09-调研报告](../../../features/risk-attribution-backtest/09-调研报告/2026-09-24-三源可得性探测.md)）；该接口无日期参数、一次全量返回后客户端裁剪，31 只循环拉取间保守 sleep 0.3s。
- **夏普 rf 依赖 `treasury_yield_curve`**：窗口内全缺时退化 rf=0 并在响应标注 `rfFallback`（raw Sharpe），不隐藏。
