# 09 · 估值域

> 市场估值仪表盘的后端域：全 A 中位数与历史分位、行业估值、ERP（沪深300股息率 − 10Y 国债）与情绪温度计。
> 数据全部来自 collector 落库快照（后端只读，写方为采集服务，见 [../architecture/05-数据类型与来源.md](../architecture/05-数据类型与来源.md) 与 [../architecture/04-数据采集服务架构.md](../architecture/04-数据采集服务架构.md)）；Agent 工具侧消费见 [01-Agent实现.md](01-Agent实现.md)；功能视角见 [../../function/modules/06-市场估值仪表盘.md](../../function/modules/06-市场估值仪表盘.md)。
> 对应代码：`backend/src/main/java/com/portfolio/invest/domain/valuation/`（`ValuationSnapshot`、`IndexValuation`、`IndustryValuation`、`TreasuryYield`、`Percentile`、`ShenwanIndustryMapping`、`ValuationRepository`）、`application/valuation/`（`ValuationApplicationService` + 4 个 View record）、`web/ValuationController.java`、`infrastructure/persistence/ValuationRepositoryImpl.java` + 5 个 JPA entity；迁移 `db/migration/V3__valuation.sql`、`V4__valuation_curve.sql`；前端 `frontend/app/valuation/page.tsx`。

## 1. 概述

估值域回答「现在市场整体贵不贵」。三个公开只读端点（无需登录——`/api/valuation/` 在 `PublicEndpointPaths.PREFIXES` 公开前缀清单中）：

- **总览**：最新全 A 快照（PE/PB 中位数、破净数/占比）+ 各指标历史分位 + ERP 及分位 + 温度计 + 5 大指数估值；
- **行业估值**：最新交易日申万行业 PE/PB/ROE/股息率（市值加权），支持 4 种排序；
- **历史走势**：全 A 快照、10Y 国债、5 指数估值的全量历史序列（走势图数据）。

所有数据经 `ValuationRepository` 从 collector 写入的表**只读**，域内无任何写路径；计算（分位、ERP、温度计）纯内存完成。

## 2. 架构与数据流

### 2.1 数据模型（collector 写、后端读）

| 表 | 迁移 | 内容 | 域读模型 |
|---|---|---|---|
| `valuation_snapshot` | V3 | 每交易日一行：`pe_median`/`pb_median`/`net_breaker_count`/`net_breaker_ratio`（`trading_day` 唯一） | `ValuationSnapshot` |
| `industry_valuation` | V3 | 交易日 × 行业：市值加权 `pe`/`pb`/`roe`/`dividend_yield`（历史行注记见下） | `IndustryValuation` |
| `index_valuation_history` | V3 | 交易日 × 指数：`pe`/`pb`/`dividend_yield` | `IndexValuation` |
| `treasury_yield_curve` | V4 | 交易日 × 期限（1Y/3Y/5Y/10Y/30Y）收益率；ERP 读侧仅取 `term='10Y'`（V3 旧表 `treasury_yield` 已废弃） | `TreasuryYield`（只含 `yield10y`） |
| `shenwan_industry_mapping` | V3 | 个股 → 申万行业映射（本域用于行业表，持仓域行业分布也复用） | `ShenwanIndustryMapping` |

数据从哪来（Tushare `daily_basic`/`index_dailybasic`、akshare 国债曲线、采集调度节奏）属于采集侧契约，见 [../architecture/05-数据类型与来源.md](../architecture/05-数据类型与来源.md)，不在本篇重复。

> **`industry_valuation` 历史行来源（MS-09 注记）**：快照出现之前的历史行由 collector 重算任务 `industry_valuation_backfill` 写入（周更、DB 内纯 SQL、只补 `MIN(trading_day)` 之前的缺失日期、幂等），**历史行的 `roe`/`dividend_yield` 为 NULL**（仅每日快照路径产出这两个条件加权指标）。本域 `industries` 端点只读最新交易日行、不受影响；历史序列的消费方是行业研究域的 5 年分位（[15-行业研究域.md](15-行业研究域.md)）。

### 2.2 指标计算（ValuationApplicationService）

**历史分位（`Percentile.of`）**：经验分布百分位——当前值在历史序列中严格小于它的占比 × 100，BigDecimal 全程运算、2 位小数 HALF_UP；历史为空返回 null（表示数据积累中，快照数 < 5 时 `dataAccumulating=true`）。

**ERP 序列（`erpHistory`，`ValuationApplicationService.java:140-150`）**：以 `tradingDay` 对齐沪深300（代码 `000300`）股息率与 10Y 国债收益率的日序列，逐日 `ERP = dividendYield − yield10y`（升序、保留 2 位）；任一侧缺失的交易日跳过。总览中的 `erp` 取序列最后一个值，`erpPercentile` 以 ERP 全序列为历史。

**温度计（`thermometer`）**：0~100，越高越「贵/热」：

```
温度计 = PE分位 × 0.4 + (100 − ERP分位) × 0.4 + (100 − 破净占比分位) × 0.2
```

（ERP 与破净占比越高市场越便宜，故反转；任一输入为 null 则温度计为 null。）

**指数估值（`indices`）**：固定 5 指数——上证50（`000016`）、沪深300（`000300`）、中证500（`000905`）、创业板指（`399006`）、科创50（`000688`），各取最新 PE/PB/股息率及其在自身历史中的分位。

### 2.3 缓存

三个端点共享应用层缓存端口 `ApplicationCache`：key 形如 `valuation:{kind}:{当日日期}`（`industries` 带排序键后缀），TTL 默认 5 分钟（`InvestProperties.AppCache`：`invest.app-cache.ttl`，默认值在代码，`application.yml` 未覆盖）。缓存实现与有界淘汰见 [02-行情数据服务.md](02-行情数据服务.md) 的应用级缓存部分。

## 4. 端点（统一前缀 `/api/valuation`，公开只读——`PublicEndpointPaths` 前缀 `/api/valuation/`）

| 端点 | 说明 |
|---|---|
| `GET /api/valuation/overview` | 最新快照 + PE/PB/破净占比分位 + ERP 及分位 + 温度计 + 5 指数估值分位 + `dataAccumulating` |
| `GET /api/valuation/industries?sort=pe` | 最新交易日行业估值列表；`sort` ∈ `pe`（默认）/`pb`/`roe`/`dividend`，null 值排最后 |
| `GET /api/valuation/history` | 全量历史：`snapshots` + `treasuryYields` + `indexValuations`（5 指数序列拼接，每点带 `indexCode`/`indexName`） |

错误码：`ValuationErrorCode.NOT_FOUND` → 404、`INVALID_INPUT` → 400（当前域内无主动抛出路径，为异常兜底保留）。

## 6. 已知限制

- **分位 = 全历史经验分布**：无回看窗口（如近 10 年）参数，序列越长早期权重越大；快照 < 5 天时 `dataAccumulating=true` 但分位照常输出。
- **`overview`/`history` 无日期参数**：始终以库内最新快照/全量历史为口径，不能查任意历史时点。
- **`history` 一次性全量返回**：5 指数 + 快照 + 国债全部序列无分页，依赖每日一行数据量可控。
- **ERP 只用 10Y 期限**：曲线表其余期限（1Y/3Y/5Y/30Y）未参与计算；股息率或国债任一侧缺失的交易日跳过（序列变疏）。
- **V3 旧表 `treasury_yield` 已废弃**：10Y 历史数据随 V4 迁入曲线表（`INSERT…SELECT`）后旧表即在 V4 中被 `DROP`（`V4__valuation_curve.sql:27`），当前 schema 无此表。
