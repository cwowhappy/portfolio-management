# 05 · 工程与运维

> 配置、部署、错误处理、可观测性、测试与代码规范。

## 1. 配置项

| 环境变量 | 默认 | 说明 |
|---|---|---|
| `DEEPSEEK_API_KEY` | — | 必填（AI 对话）；不填则仅行情数据台可用 |
| `DEEPSEEK_MODEL` | `deepseek-v4-flash` | 模型名（亦支持 `deepseek-v4-pro`） |
| `DEEPSEEK_BASE_URL` | `https://api.deepseek.com` | 兼容代理可覆盖 |
| `POSTGRES_USER` / `POSTGRES_PASSWORD` / `POSTGRES_DB` | `invest` / `invest` / `invest` | 数据库连接 |
| `ADMIN_USERNAME` / `ADMIN_PASSWORD` | — | 内置管理员（启动幂等种子；未填则不创建，需补配后重启） |
| `PORT` | `8080` | 后端端口 |
| `BACKEND_URL` | `http://localhost:8080` | 前端反代目标 |
| `NPM_REGISTRY` | `https://registry.npmjs.org/` | 构建前端镜像时的 npm 源 |

业务配置集中于 `invest.*`（`InvestProperties`）：LLM 供应商/模型，行情超时、限流、重试、各数据 TTL，以及 `invest.admin.username/password`。数据库配置在 `spring.datasource.*`，schema 由 Flyway 管理（`ddl-auto: none`）。

## 2. 部署

**方式一：Docker Compose（推荐）**

```bash
cp .env.example .env   # 填入 DEEPSEEK_API_KEY、ADMIN_USERNAME、ADMIN_PASSWORD
docker compose up -d --build
```

- `db`（postgres:16-alpine）：数据卷持久化 + `pg_isready` 健康检查，Flyway 启动时建表。
- `backend`（:8080）：带健康检查 `curl /api/agent/health`，依赖 `db` 健康（`depends_on: db: service_healthy`）；启动时幂等种子内置管理员。
- `frontend`（:3000）：`output: standalone`，依赖后端健康通过。

**方式二：本地开发**

```bash
docker compose up -d db   # 先启动 PostgreSQL（集成测试用 Testcontainers，也可不启动）
make dev                  # 后端 :8080 + 前端 :3000（.env 自动加载）
```

依赖 JDK 21+、Node 20+、pnpm、Docker。入口见根目录 `Makefile`（`dev` / `test` / `build` / `up` / `down` / `smoke`）。

**方式三：估值数据采集（Python collector）**

独立 Python 服务（`collector/`，Python 3 + psycopg + tushare/akshare + pandas + APScheduler），从公开行情源抓取全 A 股估值、申万行业映射与 10 年期国债收益率，计算市场估值快照并落库。目录结构：

```
collector/
  sources/    # 数据源适配（universe / index / industry / treasury）
  calc/       # 估值计算（快照中位数 / 破净统计 / 行业加权）
  store/      # 落库 writer（仅 upsert，零 DDL）
  scheduler/  # APScheduler 定时任务
  backfill.py # 指数历史回填（一次性任务）
```

| 环境变量 | 说明 |
|---|---|
| `DATABASE_URL` | 必填；PostgreSQL 连接串 |
| `TUSHARE_TOKEN` | 必填；tushare 访问令牌 |

调度：APScheduler 每个交易日（工作日）15:30 触发一次。运行与测试（见根目录 `Makefile`）：

```bash
make collect          # 运行一次采集（python -m collector.run_once）
make collect-test     # pytest 单测（覆盖率 >= 80%）
```

写入层仅 `INSERT ... ON CONFLICT DO UPDATE`（upsert），**零 DDL**；表结构（`valuation_snapshot` / `treasury_yield` / `index_valuation_history` / `industry_valuation` / `shenwan_industry_mapping`）仍由 Flyway 管理（`ddl-auto: none`）。

## 3. 错误处理

后端 `GlobalExceptionHandler` 统一异常出口：

| 场景 | 处理 |
|---|---|
| 行情领域异常 | 错误码映射 HTTP 状态（400/429/502），返回结构化 `{code, message}` |
| 用户域异常（`UserException`） | `USERNAME_TAKEN`/`INVALID_USERNAME`/`WEAK_PASSWORD` → 400；`FORBIDDEN`（操作管理员）→ 403 |
| 会话域异常（`ConversationException`） | `NOT_FOUND`（非本人/不存在）→ 404；`INVALID_ID` → 400 |
| 认证失败 | 未登录 401（`HttpStatusEntryPoint`）；登录状态分流 403 / 错密码 401（见 [04-接口.md](03-接口设计.md)） |
| Agent 未注册（无 Key） | 503 + 友好提示「请设置 DEEPSEEK_API_KEY 后重启服务」 |
| AG-UI 协议异常 | 400 + `AGUI_ERROR` |
| 客户端断开 SSE（停止/关页） | 静默忽略（`AsyncRequestNotUsableException` / `ClientAbortException`），不记 ERROR、不写已关闭的流 |
| 其他未处理异常 | 500 + `INTERNAL_ERROR` |

前端边界防护：行情/会话响应经 `zod` 校验（schema drift 边界报错而非深渲染崩溃）、发送失败弹错误条、SSE 断连可重试、401 跳登录。

## 4. 可观测性

- **健康检查**：`/api/agent/health`（LLM 配置 + 行情源连通性 + 延迟），供 Compose 健康探测与前端状态页脚轮询（60s）。
- **Actuator**：暴露 `health`、`info`；生产环境关闭健康详情。
- **日志**：行情降级（info）、工具失败（warn）、未处理异常（error）分级记录；AgentScope MVC 控制器的无害噪音日志被关闭（`AguiMvcController: OFF`）。

## 5. 测试与冒烟

| 层 | 方式 | 说明 |
|---|---|---|
| 后端单测 | Gradle `test` | 行情解析器（离线 fixture）、工具、限流、缓存、异常映射、用户状态机、密码策略；含 ArchUnit 分包规范强制 |
| 后端集成测试 | Testcontainers | 真实 PostgreSQL：用户仓库、会话仓库、认证/管理员/会话接口（MockMvc + 登录） |

| 前端覆盖率 | V8 | 语句/分支 ≥ 80% 门槛 |

| 浏览器 e2e | Playwright | 导航 / 行情台 / AI 对话 / 用户管理（注册→审核→登录→拒绝）/ 会话持久化；用户管理用例需 `ADMIN_USERNAME`/`ADMIN_PASSWORD` |

## 6. 代码规范约束

- **后端分包规范**：DDD 洋葱分层（`web` → `application` → `domain`，`infrastructure` 实现端口，`agent` 独立能力域），由 ArchUnit 强制（见 [../conventions/01-后端DDD分包规范.md](../conventions/01-后端DDD分包规范.md)）。`domain` 层零 Spring/JPA 注解。
- **前端**：领域类型与后端 DTO 对齐（`lib/types.ts` + `lib/auth.tsx`/`conversations.ts`），响应 schema 与类型分离（`lib/schemas.ts`）。

## 7. 已知限制

- 会话历史存服务端 PostgreSQL、归属账号（换设备可见），但多端同时编辑同一会话为**后写覆盖**（不做并发合并）。
- 每轮请求重传全部历史，会话规模小可接受，后续引入记忆压缩时再评估。
- 会话消息仅存精简历史（user/assistant 纯文本），工具调用轨迹不持久化（`payload` 预留扩展）。
- 管理员密码种子不校验强度（仅 reset-password 校验），建议配置强 `ADMIN_PASSWORD`。
- 行情数据来自免费公开接口（非官方契约），存在变更或限流风险，已用缓存 + 限流 + 多源降级缓解。
