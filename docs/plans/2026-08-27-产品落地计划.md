## 一、如何使用本文档

1. **每个里程碑**含：目标、交付范围（功能点复选框）、前置依赖、验收标准、状态与进度。
2. **状态图例**：✅ 已完成 / 🚧 进行中 / ⏳ 未开始 / ⛔ 阻塞。
3. **更新规则**：
   - 功能点交付时：勾选本文档对应复选框 + 更新模块文档的功能点状态 + 更新 `00-功能模块概览.md` 看板；
   - 里程碑内功能点全部勾选且验收标准满足 → 里程碑置 ✅，并在「七、里程碑变更记录」追加一行；
   - 范围/顺序调整 → 先改本文档并记录变更原因，再同步功能文档。
4. **节奏约定**：每个里程碑结束需通过质量门槛（见「五」），不满足不进入下一里程碑的开发收尾。

## 四、里程碑详情

### MS-00 · 一期交付基线 ✅

投研信息获取闭环：对话式投研问答（AI + 6 工具）、行情数据台、注册审核制用户体系、会话持久化、工程底座。36/36 功能点已交付（详见各模块文档）。

### MS-01 · 估值数据底座 ✅（1/1）

- **目标**：每日收盘后自动产出全市场估值快照并持久化，为估值类功能提供数据地基。
- **交付范围**：
  - [ ] M14-F07 估值数据定时抓取任务（全 A PE/PB 中位数、破净股数、行业加权估值，每日收盘后）
- **配套数据接入**（附录「新增数据需求」高优项）：
  - [ ] 申万行业分类映射静态表（内置，定期更新机制）
  - [ ] 10 年期国债收益率数据源（中国债券信息网/公开 API）
  - [ ] 主要指数 PE/PB 历史数据（东财/中证指数公司）
- **技术任务**：新增 `domain/valuation` 域并在 `PackageConventionsTest` 登记白名单；Flyway 新增快照表迁移；定时任务调度框架接入。
- **验收标准**：连续 5 个交易日快照正常落库；快照字段与中位数/破净数抽验一致；`make test` 通过。

### MS-02 · 市场估值仪表盘 ✅（8/8）

- **目标**：回答「现在市场整体贵不贵」，`/valuation` 页面上线。
- **交付范围**：
  - [ ] M06-F01 全 A PE/PB 中位数及分位
  - [ ] M06-F02 股债利差（ERP）
  - [ ] M06-F03 主要指数估值
  - [ ] M06-F04 破净股数量/占比
  - [ ] M06-F05 市场情绪温度计
  - [ ] M06-F06 估值历史走势图
  - [ ] M06-F07 行业估值对比
  - [ ] M05-F07 估值查询工具（AI 入口）
- **前置**：MS-01。
- **验收标准**：页面各指标有真实数据渲染；分位数基于落库快照计算；AI 问「现在市场贵不贵」可调用估值工具回答。
- **风险提示**：历史分位依赖快照积累，上线初期分位数据不足——需回填历史数据或页面标注「数据积累中」。

### MS-03 · 持仓组合管理 ⏳（0/11）

- **目标**：回答「买了什么、成本多少、赚了多少」，`/portfolio` 页面上线。
- **交付范围**：M08-F01~F11
  - [ ] F01 添加持仓 / [ ] F02 编辑删除 / [ ] F03 追加买入与成本（加权平均/FIFO）/ [ ] F04 卖出与已实现收益 / [ ] F05 分红记录 / [ ] F06 持仓分组
  - [ ] F07 组合总览 / [ ] F08 持仓列表 / [ ] F09 配置结构饼图 / [ ] F10 行业分布图 / [ ] F11 集中度分析
- **前置**：无硬依赖；F10 依赖 MS-01 的申万行业映射，建议排在 MS-01 后。
- **技术任务**：新增 `domain/portfolio` 域（Portfolio/HoldingGroup/Position/Trade/Dividend 模型）；现价取自现有行情服务。
- **验收标准**：买入/追加/卖出/分红全链路成本与盈亏计算正确（含两种成本口径的测试用例）；组合总览与列表数值对账一致。

### MS-04 · 资产配置基础 ⏳（0/3）

- **目标**：回答「钱应该怎么分配」，`/allocation` 页面上线。
- **交付范围**：
  - [ ] M07-F01 配置模板库（60/40、永久组合、全天候、90/10）
  - [ ] M07-F02 自定义配置方案（A股/港股/美股/债券/黄金/现金/REITs）
  - [ ] M07-F03 风险测评问卷（5-8 题 → 五档风险偏好 → 推荐方案）
- **前置**：MS-03（配置结构饼图对比目标配置的联动）。
- **技术任务**：新增 `domain/allocation` 域。
- **验收标准**：模板一键套用；测评结果与推荐方案映射正确；与 M08 持仓的实际配置偏离度展示正确。

### MS-05 · 价值筛选与行业估值 ⏳（0/4）

- **目标**：回答「哪些标的符合价值投资标准、哪些行业被低估」，`/screener` 上线 + 行业估值入口。
- **交付范围**：
  - [ ] M09-F01 多条件组合筛选（估值/盈利/财务健康/成长/市值流动性五维 AND 组合）
  - [ ] M09-F02 筛选结果排序
  - [ ] M10-F01 行业估值对比（申万 31 个一级行业 PE/PB/ROE/股息率排名）
  - [ ] M10-F02 估值热力图
- **前置**：MS-01（行业加权估值、个股估值数据）。
- **技术任务**：新增 `domain/screening`、`domain/industry` 域；筛选结果缓存 + 每周清理任务。
- **验收标准**：五维条件组合筛选结果抽验正确；行业估值点击可跳转筛选器并带入行业条件（M06/M10 → M09 联动）。
